# 쇼핑검색광고 '쇼핑몰' 비즈채널을 삭제할 경우, 광고는 어떻게 되나요?

비즈채널 관리 메뉴에서 쇼핑몰 채널을 삭제하면 해당 쇼핑몰 채널을 사용하는 캠페인 하위 광고그룹, 광고그룹 내 소재, 확장소재 전체가 삭제되며, 삭제된 내용은 절대 복구할 수 없습니다. 때문에 삭제를 해야 할지, 따로 캠페인이나 그룹을 분리해서 운영해야 할지 신중하게 판단하여 주시기 바랍니다.

다만, 삭제를 하더라도 삭제 전의 성과는 보고서를 통해서 확인 가능합니다.
