# [AI작성] 디스플레이광고 캠페인 목록 화면은 어떻게 구성되어 있나요?

**적용 대상:** 디스플레이광고(웹사이트 전환·앱 전환·인지도 및 트래픽·동영상 조회·ADVoost 쇼핑·카탈로그 판매·쇼핑 프로모션·참여 유도)

디스플레이광고 캠페인 목록 화면은 선택한 캠페인 목적의 캠페인을 표 형태로 보여주며, 캠페인별 상태와 예산, 성과 지표를 한눈에 확인할 수 있습니다. 화면 상단의 헤더/필터 영역과 캠페인 데이터 테이블로 구성됩니다. 캠페인 목록의 구성은 디스플레이광고 8개 목적에서 모두 동일합니다.

**화면 구성**

'광고 관리'에서 조회할 캠페인 목적을 선택하면 해당 목적의 캠페인 목록이 표시됩니다. 화면 상단에는 캠페인 목적 이름이 제목으로 표시되며, 캠페인명을 검색하는 입력란, 상태 필터, 성과 지표 조회 기간을 설정하는 날짜 범위 선택 영역이 함께 제공됩니다.

| **영역** | **설명** |
| --- | --- |
| 제목 | 현재 조회 중인 캠페인 목적의 이름이 표시됩니다. |
| 캠페인명 검색 | 캠페인 이름으로 목록을 검색합니다. |
| 상태 필터 | '전체', '활성', '일시정지', '종료', '삭제' 중에서 선택하여 목록을 추려서 봅니다. 기본값은 '전체'입니다. |
| 날짜 범위 선택 | 성과 지표를 조회할 기간을 설정합니다. 기본값은 최근 7일이며, 최대 92일까지, 최근 2년 범위 내에서 선택할 수 있습니다. |

**캠페인 데이터 테이블 컬럼**

캠페인 데이터 테이블은 아래 컬럼으로 구성되며, 디스플레이광고 8개 목적에서 동일하게 제공됩니다. 컬럼 머리글을 클릭하면 정렬할 수 있습니다.

| **컬럼** | **설명** |
| --- | --- |
| ON/OFF | 캠페인의 노출 상태를 켜거나 끕니다. |
| 캠페인 이름 | 캠페인 이름입니다. 클릭하면 캠페인 상세 화면으로 이동합니다. |
| 상태 | 캠페인의 현재 운영 상태입니다. |
| 캠페인 예산 | 설정된 캠페인 예산입니다. 설정하지 않은 경우 '미설정'으로 표시됩니다. |
| 결과 | 캠페인 목적별 결과 지표(전환수 등)입니다. |
| 결과당 비용 | 결과 1건당 발생한 비용입니다. |
| 총비용 | 선택한 기간의 총 광고비입니다. |
| 노출수 | 광고가 노출된 횟수입니다. |
| 평균 CPM | 노출 1,000회당 평균 비용입니다. |
| 클릭수 | 광고가 클릭된 횟수입니다. |
| 평균 CPC | 클릭 1회당 평균 비용입니다. |
| 클릭률(%) | 노출 대비 클릭이 발생한 비율입니다. |

공통 지표(노출수·클릭수·비용·클릭률)에 더해, 캠페인 목적에 따라 대표 지표가 다르게 표시됩니다. 인지도 및 트래픽은 도달수, 동영상 조회는 동영상 조회수, 참여 유도는 참여수, 전환 계열(웹사이트 전환·앱 전환·카탈로그 판매·쇼핑 프로모션)은 전환수입니다.

**주요 기능**

화면 상단에서는 다음 기능을 사용할 수 있습니다.

-   \[새 캠페인\] — 새 캠페인을 만듭니다.
    
-   \[다운로드\] — 캠페인 목록을 파일로 내려받습니다.
    
-   \[열 맞춤 설정\] — 테이블에 표시할 컬럼을 추가로 선택합니다.
    

**참고.**

등록된 캠페인이 없으면 비어 있다는 안내와 함께 캠페인 만들기 버튼이 표시됩니다. 검색이나 필터 결과가 없으면 결과가 없다는 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
