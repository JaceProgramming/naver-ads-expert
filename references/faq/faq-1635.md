# [AI작성] 광고 정보를 일괄로 다운로드하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 보고서 > 대용량 다운로드 보고서\]의 \[광고 정보 일괄 다운로드\] 탭에서 다운로드 항목과 조회 기간을 설정하고 \[생성요청\]을 클릭하면 광고 정보 마스터 파일이 생성됩니다.

**일괄 다운로드 절차**

1.  \[광고주센터 > 검색광고 > 보고서 > 대용량 다운로드 보고서\]에 진입합니다.
    
2.  \[광고 정보 일괄 다운로드\] 탭을 선택합니다.
    
3.  '다운로드 항목 선택'의 '항목 선택' 목록에서 다운로드 항목을 선택합니다. (예: 캠페인 마스터 / 광고그룹 마스터 / 비즈채널 마스터 / 확장소재 마스터 / 파워링크 반응형 소재 마스터 / 파워링크 반응형 소재연결 마스터 / 파워링크 애셋 마스터 / 공유예산 마스터 / 타겟팅 대상 마스터 등)
    
4.  '조회 기간 선택'에서 '현재 시점' 또는 '부터 현재까지 변경분을 포함'을 선택합니다.
    
5.  \[생성요청\]을 클릭합니다.
    
6.  결과 표에 요청이 추가되며, '상태'가 '생성 완료'로 변경되면 \[다운로드\]를 클릭해 파일을 내려받습니다.
    

**알아두세요.**

'현재 시점'을 선택하면 현재 시점의 광고 정보가 제공되며, '변경분'을 선택하면 선택한 일자부터 현재까지 변경/삭제가 있었던 광고 정보도 함께 제공됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
