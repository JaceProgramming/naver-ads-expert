# [AI작성] 대시보드 알림 메시지를 확인하고 닫으려면 어떻게 하나요?

대시보드 우측의 '알림' 영역에서 운영·프로모션 관련 메시지를 확인하고, 필요 없는 메시지는 닫을 수 있습니다. 넓은 화면에서만 노출됩니다.

**탭 구성**

| **탭** | **설명** |
| --- | --- |
| 전체 | 운영·프로모션 메시지를 모두 표시합니다. |
| 운영 | 운영 유형 메시지만 표시합니다. |
| 프로모션 | 프로모션 유형 메시지만 표시합니다. |

**메시지 확인과 닫기**

1.  각 메시지 카드에는 제목·본문과 이동 버튼이 있으며, 이동 버튼을 누르면 관련 화면이 새 탭으로 열립니다.
    
2.  개별 메시지는 카드의 닫기(X)로 닫을 수 있습니다.
    
3.  현재 탭의 메시지를 한 번에 닫으려면 영역 상단의 \[전체 닫기\](또는 탭별 닫기) 버튼을 클릭합니다.
    

**알아두세요.**

메시지를 불러오지 못하면 에러 안내와 \[다시 시도\] 버튼이 표시됩니다.

**참고.**

모든 메시지를 확인하면 '모든 알림을 확인했어요. 새로운 알림이 생기면 실시간으로 알려드릴게요'라는 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
