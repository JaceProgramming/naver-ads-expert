# [AI작성] 쇼핑검색 소재 목록 화면은 어떻게 구성되어 있나요?

쇼핑검색 광고그룹 상세의 소재 탭에서 등록된 소재 목록을 조회할 수 있습니다.

**진입 경로**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 쇼핑검색\] 캠페인 상세로 이동합니다.
    
2.  광고그룹 이름을 클릭하여 광고그룹 상세로 이동합니다.
    
3.  소재 탭을 선택합니다.
    

**소재 목록 테이블**

| **컬럼** | **설명** |
| --- | --- |
| ON/OFF | 소재 노출 상태를 전환합니다. |
| 소재 | 소재 썸네일 이미지와 이름이 표시됩니다. |
| 상태 | 소재의 검수 상태가 '운영가', '검수중', '보류' 등으로 표시됩니다. |
| 현재 입찰가(VAT 미포함) | 소재별 입찰가입니다. 클릭하여 50원~100,000원 범위 내에서 직접 수정할 수 있습니다. |
| 품질지수 | 광고 품질을 나타내는 지수로, 입찰가 책정과 노출 우선순위에 영향을 줍니다. |
| 성과 지표 | 노출수, 클릭수, 클릭률, 평균 CPC, 총비용 등이 표시됩니다. |

**주요 기능**

| **기능** | **설명** |
| --- | --- |
| \[새 소재\] | 새 소재를 등록합니다. 광고그룹당 등록 가능한 소재 수에 한도가 있습니다. |
| \[선택한 소재 관리\] | 소재를 1개 이상 선택하면 활성됩니다. 삭제 등 일괄 작업을 수행할 수 있습니다. |
| \[다운로드\] | 소재 목록을 파일로 내려받습니다. |
| \[열 맞춤 설정\] | 테이블에 표시할 컬럼을 선택합니다. |
| \[상세 데이터\] | 전환 관련 추가 지표(총 전환수, 총 전환율, 구매완료 전환수 등)를 표시합니다. |

**참고.**

검수가 반려된 소재는 '상태' 열에서 반려 사유를 확인한 후 소재를 수정하거나 재검토를 요청할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
