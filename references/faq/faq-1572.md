# [AI작성] 이미지 라이브러리에서 이미지를 선택하려면 어떻게 하나요?

**적용 대상:** 검색광고 (소재·확장 소재 공용 이미지)

소재 또는 확장 소재를 등록·수정할 때 이미지가 필요하면, 이미지 입력 영역의 \[이미지 라이브러리에서 불러오기\]를 클릭해 기존에 업로드한 이미지를 선택할 수 있습니다.

**선택 절차**

1.  파워링크 소재 만들기·확장 소재 등록 등 이미지가 필요한 창에 진입합니다.
    
2.  이미지 입력 영역에서 \[이미지 라이브러리에서 불러오기\]를 클릭합니다.
    
3.  라이브러리에 등록된 이미지 목록(컬럼: 이미지 종류 / 파일이름 / 이미지 미리보기 / 라이브러리 등록시간)에서 사용할 이미지를 선택합니다.
    
4.  선택을 확정하면 소재 입력란에 이미지가 적용됩니다.
    

**알아두세요.**

라이브러리에 이미지가 없거나 새 이미지를 사용하려면 창 내 \[이미지 업로드\]로 직접 업로드할 수 있으며, 업로드한 이미지는 자동으로 이미지 라이브러리에 등록됩니다.

**참고.**

등록 화면에 따라 이미지를 1개만 선택하거나 여러 개를 선택할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
