# [AI작성] 브랜드검색/신제품검색 광고그룹 상세 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 광고 관리 > 브랜드검색/신제품검색\]에서 광고그룹 이름을 클릭하면 광고그룹 상세 화면으로 진입합니다.

**광고그룹 정보 영역**

-   상태 — 운영 가능 / 중지: 그룹 OFF 등
    
-   채널 정보 — 등록된 URL
    
-   **그룹 유형** — 브랜드검색 - 일반형 / 브랜드검색 - 브랜드존형 / 신제품검색형
    
-   **계약 이름** — 미계약 / 계약명
    
-   **집행 기간** — 미계약 / 시작일~종료일
    
-   \[계약하기\] 버튼
    
-   연결된 계약 — N건
    

**광고그룹 \[수정\] 창**

-   **광고그룹 유형** (읽기 전용)
    
-   **광고 그룹 이름** (30자)
    
-   **URL** (읽기 전용)
    
-   **대상 매체** (예: PC / 모바일)
    
-   **선택 템플릿 유형** (예: PC 라이트형 일반 (신제품))
    

**탭 구성**

-   키워드 / 소재 2탭 (※ 제외 검색어·확장 소재·타겟팅 탭 없음)
    
-   키워드 컬럼: ON/OFF / 키워드 / 상태 / 노출수 / 클릭수 / 클릭률(%)
    
-   소재 컬럼: ON/OFF / 소재 / 상태 / 소재 ID / 노출수 / 클릭수 / 클릭률(%)
    

**관리 버튼**

\[계약하기\] / \[계약 관리\] / \[다운로드\] / \[열 맞춤 설정\] / \[상세 데이터\]

**알아두세요.**

브랜드검색/신제품검색 광고그룹은 노출될 매체와 형상을 결정합니다. '계약 이름'에 계약이 체결되어 있고 광고그룹이 ON 상태여야 광고가 노출됩니다. 광고 노출을 위해 \[계약하기\] 또는 \[계약 관리\]에서 계약을 체결해야 합니다.

**알아두세요.**

정액제 상품이므로 키워드·소재 모두 입찰가 항목이 없습니다.

**주의하세요.**

아직 계약을 체결하지 않은 광고그룹에는 다음 안내가 표시됩니다. "광고를 노출하려면 키워드와 소재 검토 후 계약하기를 눌러 계약을 체결해 주세요." 검토에는 영업일 기준 1~2일이 소요됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
