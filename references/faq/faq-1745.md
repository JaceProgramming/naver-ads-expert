# [AI작성] 광고 계정 목록 화면은 어떻게 구성되어 있나요?

광고 계정 화면에서는 내가 생성하거나 권한을 받은 광고 계정을 한곳에서 조회하고 관리할 수 있습니다. \[광고 계정 관리 > 광고 계정\] 탭에서 확인합니다.

**목록 컬럼**

| **컬럼** | **설명** |
| --- | --- |
| 광고계정(ID) | 광고 계정 이름과 계정 ID. 이름을 클릭하면 해당 광고계정 화면으로 이동합니다. |
| 권한 레벨 | '계정 책임자' / '운영 관리' / '운영 조회' 중 본인 권한 |
| 계정 상태 | '이용 가능' 또는 '이용 정지 (제재)' |
| 즐겨 찾기 | 즐겨찾기 등록·해제 |
| 광고주센터 | \[바로가기\] 링크로 새 탭에서 광고주센터 이동 |

**검색과 페이지 이동**

컬럼 머리글의 필터로 '광고 계정 이름' 또는 '광고 계정 ID'로 검색할 수 있으며, 목록은 기본 10개씩 표시됩니다.

**알아두세요.**

검색·필터 결과가 없으면 데이터가 없다는 안내가 표시됩니다.

**참고.**

새 광고 계정 추가, 즐겨찾기 등록·해제 등 개별 동작은 별도 도움말을 참고해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
