# [AI작성] 전체 캠페인 목록 화면은 어떻게 구성되어 있나요?

전체 캠페인 목록은 검색광고와 디스플레이 광고의 캠페인을 한 화면에서 통합 조회·관리하는 화면입니다. 좌측 메뉴에서 '전체 캠페인'을 클릭하거나, 대시보드의 '광고비 집중 캠페인'에서 \[전체 캠페인 보기\]를 눌러 진입합니다.

**화면 구성**

| **영역** | **설명** |
| --- | --- |
| 헤더 | '전체 캠페인' 제목과 조회 기간 선택 영역으로 구성됩니다. |
| 성과지표 | 선택 기간의 일별 성과 추이를 차트로 표시합니다. |
| 캠페인 테이블 | 검색광고·디스플레이 광고 캠페인을 통합 목록으로 표시하고, 생성·조회·관리 기능을 제공합니다. |

**테이블 컬럼**

테이블에는 ON/OFF · 광고 구분 · 상태 · 캠페인 이름 · 캠페인 분류 · 노출수 · 클릭수 · 클릭률(%) · 평균 CPC · 총비용 · 총 전환수 · 총 전환매출액 컬럼이 표시됩니다. 캠페인 이름 아래에는 캠페인 ID가 회색으로 함께 표시되며, '광고 구분'은 '검색광고' 또는 '디스플레이 광고'로 구분됩니다. 목록 하단에는 '캠페인 N개 결과'와 지표 합계가 표시됩니다.

**알아두세요.**

목록에서 수행하는 기간 설정·성과 차트·테이블 관리·ON/OFF·삭제·새 캠페인 만들기는 각각 별도 도움말에서 안내합니다.

**참고.**

캠페인 이름을 클릭하면 검색광고·디스플레이 광고 각각의 캠페인 관리 화면으로 이동합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
