# 파워링크 키워드 삽입과 대체 키워드는 무엇인가요?

**키워드 삽입이란?**

키워드 삽입은 구매한 검색 키워드를 소재에 자동으로 삽입하여 노출하는 기능으로 키워드 삽입 기능을 통해 보다 소재의 주목도를 높일 수 있습니다.

**예시.**

소재 내 ‘여름원피스’ 단어 자리에 ‘키워드삽입’을 하면 아래와 같은 소재가 완성됩니다.

제목 : **{키워드:대체키워드}**는 네이버닷컴

설명 : **{키워드:대체키워드}**는 시원하고 가벼운 네이버닷컴, Hot 세일도 함께하세요.

위 소재가 등록된 광고그룹에 아래 3개 키워드가 등록되었다고 가정하면, 실제 광고 노출 시 소재에 해당 키워드가 삽입되어 노출됩니다.

**키워드 삽입 기능 사용 시, 대체 키워드를 필수로 입력해야 하나요?**

키워드 삽입 기능 사용 시, 대체 키워드를 필수로 입력해야 합니다.

대체 키워드는 키워드 삽입 시, 다음의 경우에 검색 키워드를 대신해서 소재에 노출되는 단어입니다. 따라서 대체 키워드는 광고그룹에 등록한 키워드를 대표하는 단어로 기재하는 것이 좋습니다.

-   소재 전체 글자수가 초과되거나 미달되는 경우
    
-   병의원 광고인 경우
    
    -   2018년 9월 28일 이후부터 의료광고 사전심의에 따라 병/의원 광고는 키워드 삽입 기능이 동작하지 않으며, 소재 등록시 입력한 대체 키워드로 노출됩니다.

**예시.**

소비자가 네이버에 ‘여름휴가예쁜원피스’ 키워드를 검색하면, 광고 소재 제목은

‘여름휴가예쁜원피스는 네이버닷컴’으로 글자수가 총 16자가 되어 광고 노출이 불가합니다.

바로 이 때, ‘대체키워드’가 적용되어 ‘여름휴가예쁜원피스’ 단어 대신 ‘원피스’ 라는 대체키워드가 삽입되어 ‘원피스는 네이버닷컴’이라는 소재가 노출됩니다.

**주의하세요.**

-   반응형, 단일형 모두 공통적으로 키워드 삽입은 제목에는 1회, 설명에는 2회만 사용할 수 있습니다.
    
-   반응형 소재에서 키워드 삽입 사용 시 여러 제목, 설명 간 같은 문구가 반복되지 않도록 구성하는 것이 좋습니다.
    
-   예시) {키워드: 파스타맛집} 네이버푸드 - {키워드: 피자맛집} 네이버푸드 - {키워드: 맛있는파스타} 네이버푸드 (X)
    
-   '확장검색' 기능으로 검색된 광고의 경우, 광고그룹에 등록된 연결 URL 1개에 키워드 1개가 매칭될 때 키워드 삽입 기능이 정상적으로 동작할 수 있습니다. 이 외에는 소재에 입력된 대체 키워드로 변환됩니다.
