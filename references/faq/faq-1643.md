# [AI작성] 검색광고 대량 관리 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 도구 > 대량 관리\]에서 광고를 한 번에 내려받거나, 파일 업로드로 일괄 등록·수정·삭제하거나, 광고그룹을 대량 복사할 수 있습니다. 화면은 4개 탭으로 구성됩니다.

**탭 구성**

| **탭** | **설명** |
| --- | --- |
| 광고 다운로드 | 캠페인 유형과 캠페인(최대 20개)을 선택해 광고 데이터를 Excel 파일로 대량 다운로드합니다. 브랜드검색/신제품검색·플레이스 유형은 지원하지 않습니다. |
| 대량 등록/수정/삭제 | 엑셀·CSV 파일을 업로드해 광고를 일괄 등록·수정·삭제합니다. |
| 대량 광고그룹 복사 | 광고그룹을 골라(키워드·소재·확장 소재 포함) 다른 캠페인으로 한 번에 복사합니다. |
| Easy 대량 관리(beta) | CSV 업로드 또는 직접 입력으로 확장 소재를 대량 등록·삭제합니다. |

**대량 작업 신청 목록**

Easy 대량 관리(beta)를 제외한 탭은 공통으로 '대량 작업 신청 목록'을 함께 보여줍니다(최대 200건). 신청한 작업의 진행 상황과 결과를 확인하며, 표는 다음 컬럼으로 구성됩니다.

| **컬럼** | **설명** |
| --- | --- |
| 신청일자 | 작업을 신청한 날짜입니다. |
| 작업 유형 / 작업 이름 | 신청한 작업의 종류와 이름입니다. (예: 대량 등록·수정·삭제, 광고그룹 복사, 키워드·애셋 다운로드) |
| 신청자 / 취소자 | 작업을 신청하거나 취소한 사용자입니다. |
| 작업 상태 | 완료 / 처리중 / 취소됨 / 실패 상태를 표시합니다. |
| 신청건수 / 성공건수 / 실패건수 | 처리 건수 현황입니다. |
| 종료일 | 작업이 끝난 날짜입니다. |
| 다운로드 | 완료 시 \[다운로드\], 실패 건이 있으면 \[결과보기\]가 표시됩니다. |

**알아두세요.**

광고 다운로드 결과 파일은 압축(ZIP) 폴더로 제공되며 다운로드 파일을 통해 대량 등록·수정에 필요한 '광고그룹 ID·키워드 ID' 등을 확인할 수 있습니다.

**참고.**

Easy 대량 관리(beta) 탭은 대량 작업 신청 목록을 제공하지 않습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
