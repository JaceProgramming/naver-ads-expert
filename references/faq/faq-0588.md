# 파워컨텐츠 캠페인에서 추적기능을 사용할 수 없는 이유는 뭔가요?

네이버 블로그, 카페, 서비스는 일반 홈페이지와는 다르게 정책상 개별적인 로그 분석 프로그램 사용이 제한되어 있습니다. 하지만 추적 기능 사용을 위해서는 사이트 내 스크립트 설치가 필요하므로 네이버 블로그, 카페, 포스트와 같이 스크립트 설치가 어려운 사이트로 광고를 노출하는 파워컨텐츠 캠페인에서는 추적 기능을 제공해드리기 어렵습니다. 다만 추후 활용이 가능한 방법을 검토하고 있으며 가능 시점에 별도 공지로 안내 드릴 예정입니다.
