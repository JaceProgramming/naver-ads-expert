# 파워컨텐츠 URL 등록시 표시 URL과, 업체 URL은 어떤 정보를 넣어야 하나요?

광고그룹 생성 단계에서 URL을 등록합니다. 파워컨텐츠는 'URL'과 '홈URL' 두 가지 URL 정보를 등록해야 합니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMjEy/MDAxNzc0OTI3NjU5ODM3.JO7CXwkrGd-mG5DcUsf_VxjUPyMATwkAMLtHMZ0w_MYg.o6k5rUgO37IPk94Yfg8KWTjOOMloOLqEBugDdyQmmVMg.PNG/image.png)

-   'URL'은 파워컨텐츠 광고 영역에 노출되는 정보로 파워컨텐츠를 진행할 컨텐츠가 작성된 네이버블로그/카페의 메인 URL을 기재합니다.
    

Ex. [www.blog.nver.com/OOOOOO](http://www.blog.nver.com/OOOOOO)

-   '업체 URL'은 광고주님의 업종 속성 등을 파악하기 위해 확인하는 정보로, 현재 관리하는 공식 홈페이지 URL을 기재합니다. (Ex.[www.naver.com](http://www.naver.com%29)[)](http://www.naver.com%29)
    

만약 광고로 노출할 파워컨텐츠 페이지가 공식 홈페이지인 경우, 표시 URL과 같은 URL로 기재합니다.

**참고.**

등록된 URL 정보는 수정할 수 없습니다. 등록 전 올바른 정보로 기재하였는지 확인해 주세요.
