# [AI작성] 쇼핑 브랜드 소재를 등록하려면 어떻게 하나요?

쇼핑 브랜드 유형 광고그룹에서는 이미지 기반 브랜드 소재를 등록할 수 있습니다. 브랜드 소재는 이미지섬네일형 또는 이미지배너형 중 하나의 유형을 선택하여 만듭니다.

**브랜드 소재 등록 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 쇼핑검색\]에서 쇼핑 브랜드 유형 캠페인의 광고그룹 상세 화면으로 이동합니다.
    
2.  소재 탭에서 \[새 소재\]를 클릭합니다.
    
3.  소재 유형 카드에서 이미지섬네일형 또는 이미지배너형 중 하나를 선택합니다.
    
4.  선택한 유형에 맞는 입력 폼이 표시됩니다. 각 항목을 입력합니다.
    
5.  이미지를 업로드하고 필요한 경우 자르기(Crop)합니다.
    
6.  우측 미리보기 영역에서 PC/모바일 노출 모습을 확인합니다.
    
7.  \[저장\]를 클릭합니다.
    

**소재 유형별 입력 항목**

| **소재 유형** | **입력 항목** |
| --- | --- |
| 이미지섬네일형 | 이미지, 제목, 설명 |
| 이미지배너형 | 이미지(큰 배너), 제목 |

**알아두세요.**

이미지 품질이 낮은 경우 업로드가 제한될 수 있습니다. 고해상도 이미지를 사용해 주세요.

**주의하세요.**

소재 유형을 먼저 선택해야 입력 폼이 표시됩니다. 유형을 선택하지 않으면 저장할 수 없습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
