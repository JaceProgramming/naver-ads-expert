# [AI작성] 디스플레이광고 프로필 화면은 어떻게 구성되어 있나요?

**디스플레이광고 프로필 조회 화면 안내**

프로필 화면에서는 디스플레이광고 광고계정에 등록된 프로필 이미지와 이름, 링크 URL을 확인할 수 있습니다. 프로필 이미지는 일부 광고 형식에 노출됩니다.

경로: \[광고주센터 > 디스플레이광고 > 구성요소 관리 > 프로필\]

**화면 구성**

| **항목** | **설명** |
| --- | --- |
| 프로필 이미지 | 원형으로 표시되는 프로필 이미지. 미등록 시 기본 아이콘 표시 |
| 프로필 이름 | 광고주 표시명(1~19자) |
| 링크 URL | 광고 클릭 시 이동할 주소(선택 사항) |

프로필을 변경하거나 새로 등록하려면 \[정보 변경\] 버튼을 클릭해 수정 화면으로 이동합니다.

**알아두세요.**

프로필이 등록되지 않은 경우 기본 아이콘과 함께 '프로필 미등록'으로 표시되며 편집이 강조됩니다. 이미지를 불러오지 못하면 기본 아이콘이 대신 표시됩니다.

**주의하세요.**

\[정보 변경\] 버튼은 권한에 따라 비활성화될 수 있습니다. 조회는 모든 권한에서 가능합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
