# [AI작성] 검색광고가 노출되지 않는 이유는 어떻게 확인하나요?

**적용 대상:** 파워링크 · 쇼핑검색 · 파워컨텐츠 · 플레이스 · 브랜드검색/신제품검색/서칭뷰

광고가 노출되지 않을 때는 캠페인·광고그룹·소재·키워드·확장 소재의 '상태' 값에서 원인을 확인하고, \[도구 > 광고 노출 진단\]에서 키워드의 노출 가능 여부를 점검합니다.

**상태 종류**

| **상태** | **설명** |
| --- | --- |
| 운영 가능 | 정상적으로 광고가 노출될 수 있는 상태입니다. |
| 일부 노출 가능 | 일부 조건에 의해 제한적으로 노출되는 상태입니다. |
| 노출 불가 | 광고 노출이 불가한 상태입니다. |
| 중지 | 광고주가 직접 중지했거나 시스템 사유로 중지된 상태입니다. |

**주요 상태 사유**

| **사유** | **설명** |
| --- | --- |
| 캠페인 OFF / 그룹 OFF | 캠페인 또는 광고그룹이 OFF 상태입니다. |
| 예산 도달 | 하루 예산에 도달하여 노출이 중단되었습니다. |
| 기간 외 | 설정한 광고 노출 기간이 아닙니다. |
| 계정 잔액 부족 | 비즈머니 잔액이 부족합니다. |
| 비즈채널 노출 제한 | 비즈채널이 노출 제한 상태이거나 정상적으로 연결되지 않았습니다. |
| 운영 가능한 소재 없음 / 소재 검토중 | 광고그룹에 노출 가능한 소재가 없거나 소재가 검토 중입니다. |

**알아두세요.**

상태 열에 표시된 사유를 해소하면 광고 노출이 재개됩니다. 상위(캠페인)가 '운영 가능'이어도 하위 광고그룹·소재 단위의 상태 사유로 노출되지 않을 수 있으니 단계별로 확인해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
