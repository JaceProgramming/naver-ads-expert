# 쇼핑검색광고 쇼핑몰 비즈채널 등록 후, 내용을 수정할 수 있나요?

쇼핑몰 URL은 수정할 수 없으며, \[구성요소 관리> 비즈채널 관리\] 메뉴에서 비즈채널 이름을 수정할 수 있습니다.

만약 쇼핑몰 URL 수정이 필요한 경우,삭제 후 재등록 해야 합니다. 새로운 비즈채널 등록 후, 캠페인, 광고그룹, 소재(상품)은 다시 등록해 주셔야 하며, 등록된 정보는 검토 진행 후 통과되면 노출됩니다.

**주의하세요.**

연동한 쇼핑몰의 정보 수정이 필요한 경우 네이버 쇼핑에서 수정 가능합니다.
