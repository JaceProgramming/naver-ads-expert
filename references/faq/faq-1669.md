# [AI작성] SA API 사용 관리 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 도구 > SA API 사용 관리\]에서 네이버 검색광고 API의 검색광고 Key(엑세스라이선스·비밀키)를 발급·재발급·복사·해지합니다.

**화면 구성**

-   **안내 영역**: '네이버 검색광고API란?' 안내문 + \[닫기\] / \[API 이용약관\]
    
-   **이용 상태 안내**: 'API 서비스를 이용 중입니다.' / '현재 접근 중인 광고계정 : CUSTOMER\_ID = NNNNNN' 표시
    
-   **검색광고 Key 표**: 컬럼 '항목 / 값 / 재발급' / 항목 2종 (엑세스라이선스 / 비밀키) / \[복사\] / \[재발급\]
    
-   **하단**: \[네이버 검색광고API 서비스 해지\] 버튼
    

**해지 창**

1.  \[네이버 검색광고API 서비스 해지\]를 클릭하면 '네이버 검색광고API 서비스 해지' 창이 열립니다.
    
2.  창의 안내사항 3가지를 확인합니다.
    

-   서비스 해지 시 발급 받으신 모든 액세스라이선스와 비밀키 정보가 삭제됩니다. 이에 따라 네이버 검색광고 API를 기반으로 구축된 광고 관리 어플리케이션이나 웹사이트를 통해 네이버 검색광고의 광고주님 광고 정보에 접근할 수 없습니다.
    
-   네이버 검색광고 API 서비스의 사용은 횟수 제한 없이 언제든 다시 신청 하실 수 있습니다.
    
-   서비스 해지 이후 다시 신청하기 전까지는 광고주님께서 직접 네이버 검색광고 API 서비스를 사용할 수 없습니다. 단, 파트너사나 솔루션사를 이용하시는 경우 이용하시는 솔루션을 통해 네이버 검색광고 API 사용은 계속 가능합니다.
    

1.  '위 내용을 모두 읽고 확인했습니다.' 선택 항목에 체크합니다.
    
2.  \[해지 신청\]을 클릭해 해지를 진행합니다.
    

**알아두세요.**

본 화면은 광고 계정의 계정 책임자 권한이 있어야 접근할 수 있습니다. 운영 관리 권한만 있는 사용자는 'API 서비스를 이용할 수 없습니다. 계정 책임자 권한으로 다시 시도해 주세요.' 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
