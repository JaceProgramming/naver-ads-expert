# [AI작성] 외부 서비스 연동형 비즈채널(쇼핑몰·플레이스·네이버 톡톡 등)을 연결하려면 어떻게 하나요?

외부 서비스 연동형 비즈채널(쇼핑몰·플레이스·네이버 톡톡·네이버 예약·네이버 TV·브랜드스토어(브랜드존)·쇼핑검색(브랜드형)·쇼핑 제조사)은 네이버의 외부 서비스 파트너센터·인증을 통해 정보를 가져와 비즈채널로 등록합니다.

**유형별 창**

| **유형** | **창 안내·입력** |
| --- | --- |
| **쇼핑몰** | 비즈채널 이름(30자) + 네이버 쇼핑몰 인증 안내 (스마트스토어·브랜드스토어·CPC/CPS 입점 쇼핑몰 등록 가능, 최초 1회 쇼핑 파트너센터 인증, '정상' 서비스 상태만 활용) + \[동의 후 인증하기\] |
| **네이버 예약** | 비즈채널 이름(30자) + URL (https://) + 안내 (예약 URL은 네이버 예약 파트너센터에서 예약 서비스 등록·검토 완료 후 확인) + \[네이버예약 바로가기\] + \[예약 연결하기\] + \[저장 후 닫기\] |
| **네이버 톡톡** | 비즈채널 이름(30자) + 안내 (톡톡 로그인 ID = 광고주센터 로그인 ID 동일 필수, 새 톡톡 계정 추가 시 톡톡 파트너센터 \[계정 관리 > 기본 설정 > 프로필\] 확인, 파워링크 일부 업종만 제공) + \[동의 후 인증하기\] |
| **네이버 TV** | 비즈채널 이름(30자) + 네이버TV 연동 및 인증 안내 (네이버 TV 채널 전체 공개·노출가능 상태 필수, 연동한 TV 정보는 검색광고센터에 저장·소재정보 활용) + \[동의 후 인증하기\] |
| **브랜드스토어(브랜드존)** | 비즈채널 이름(30자) + 네이버 쇼핑몰 인증 안내 (브랜드 권한 있는 쇼핑몰만 등록 가능, 최초 1회 쇼핑 파트너센터 인증, '정상' 서비스 상태) + \[동의 후 인증하기\] |
| **쇼핑검색(브랜드형)** | 비즈채널 이름(30자) + 네이버 쇼핑몰 인증 안내 (브랜드 권한 있는 쇼핑몰만 등록, 브랜드 권한 소유권 확인) + \[동의 후 인증하기\] |
| **쇼핑 제조사** | 비즈채널 이름(30자) + 제조사 등록 안내 (네이버쇼핑 카탈로그 활용 '쇼핑 검색광고 제품 카탈로그형' 광고 등록 필요, 광고 집행 권한 있는 제조사·총판·위임 광고 담당자만 등록, 제출 서류 필요할 수 있음, 제조사·카탈로그 정보는 네이버쇼핑과 연동·자동 반영) + \[새 제조사 등록\] |
| **플레이스** | 비즈채널 이름(30자) + 네이버 스마트플레이스 입점확인 및 인증 안내 (네이버 스마트 플레이스 업체 정보 '정상 반영중' 필수, 플레이스 업체명/소유자가 검색광고와 다르면 노출 제한) + \[동의 후 인증하기\] |

**채널 정보 표시 형식**

| **유형** | **채널 정보** |
| --- | --- |
| 네이버 톡톡 | 비즈채널 이름·\[네이버 톡톡 파트너센터 바로가기\] (연결 안 됨 시 상태 '노출제한(연결안됨)') |
| 네이버 예약 | 비즈채널 이름·URL·대표자명·\[네이버 예약 파트너센터 바로가기\] |
| 쇼핑 제조사 | 비즈채널 이름·제조사명 |
| 플레이스(위치정보) | 사업장 이름·도로명·지번 |
| 전화번호 (통화추적) | 비즈채널 이름·통화추적번호·1차 착신번호·2차 착신번호·\[통화추적번호 보고서\] |
| 콘텐츠 | 비즈채널 이름·표시 URL·업체 URL·콘텐츠 유형(블로그/카페) |

**알아두세요.**

외부 서비스 연동형 비즈채널의 정보 수정은 해당 서비스의 파트너센터에서 진행되며, 광고 플랫폼에는 일정 시간 후 반영됩니다. 스마트스토어·브랜드스토어는 전환 성과 추적이 자동으로 제공되어 광고 클릭 시 전환 추적용 URL 파라미터가 자동으로 추가됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
