# [AI작성] 전체 캠페인 목록의 성과지표 차트를 확인하려면 어떻게 하나요?

전체 캠페인 목록의 '성과지표' 영역에서는 선택한 기간의 일별 성과 추이를 좌·우 두 개 지표로 비교해 볼 수 있습니다. 검색광고와 디스플레이 광고의 성과가 통합되어 하나의 차트에 표시됩니다.

**지표 선택**

1.  좌측 지표와 우측 지표를 각각 선택합니다. 기본값은 좌측 '노출수', 우측 '평균 CPC'입니다.
    
2.  선택한 두 지표가 일별 라인 차트로 표시되며, 차트 위에는 선택한 두 지표와 조회 일수를 조합한 '○○, ○○ 기준 N일간 추이' 형태의 안내가 표시됩니다.
    

**선택 가능한 지표**

다음 11개 지표 중에서 선택할 수 있습니다.

-   노출수 · 클릭수 · 클릭률 · 평균 CPC · 총비용 · 총 전환수 · 총 전환매출액 · 기여전환수(마지막클릭) · 기여전환매출액(마지막클릭) · 기여전환수(데이터기반) · 기여전환매출액(데이터기반)
    

**알아두세요.**

데이터를 불러오지 못하면 에러 안내와 \[다시 시도\] 버튼이 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
