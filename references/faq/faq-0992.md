# Easy 대량관리에서 엑셀 파일을 불러올 수 있나요?

파일 가져오기를 이용하여 CSV 파일을 불러올 수 있습니다. 가져온 파일은 하단 입력 시트에 보여지며 수정 및 편집이 가능합니다. 단, 입력 시트에서 ‘파일 가져오기’는 별도의 템플릿을 지원하지 않습니다.

엑셀 파일 가져오기를 이용할 경우 \[광고 그룹ID / 기간 시작일 / 기간 종료일 / 추가 제목\] 등 유형별 입력 시트 순서대로 엑셀 파일에 입력해야하며, 엑셀의 1행은 제목으로 간주하여 2행부터 입력 시트에 조회되므로 1행은 빈칸으로 두거나 제목을 넣고 엑셀 2행부터 확장 소재 내용을 입력 후 파일을 업로드 합니다. (파일 형식은 CSV만 지원)
