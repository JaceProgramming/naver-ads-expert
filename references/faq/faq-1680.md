# [AI작성] 전화번호 비즈채널의 통화추적번호 보고서를 확인하려면 어떻게 하나요?

전화번호 비즈채널 행에서 '통화추적번호 보고서' 아이콘을 클릭하면 통화추적번호 노출·클릭·통화 지표를 일자별로 확인할 수 있는 보고서 창이 열립니다. \[광고주센터 > 검색광고 > 구성요소 관리 > 비즈채널\]의 해당 전화번호 비즈채널 행에서 진행합니다.

**창 구성**

창 상단에는 "'{전화번호}' 통화추적번호 보고서" 제목과 함께 다음 안내가 표시됩니다.

-   이 보고서의 통화추적번호 노출수와 콜 클릭수는 통화추적번호가 노출·클릭된 횟수를 의미합니다.
    
-   광고의 총 노출수와 클릭수는 광고관리시스템 > 보고서에서 별도로 확인합니다.
    
-   사용자가 전화기에서 여러 번 전화를 거는 경우가 있으므로 '통화추적번호 콜 클릭수'보다 '통화시도수'나 '연결 횟수'가 더 많을 수 있습니다.
    
-   사용자가 전화버튼을 클릭한 후 실제로 전화를 걸지 않는 경우가 있으므로 '통화추적번호 콜 클릭수'보다 '통화시도수'나 '연결 횟수'가 더 적을 수 있습니다.
    
-   미연결 횟수는 발신자의 취소, 착신자의 미수신, 통화 중 등의 사유로 통화가 연결되지 못한 경우입니다.
    

**조회 영역**

안내 영역 아래에는 다음 영역이 표시됩니다.

-   \[다운로드\] 버튼 — 현재 조회 결과를 파일로 내려받습니다.
    
-   기간 이동 — 좌우 화살표(< >)와 표시 영역(예: '지난달 : 2026.05.01. ~ 2026.05.31.')으로 조회 기간을 이동합니다.
    

**지표 테이블 컬럼**

| **컬럼** | **설명** |
| --- | --- |
| 일자 | 통화 발생 일자입니다. |
| 통화추적번호 노출수 | 통화추적번호가 광고에 노출된 횟수입니다. |
| 통화추적번호 콜 클릭수 | 통화추적번호의 전화 버튼이 클릭된 횟수입니다. |
| 통화시도수 | 실제로 통화를 시도한 횟수입니다. |
| 연결 횟수 | 통화가 정상적으로 연결된 횟수입니다. |
| 미연결 횟수 | 발신자 취소·착신자 미수신·통화 중 등으로 연결되지 못한 횟수입니다. |
| 평균 통화시간 | 연결된 통화의 평균 시간입니다. |
| 10초이상 통화수 | 10초 이상 연결된 통화 건수입니다. |

**기능 종료 안내**

**알아두세요.**

화면 하단의 \[닫기\]를 클릭하면 보고서 조회를 종료합니다.

**참고.**

조회된 데이터가 없는 기간은 테이블 영역에 '조회된 내역이 없습니다.' 안내가 표시됩니다.

**주의하세요.**

통화추적번호 기능은 종료되어 더 이상 데이터가 업데이트되지 않습니다. 종료 이전(2025년 7월 15일까지)의 통화추적번호 보고서만 확인할 수 있습니다. 자세한 내용은 창의 '공지 바로 가기'를 확인해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
