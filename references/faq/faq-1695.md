# [AI작성] 목록의 컬럼과 상세 데이터를 조회하려면 어떻게 하나요?

**컬럼 구성과 상세 데이터 조회**

광고그룹 목록은 광고그룹별로 다양한 성과 지표를 표 형태로 보여줍니다. 표시되는 컬럼을 직접 선택하거나, 상세 데이터를 펼쳐 더 많은 지표를 확인할 수 있습니다.

**기본 컬럼 구성**

| **컬럼** | **설명** |
| --- | --- |
| ON/OFF | 광고그룹 노출 상태 전환 |
| 캠페인 이름 | 해당 광고그룹이 속한 캠페인 |
| 광고그룹 이름 | 광고그룹 이름 |
| 상태 | 현재 노출 상태와 사유 |
| 계약 이름 | 연결된 계약 정보 |
| 기본 입찰가 | 광고그룹 기본 입찰가 |
| 채널 정보 | 연결된 채널 정보 |
| 노출수 / 클릭수 / 클릭률(%) | 노출·클릭 성과 지표 |
| 평균 CPC / 총비용 | 비용 지표 |
| 총 재생수 / 평균 CPV | 동영상 성과 지표 |

**컬럼·데이터 조회 방법**

1.  \[열 맞춤 설정\]에서 표에 표시할 컬럼을 선택합니다.
    
2.  \[상세 데이터\]를 클릭하면 추가 성과 지표를 함께 확인할 수 있습니다.
    
3.  \[다운로드\]를 클릭하면 목록 데이터를 파일로 내려받을 수 있습니다.
    

**알아두세요.**

표시되는 성과 지표는 화면 상단에서 설정한 조회 기간을 기준으로 합니다.

**참고.**

\[다운로드\]로 파일을 내려받는 동작은 다운로드 권한 및 브라우저 설정에 따라 동작합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
