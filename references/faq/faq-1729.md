# [AI작성] 디스플레이광고 비즈채널을 새로 등록하려면 어떻게 하나요?

**디스플레이광고 비즈채널 등록**

디스플레이광고 비즈채널은 유형 선택 후 유형별 정보를 입력하는 방식으로 등록합니다. 등록한 비즈채널은 검토를 거쳐 승인되어야 광고에 사용할 수 있습니다.

**등록 절차**

1.  비즈채널 목록에서 \[비즈채널 추가\]를 클릭합니다.
    
2.  등록할 채널 유형을 웹사이트, 모바일 앱, 네이버 쇼핑 중에서 선택하고 다음 단계로 이동합니다.
    
3.  선택한 유형에 맞는 정보를 입력합니다.
    
4.  입력을 마치고 \[등록\]을 클릭하면 검토 요청과 함께 등록됩니다.
    

**유형별 입력 항목**

| **유형** | **입력 항목** |
| --- | --- |
| 웹사이트 | 이름, URL |
| 모바일 앱 | 이름, 플랫폼(iOS/Android), 앱 URL |
| 네이버 쇼핑 | 이름, 스토어 플랫폼, 스마트스토어 인증 |

**알아두세요.**

등록 후 영업일 기준 1~2일의 검토가 진행됩니다.

**주의하세요.**

입력값에 오류가 있으면 다음과 같이 안내됩니다.

-   웹사이트 URL 형식이 올바르지 않으면 입력란 아래 오류가 표시됩니다. 형식을 확인해 다시 입력해 주세요.
    
-   모바일 앱 URL 형식이 올바르지 않으면 입력란 아래 오류가 표시됩니다.
    
-   네이버 쇼핑 인증 정보가 만료되면 안내가 표시됩니다. 다시 인증해 주세요.
    
-   등록 직후 검토에서 거부되면 안내와 함께 검토 의견이 표시됩니다. 내용을 수정해 다시 등록해 주세요.
    

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
