# [AI작성] 검색광고 키워드의 광고 연관지수·클릭 기대지수와 검수 상태를 확인하려면 어떻게 하나요?

**적용 대상:** 파워링크

광고그룹 상세 \[키워드\] 탭의 키워드 목록 표에서 각 키워드의 '광고 연관지수'·'클릭 기대지수'·'상태' 컬럼을 확인합니다. 또한 표의 '노출현황보기' 컬럼에서 \[보기\]를 클릭하면 실제 통합검색 노출 현황을 확인할 수 있습니다.

**확인 위치**

-   **키워드 목록 표 컬럼**: 광고그룹 상세 \[키워드\] 탭에서 다음 컬럼을 확인합니다.
    
-   ON/OFF
    
-   키워드
    
-   상태 (노출가능 / 검토중 / 보류 / 노출 제한 등)
    
-   현재 입찰가(VAT미포함) (예: \[기본\] 500원)
    
-   광고 연관지수
    
-   클릭 기대지수
    
-   노출수 / 클릭수 / 클릭률(%)
    
-   노출현황보기 (\[보기\] 버튼)
    
-   평균 CPC / 총비용
    
-   **노출현황보기 창**: 컬럼의 \[보기\]를 클릭하면 '"{키워드}" 키워드의 노출현황보기' 창이 열립니다.
    
-   \[PC통합검색\] / \[모바일\] 탭
    
-   노출 지역 선택 영역 (시/도·시/군/구·읍/면/동)
    
-   \[초기화\] / \[검색\]
    
-   최근 검색 이력 표시
    
-   안내: 노출 현황보기는 실제 광고 개수와 관계없이 파워링크 PC:10개/모바일:4개, 파워컨텐츠 PC:3개/모바일:3개로 고정 제공
    

**광고 연관지수·클릭 기대지수**

| **지표** | **의미** |
| --- | --- |
| 광고 연관지수 | 광고그룹의 키워드와 광고 소재의 관련성을 평가한 지수입니다. 높을수록 관련성이 큽니다. |
| 클릭 기대지수 | 광고의 노출 시 사용자가 클릭할 것으로 예상되는 정도를 평가한 지수입니다. |

**알아두세요.**

광고 연관지수와 클릭 기대지수는 광고 운영 품질지수로 활용되며, 두 지수가 높을수록 광고 노출 순위·노출 매체에 유리하게 작용합니다. 산출 데이터가 부족한 경우 '-'로 표시될 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
