# 스마트플레이스 관리권한은 어떻게 교체하거나 위임하나요?

**관리권한이란?**

지도 검색에 등록된 업체 데이터를 직접 관리할 수 있는 권한을 의미합니다.

본인의 업체정보이지만 현재 관리 권한이 없는 상태라면(타인이 대신 등록한 경우 등) '관리권한 신청’ 절차를 통해 관리권한을 받은 후 직접 데이터를 관리합니다.

**관리권한 신청 및 교체**

스마트플레이스 서비스 등록 내역 페이지에서 본인의 업체정보를 조회한 후, 조회 결과 하단의 \[관리 권한 위임\]이나 \[관리자 권한 교체\] 버튼을 클릭합니다.

ARS 인증 방식으로 업체 정보 관리자 권한을 신청합니다.
