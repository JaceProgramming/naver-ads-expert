# 비즈니스 진단을 받으려면 어떻게 하나요? 

**\[소개\]**

비즈니스 진단은 등록된 비즈니스 정보를 자동으로 감지·분석해 업종과 광고 목적에 맞는 광고 상품을 추천해 주는 기능입니다.

대시보드의 '내게 딱 맞는 광고를 알고 싶다면?' 영역 또는 좌측 메뉴(LNB)의 \[비즈니스 진단하기\] 클릭을 통해 시작됩니다.

계정을 새로 만든 뒤 7일간 등록한 캠페인이 없으면 하루 1회 비지니스 진단 기능이 실행됩니다.

**\[진단 방법\]**

1\. 내 비즈니스 정보 자동 감지

진단을 시작하면 네이버에 등록된 비즈채널·플레이스 정보를 자동으로 감지해 \[내 비즈니스 현황\] 화면에 보여줍니다.

감지된 정보가 있다면 별도 입력 없이 진단이 진행됩니다.

2\. 감지 정보에 따른 진단

• 정보가 충분한 경우(업종 · 광고 목적 자동 확인): 추가 질문 없이 바로 결과 화면으로 이동

• 일부 정보가 필요한 경우: 광고 목적 또는 업종을 확인하는 질문(1~2개)

• 등록된 정보가 없는 경우: 광고 목적과 업종을 직접 선택

3\. 추천 결과 확인

결과 화면의 제공 항목은 업종 · 광고 목적 · 광고 상품에 따라 달라집니다.

• 업종 · 목적에 맞는 추천 광고 상품이 최대 3개 노출 됩니다.

• 상품에 따라 기대 효과 · 추천 예산을 제공하며, 광고비 규모(소·중·대) 별 예산 · 기대 효과 데이터를 확인할 수 있습니다.

(데이터 모수가 충분하지 않거나 예산 설정이 필수가 아닌 상품은 제외될 수 있습니다)

• 이미 운영 중인 광고 상품은 '운영중'으로 표시됩니다.

• 추천 결과에서 바로 \[광고 만들기\] 로 연결됩니다.
