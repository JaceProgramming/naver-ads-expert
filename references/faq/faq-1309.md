# 비즈채널(쇼핑몰) 검토 통과되었는데, '노출가능한 소재가 없다'라고 나와요.

쇼핑검색광고는 등록하신 쇼핑몰 비즈채널과 소재의 검토 결과가 모두 통과된 상태로, '노출가능' 상태에서만 노출이 가능합니다.

따라서 비즈채널 검토가 통과된 경우라도 광고그룹에 등록된 소재가 '검토중' 또는 '노출제한' 상태에서는 해당 메시지가 노출됩니다.

'검토중' 상태는 등록하신 광고의 검토가 완료되지 않은 상태로 비즈머니가 충분한 경우, 검토가 완료된 이후 '노출가능'상태에서 광고 노출이 가능하며, '노출제한' 상태는 등록하신 광고가 검토 기준에 맞지 않아 광고 노출이 제한된 상태로, 노출제한 사유를 확인하여 재검토요청이 필요합니다.
