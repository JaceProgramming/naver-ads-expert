# 브랜드검색 키워드 상태값의 '사용제한'은 무엇인가요?

키워드 검토 결과 특정 키워드의 사용권을 인정하기 어려운 키워드를 등록하여 등록이 거절된 상태의 경우 '사용제한' 상태로 표시됩니다. '사용제한' 상태에서는 키워드 재검토가 불가하며 삭제만 가능합니다.
