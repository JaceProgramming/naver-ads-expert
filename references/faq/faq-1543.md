# [AI작성] 플레이스 캠페인 상세 화면은 어떻게 구성되어 있나요?

플레이스 캠페인 상세 화면에서 캠페인 성과를 확인하고 하위 광고그룹을 관리합니다. 캠페인 목록에서 캠페인 이름을 클릭하면 진입합니다.

**캠페인 정보 영역**

우측 \[수정\]으로 설정을 변경하고 ON/OFF로 노출 상태를 전환합니다.

| **항목** | **설명** |
| --- | --- |
| 상태 | 운영 가능 / 중지: 캠페인 OFF / 광고 집행 종료 등이 표시됩니다. |
| 캠페인 유형 | '플레이스'로 표시됩니다. |
| 기간 | 계속노출 / 종료일 설정으로 표시됩니다. |
| 하루 예산 | 50원~300,000원으로 표시됩니다. |
| 예산배분 | 균등노출 / 일반노출 중 설정값이 표시됩니다. |

**광고그룹 목록 표**

'광고그룹' 탭 1개가 제공되며, 표 컬럼은 다음과 같습니다.

| **컬럼** | **설명** |
| --- | --- |
| ON/OFF | 광고그룹의 노출 상태를 전환합니다. |
| 광고그룹 이름 | 클릭하면 광고그룹 상세로 이동합니다. |
| 상태 | 광고그룹 운영 상태입니다. |
| 기본 입찰가 | 플레이스검색은 입찰가, 지역소상공인광고·디지털 옥외광고는 노출가가 표시됩니다. |
| 노출수 / 클릭수 / 클릭률(%) / 평균 CPC / 총비용 | 조회 기간 내 성과 지표입니다. |
| 총 재생수 / 평균 CPV | 디지털 옥외광고 동영상의 재생수·재생당 비용입니다. |

관리 버튼으로 \[새 광고그룹\]·\[선택한 광고그룹 관리\]·\[다운로드\]·\[열 맞춤 설정\]·\[상세 데이터\]가 제공됩니다.

**알아두세요.**

플레이스 캠페인에는 캠페인 단위 확장 소재 탭이 없습니다. 확장 소재는 광고그룹 상세에서 관리합니다. 캠페인 OFF 시 '캠페인이 OFF 상태여서 광고가 노출되지 않습니다.' 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
