# [AI작성] 대시보드 공지사항과 팝업 공지는 어떻게 확인하나요?

대시보드의 '공지사항' 영역에서 광고 플랫폼의 최신 공지와 변경 사항을 확인할 수 있습니다.

**공지사항 확인**

1.  각 공지에는 구분 라벨(필수 · 공통 · 검색광고 · 디스플레이 광고)과 제목, 게시일이 함께 표시됩니다.
    
2.  공지 제목을 클릭하면 전체 공지 페이지가 새 탭으로 열립니다.
    
3.  전체 공지를 보려면 영역 우측 상단의 \[전체보기\] 버튼을 클릭합니다.
    

**팝업 공지**

중요한 공지는 대시보드 진입 시 팝업 형태로 자동 표시됩니다. 팝업에서는 다음과 같이 선택할 수 있습니다.

-   \[확인\] — 팝업을 닫습니다. '해당 팝업을 확인했으며 다시 보지 않습니다.'에 체크한 뒤 확인하면 해당 공지를 다시 표시하지 않습니다.
    
-   \[오늘 하루 보지 않기\] — 오늘 하루 동안 해당 팝업을 표시하지 않습니다.
    

**알아두세요.**

첨부파일이 있는 공지는 팝업 본문에서 파일 다운로드 링크가 함께 표시됩니다.

**참고.**

공지가 없을 때는 목록이 비어 있는 상태로 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
