# [AI작성] 광고그룹을 다른 캠페인으로 대량 복사하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 도구 > 대량 관리\] \[대량 광고그룹 복사\] 탭에서 Step 1과 Step 2 두 단계로 광고그룹을 다른 캠페인으로 대량 복사합니다.

**복사 절차 (Step 1·2)**

1.  \[광고주센터 > 검색광고 > 도구 > 대량 관리\]에 진입합니다.
    
2.  \[대량 광고그룹 복사\] 탭을 선택합니다.
    
3.  '캠페인 유형 선택'에서 캠페인 유형(파워링크 등)을 선택합니다.
    
4.  **1\. 복사할 광고그룹 선택**
    

-   캠페인 목록에서 캠페인을 선택합니다. (각 캠페인 옆에 ON/OFF 상태 표시)
    
-   해당 캠페인의 광고그룹 목록이 표시되면 복사할 광고그룹을 체크합니다.
    
-   '광고그룹 내 포함 요소' 영역에서 함께 복사할 항목 체크: **키워드 / 소재 / 확장 소재**
    

1.  **2\. 복사 위치 캠페인 선택 (N/52)**
    

-   복사 대상 캠페인 목록에서 캠페인 옆 '개' 입력란에 복사 개수를 입력합니다. (최대 52개 캠페인까지 선택)
    
-   '총 N개를 복사합니다. (최대 100개)' 합계가 표시됩니다.
    
-   '대상 캠페인에서 복사한 광고그룹을 OFF합니다.' 선택 항목 선택 시 복사된 광고그룹이 OFF 상태로 생성됩니다.
    

1.  \[입력값 지우기\]로 초기화하거나 \[대량 복사하기\]를 클릭해 작업을 신청합니다.
    
2.  '대량 작업 신청 목록 (N/200)'에서 작업 유형 '대량 광고그룹 복사' / 상태(완료/취소됨) / \[결과보기\]·\[다운로드\]로 결과를 확인합니다.
    

**안내**

-   광고그룹 복사 시 광고그룹 하위 항목들의 포함 여부를 선택하세요. 선택하지 않으면 광고그룹만 복사됩니다(기본 입찰가 등 그룹정보, 제외 검색어 포함).
    
-   캠페인당 등록 가능한 그룹수는 1천개이며, 광고그룹 복사 시 등록 가능 개수를 초과하면 가능한 개수까지만 생성됩니다.
    
-   복사 완료 후 복사된 광고그룹에 다른 광고그룹과 구별을 위해, 광고그룹 이름 뒤에 임의의 번호가 자동 입력됩니다. (광고그룹 이름에 마우스 오버 후 광고그룹 이름 수정이 가능합니다.)
    

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
