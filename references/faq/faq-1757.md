# [AI작성] 계정 설정의 즐겨찾기 화면은 어떻게 구성되어 있나요?

계정 설정의 즐겨찾기 화면에서는 즐겨찾기에 등록한 광고 계정과 관리 계정을 한곳에서 모아볼 수 있습니다. 우측 상단에서 계정 클릭 후 좌측 메뉴의 \[즐겨찾기\]로 이동합니다.

**목록 컬럼**

| **컬럼** | **설명** |
| --- | --- |
| 계정 이름 | 즐겨찾기한 계정 이름 및 계정 ID |
| 계정 유형 | '광고 계정' 또는 '관리 계정' |
| 권한 | '계정 책임자' / '운영 관리' / '운영 조회' |
| 광고주센터 | \[바로가기\] 링크 |

광고 계정과 관리 계정의 즐겨찾기가 별도 탭 없이 하나의 목록으로 통합 표시되며, 검색·필터와 페이지 크기 설정을 제공합니다.

**알아두세요.**

이 즐겨찾기는 계정 설정 영역의 광고·관리 계정 즐겨찾기로, 검색광고의 광고그룹·소재·키워드 즐겨찾기와는 별개입니다.

**참고.**

즐겨찾기 등록된 계정이 없으면 안내 메시지와 광고 계정 목록 바로가기가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
