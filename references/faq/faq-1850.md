# [AI작성] 디스플레이광고 광고 그룹의 디바이스·게재 위치·잠재고객을 설정하려면 어떻게 하나요?

**적용 대상:** 웹사이트 전환 · 앱 전환 · 인지도 및 트래픽 · 동영상 조회 · 카탈로그 판매 · 쇼핑 프로모션 · 참여 유도 (ADVoost 쇼핑은 애셋그룹/애셋 그룹 시그널 구조로 별도 운영)

광고 그룹의 타게팅 설정 안에서 광고가 노출될 디바이스와 게재 위치, 잠재고객, 관심사·구매의도를 지정할 수 있습니다.

**설정 항목**

| **항목** | **설명** |
| --- | --- |
| 디바이스 | 기본값은 '노출 가능한 모든 디바이스 선택'이며, 직접 선택 시 PC, 모바일(Android, iOS) 등을 지정합니다. |
| 게재 위치 | 기본값은 '노출 가능한 모든 게재위치 선택'이며, 직접 선택 시 게재 위치를 그룹별로 지정합니다. |
| 잠재고객, 관심사/구매의도 | 잠재고객 불러오기. 관심사 카테고리와 구매의도 카테고리를 선택해 노출 대상을 좁힐 수 있습니다. |
| 타겟 확장 | '피드 광고 자동 타겟 확장'을 켜면 설정한 타겟 외에 머신러닝으로 적합한 이용자를 추가로 찾습니다. |

**알아두세요.**

'피드 광고 자동 타겟 확장'을 켜면 설정하신 타겟 이용자뿐 아니라 머신러닝을 통해 광고에 보다 적합한 이용자를 찾습니다.

**참고.**

게재 위치를 변경하면 그에 따라 디바이스 타겟 또는 확장 데모 설정이 자동으로 조정될 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
