# 성과형 디스플레이광고 고객 파일이 무엇인지 궁금해요.

**고객 파일이란?**

고객 파일은 광고주가 직접 수집한 광고 식별자 목록(ADID, 이메일/전화번호)을 업로드하여 타겟팅 모수로 등록하는 기능입니다.

제공된 템플릿 파일 양식에 따라 광고 식별자 목록을 정리한 파일을 업로드하면, 이를 시스템이 분석하여 타겟으로 생성합니다.

**고객 파일 등록 및 사용 방법**

**STEP 1.** **도구 > 잠재고객 관리 > 내 데이터 타겟 > 고객 파일 화면으로 이동하여 \[ + 고객 파일 등록 \] 버튼 클릭**

**STEP 2.** **고객 파일 업로드 시, 고객 파일 분석 및 생성**

• CSV 형식의 고객 식별자 목록(ADID, 이메일/전화번호)을 업로드하면, 시스템이 데이터를 분석하여 유효성 검증과 중복 제거를 수행합니다.

• 고객 파일이 승인되려면 특정 서식 지침을 따라야 하며, 이를 지키지 않을 경우 업로드 오류나 일치하는 타겟 수 감소가 발생할 수 있습니다.

◦ ADID : 8-4-4-4-12 구조의 36자리 문자열

◦ 이메일 : 도메인 이름 포함, 소문자로만 입력 및 공백 모두 제거

◦ 전화번호 : E.164 형식(국제 표준 형식), \[+\]\[국가코드\]\[지역/식별번호\]\[가입자번호\]

■ 기본적으로 E.164 형식을 권장하나, 편의를 위해 평문 업로드 시 아래 입력 형태도 내부적으로 자동 정규화 처리합니다.

(단, 해시된 파일 업로드에는 자동 정규화가 적용되지 않으므로 반드시 E.164로 정규화한 값을 SHA-256으로 해시해서 업로드해주셔야 합니다.)

• ① +8210-1234-5678

• ② 8210-1234-5678

• ③ 010-1234-5678

• ④ 01012345678

◦ 이메일/전화번호 : 해시되지 않은(평문) 서식과 해시 처리된 포맷 모두 지원하지만, 두 형식이 혼재된 경우 사용 불가

■ 해싱 처리 전 평문 서식 지침에 맞춰 작성하며, 해싱 형식은 SHA-256로 지정해야 함

• CSV 형식은 '고객 파일 등록' 팝업에서 제공되는 템플릿 파일을 통해 확인 가능하며, 아래와 같은 샘플 목록을 확인할 수 있습니다.

◦ ADID

■ C44EA1C9-7266-4895-AAD6-467B8AA38901

■ 36C5326B-6754-4C94-A558-95110C0258C4

◦ 이메일/전화번호

■ abc@naver.com

■ +821012345678

• 업로드한 고객 파일은 총 200MB 이내, 최대 10개까지 등록 가능하며, 형식은 반드시 CSV여야 합니다.

**STEP 3.** **고객 파일 생성 확인**

• 등록이 완료되면 고객 파일은 ‘준비중’ 상태로 리스트에 표시됩니다.

• 모수 집계 전까지 시스템이 업로드한 데이터를 분석하여 결과를 제공합니다.

• 분석 결과는 등록 성공 수/실패 수/중복 수에 대해서 확인 가능합니다.

• 타겟 모수가 추출되기까지 최대 1시간 정도 소요될 수 있습니다.

• 모수가 집계된 후 ‘사용 가능’ 상태가 되면 광고에 활용할 수 있게 됩니다.

**STEP 4.** **광고 그룹 만들기 > 잠재고객 > \[ + 타겟 불러오기 \] 를 통해 고객 파일을 잠재고객으로 설정**

• 광고그룹 생성 또는 수정 시 \[잠재고객 설정 > + 타겟 설정하기\] 메뉴로 진입합니다.

• 리스트에서 ‘사용 가능’ 상태의 고객 파일을 선택하여 타겟팅 옵션으로 적용합니다.

**주의사항**

• 타겟 모수는 등록한 식별자 중 최근 30일 이내 광고 노출 이력이 있는 일부를 샘플링해 추정한 수치로, 등록 후 일정 시간 내 표시되며 정기적으로 갱신 됩니다.

• 타겟 모수 1,000 미만인 경우 잠재고객 설정 시 포함(타겟팅) 설정할 수 없으며, 광고 집행 중 모수가 1,000 미만으로 줄어들 경우 광고 집행이 중지될 수 있습니다.

• 최근 6개월 이내 수집된 데이터를 등록하실 것을 권장 드리며, 주기적으로 최신 데이터로 갱신해 주시기 바랍니다. 오래된 데이터는 타겟 모수가 크게 줄어들 수 있습니다.

• 인종, 종교, 성적 지향, 병력 정보와 같은 민감 정보 처리, 또는 만 14세 미만 아동 정보로부터 수집된 광고 식별자는 제외하여야 합니다.

• 광고 식별자 데이터를 업로드할 때에는 광고주가 직접 적법한 절차로 수집한 정보만 사용해야 합니다.

• 개인정보 보호법을 준수하지 않아 발생한 손해, 오류 및 법적 분쟁에 대한 법적 책임은 광고주에게 있습니다.

**FAQ**

Q1. 고객 파일은 최대 몇 개 까지 등록할 수 있나요?

광고 계정당 최대 50개까지 등록할 수 있습니다.

Q2. 고객 파일을 수정하려면 어떻게 하나요?

기존 파일을 직접 수정할 수는 없으며, 수정이 필요한 경우 새로운 고객 파일로 재등록해야 합니다.

단, 이름은 ‘정보 변경’ 버튼을 통해 수정 가능합니다.

Q3. 고객 파일의 상태가 '사용 불가'로 표시되는 이유는 무엇인가요?

고객 파일은 아래와 같은 사유일 때 ‘사용 불가’ 상태로 전환됩니다.

장기간 미사용 : 생성된 고객 파일이 90일 이상 광고에 사용되지 않으면 자동으로 비활성화되며, 상태가 ‘사용 불가’로 표시됩니다.

시스템 오류 : 내부 시스템 오류로 인해 타겟 생성 또는 갱신이 정상적으로 이루어지지 않은 경우에 상태가 ‘사용 불가’로 표시됩니다.

업로드 파일 이슈 : 헤더가 유효하지 않거나 해시/평문 형식이 혼합되어 있는 경우, 또는 형식 오류로 인해 유효한 데이터가 0건인 경우에도 상태가 ‘사용 불가’로 표시됩니다.

Q4. 고객 파일이 광고 그룹에 연동되어 있는 상태에서 삭제할 수 있나요?

불가능합니다. 해당 고객 파일을 삭제하려면 연동된 광고 그룹의 타겟 설정을 해제하고, 해당 고객 파일로 생성된 유사 타겟도 먼저 삭제해야 합니다.
