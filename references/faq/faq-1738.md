# [AI작성] 디스플레이광고 브랜드를 등록하거나 수정하려면 어떻게 하나요?

디스플레이광고 브랜드는 \[광고주센터 > 디스플레이광고 > 구성요소 관리 > 브랜드\]에서 등록하고 수정할 수 있습니다. 등록한 브랜드는 캠페인 등록 시 식별자로 사용됩니다.

**등록 절차**

1.  브랜드 목록에서 \[새 브랜드\]를 클릭합니다. 기존 브랜드를 변경하려면 해당 행의 \[수정\]을 클릭합니다.
    
2.  파트너명은 광고계정 정보가 자동으로 표시되며 변경할 수 없습니다.
    
3.  브랜드명을 1~30자로 입력하고 \[중복 확인\]을 클릭합니다. 사용 가능한 이름이면 등록을 진행할 수 있습니다.
    
4.  필요하면 설명을 최대 200자까지 입력합니다.
    
5.  입력을 마치면 저장합니다.
    

**입력 조건**

-   브랜드명은 필수 입력이며 1~30자까지 입력할 수 있습니다.
    
-   중복 확인을 통과해야 등록·수정을 완료할 수 있으며, 이름을 변경하면 중복 확인을 다시 수행해야 합니다.
    
-   설명은 선택 입력이며 최대 200자까지 입력할 수 있습니다.
    

**참고.**

브랜드 등록·수정은 권한이 있는 광고주님만 가능하며, 다른 계정에서 등록한 브랜드는 수정할 수 없습니다.

**주의하세요.**

이미 사용 중인 이름이면 사용할 수 없다는 안내가 표시됩니다. 이름을 변경한 뒤 다시 중복 확인을 해주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
