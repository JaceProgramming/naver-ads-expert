# 파워컨텐츠는 어떠한 검토 절차를 거치게 되나요?

파워컨텐츠 캠페인으로 등록한 키워드와 소재의 연관도를 검토하며, 광고 클릭 시 연결되는 랜딩페이지의 파워컨텐츠와 키워드의 연관도 및 작성 가이드 준수 여부를 검토하여 최종적으로 검토 결과가 확정됩니다.

등록한 키워드와 업종에 맞는 광고 소재 작성이 필요하며, 파워컨텐츠 광고등록기준은 아래 링크를 통해 확인 가능합니다.
