# [AI작성] 브랜드검색/신제품검색 소재는 어떻게 만드나요?

광고그룹 상세의 '소재' 탭에서 \[새 소재\]를 누르면 브랜드 소재를 만드는 별도 화면으로 이동합니다. 이 화면은 좌측에 입력 폼, 우측에 실시간 미리보기가 함께 표시되는 통합 템플릿 편집 화면입니다.

**작성 절차**

1.  소재 탭에서 \[새 소재\]를 클릭합니다.
    
2.  소재 이름을 입력합니다. (1~30자)
    
3.  광고그룹에서 선택한 템플릿에 맞춰 제목·이미지·링크 등을 입력합니다. 입력하는 즉시 우측 미리보기에 반영됩니다.
    
4.  필요 시 노출 기간(시작일·종료일)을 지정합니다.
    
5.  작성을 마치면 저장합니다. 저장 후에는 이전 광고그룹 상세 화면으로 돌아갑니다.
    

**신제품검색 소재의 출시일**

신제품검색형 소재에는 출시일 입력 항목이 있습니다. 출시일은 노출 개시일로부터 6개월(180일) 이내여야 합니다.

**알아두세요.**

소재 등록 후 검토에는 영업일 기준 1~2일이 소요됩니다. 광고그룹의 키워드·채널 검토가 끝나지 않은 경우 \[새 소재\] 버튼이 비활성화될 수 있습니다.

**주의하세요.**

노출 기간을 지정할 때 시작일은 오늘 이후여야 하며, 종료일보다 빠르거나 같아야 합니다. 소재 이름이 1~30자 범위를 벗어나면 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
