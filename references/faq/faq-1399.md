# 통합 검색 기능이 궁금해요.

여러 개의 캠페인, 광고그룹, 키워드, 확장소재 등을 운영하는 경우, 검색 기능을 사용하여 원하는 내용을 보다 쉽고 빠르게 찾아볼 수 있습니다.

네이버광고주센터의 검색 기능에 대해 알아봅니다.

---

**검색 대상**

검색 대상은 계정에 등록된 캠페인 이름, 광고 그룹 이름, 키워드, 소재(소재 ID, 소재 텍스트 내용),확장소재(확장소재ID, 확장소재 텍스트 내용)입니다.

위 검색 대상을 제외한 나머지(즐겨찾기 이름, 비즈채널에 등록한 주소 전화번호 빛 비즈채널 이름 등)의 검색 결과는 제공되지 않습니다.

---

**검색하기**

\[광고 관리\] 메뉴 왼쪽 트리 영역 위의 검색 창을 통해 검색을 할 수 있습니다.

1\. 검색 창에 검색하고자 하는 키워드를 입력합니다.

2\. 키워드를 입력하면 검색 창 아래에 해당 키워드가 포함된 캠페인 이름, 광고 그룹 이름, 소재, 키워드, 확장소재 검색 결과가 표시됩니다.

3\. 표시된 검색 결과 중 원하는 검색 결과를 클릭하면, 해당 캠페인, 광고 그룹, 소재, 키워드의 관리 화면으로 바로 이동할 수 있습니다.

**Tip.**

'정확히 일치한 결과 검색' 에 체크후에 검색하면, 검색대상과 정확히 일치한 대상만 검색할 수 있습니다.

그리고, 여러개의 키워드를 동시에 검색하려면 정확히 일치한 결과 검색에 체크한 후 콤마로 구분하여

동시에 최대 40개 내외로 키워드를 검색할 수 있습니다. (키워드 길이에 따라 최대 입력 개수는 달라질 수 있습니다.)

'김','마','닭' 처럼 일음절로 된 키워드도 정확히 일치한 결과 검색에 체크하면 검색이 가능합니다.

예) '정확히 일치한 결과 검색'

4\. 검색 결과에서 \[전체보기\]를 클릭하면 오른쪽 화면에 해당 검색 결과가 표시됩니다. 이때 오른쪽 화면 검색 결과 목록 위의 검색 창을 통해 재검색을 진행할 수 있습니다.

**검색 후 관리**

검색 후 오른쪽 화면의 검색 결과 목록 화면(전체보기 클릭)에서 광고 관리의 캠페인, 광고 그룹, 키워드, 소재 목록에서 제공하는 대부분의

관리 기능을 사용할 수 있습니다.

**Tip. 키워드 일괄 검색 활용 하기**

네이버광고주센터의 키워드들이 여러 캠페인과, 광고그룹에 분할된 경우 검색 기능을 활용, 입찰가나 ON/OFF변경을빠르고 편리하게 할 수 있습니다.

예를들어 광고집행 이후 보고서를 확인후 입찰, ON/OFF 등이 필요한 키워드를 필터링 한 후에 변경이 필요한 키워드들만 선별하여 일괄검색(콤마로 구분하여 여러개 검색) 후, 전체보기를 클릭 하여 검색 화면 이동 후 빠르게 변경을 할 수 있습니다.

예시)

1\. 다차원 보고서를 활용하여, 최근7일간 전환수가 10 이상인 키워드들을 다운로드 받습니다.

2\. 해당 키워들을 검색창에 입력합니다. (콤마로 구분 필수)

3\. '정확히 일치한 결과 검색' 에 체크 후 해당 키워드들을 한번에 검색합니다

4\. 검색 결과 목록에서 키워드들을 확인 후에, 입찰가 조절 등의 작업을 실행합니다.

(지속적인 관리가 필요하다고 판단되는 키워드들은, ['](https://ads.naver.com/help/faq/262)[즐겨찾기' 설정](https://ads.naver.com/help/faq/262) [](https://ads.naver.com/help/faq/262)을 활용해 보세요.)

\* 여러개 키워드 입력시 직접 콤마를 입력하여야 합니다. 엑셀에서 바로 복사하여 붙여넣기 할 경우

콤마가 없어 검색이 되지 않습니다. 자동으로 콤마를 붙여주는 엑셀파일을 첨부하였으니

입력 키워드가 많을 경우 참고로 활용해 보시기 바랍니다.

(파일 실행시, 매크로 사용 ON을 설정해야 엑셀파일이 동작합니다.)
