# [AI작성] 세금계산서 수정 요청의 처리 현황을 확인하려면 어떻게 하나요?

세금계산서 수정 요청의 접수·처리 상태를 \[광고주센터 > 우측 상단 네이버 ID > 광고 계정 관리 > 광고 계정 클릭 > 도구 > 요청 처리 내역\]에서 확인할 수 있습니다. 요청 목록과 처리 단계가 함께 표시됩니다.

**요청 처리 내역 항목**

목록은 한 페이지에 10건씩 다음 5개 항목으로 표시됩니다.

| **항목** | **설명** |
| --- | --- |
| 요청 시간 | 요청이 접수된 날짜와 시각 |
| 구분 | 요청 유형(예: 세금계산서 수정요청) |
| 사유 | 수정을 요청한 사유 |
| 답변상태 | 대기 / 처리중 / 답변완료 |
| 처리시간 | 처리가 완료된 날짜와 시각 |

**답변상태 안내**

| **상태** | **의미** |
| --- | --- |
| 대기 | 광고주님의 문의 건이 접수되어 담당자 지정 대기 상태입니다. |
| 처리중 | 담당자가 지정되어 처리 중입니다. 세금계산서 수정발행의 경우, 영업일 기준 7일 이상 소요될 수 있습니다. |
| 답변완료 | 담당자 답변완료되어 처리결과 확인이 가능합니다. 완료된 요청 목록을 클릭하여 상세결과 확인이 가능합니다. |

**처리 상세 확인**

1.  답변완료된 요청 행을 클릭합니다.
    
2.  '세금계산서 수정발행처리' 창이 열려, 요청 정보(요청 시간·구분·변경 사유·신청 대상)와 진행 상황(처리 시간·상태·처리 결과)을 확인할 수 있습니다.
    

**알아두세요.**

처리 내역이 없으면 "변경된 내역이 없습니다."가 표시됩니다.

**참고.**

세금계산서 발행·수정 관련 결제 업무는 결제 관리 화면에서 신청하며, 본 화면에서는 신청한 요청의 처리 현황을 확인합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
