# [AI작성] 쇼핑검색 캠페인 목록 화면은 어떻게 구성되어 있나요?

쇼핑검색 캠페인 목록 화면에서는 등록된 쇼핑검색 캠페인의 성과 데이터를 조회하고, 캠페인을 생성하거나 관리할 수 있습니다.

**진입 경로**

\[광고주센터 > 검색광고 > 광고 관리 > 쇼핑검색\] 메뉴를 클릭합니다.

**화면 구성**

쇼핑검색 캠페인 목록 화면은 크게 **헤더 영역**과 **캠페인 테이블 영역**으로 구성됩니다.

**헤더 영역**

-   **날짜 범위 선택**: 성과 데이터를 조회할 기간을 설정합니다. 기본값은 최근 7일이며, 최대 90일까지 조회할 수 있습니다. 기간 프리셋(오늘, 어제, 최근 7일, 최근 30일)을 활용하면 빠르게 기간을 설정할 수 있습니다.
    
-   **기간 이동**: 좌우 화살표를 클릭하면 현재 조회 기간 단위만큼 이전 또는 다음 기간으로 이동합니다.
    
-   **비즈머니 잔액 부족 안내**: 비즈머니 잔액이 부족하여 광고가 일시 중지된 경우, 상단에 '비즈머니 잔액이 부족하여 광고가 일시 중지되었습니다.' 안내와 \[지금 충전하기\]가 표시됩니다. 단, 브랜드검색/신제품검색은 이 안내 대상에서 제외됩니다.
    

**캠페인 테이블 영역**

| **항목** | **설명** |
| --- | --- |
| ON/OFF | 캠페인의 광고 노출 여부를 설정합니다. |
| 캠페인 이름 | 캠페인 이름을 표시합니다. 클릭하면 캠페인 상세 화면으로 이동합니다. |
| 상태 | 캠페인의 현재 운영 상태를 표시합니다. '운영중', '중지: 캠페인 OFF', '검토 중', '집행 종료' 등으로 표시됩니다. |
| 노출수 | 선택한 기간 동안의 광고 노출수입니다. |
| 클릭수 | 선택한 기간 동안의 광고 클릭수입니다. |
| 클릭률(%) | 노출 대비 클릭 비율입니다. |
| 평균 CPC | 클릭당 평균 비용입니다. |
| 총비용 | 선택한 기간 동안 소진된 총 광고비입니다. |
| 하루 예산 | 캠페인에 설정된 하루 예산 금액입니다. |

**테이블 상단 기능**

-   **\[새 캠페인\]**: 새 쇼핑검색 캠페인을 생성합니다.
    
-   **\[선택한 캠페인 관리\]**: 캠페인을 선택한 후 기간 변경, 예산 변경 등 일괄 작업을 수행합니다.
    
-   **\[열 맞춤 설정\]**: 테이블에 표시할 항목의 순서와 표시 여부를 설정합니다.
    
-   **\[상세 데이터\]**: PC/모바일 구분, 요일 구분 등 추가 성과 데이터를 조회합니다.
    
-   **\[전체 다운로드\]**: 현재 조회 중인 캠페인 목록을 CSV 파일로 다운로드합니다.
    

또한 필터 입력 바를 활용하면 상태별 또는 캠페인 이름으로 목록을 필터링할 수 있습니다.

**참고.**

테이블 하단의 결과 요약 행에서 전체 캠페인의 합계 수치를 한눈에 확인할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
