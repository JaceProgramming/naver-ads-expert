# 스마트스토어 광고의 전환 데이터가 실제 스토어의 주문수 데이터와 다릅니다.

아래와 같은 집계 기준의 차이로, 스마트스토어 광고의 전환 데이터와 실제 판매 데이터 간에 다소 차이가 발생할 수 있습니다.

| **구분** | **스마트스토어 지표** | **스마트스토어 광고** |
| --- | --- | --- |
| 집계 기간 차이 | · 별도의 집계 기간 제한없이 판매 건수가 집계 | · 스마트스토어 광고를 본 이후 일정 기간 동안 발생한 구매만 전환으로 집계 |
| 전환 성과 차이 | · 전체 노출, 클릭으로 발생한 전환 성과 | · 스마트스토어 광고를 통해 노출/클릭된 상품으로부터 발생한 전환 성과 |
| 취소, 반품 건 집계 | · 집계 시점에 실시간으로 취소, 반품 건 반영 | · 전환으로 집계된 후의 취소/반품된 건 미차감<br>(집계 시점의 판매 현황을 바탕으로 계산됨) |
