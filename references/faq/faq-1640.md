# [AI작성] 키워드 도구로 연관키워드를 조회하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 도구 > 키워드 도구\]의 '연관키워드 조회 기준' 영역에서 조건을 입력·선택한 뒤 \[조회하기\]를 클릭하면 '연관키워드 조회 결과' 표에 결과가 표시됩니다.

**조회 기준 항목**

| **항목** | **설명** |
| --- | --- |
| 키워드 | 한 줄에 하나씩 최대 5개까지 입력합니다. 각 키워드는 1~30자입니다. |
| 웹사이트 | 체크 후 광고계정에 등록된 웹사이트 비즈채널을 선택합니다. 키워드 입력과 웹사이트 선택 중 하나 이상은 반드시 지정해야 합니다. |
| 업종 | 체크 후 업종 카테고리를 대분류 > 중분류 > 소분류 순으로 선택해 추천 정확도를 높입니다. |
| 시즌 월 / 시즌 테마 | 시즌성 키워드를 발굴할 때 사용하는 선택 항목으로, 여러 개를 함께 지정할 수 있습니다. |

**조회 방법**

1.  키워드를 입력하거나 웹사이트를 선택합니다. 필요하면 업종·시즌 조건을 함께 지정합니다.
    
2.  \[조회하기\]를 클릭하면 결과 표에 연관키워드가 표시됩니다. 표 컬럼은 '연관키워드 / 월간검색수(PC·모바일) / 월평균클릭수(PC·모바일) / 월평균클릭률(PC·모바일) / 경쟁정도 / 월평균노출광고수'입니다.
    
3.  입력값을 처음부터 다시 설정하려면 \[입력값 지우기\]를 사용합니다.
    
4.  필요 시 '필터를 입력해 주세요' 입력란으로 결과를 좁히거나 \[전체 다운로드\]로 내려받습니다.
    

키워드와 웹사이트가 모두 비어 있으면 \[조회하기\]가 비활성화됩니다.

**입력 시 주의할 점**

| **상황** | **안내** |
| --- | --- |
| 키워드 5개 초과 | 안내가 표시됩니다. 키워드 수를 5개 이하로 줄여 주세요. |
| 키워드 30자 초과 | 오류 안내가 표시됩니다. 길이를 줄여 다시 입력해 주세요. |
| 등록된 비즈채널 없음 | 웹사이트를 선택할 수 없습니다. 먼저 웹사이트 비즈채널을 등록해 주세요. |

**알아두세요.**

연관키워드 조회는 '파워링크 캠페인' 유형에 한해 지원됩니다. 연관키워드는 과거 데이터를 바탕으로 추출된 통계 결과로, 실제 광고 성과나 광고 검토 통과를 보장하지 않습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
