# [AI작성] 디스플레이광고 유사 타겟을 새로 만들려면 어떻게 하나요?

잠재고객 관리의 '유사 타겟' 탭에서 \[유사 타겟 등록\]을 클릭하면 기존 타겟을 시드로 한 유사 타겟을 두 단계로 생성할 수 있습니다.

**생성 방법**

1.  **1단계 시드 타겟 선택** — 내 데이터·맞춤·네이버 쇼핑 타겟 중 시드로 사용할 항목을 선택합니다. 유형 필터와 검색으로 시드를 찾을 수 있으며, 시드를 선택해야 \[다음\]이 활성화됩니다.
    
2.  **2단계** 타겟 규모 설 — 1단계(가장 유사·좁음)부터 10단계(가장 넓음)까지의 슬라이더로 크기를 조정하면 예상 인구가 즉시 표시됩니다.
    
3.  타겟 이름을 입력합니다. 필수 입력이며 최대 128자, 광고 계정 내에서 중복되지 않아야 합니다.
    
4.  \[등록\]을 클릭해 생성을 요청합니다.
    

**참고.**

생성 요청이 완료되면 '생성 요청 완료, 빌드까지 24h 소요' 안내가 표시됩니다.

**주의하세요.**

시드로 사용할 타겟이 없으면 안내가 표시되며 다음 단계로 진행할 수 없습니다. 이때는 시드로 쓸 타겟을 먼저 생성해 주세요. 이미 사용 중인 이름은 입력란에 오류로 표시되므로 다른 이름을 입력해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
