# [AI작성] 광고 계정 변경 이력은 어떻게 조회하나요?

광고 계정의 설정·결제 관련 변경 내용을 \[광고주센터 > 우측 상단 네이버 ID > 광고 계정 관리 > 광고 계정 클릭 > 도구 > 광고 계정 변경 이력\]에서 조회할 수 있습니다. 계정 책임자, 운영 관리, 운영 조회 권한 회원 모두 조회할 수 있습니다.

**탭 구성**

진입 시 '계정 관리' 탭이 기본으로 열리며, 상단에서 두 가지 탭을 전환할 수 있습니다.

| **탭** | **조회 대상** |
| --- | --- |
| 계정 관리 | 회원 관리, 계정 관계, 계정 관리 등 계정 설정 변경 이력 |
| 결제 관리 | 결제 설정, 통합 결제, 대행사 운영 등 결제 관련 변경 이력 |

**조회 방법**

1.  조회할 탭('계정 관리' 또는 '결제 관리')을 선택합니다.
    
2.  상단에서 조회 기간을 선택합니다. 기본값은 최근 7일이며, \[이전 기간\] / \[다음 기간\]으로 기간을 이동할 수 있습니다.
    
3.  검색·필터 영역에서 '구분'을 선택해 원하는 변경 유형만 추려서 봅니다. 계정 관리 탭은 '전체 / 회원 관리 / 계정 관계 / 계정 관리 / 기타', 결제 관리 탭은 '전체 / 결제 설정 / 통합 결제 / 대행사 운영'으로 구분됩니다.
    

**조회 결과 항목**

변경 이력 목록은 다음 6개 항목으로 구성됩니다.

| **항목** | **설명** |
| --- | --- |
| 변경 일시 | 변경이 발생한 날짜와 시각 |
| 구분 | 변경이 일어난 영역 분류 |
| 발신 | 변경 전 값 |
| 수신 | 변경 후 값 |
| 변경 내용 | 구체적인 변경 사항 |
| 처리자 | 변경을 수행한 회원 |

**알아두세요.**

조회 조건에 맞는 이력이 없으면 "변경 이력이 없습니다."가 표시됩니다. '변경 일시'와 '구분' 항목은 머리글을 눌러 정렬할 수 있습니다.

**참고.**

조회 기간은 최대 90일까지 선택할 수 있으며, 90일을 초과해 선택하면 안내 메시지가 표시됩니다. 목록은 한 페이지에 20건씩 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
