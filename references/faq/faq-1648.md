# [AI작성] 검색광고 전환 추적 관리 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 도구 > 전환 추적 관리\]에서 광고를 클릭한 사용자의 특정 행동(전환)을 추적하여 광고 성과를 측정합니다. 무료로 제공됩니다.

**화면 구성**

-   **안내 영역**: '광고를 클릭한 사용자의 특정 행동(전환)을 추적하여 광고 성과를 측정하는 기능입니다.(무료)' 안내문과 함께 다음 링크가 표시됩니다.
    
-   \[더 알아보기\] — 전환 추적 사용 시 광고 보고서에 표시되는 항목 안내
    
-   \[바로가기\] — 네이버 전환 스크립트 어시스턴트 (사이트에 전환 추적 스크립트가 올바르게 설치되었는지 확인)
    
-   **관리 버튼**: \[전환 추적 신청\] 버튼이 표 상단에 위치합니다.
    
-   **전환 추적 대상 표**: 컬럼은 '채널 유형 / 전환 추적 대상 / 네이버 공통키 / 상태 / 전환추적기간 / 최근 변경이력 / 관리'로 구성됩니다.
    
-   상태값: 미사용 / 사용중 / 해지중
    
-   관리 컬럼: 상태가 '사용중'일 때 \[해지 신청\] 버튼이 표시됩니다.
    
-   최근 변경이력: '신규 서비스 신청 완료', '신규 서비스 해지 신청', '신규 서비스 해지 신청 완료' 등 변경 이벤트와 일자가 표시됩니다.
    
-   **페이지네이션**: 하단에서 페이지·페이지 크기를 설정합니다.
    

**알아두세요.**

전환 추적 서비스를 사용하면 광고를 통해 발생한 전환수와 전환 매출액 등이 광고 보고서에 표시됩니다. 네이버 공통키는 사용자가 입력한 식별값이며, 전환추적기간은 일 단위로 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
