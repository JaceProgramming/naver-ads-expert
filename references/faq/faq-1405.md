# 파워링크 기본 입찰가 설정 방법이 궁금해요.

**1\. 기본 입찰가 설정하기**

광고그룹 생성 시 기본 입찰가를 설정할 수 있습니다.

기본입찰가는 광고 그룹에 속한 모든 키워드에 적용되는 입찰가로 키워드별 입찰가를 별도로 설정하지 않은 경우 기본입찰가로 설정됩니다.

기본입찰가는 70원(VAT제외)에서 10만원(VAT제외) 설정할 수 있으며 그룹 생성 시 보여지는 값은 70원입니다.

**2\. 기본 입찰가 수정하기**

기본 입찰가를 수정하는 방법은 3가지가 있습니다.

1) 하나의 광고그룹 기본 입찰가를 수정하는 경우

① ‘캠페인 클릭 > 광고그룹 클릭 > 광고그룹 정보 \[수정\]’을 클릭합니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMTA1/MDAxNzc0OTEzMTc0MTA1.OpJpBK6-UzyxIfB3R2i-evvTk1nRz7xLtt4aArjiUcog.3Ood2jWpLh71POyM5psmk6B5qmjuowJPZdwcaTGzut8g.PNG/image.png)

② 기본 입찰가를 입력 또는 수정한 후, \[저장 후 닫기\] 버튼을 클릭합니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMjIw/MDAxNzc0OTEzMTg0MTI3.f-Qh7mGjb4lLczn6aMBWkQ6UxEyVfkNJ_fxLu8oI5Usg.xOaoRGzLbJnoHxHV-sWH1UJsMqfI9W3JqCwSP98g074g.PNG/image.png)

2) 여러 광고그룹의 기본 입찰가를 동일하게 수정하는 경우

① 기본입찰가 변경할 그룹들을 선택 후 \[선택한 광고 그룹 관리\] > '입찰가 변경'을 클릭합니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMjUz/MDAxNzc0OTEzMTkzNzEy.hFeiF0Kl7phjOq8MzTZjpvE2bkzeiv-CPsyszJM5wcYg.LJUTFjFSHjrfFfDhc9i3NYvDMUj8DLBpoe3rCQLbL3Ug.PNG/image.png)

② 입찰가를 직접 입력한 후 \[변경사항 확인\] > \[변경\] 버튼을클릭합니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMjE3/MDAxNzc0OTEzMjA3NDMy.pKM_GkojIZEo1u0TsxLRbeOaHkt0PQ4LqYwJG69UgdQg.ZC8A8QKUNHQdGK3dHrvGA82JV7OkmuxDFIlhY0rv4Wwg.PNG/image.png)

**주의하세요.**

• 입찰가는 최소 70원부터 최대 10만원 (VAT 제외)까지 입력할 수 있습니다.

입찰가와 관련된 내용은 우측 도움말을 참고해 주세요. [입찰가의 정의 도움말 보기](https://ads.naver.com/help/faq/1348) 

• 파워링크 노출 순위는 입찰가 뿐만 아니라, 검색어와 사이트 콘텐츠의 연관성, 소재 품질 등의 종합적인 결과를 바탕으로 결정됩니다.

• 키워드에 개별 입찰가가 설정되어 있다면, 개별 입찰가가 우선 적용됩니다.

• 키워드별 경쟁 상황이 다를 수 있으므로, 광고그룹의 기본 입찰가는 상황에 맞게 사용해 주세요.

• 변경한 입찰가는 광고시스템 화면에는 즉시 반영되나 실제 광고 노출에 반영 되기까지 수 분 정도가 소요 됩니다.

그러나 사용자가 많은 등 상황에 따라서는 수 십분까지 소요될 수 있습니다.
