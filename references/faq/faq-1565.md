# [AI작성] 검색광고 광고그룹의 상태를 변경하려면 어떻게 하나요?

적용 대상: 파워링크 · 쇼핑검색 · 파워컨텐츠 · 플레이스. 광고그룹 목록에서 \[선택한 광고그룹 관리\]를 통해 여러 광고그룹의 상태를 한 번에 변경할 수 있습니다.

**상태 변경 절차**

1.  캠페인 목록에서 캠페인 이름을 클릭해 상세로 이동합니다.
    
2.  '광고그룹' 탭에서 변경할 광고그룹을 1건 이상 선택합니다.
    
3.  \[선택한 광고그룹 관리\]에서 상태 변경을 선택합니다.
    
4.  \[변경\]을 클릭하면 상태가 변경됩니다.
    

**알아두세요.**

상태 전환이 불가능하면 안내 메시지가 표시됩니다. 사유를 확인하고 조건을 충족한 뒤 다시 시도해 주세요.

**참고.**

상태 변경은 편집 권한이 있는 사용자만 수행할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
