# [AI작성] 동영상 조회 캠페인 설정에서는 어떤 항목을 입력하나요?

동영상 조회는 동영상을 네이버의 다양한 영역에 노출해 더 많은 조회를 유도하고, 랜딩 페이지의 동영상 조회수를 극대화하는 캠페인 목적입니다. 캠페인 만들기 과정의 '캠페인 설정' 단계에서는 동영상 조회 목적에 맞춰 아래 항목이 노출되며, 다른 목적에서 사용하는 '최적화 전환 유형'은 노출되지 않습니다.

**동영상 조회 캠페인 설정 항목**

| **항목** | **설명** |
| --- | --- |
| 대표 URL | 캠페인에 사용할 비즈채널 URL을 선택합니다. 비즈채널이 없으면 \[비즈채널 관리 바로가기\]에서 먼저 등록합니다. 수정 시에는 변경할 수 없습니다. 입력 안내 문구는 '비즈채널 URL을 선택해 주세요.'입니다. |
| 브랜드 | 본 캠페인의 대상 브랜드를 선택하는 필수 항목입니다. 안내 문구로 '여러 브랜드를 보유하신 경우, 본 캠페인의 대상 브랜드를 선택해 주세요.'가 표시되며, \[브랜드 설정하기\]에서 브랜드를 등록할 수 있습니다. |
| 전환 추적 대상 | 전환을 측정할 대상을 선택합니다. 입력 안내 문구는 '전환추적대상을 선택해 주세요.'이며, '소재 랜딩 URL의 도메인이 전환 추적 대상의 도메인과 일치하는지 확인해 주세요.'라는 안내가 함께 제공됩니다. \[전환 추적 관리 바로가기\]에서 전환 추적을 설정할 수 있습니다. |

대표 URL, 브랜드, 전환 추적 대상은 모두 필수 입력 항목입니다. 세 항목을 모두 선택해야 \[다음\] 버튼이 활성화됩니다.

**참고.**

동영상 조회 캠페인에서는 '최적화 전환 유형'이 노출되지 않습니다. 또한 카탈로그 연동, 설문조사 등 다른 캠페인 목적에서 쓰이는 설정 항목도 동영상 조회에는 표시되지 않습니다.

**주의하세요.**

비즈채널이 검토 대기 중이면 \[다음\] 버튼이 비활성화됩니다. 검토가 완료된 후 다음 단계로 진행해 주시기 바랍니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
