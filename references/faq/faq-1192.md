# 외국인 실명 인증은 어떻게 하나요?

네이버광고주센터에서 비즈머니를 충전할 때 최초 1회에 한하여 실명 인증 절차를 거칩니다.

최초 충전 시 나타나는 \[금융거래를 위한 주민등록번호 수집\] 대화 상자에서 국내 거주 외국인의 경우 외국인 등록번호를 입력하면 됩니다.

국내 거주 외국인에 대한 실명 인증은 법무부 출입국 관리소에 등록되어 있는 "91일 이상 국내 체류 외국인 등록 DB"를 연동하여 이루어집니다.

**주의하세요.** 실명 인증이 되지 않을 경우, 아래 사항을 확인해 주세요.

**1\. 사용자 정보가 출입국 관리국의 "91일 이상 국내 체류 외국인 등록 DB"에 등록되어 있지 않은 경우**

출입국관리소에서 외국인등록증을 발급받지 않은 외국인에 대해서는 실명 인증이 불가능합니다.

외국인등록증 발급 후에도 실제 DB 등록까지는 2~3일 정도 소요될 수 있으므로, 해당 소요일 경과 후 다시 시도하시기 바랍니다.

**2\. 사용자 정보를 잘못 입력한 경우**

출입국 관리소에서 발급받은 신분증(외국인등록증, 재외국민거소증 등)에 기재되어 있는대로 정확히 입력해야 합니다.

영문의 경우 대소문자를 정확히 기재하셔야 하며, 공백도 반드시 신분증에 있는대로 입력합니다.

반복해서 실명 인증에 실패할 경우, SCI평가정보 ([www.sci.co.kr](http://www.sci.co.kr%C2%A0/%C2%A01577-%C2%A01006%29%EB%A1%9C%C2%A0%EB%AC%B8%EC%9D%98%ED%95%98%EC%8B%9C%EA%B8%B0%C2%A0%EB%B0%94%EB%9E%8D%EB%8B%88%EB%8B%A4.) / 1577-1006)로 문의하시기 바랍니다.
