# 신제품검색광고 소재 메인 텍스트는 어떻게 제작하나요?

1.  서브타이틀 : 1~14자 내에서 등록합니다.
    
2.  타이틀 : 1~12자 내에서 등록합니다.
    
3.  \- 서브타이틀 혹은 타이틀에 제품명이 반드시 포함되어야 합니다.
    
4.  설명문구 : 각 줄 별로 1~14자 내에서 등록합니다.
    
5.  메인텍스트 링크 : [http://,](http://,) https://, tel:, market://중 한 개를 선택하여 텍스트에 링크 될 URL을 삽입합니다. 삽입된 URL의 랜딩은 광고주 소유여야 합니다
