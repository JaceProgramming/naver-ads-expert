# [AI작성] 카탈로그 판매 소재에 아이템 세트를 연동하려면 어떻게 하나요?

카탈로그 판매 소재는 캠페인에 연동한 카탈로그의 아이템 세트를 기반으로 구성됩니다. 소재 만들기 흐름에서 광고에 사용할 아이템 세트를 선택하면, 그 세트에 포함된 제품들이 소재로 구성됩니다.

**연동 절차**

1.  소재 유형 선택 단계에서 카탈로그 소재를 선택합니다.
    
2.  미디어 입력 단계에서 광고에 노출할 아이템 세트를 선택합니다.
    
3.  소재 이름을 입력하고 미리보기로 확인한 뒤 저장합니다.
    

**주의하세요.**

카탈로그가 연동되지 않은 캠페인에서는 카탈로그 소재 만들기로 진입할 수 없습니다. 캠페인 설정에서 카탈로그를 먼저 연동해 주십시오. 캠페인에 브랜드가 설정되어 있지 않으면 소재 저장 시 브랜드 설정을 요청하는 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
