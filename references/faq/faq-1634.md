# [AI작성] 대용량 다운로드 보고서 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 보고서 > 대용량 다운로드 보고서\]에서 계정 단위로 전체 광고 정보와 보고서를 다운로드합니다. 고급 사용자용 보고서이며 실시간이 아닙니다.

**화면 구성**

-   **안내 영역**: '계정 단위로 전체 광고 정보와 보고서를 다운로드 할 수 있는 고급 사용자용 보고서 입니다.' 안내문과 '최근 집계 완료 시간: yyyy.mm.dd. hh:mm'이 표시됩니다.
    
-   **탭**: 광고 정보 일괄 다운로드 / 대용량 보고서 다운로드 2개 탭이 제공됩니다.
    
-   **생성 요청 영역**:
    
-   다운로드 항목 선택: '항목 선택' 목록에서 보고서 종류(캠페인 마스터·광고그룹 마스터·확장소재 마스터·비즈채널 마스터·파워링크 반응형 소재 마스터·파워링크 애셋 마스터·공유예산 마스터·타겟팅 대상 마스터 등)를 선택합니다.
    
-   조회 기간 선택: '현재 시점' 또는 '부터 현재까지 변경분을 포함'을 선택합니다.
    
-   \[생성요청\] 버튼을 클릭해 보고서를 생성합니다.
    
-   \[도움말 보기\] 링크가 제공됩니다.
    
-   **생성 결과 표**: 컬럼은 '요청 ID / 보고서종류 / 시작 일자 / 종료 일자 / 생성자 / 상태 / 생성 시점 / 다운로드'로 구성됩니다. 상태가 '생성 완료'인 항목은 \[다운로드\] 링크를 통해 파일을 내려받을 수 있습니다.
    

**알아두세요.**

'현재 시점'을 선택하면 현재 시점의 광고 정보가 제공되며, '변경분'을 선택하면 선택한 일자부터 현재까지 변경·삭제가 있었던 광고 정보도 함께 제공됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
