# [AI작성] 파워링크 캠페인 상세 화면 안내

파워링크 캠페인 상세 화면에서는 캠페인 성과 추이를 확인하고 하위 광고그룹과 확장 소재를 관리합니다. 캠페인 목록에서 캠페인 이름을 클릭하면 진입합니다.

**진입 경로**

\[광고주센터 > 검색광고 > 광고 관리 > 파워링크\] 캠페인 목록에서 캠페인 이름을 클릭합니다.

**화면 구성**

상단 경로 표시, 헤더(조회 기간), 성과 추이 차트, 캠페인 정보 영역, 탭 영역으로 구성됩니다. 상단 경로의 '파워링크 ▼'에서 캠페인 유형을, 캠페인 이름에서 같은 유형의 다른 캠페인을 빠르게 전환할 수 있습니다.

**캠페인 정보 영역**

우측 \[수정\]으로 설정을 변경할 수 있습니다.

| **항목** | **설명** |
| --- | --- |
| 상태 | 운영가능 / 중지: 캠페인 OFF / 광고 집행 종료 등이 표시됩니다. |
| 캠페인 유형 | '파워링크'로 표시됩니다. |
| 기간 | 계속노출 / 종료일 설정으로 표시됩니다. |
| 하루 예산 | 50원~1,000,000,000원 또는 제한없음으로 표시되며, 클릭해 바로 수정할 수 있습니다. |
| 예산배분 | 균등노출 / 일반노출 중 설정값이 표시됩니다. |
| ON/OFF | 우측 상단에서 캠페인 노출 상태를 켜거나 끌 수 있습니다. |

**탭 구성**

'광고그룹' 탭이 기본 활성화되며 '확장 소재' 탭이 함께 제공됩니다.

| **탭** | **설명** |
| --- | --- |
| 광고그룹 | 캠페인에 등록된 광고그룹 목록을 조회·관리합니다. 컬럼은 ON/OFF / 광고그룹 이름 / 상태 / 기본 입찰가 / 채널 정보 / 노출수 / 클릭수 / 클릭률(%) / 평균 CPC / 총비용으로 구성됩니다. |
| 확장 소재 | 캠페인 단위 확장 소재를 조회·관리하며, 캠페인 내 모든 광고그룹에 공통 적용됩니다. |

관리 버튼으로 \[새 광고그룹\]·\[선택한 광고그룹 관리\]·\[다운로드\]·\[열 맞춤 설정\]·\[상세 데이터\]가 제공됩니다.

**알아두세요.**

캠페인 정보 영역의 ON/OFF 및 \[수정\]은 편집 권한이 있는 사용자만 사용할 수 있습니다. 잔액 부족·검토 중에도 ON/OFF는 변경할 수 있습니다.

**참고.**

캠페인의 운영 상태에 따라 화면 상단에 안내 메시지가 표시될 수 있습니다.

-   캠페인이 OFF 상태인 경우 '캠페인이 OFF 상태여서 광고가 노출되지 않습니다' 안내가 표시됩니다.
    
-   하루 예산이 모두 소진된 경우 '캠페인의 일예산이 모두 소진되어 광고가 노출되지 않습니다' 안내와 함께 오늘 예상 소진액이 표시됩니다.
    

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
