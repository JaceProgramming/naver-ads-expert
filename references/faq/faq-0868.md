# 외부 오디언스가 무엇인지 궁금해요.

**외부 오디언스란?**

외부 오디언스는 MMP에서 생성한 오디언스를 디스플레이광고로 연동하여 타게팅 모수를 생성하는 기능입니다.

연동한 외부 오디언스는 광고 그룹 잠재고객 설정 시 포함(타게팅) 또는 제외(디타게팅)로 사용할 수 있습니다.

Airbridge와 AppsFlyer의 오디언스를 연동할 수 있으며, 그 외 MMP는 지원 검토 예정입니다.

**외부 오디언스 연동 및 사용 방법**

**STEP 1.** **API Key 생성**

-   디스플레이광고와 MMP는 API Key 방식으로 연동합니다.
    
-   도구 > 잠재고객 관리 > 내 데이터 타겟 > 외부 오디언스 화면으로 이동하여 \[ + API Key 생성 \] 버튼을 클릭하여 API Key를 생성할 수 있습니다.

**STEP 2.** **MMP 대시보드에서 디스플레이광고와 연동 설정**

MMP에서 제공하는 가이드를 참고해 주세요.

-   **Airbridge :** [**https://help.airbridge.io/ko/guides/send-audience**](https://help.airbridge.io/ko/guides/send-audience)****
    
-   **AppsFlyer :** [**https://support.appsflyer.com/hc/ko/articles/360013960577-오디언스-파트너-연결**](https://support.appsflyer.com/hc/ko/articles/360013960577-%EC%98%A4%EB%94%94%EC%96%B8%EC%8A%A4-%ED%8C%8C%ED%8A%B8%EB%84%88-%EC%97%B0%EA%B2%B0)****
    

**STEP 3.** **연동된 오디언스 확인**

-   MMP 대시보드에서 오디언스 연동 설정을 정상적으로 완료한 경우 디스플레이광고에 타겟이 자동으로 등록됩니다.
    
-   오디언스 연동 직후 '준비중' 상태가 되며, 일반적으로 5시간 이내에 타겟 상태와 모수가 업데이트 됩니다.
    
-   타겟 상태가 '사용 가능'으로 변경되면 광고 그룹 잠재고객으로 설정하여 사용할 수 있습니다.
    
-   단, 시스템 상황에 따라 타겟 모수 집계 및 상태 업데이트가 지연될 수 있습니다.

**STEP 4.** **광고 그룹 만들기 > 잠재고객 > \[ + 타겟 불러오기 \] 를 통해 외부 오디언스를 잠재고객으로 설정**

-   광고 그룹당 잠재고객은 최대 30개까지 설정할 수 있습니다.
    
-   잠재고객으로 설정된 타겟은 포함(타게팅) 또는 제외(디타게팅) 설정할 수 있습니다.

**주의 사항**

-   적법한 절차를 통해 직접 확보한 데이터로 생성한 오디언스만 연동해 주세요.
    
-   개인을 식별할 수 없는 데이터만 처리되나, 인종, 종교, 성적 지향, 병력 정보와 같은 민감 정보 처리, 또는 만 14세 미만 아동 정보로부터 수집된 광고 식별자는 제외해야 합니다.
    
-   타겟 모수 1,000 미만인 경우 잠재고객 설정 시 포함(타게팅) 설정할 수 없으며, 광고 집행 중 모수가 1,000 미만으로 줄어들 경우 포함(타게팅) 설정이 적용되지 않습니다.
    
-   연동 업체에서 오디언스 연동을 해제할 경우 타겟이 업데이트 되지 않습니다. 외부 오디언스를 잠재고객 타게팅에 사용 중이라면 연동 상태를 유지해 주세요.
    
-   연동 업체로부터 오디언스가 정상적으로 전송되지 않아 광고 집행에 영향이 발생한 경우 네이버의 고의 또는 중과실이 없는 한 디스플레이광고에서 보상하지 않습니다.
    
-   광고그룹에서 'ADVoost 오디언스' 타게팅 유형을 선택한 경우, 외부 오디언스는 시그널로 활용될 수 있습니다.
    

ADVoost 오디언스와 관련한 자세한 사항은 [도움말](https://ads.naver.com/help/faq/924) 참고 부탁드립니다.

**FAQ**

Q1. 외부 오디언스는 최대 몇 개 까지 등록할 수 있나요?

광고 계정당 최대 30개까지 등록할 수 있습니다.

최대 연동 개수를 초과한 경우 앞서 연동된 오디언스를 디스플레이광고 대시보드에서 삭제해야 신규 오디언스를 연동할 수 있습니다.

Q2. 발급한 API Key를 다른 광고 계정에서도 사용할 수 있나요?

API Key는 계정당 하나씩 부여되며, 발급한 계정에서만 사용할 수 있습니다.

Q3. 외부 오디언스 갱신 주기는 어떻게 되나요?

일 1회 갱신됩니다.

Q4. MMP 대시보드의 모수와 디스플레이광고 대시보드의 모수가 큰 차이가 납니다. 이유가 무엇인가요?

디스플레이광고의 타겟 모수는 MMP로부터 전달된 식별자 중 네이버의 데이터(광고 식별자)와 비교하여 유효한 광고 식별자를 추출한 결과입니다.

그러므로, MMP 대시보드의 모수와 차이가 발생할 수 있습니다.

Q5. 오디언스를 연동했으나 모수가 너무 작아 잠재고객 '포함'으로 사용할 수 없습니다. 어떻게 해야하나요?

MMP 대시보드에서 오디언스 생성 조건을 완화하여 모수를 충분히 확보한 후 재연동하시길 권장 드립니다.

Q6. 외부 오디언스가 '사용 불가' 상태로 변경되었어요.

오디언스 연동에 실패했거나 최초 연동일로부터 90일 이내에 광고 그룹 잠재고객으로 사용되지 않은 타겟은 '사용 불가' 상태로 변경될 수 있습니다.

또한, 외부 오디언스가 최근 30일 동안 갱신되지 않았다면 '사용 불가' 상태로 변경될 수 있습니다. MMP 대시보드에서 연동 상태를 확인해 주세요.

'사용 불가' 상태로 변경된 타겟은 광고 그룹 잠재고객으로 설정할 수 없으며 이미 설정된 상태이더라도 타게팅에 반영되지 않습니다. 그러므로, 해당 오디언스는 삭제하시고 다시 연동하시길 권장 드립니다.
