# [AI작성] 파워컨텐츠 소재 목록 화면은 어떻게 구성되어 있나요?

**파워컨텐츠 소재 목록 화면 안내**

파워컨텐츠 광고그룹 상세의 '소재' 탭에서는 블로그·포스트 콘텐츠 소재를 관리합니다. 소재별 유형·연결 URL·검수 상태·성과를 확인하고, 새 소재를 만들거나 소재를 미리보고 관리할 수 있습니다.

**목록 구성**

소재 목록에는 다음 항목이 표시됩니다.

| **항목** | **설명** |
| --- | --- |
| ON/OFF | 소재의 노출 상태를 켜거나 끕니다. |
| 소재 | 광고에 노출되는 정보로, \[편집후 새로등록\]을 클릭하면 소재 편집 화면으로 이동합니다. |
| 연결 URL | 콘텐츠가 연결된 URL로, 클릭하면 새 탭에서 열립니다. |
| 검수 상태 | '검수 중'·'노출가'·'보류' 중 현재 상태를 표시합니다. |
| 소재 ID·노출수·클릭수·클릭률(%)·평균 CPC·총비용 | 소재 식별값과 조회 기간 기준 성과 지표입니다. |

**주요 작업**

-   \[새 소재\]로 콘텐츠 소재를 만듭니다.
    
-   \[소재 미리보기\]로 소재의 노출 형태를 확인합니다.
    
-   \[편집후 새로 등록\]으로 기존 소재 내용을 불러와 새 소재로 등록합니다.
    
-   \[선택한 소재 관리\]에서 상태 변경·재검토 등을 진행합니다.
    

**알아두세요.**

검수는 영업일 기준 1~2일이 소요됩니다. 반려된 소재는 검수 상태 표시에서 반려 사유를 확인할 수 있으며, 소재를 수정한 뒤 재검토를 요청하면 다시 검수가 진행됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
