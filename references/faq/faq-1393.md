# ‘목적별 캠페인’은 어떻게 구성되어 있나요?

목적별 캠페인은 검색광고, 디스플레이 광고 구분 없이 전체 광고를 그룹핑해 보여줍니다.

• 검색광고 + 디스플레이 광고를 '목적 단위'로 묶어 제공

• 선택 흐름:

1\. 목적 선택

2\. 캠페인 선택

3\. \[다음\] 클릭

4\. LNB가 선택한 캠페인에 맞는 탭으로 자동 전환

5\. 해당 캠페인의 등록 화면 노출
