# [AI작성] 광고 데이터를 Excel 파일로 대량 다운로드하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 도구 > 대량 관리\] \[광고 다운로드\] 탭에서 캠페인 유형과 캠페인을 선택해 \[다운로드 생성\]을 클릭하면 광고 데이터가 압축 파일(ZIP)로 생성됩니다.

**다운로드 절차**

1.  \[광고주센터 > 검색광고 > 도구 > 대량 관리\]에 진입합니다.
    
2.  \[광고 다운로드\] 탭을 선택합니다.
    
3.  '캠페인 유형 선택'에서 다운로드할 캠페인 유형(파워링크·쇼핑검색·파워컨텐츠 등)을 선택합니다.
    
4.  '캠페인 선택'에서 다운로드 대상 캠페인을 최대 20개까지 선택합니다.
    
5.  필요 시 \[입력값 지우기\]로 선택을 초기화할 수 있습니다.
    
6.  \[다운로드 생성\]을 클릭합니다.
    
7.  '대량 작업 신청 목록'에서 작업 상태가 '완료'로 변경되면 '다운로드' 컬럼의 \[다운로드\]를 클릭해 파일을 내려받습니다.
    

**알아두세요.**

다운로드 파일은 압축(ZIP) 폴더 형식으로 제공되며, 광고 다운로드 파일을 통해 대량 등록·수정 작업에 필요한 '광고그룹 ID·키워드 ID' 등의 정보를 확인할 수 있습니다.

**주의하세요.**

브랜드검색/신제품검색·플레이스 캠페인 유형은 광고 다운로드를 지원하지 않습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
