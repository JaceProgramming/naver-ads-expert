# 브랜드검색 앰배서더형 환급 규정 및 환급가능 금액이 궁금해요.

브랜드검색 앰배서더형 계약을 취소하는 경우 환급 규정은 다음과 같습니다.

\[1\] 광고주 사유로 계약을 취소하는 경우, 기존 브랜드검색의 취소 환급금 정책을 따릅니다.

-   **광고 집행 전 계약 취소 시: 광고비 전액 환급**
    
-   **광고 집행 중 계약 취소 시: 일할 계산하여 환급**
    
-   단, 일할 계산한 광고비가 템플릿 유형별 '기준 조회수' 최소 구간 단가의 50%에 해당하는 금액보다 적을 경우에는 '기준 조회수' 최소 구간 단가의 50%를 공제하고 환급
    
-   환급가능금액 = 계약금액 - MAX\[{취소일까지 일할 계산한 광고 집행 금액}, {(템플릿 별 “기준 조회수” 최소 구간 단가)\*1/2}\]
    

**< 환급 계산 예시 >**

1\. 앰배서더형 이미지 일반 0 ~ 34,200 구간 7일 광고비 100,000원에 계약했고, 3일째 되는 날 취소하게 되는 경우

→ 환급액 : 50,000원 (광고비 100,000원 - MAX\[{100,000\*3/7(취소일까지 일할 계산한 광고 집행 금액)}, {100,000\*1/2}\])

: 3일 동안 집행한 광고 집행한 금액은 42,857원이나, 템플릿별 최소 기준 조회수 가격의 1/2이 5만원이므로 환급액은 계약금액 10만원에서 둘 중 큰 금액인 5만원을 차감한 금액인 5만원입니다.

2\. 앰배서더형 이미지 일반 248,501 ~ 308,500 구간 7일 광고비 700,000원원에 계약했고, 3일째 되는 날 취소하게 되는 경우

→ 환급액 : 400,000원 (광고비 700,000원 - MAX\[{700,000\*3/7(취소일까지 일할 계산한 광고 집행 금액)}, {100,000\*1/2}\])

: 3일 동안 집행한 광고 집행한 금액은 30만원이고, 해당 템플릿 유형(이미지 일반)의 기준 조회수 최소 구간 단가의 1/2은 5만원이므로 환급액은 계약 금액 70만원에서 둘 중 큰 금액인 30만원을 차감한 금액인 40만원입니다.

\[2\] 인물 본인 측이 해당 인물명 키워드에 대한 브랜드검색 광고(앰배서더형을 제외한 모든 브랜드검색 광고) 집행을 희망하여 특정 키워드만 삭제하거나 계약 전체를 취소하는 경우, 아래 방식으로 환급됩니다.

-   **계약 내 특정 키워드만 삭제하는 경우 :**
    
    -   **특정 키워드의 미집행 기간에 해당하는 광고비와 해당 금액의 20%를 추가로 환급**
        
    -   계산식 : {총 광고비 X (삭제 키워드의 기준 조회수/전체 키워드의 기준 조회수) X (미집행 기간/총 광고집행 기간)} + {해당 금액}의 20%
        
    -   미집행 기간은 키워드를 삭제한 날부터 일 단위로 계산함
        
    -   환급 금액은 전액 유상 비즈쿠폰(vat 포함)으로 영업일 기준 10일 이내 지급
        

-   **계약 전체를 취소하는 경우 :**
    
    -   **미집행 기간에 해당하는 광고비와 그 금액의 20%를 추가로 환급**
        
    -   계산식 : {총 광고비 X (미집행 기간/총 광고집행 기간)} + {해당 금액}의 20%
        
    -   미집행 기간은 계약을 취소한 다음 날부터 일 단위로 계산함
        
    -   미집행 기간에 대한 광고비는 비즈머니로 즉시 환급, 추가 20% 금액은 유상 비즈쿠폰으로 10일 이내 지급
        
    -   단, 취소일까지 일할 계산한 광고 집행 금액이 해당 템플릿 유형별 '기준 조회수' 최소 구간 단가의 50%에 해당하는 금액보다 적을 경우에는
        
    -   '기준 조회수' 최소 구간 단가의 50%를 공제한 금액이 비즈머니로 즉시 환급되며, 남은 금액은 유상비즈쿠폰(vat 포함)으로 보정처리하여 여업일 기준 10일 이내 지급
        

**< 환급 계산 예시 >**

1\. (집행 전) 7일 광고비 700,000원인 계약에서 특정 키워드만 삭제하는 경우

(계약 내 전체 키워드의 기준 조회수는 300,000 / 삭제 키워드의 기준 조회수는 30,000 가정)

→ 환급액(유상 비즈쿠폰) : 70,000원 (광고비 700,000원\*30,000/300,000(삭제 키워드의 기준 조회수/전체 키워드의 기준 조회수))

→ 추가 환급액(유상 비즈쿠폰) : 14,000원 (환급액\*20%)

: 총 환급 금액은 8만 4천원이며, 전액 유상 비즈쿠폰으로 영업일 기준 10일 이내 지급됩니다.

2\. (집행 중) 7일 광고비 700,000원인 계약에서 특정 키워드만 3일째 되는 날 취소하게 되는 경우

(계약 내 전체 키워드의 기준 조회수는 300,000 / 삭제 키워드의 기준 조회수는 30,000 가정)

→ 환급액(유상 비즈쿠폰) : 50,000원 (광고비 700,000원\*1/10(삭제 키워드의 기준 조회수/전체 키워드의 기준 조회수)\*5/7(미집행기간/총 광고집행 기간)) ※ 취소 당일부터 일 단위로 미집행 기간 계산

→ 추가 환급액(유상 비즈쿠폰) : 10,000원 (환급액\*20%)

: 총 환급 금액은 6만원이며, 전액 유상 비즈쿠폰으로 10일 이내 지급됩니다.

3\. (집행 전) 7일 광고비 700,000원인 계약 전체를 취소하게 되는 경우

→ 환급액(비즈머니) : 광고비 700,000원

→ 추가 환급액(유상 비즈쿠폰) : 140,000원 (환급액\*20%)

: 총 환급 금액은 84만원이며 비즈머니로 70만원 즉시 환급, 유상 비즈쿠폰으로 영업일 기준 10일 이내 14만원이 지급됩니다.

4\. (집행 중 & 취소일까지 일할 계산한 광고비가 해당 템플릿 유형별 '기준 조회수' 최소 단가의 50% 금액보다 큼)

7일 광고비 700,000원인 앰배서더형 '이미지 일반' 템플릿 계약 전체를 3일째 되는 날 취소하게 되는 경우

→ 환급액(비즈머니) : 400,000원 (광고비 700,000원\*4/7(미집행 기간/총 광고집행 기간)) ※ 취소 다음 날부터 일 단위로 미집행 기간 계산

→ 추가 환급액(유상 비즈쿠폰) : 80,000원 (환급액\*20%)

: 취소일까지 일할 계산한 광고 집행금액 30만원(광고비 700,000\*3/7)보다 '이미지 일반' 템플릿 유형의 '기준 조회수' 최소 단가의 50%인 5만원보다 크므로 미집행 기간에 해당하는 광고비 전액이 비즈머니로 환급됩니다.

: 총 환급 금액은 48만원이며 비즈머니로 40만원 환급, 유상 비즈쿠폰으로 영업일 기준 10일 이내 8만원이 지급됩니다.

5\. (집행 중 & 취소일까지 일할 계산한 광고비가 해당 템플릿 유형별 '기준 조회수' 최소 단가의 50% 금액보다 적음)

7일 광고비 100,000원인 앰배서더형 '이미지 일반' 템플릿 계약 전체를 2일째 되는 날 취소하게 되는 경우

→ 환급액(비즈머니 & 유상 비즈쿠폰) : 71,428원 (광고비 100,000원\*5/7(미집행 기간/총 광고집행 기간)) ※ 취소 다음 날부터 일 단위로 미집행 기간 계산

→ 추가 환급액(유상 비즈쿠폰) : 14,285원 (환급액\*20%)

: 취소일까지 일할 계산한 광고 집행금액 28,572원(광고비 100,000\*2/7)보다 '이미지 일반' 템플릿 유형의 '기준 조회수' 최소 단가의 50%인 5만원이 더 크기 때문에 비즈머니로는 5만원만 즉시 환급되며, 추가로 환급되어야 하는 21,428원(미집행 기간에 해당하는 광고비 71,428원에서 비즈머니로 즉시 환급 5만원 제외)은 유상 비즈쿠폰으로 추가 보정처리하여 영업일 기준 10일 이내 지급됩니다.

: 총 환급 금액은 85,713원이며 비즈머니로 5만원 환급, 유상 비즈쿠폰으로 영업일 기준 10일 이내 35,713원(미환급액 21,428원 + 추가 환급액 14,285원)이 지급됩니다.
