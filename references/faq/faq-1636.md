# [AI작성] 대용량 보고서 다운로드 탭은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 보고서 > 대용량 다운로드 보고서\]는 '광고 정보 일괄 다운로드'와 '대용량 보고서 다운로드' 2개 탭으로 구성됩니다. '대용량 보고서 다운로드' 탭에서는 통계 지표를 포함한 대용량 보고서를 신청하고, 처리가 완료된 보고서를 다운로드합니다.

**화면 구성**

탭 상단에는 새 보고서를 신청하는 영역(보고서 유형·분석 단위·기간 선택, \[생성요청\])과 데이터 변경 관련 안내가 표시되고, 그 아래에 신청 내역 목록이 표시됩니다. 목록은 다음 컬럼으로 구성됩니다.

| **컬럼** | **설명** |
| --- | --- |
| 요청 ID | 신청한 보고서의 요청 식별 번호입니다. |
| 보고서종류 | 신청한 보고서의 유형입니다. |
| 시작 일자 / 종료 일자 | 보고서 조회 기간입니다. |
| 생성자 | 보고서를 신청한 사용자입니다. |
| 상태 | 생성중 / 완료 / 데이터 변경됨 / 실패 상태를 표시합니다. |
| 생성 시점 | 보고서가 생성된 시점입니다. |
| 다운로드 | '완료' 상태의 보고서를 내려받는 \[다운로드\]가 표시됩니다. |

**보고서 상태**

| **상태** | **설명** |
| --- | --- |
| 생성중 | 보고서가 만들어지고 있는 상태입니다. |
| 완료 | 보고서가 생성되어 다운로드할 수 있는 상태입니다. |
| 데이터 변경됨 | 생성 후 지표가 변경되어 다운로드할 수 없는 상태입니다. |
| 실패 | 보고서 생성에 실패한 상태입니다. |

**참고.**

신청한 내역이 없으면 목록에 '저장된 보고서 형식이 없습니다.'라고 표시됩니다.

**주의하세요.**

생성된 보고서는 48시간 이내 지표가 변경될 수 있습니다. 지표가 변경된 보고서는 '데이터 변경됨' 상태로 표시되며 다운로드할 수 없습니다. 보고서에 포함된 지표는 생성 시점으로부터 48시간 경과 후 최종 확정됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
