# [AI작성] 파워컨텐츠 소재를 편집 후 새로 등록하려면 어떻게 하나요?

파워컨텐츠 광고그룹 상세 \[소재\] 탭에서 기존 소재의 \[편집 후 새로 등록\]을 클릭하면 '소재 만들기' 창이 기존 소재 정보로 채워진 상태로 열립니다. 정보를 수정하고 \[저장\]하면 새 소재로 등록됩니다.

**등록 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 파워컨텐츠\]에서 광고그룹 상세로 이동합니다.
    
2.  \[소재\] 탭의 기존 소재 행에서 \[편집 후 새로 등록\]을 클릭합니다.
    
3.  '소재 만들기' 창이 기존 소재의 입력값으로 채워진 상태로 열립니다.
    
4.  제목(7~28자)·설명(80~110자)·URL/연결 URL·이미지(400×400~2000×2000)·업체(브랜드)명(1~20자)·프로필 이미지 연동·콘텐츠 발행일 등을 필요에 맞게 수정합니다.
    
5.  의료광고 심의 대상이면 '의료광고 심의필 번호'(예: 의12345)를 입력합니다.
    
6.  필요 시 '검토 요청'에서 \[네\] 선택 후 전달 내용·서류를 첨부합니다.
    
7.  \[저장\]을 클릭해 새 소재로 등록합니다. 기존 소재는 삭제되지 않고 별도로 유지됩니다.
    

**알아두세요.**

\[편집 후 새로 등록\]은 기존 소재를 직접 수정하는 것이 아니라, 기존 소재의 정보를 복제해 새 소재를 만드는 기능입니다. 노출 중인 소재의 검토 상태에 영향을 주지 않고 변형된 소재를 빠르게 등록할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
