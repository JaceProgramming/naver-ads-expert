# [AI작성] 광고그룹 연결URL 수집상태를 진단하려면 어떻게 하나요?

연결URL 수집상태 진단은 검색광고에서 제공되는 기능입니다. 광고그룹의 소재에 설정된 연결 URL이 검색 엔진에 정상적으로 수집·색인되고 있는지 유형별로 확인할 수 있습니다. 광고그룹 목록의 '연결URL 수집상태' 항목 또는 광고그룹 상세에서 진입합니다.

**진단 화면 진입 방법**

1.  캠페인 목록에서 캠페인 이름을 클릭합니다.
    
2.  광고그룹 목록(또는 광고그룹 상세)에서 '연결URL 수집상태' 항목을 클릭합니다.
    
3.  '수집 대상URL 상세 결과' 화면으로 이동합니다. 상단에는 \[파워링크 > 캠페인명 > 광고그룹명\] 경로가 표시됩니다.
    

**화면 구성**

| **영역** | **설명** |
| --- | --- |
| 요약 지표 | '색인 성공', 'SEO 점검필요', '색인 실패', '수집 실패' 4개 지표가 백분율로 표시됩니다. 우측 상단에는 종합 상태(예: '정상') 배지가 함께 표시됩니다. |
| 유형별 상세 결과 | 색인/수집 결과를 유형별로 구분하여 상세 내용과 개선 예시를 제공합니다. |

**유형별 상세 결과 테이블 컬럼**

| **컬럼** | **설명** |
| --- | --- |
| 유형 | 색인/수집 결과 유형입니다. (예: '색인 성공 : SEO 점검필요') |
| 상세 유형 | 세부 진단 유형입니다. (예: '<meta name="description"> 설명 누락', '<H1> 요소가 2개 이상 발견') |
| 상세 내용 | 해당 유형의 상세 내용 설명입니다. |
| 개선 예시 | 해당 유형을 보완하기 위한 개선 예시를 제공합니다. |
| 수집 대상 URL 수 (전체보기) | 해당 유형에 해당하는 수집 대상 URL의 개수입니다. 숫자를 클릭하면 대상 URL 목록을 확인할 수 있습니다. |

**알아두세요.**

'색인 성공' 외 유형의 '수집 대상 URL 수'를 클릭해 대상 목록을 확인하고 보완하시길 권유드립니다.

**참고.**

통계 기간과는 무관하게 진단 결과는 전일 기준이며 하루에 한 번 업데이트됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
