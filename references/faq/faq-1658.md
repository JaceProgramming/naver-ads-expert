# [AI작성] 광고 노출을 제한할 IP 주소를 등록하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 도구 > 광고 노출제한 관리\]의 등록 영역에서 광고노출제한 IP와 설명을 입력하고 \[추가하기\]를 클릭해 IP를 등록합니다. 등록한 IP는 화면 하단의 '관리목록' 표에 추가됩니다.

**등록 절차**

1.  \[광고주센터 > 검색광고 > 도구 > 광고 노출제한 관리\]에 진입합니다.
    
2.  화면 상단의 등록 영역에서 차단할 IP 주소를 '광고노출제한 IP' 입력란에 입력합니다.
    

-   고정 IP: 'x.x.x.x' 형식으로 입력합니다.
    
-   유동 IP: 마지막 네 번째 자리에 와일드카드(\*)를 사용합니다. (예: 10.255.255.\*)
    
-   사설 IP 대역(10.0.0.0~10.255.255.255 / 172.16.0.0~172.31.255.255 / 192.168.0.0~192.168.255.255)은 입력이 불가능합니다.
    

1.  필요 시 '설명' 입력란(0/25)에 IP 등록 이유를 메모합니다.
    
2.  \[추가하기\]를 클릭해 IP를 등록합니다. 등록된 IP는 '관리목록 (등록수/600)' 표에 '등록일시 / 광고노출제한 IP / 설명' 컬럼으로 표시됩니다.
    

**주의하세요.**

광고노출제한 IP는 최대 600개까지 등록할 수 있습니다. 부정적인 목적의 사용자 외 다른 유효한 사용자가 차단될 수 있으므로 등록 전 해당 IP가 유효 트래픽인지 신중히 검토하시기 바랍니다. 등록한 IP에서도 경우에 따라 광고가 노출될 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
