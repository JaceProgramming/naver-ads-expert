# [AI작성] NaverTV 클립을 등록하려면 어떻게 하나요?

**적용 대상:** 검색광고 > 파워링크 (홍보 영상 확장 소재)

파워링크 확장 소재 중 '홍보 영상'을 등록할 때 NaverTV에 업로드된 클립의 URL을 입력하여 동영상을 연동할 수 있습니다.

**NaverTV 클립 등록 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 파워링크\]에서 광고그룹 상세의 '확장 소재' 탭으로 이동합니다.
    
2.  \[새 확장 소재\]에서 '홍보 영상' 유형을 선택해 등록 화면을 엽니다.
    
3.  'NaverTV 클립 등록'을 선택하고 NaverTV 클립 URL을 입력합니다.
    
4.  URL을 입력하면 클립의 제목, 썸네일 등의 정보가 자동으로 불러와집니다.
    
5.  \[등록\]을 클릭하면 클립이 등록됩니다.
    

**입력 항목**

| **항목** | **설명** |
| --- | --- |
| URL 입력 | NaverTV 클립의 URL을 입력합니다. |
| 클립 정보 | URL 입력 후 클립의 제목, 썸네일 등의 정보가 자동으로 표시됩니다. |

**클립 상세보기**

등록된 NaverTV 클립을 클릭하면 상세보기 화면에서 동영상을 재생하고 클립 정보를 확인할 수 있습니다.

**참고.**

NaverTV에 업로드되지 않은 URL은 등록할 수 없습니다. NaverTV에 먼저 클립을 업로드한 후 등록해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
