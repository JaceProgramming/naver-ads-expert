# 파워링크 PC/모바일 입찰가 가중치 설정 방법이 궁금해요.

PC와 모바일 입찰가는 ‘PC/모바일 입찰가 가중치’를 이용하여 다르게 설정할 수 있습니다. 입찰가 가중치는 광고 그룹 단위로 설정할 수 있습니다. 입찰가 가중치를 설정하는 방법은 아래와 같습니다.

---

**복수의 광고 그룹에 입찰가 가중치 일괄 설정하기**

1.캠페인을 선택하여 광고 그룹 목록으로 이동합니다.

2\. 입찰가 가중치를 설정할 광고 그룹을 확인란으로 선택한 후, \[선택한 광고 그룹 관리\] 드롭다운 목록 상자에서 \[PC/모바일 입찰가중치 변경\]을 클릭합니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMTIz/MDAxNzc0OTE0NzI1NjA1.UZLnkJVKw6ynmI5GHY7R6qx--8T29p72-YzG6wgIbTgg.ltfeCKkiHY2gxd6aNmHGS3BxwMhhIwOwQ27QD9vJuKUg.PNG/image.png)

3\. 원하는 값을 입력한 후 \[변경\] 버튼을 클릭합니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMjYw/MDAxNzc0OTE0NzQwMTg5.W6tOajYqeCucB6wwWupyKO1VHEbjH4ojAJkXhWnRajkg.YhfyKCpj7ZYE18EN4IidsuI294P3buYvwlixt1HMiSEg.PNG/image.png)

---

**개별 광고 그룹 단위로 입찰가 가중치 설정하기**

1\. 설정을 원하는 '광고 그룹 이름' 위에 마우스 포인터를 올린 후 오른쪽에 나타나는 연필 모양의 아이콘을 클릭합니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfODMg/MDAxNzc0OTE0NzQ5OTQ1.G4Oz-Usk37pxucAB81j-bXfBfT_0QpDzC1ga2w0PiwMg.dvRlmRJe8V29wMSmXvnBo1124oIYN6BEiIO6MOGexC4g.PNG/image.png)

또는 설정을 원하는 광고 그룹의 상세 페이지의 오른쪽 위에서 \[수정\] 버튼을 클릭합니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfNTAg/MDAxNzc0OTE0NzU4NjIw.-bnjK1SLlqHvjj52qZ85wZibirqqAWwqnWOj16wrzlEg.2LpzbzNrCemc3h08-_poUTr1Rq4t27C6SOFxovwmB9Eg.PNG/image.png)

2\. \[광고그룹 수정\]대화 상자에서 \[고급옵션\]을 클릭합니다.

**참고.** 새 광고그룹을 만드는 단계에서도 \[새 광고그룹\] 대화 상자의 \[고급옵션\]에서 입찰가 가중치를 설정할 수 있습니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMjcw/MDAxNzc0OTE0NzY2OTY0.VF4G4KFFxtLMtYS_SR7oK7HBdJ1KCKbRU-mHIypIySAg.8HsarvTd0U3N5Ua9JPwM5M818l5pQvn1cMLhvzkj7Gcg.PNG/image.png)

3\. \[고급옵션\] 가장 아랫부분의 \[PC/모바일 입찰가 가중치\]에서 입찰가 가중치를 설정할 수 있습니다. 원하는 값을 입력한 다음 \[저장 후 닫기\] 버튼을 클릭합니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMTIg/MDAxNzc0OTE0Nzc3MDUy.tI4tAc5hwM95Nh6cr-KbJUMg7SaiNM4I-yKCpy744vYg.XduF6wN6xkx9O0T_ANohLcngluml_VIb4Ka1auEvnTMg.PNG/image.png)

**주의하세요.**

-   입찰가 가중치는 광고그룹의 기본 입찰가를 기준(100%)으로 하여 10~500%까지 입력할 수 있습니다.
    
-   설정한 입찰가 가중치는 노출 매체의 PC와 모바일 구분에 따라 기본 입찰가, 키워드 입찰가, 추천 및 콘텐츠 지면 전용 입찰가에 모두 적용됩니다.
    
-   설정한 입찰가 가중치에 따라 계산된 입찰가의 원 단위 값이 있을 경우 올림한 입찰가로 입찰됩니다. (예시 키워드 입찰가 100원 \* PC 입찰가 가중치 112% = 112원 => 120원으로 입찰)
    

| **예시. '**나시원피스', '쉬폰원피스'라는 키워드가 등록되어 있는 '여름 원피스' 광고그룹을 예로 들어 각 조건별로 적용되는 입찰가를 계산해 보겠습니다.<br>\- 광고 그룹: 여름 원피스 (기본 입찰가 500원, 추천 및 콘텐츠 지면 전용 입찰가 100원)<br>\- **PC 입찰가 가중치 100%****,** **모바일 입찰가 가중치 200%**<br>\- 광고 키워드: 나시원피스 (키워드 입찰가 설정되지 않음, 기본 입찰가 사용), 쉬폰원피스 (키워드 입찰가 700원)<br>**경우 1.** 두 키워드가 모두 PC 노출 매체인 네이버 **PC 통합검색**에 노출될 때<br>나시원피스: 기본 입찰가 500원 x **PC 입찰가 가중치 100%** = 500원으로 입찰<br>쉬폰원피스: 키워드입찰가 700원 x **PC 입찰가 가중치 100%** = 700원으로 입찰<br>**경우 2.** 두 키워드가 모두 모바일 노출 매체인 네이버 **모바일 통합검색**에 노출될 때<br>나시원피스: 기본입찰가 500원 x **모바일 입찰가 가중치 200%** = 1,000원으로 입찰<br>쉬폰원피스: 키워드입찰가 700원 x **모바일 입찰가 가중치 200%** = 1,400원으로 입찰<br>**경우 3.** 두 키워드가 모두 추천 및 콘텐츠지면인 네이버 블로그에 노출될 때<br>**PC 환경**에서 노출되는 네이버 블로그 매체인 경우<br>나시원피스: 추천 및 콘텐츠 지면 전용 입찰가 100원 x **PC 입찰가 가중치 100%** = 100원으로 입찰<br>쉬폰원피스: 추천 및 콘텐츠 지면 전용 입찰가 100원 x **PC 입찰가 가중치 100%** = 100원으로 입찰<br>**모바일 환경**에서 노출되는 네이버 블로그 매체인 경우<br>나시원피스: 추천 및 콘텐츠 지면 전용 입찰가 100원 x **모바일 입찰가 가중치 200%** = 200원으로 입찰<br>쉬폰원피스: 추천 및 콘텐츠 지면 전용 입찰가 100원 x **모바일 입찰가 가중치 200%** = 200원으로 입찰 |
