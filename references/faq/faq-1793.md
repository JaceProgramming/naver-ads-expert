# [AI작성] 관리 계정 보고서 목록 화면은 어떻게 구성되어 있나요?

관리 계정 보고서에서는 연동된 하위 광고 계정별 광고비와 광고 성과를 조회할 수 있습니다. 로그인 후 좌측 메뉴에서 '보고서'를 선택해 진입하며, 화면은 보고서 4종을 안내하는 목록으로 구성됩니다.

**안내 사항**

-   관리 계정 보고서에서는 하위 연동된 광고 계정별 광고비 및 광고 성과를 조회할 수 있습니다.
    
-   동일 광고 계정의 검색광고 / 디스플레이 광고 성과는 구분되어 개별 보고서로 제공됩니다.
    
-   검색광고의 경우 검색광고 플랫폼의 다차원 보고서를 통해 보다 많은 지표를 조회할 수 있습니다.
    

**보고서 목록**

목록은 보고서 이름 / 분석 단위 / 통계 기간 컬럼으로 구성되며, 통계 기간은 모두 '최근 7일 (오늘 제외)'로 표기됩니다. 보고서 이름 또는 분석 단위를 선택하면 해당 보고서 상세 화면으로 이동합니다.

| **보고서 이름** | **분석 단위** |
| --- | --- |
| 검색광고 성과 보고서 | 광고 계정 / 캠페인 유형 |
| 검색광고 광고비 보고서 | 광고 계정 |
| 디스플레이 광고 성과 보고서 | 광고 계정 / 캠페인 / 광고그룹 / 애셋 그룹 / 광고 소재 |
| 디스플레이 광고 광고비 보고서 | 광고 계정 |

**알아두세요.**

조회 권한이 없는 보고서는 목록에서 해당 행이 비활성화됩니다. 조회된 데이터가 없는 보고서는 선택 시 빈 보고서 화면이 표시됩니다.

**참고.**

본 화면은 보고서 진입을 위한 목록이며, 실제 성과 데이터는 각 보고서 상세 화면에서 확인합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
