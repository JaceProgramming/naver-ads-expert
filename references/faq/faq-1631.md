# [AI작성] 다차원 보고서에 표시할 열을 설정하려면 어떻게 하나요?

다차원 보고서의 분석 결과 표에 표시할 열은 좌측 '보고서 항목 목록' ↔ 우측 '보고서 설정하기' 영역 사이에서 드래그앤드롭으로 추가·제거합니다.

**열 설정 절차**

1.  \[광고주센터 > 검색광고 > 보고서 > 다차원 보고서\]에서 \[새 보고서\]를 클릭하거나 기존 보고서를 엽니다.
    
2.  좌측 '보고서 항목 목록' 영역에서 추가할 항목을 우측 '보고서 설정하기' 영역으로 드래그합니다.
    
3.  제거할 항목은 '보고서 설정하기'에서 다시 '보고서 항목 목록'으로 드래그해 제거합니다.
    
4.  적용 후 '보고서 조회 결과' 영역의 표에 선택한 열만 표시됩니다.
    
5.  저장하려면 화면 상단의 \[보고서 형식 저장\]을 클릭합니다.
    

**보고서 항목 목록 (4분류 / 47개+)**

**① 광고 정보**

캠페인 / 캠페인 유형 / 광고그룹 / 광고그룹 유형 / 키워드 / 소재 / 소재 유형 / URL / 확장 소재 유형 / 확장 소재 / 검색 유형 / 검색어 / 타겟팅 구분 / 매체이름 / PC/모바일 매체 / 검색/콘텐츠 매체 / 지역 / 상세 지역 / 성별 / 연령대

**② 광고 성과**

노출수 / 클릭수 / 클릭률(%) / 평균 CPC / 총비용 / 평균노출순위 / 총 재생수 / 반응수

**③ 전환 성과**

총 전환수 / 직접전환수 / 간접전환수 / 총 전환율(%) / 총 전환매출액 / 직접전환매출액 / 간접전환매출액 / 총 전환당비용 / 총 광고수익률(%) / 구매완료 전환수 / 구매완료 전환매출액 / 구매완료 광고수익률(%) / 전환 유형

**④ 시간구분**

일별 / 주별 / 요일별 / 시간대별 / 월별 / 분기별

**알아두세요.**

'보고서 항목 목록'에는 차원(예: 캠페인·광고그룹·키워드·소재·매체·기간)과 지표(노출수·클릭수·전환수·총비용 등)가 분류별로 표시되며, 보고서 카테고리(기본·전환·시간·지역·매체)에 따라 선택 가능한 항목이 일부 달라집니다.

**참고.**

'필터' 기능을 활용하면 원하는 항목과 조건을 선택해 결과를 좁힐 수 있습니다. 조회 결과는 표 하단에서 페이지·페이지 크기(30개 등)를 설정해 볼 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
