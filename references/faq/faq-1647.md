# [AI작성] Easy 대량 관리(beta)로 확장 소재를 대량 등록하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 도구 > 대량 관리\]의 \[Easy 대량 관리(beta)\] 탭에서 CSV 파일 업로드 또는 광고플랫폼 내 직접 입력으로 확장 소재 등을 대량 등록·삭제할 수 있습니다.

**베타 지원 범위**

베타 버전에서는 다음 항목을 대량으로 등록·삭제할 수 있습니다.

-   파워링크 병의원 특화 소재 등록
    
-   파워링크 캠페인의 확장 소재 7종 — 추가 제목 / 추가 설명 / 홍보 문구 / 서브 링크 / 계산 / 파워링크 이미지 / 이미지형 서브링크
    
-   확장 소재 삭제
    

**등록 방법**

1.  '작업 유형'을 선택합니다.
    
2.  입력 방식을 '시트에 바로 넣기' / 'csv' / 'xlsx' 중에서 고릅니다. csv·xlsx를 고르면 파일 업로드가 활성화됩니다.
    
3.  파일 업로드 시 한글이 깨지면 인코딩을 'EUC-KR' 또는 'UTF-8'로 바꿔 다시 시도합니다.
    
4.  직접 입력 시 스프레드시트에 데이터를 입력하며, \[행 추가\]로 입력 행을 늘립니다.
    
5.  입력 내용을 확인한 뒤 \[전송하기\]를 클릭합니다. 입력한 내용은 Excel 파일로 다운로드할 수 있습니다.
    

입력 중에는 전체 / 입력 오류 / 전송 / 성공 / 실패 건수가 실시간으로 표시됩니다.

**입력 시 유의사항**

| **상황** | **안내** |
| --- | --- |
| 작업 유형 변경 | 입력 중인 데이터가 있으면 초기화 확인 후 비워집니다. |
| 입력 오류 존재 | 입력 오류 건수가 강조되고 \[전송하기\]가 비활성화됩니다. 오류 셀을 수정해 주세요. |
| 병의원 특화소재 | 비즈채널에 사이트 이름이 등록되어 있지 않으면 대량 등록이 불가합니다. |
| 확장 소재 삭제 | 최대 10,000건까지 입력할 수 있으며, 파워링크 캠페인의 확장 소재만 대상입니다. |

**참고.**

Easy 대량 관리(beta)는 대량 작업 신청 목록을 제공하지 않습니다. 입력 결과는 화면의 작업 결과 카운터로 확인해 주세요.

**주의하세요.**

Chrome 76 버전에서는 시트에 복사·붙여넣기 시 특수문자(<, >, &)가 HTML 치환코드로 바뀔 수 있습니다. 메모장 등 다른 편집기를 거쳐 복사한 뒤 붙여넣어 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
