# [AI작성] 검색광고 캠페인 단위 확장 소재 목록 안내

적용 대상: 파워링크 · 쇼핑검색 · 플레이스. 캠페인 '확장 소재' 탭에서 캠페인 단위로 등록된 확장 소재를 조회·관리합니다. 캠페인 단위 확장 소재는 캠페인 내 모든 광고그룹에 공통 적용됩니다.

**진입 경로**

캠페인 목록에서 캠페인 이름을 클릭한 뒤 '확장 소재' 탭을 선택합니다.

**확장 소재 목록 표**

| **컬럼** | **설명** |
| --- | --- |
| ON/OFF | 확장 소재의 노출 상태를 켜거나 끕니다. |
| 확장소재 | 확장 소재의 제목(부제)이 표시됩니다. |
| 상태 | 현재 운영 상태가 표시됩니다(비즈채널 검토 중·노출제한, 상위 광고그룹 OFF 등 사유 포함). |
| 확장 소재 유형 | 등록된 확장 소재의 유형이 표시됩니다. |
| 요일/시간 | 노출 요일·시간 설정이 표시됩니다(기본값 '모든 요일 및 시간'). |
| 노출수 / 클릭수 / 클릭률(%) / 평균 CPC / 총비용 | 성과 지표입니다. |
| 총 재생수 / 반응수 | 확장 소재 고유 지표이며, 데이터가 없으면 '-'로 표시됩니다. |
| 확장 소재 ID | 확장 소재 고유 ID입니다. |

**주요 기능**

-   **\[새 확장 소재\]**: 등록 가능한 확장 소재 유형 목록에서 유형을 선택해 등록합니다.
    
-   **\[선택한 확장 소재 관리\]**: 1건 이상 선택 시 일괄 ON/OFF·삭제·재검토 요청을 수행합니다.
    
-   **\[대량관리\]**: 캠페인 단위 확장 소재를 대량 편집하는 화면으로 이동합니다.
    
-   **\[다운로드\]·\[열 맞춤 설정\]** 및 필터를 제공합니다.
    

**참고.**

등록된 확장 소재가 없으면 '등록한 확장 소재가 없습니다. 새로운 '확장 소재'를 등록해보세요.' 메시지가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
