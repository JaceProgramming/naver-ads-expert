# URL 수집 상태의 상세 유형이 궁금해요.

URL 수집진단 기능에서는 URL별로 수집 상태를 28가지 유형으로 분류하여 상세 설명, 개선 예시와 함께 제공합니다.

'색인 성공' 유형 이외에는 광고 품질 저하 및 광고 미노출의 원인이 될 수 있기 때문에 개선 예시를 참고하여 보완하시길 권유 드립니다.

**Tip.** 보완 작업을 진행할 때 반드시 광고용 검색로봇과 네이버 광고 IP/UA 차단을 검토하시길 바랍니다.

| **유형** | **상세 유형** | **상세 내용** | **개선 예시** |
| --- | --- | --- | --- |
| 색인 성공 | 색인된 페이지 | 수집/색인이 모두 정상적으로 완료된 상태 | \- |
| 색인 성공 : SEO 점검필요 | <title> 요소를 찾을 수 없음 | <title> 요소가 없어 페이지 주제가 파악하기 어려움 | 페이지 주제를 나타내는 정확하고 고유한 제목 텍스트를 HTML 문서 <head> 요소 안 <title> 요소 추가 |
| 색인 성공 : SEO 점검필요 | <meta name="description"> 설명 누락 | 페이지 내용을 요약하는 <metan name="description"> 태그에 설명을 작성 누락 | HTML 문서 <head> 요소 안 <metan name="description"> 태그 설명 추가 |
| 색인 성공 : SEO 점검필요 | <title> 요소가 2개 이상 발견 | 콘텐츠 주제인 <title> 요소가 2개 이상 발견되는 중복 이슈 | 불필요한 <title>을 제거하여 HTML 문서를 대표하는 <title> 요소 하나만 유지 |
| 색인 성공 : SEO 점검필요 | <title> 요소 텍스트 길이 확인 필요 | 필요 이상으로 긴 <title> 요소를 사용할 경우 검색 결과에 표시될 때 생략될 수 있음 | <title> 요소의 텍스트 길이 축소 |
| 색인 성공 : SEO 점검필요 | <H1> 요소가 2개 이상 발견 | <H1> 요소가 2개 이상 발견되어 검색로봇이 이해하기 어려운 구조 | 문서 구조의 명확성을 위해 고유한 <H1> 요소 하나만 유지 |
| 색인 성공 : SEO 점검필요 | Alt 속성 누락 | <img> 요소에 Alt 속성이 없거나 설명 미존재 | 콘텐츠 이미지에 설명(Alt) 속성 추가 |
| 색인 성공 : SEO 점검필요 | 프로토콜이 다른 내부 링크 존재 | HTTPS 페이지에는 HTTPS 컨텐츠만 넣을 수 있는 다른 프로토콜의 링크 존재 (반대의 경우도 있음) | URL 프로토콜과 동일한 리소스 URL로 변경 |
| 색인 성공 : SEO 점검필요 | 접근이 제한된 리소스가 존재 | 페이지 내 일부 요소에서 렌더링에 필요한 xhr, script를 읽을 수 없음 | 페이지 내 중요 콘텐츠가 XHR 방식으로만 제공될 경우, 검색엔진이 해당 콘텐츠를 인식할 수 있도록 SSR 또는 프리렌더링 적용 |
| 색인 성공 : SEO 점검필요 | 다운로드 크기가 큰 페이지 | 일반 페이지의 파일 크기보다 큰 페이지로 다운로드된 HTML까지만 불완전하게 수집 문서를 생성 | HTML 문서 사이즈가 4MB를 초과하지 않도록 사용하지 않는 JS/CSS 압축 및 제거 |
| 색인 성공 : SEO 점검필요 | 다운로드 소요 시간이 긴 페이지 | 다운로드 응답에 걸리는 시간이 긴 페이지로 응답 시간이 길기 때문에 크롤러는 일부만 다운로드 | 외부 리소스 최소화 등 응답 속도를 개선해 페이지 최적화 |
| 색인 실패 | HTML 내용이 없는 페이지 | HTML에 내용이 없거나 단순한 script만 존재하는 페이지로 추출할 내용이 없기 때문에 색인에 실패 | 페이지 이동의 경우 HTTP 응답코드 중 301 혹은 302 방식으로 이동 |
| 색인 실패 | 소프트 404 페이지 | 200 응답 코드를 반환하는 페이지 중 오류 페이지, 로그인 페이지, 의미 없는 페이지 등의 사유로 색인에 실패 | 광고목적물로 사용하지 않는 페이지라면 정상 URL로 교체 |
| 색인 실패 | Content-Type과 페이지 포맷이 비활성화되어 색인에 실패 | Content-Type과 페이지 포맷이 비활성화되어 색인에 실패 | 서버 응답 헤더의 Content-Type을 text/html로 설정 |
| 색인 실패 | 계정 예산 잠김, 캠페인/광고그룹/소재 OFF, 리다이렉트 페이지 | 소재 OFF로 색인 실패하였거나, 리다이렉트 오류로 수집 실패된 경우 | 현황 진단 상태에 따라 소재 상태를 ON으로 변경하거나, 혼합 프로토콜 등 리다이렉트 오류 점검<br>\* 소재 ON 후 색인 반영까지는 최대 4시간이 소요될 수 있습니다. |
| 수집 실패 | 리다이렉트 무한 순환 상태 | 페이지가 다른 페이지로 리다이렉트 되고 다시 원래 페이지로 리다이렉트 되는 구조의 페이지로 무한 순환이 되고 있는 상태<br>• 리다이렉트 구조 예시 : A → B → C → D → E → A / A → B → C → B / A → B → A | 리다이렉트 URL이 반복되는 구조를 제거하고 UTM 파라미터 등 추적 파라미터가 제거된 연결URL과 다른 단방향의 리다이렉트URL 설정 |
| 수집 실패 | 리다이렉트 횟수 초과 | 페이지가 연속해서 리다이렉트 하는 경우로, 리다이렉트 횟수가 컬렉터에 설정된 범위를 넘는 상태<br>• 리다이렉트 구조 예시 : A → B → C → D → E → F | 리다이렉트 횟수를 5회 미만으로 설정 |
| 수집 실패 | 자기 자신을 리다이렉트하는 페이지 | 페이지가 자기 자신을 리다이렉트하는 상태로, 자신을 반복적으로 리다이렉트하기 때문에 최종 페이지에 액세스할 수 없음<br>• 리다이렉트 구조 예시 : A → A | UTM 파라미터 등 추적 파라미터가 제거된 연결URL과 리다이렉트 URL을 다르게 설정하고, 리다이렉트 횟수를 5회 미만으로 설정 |
| 수집 실패 | 리다이렉트대상URL문제 | 리다이렉트되는 최종 Landing URL을 검색 로봇이 인지할 수 없음 | 체인이 짧고 정확한 리다이렉트 URL로 교체 |
| 수집 실패 | robots.txt에 의해 수집 차단된 페이지 | robots.txt에서 'Ads-Naver' Robot 접근을 제한하는 경우 접근제한된 페이지는 다운로드가 불가능 | 광고용 웹수집 검색로봇인 'Ads-Naver'에 대해 수집 허용 설정 |
| 수집 실패 | 페이지 접속 실패 | 페이지 연결에 실패한 경우로 크롤러가 다운로드하기 전에 페이지 연결을 시도하는데 연결 지연으로 다운로드 할 수 없음 | IP/UA 차단을 점검하거나, 일시적 연결 문제 없이 항상 접근 가능한 URL로 교체 |
| 수집 실패 | 접근 불능의 페이지 | 400 응답 코드를 반환하는 페이지로 페이지 누락, 권한 등으로 접속이 되지 않아 다운로드 할 수 없는 상태 | IP/UA 차단을 점검하거나, 정상 접속 가능한 URL로 교체 |
| 수집 실패 | 접근권이 없는 페이지 | 401 응답 코드를 반환하는 페이지로, 해당 페이지에 유효한 인증 자격이 없어 다운로드가 불가한 상태 | IP/UA 차단을 점검하거나, 로그인 없이 접근 가능한 공개 페이지를 연결URL로 등록 |
| 수집 실패 | 접속 금지 페이지 | 403 응답 코드를 반환하는 페이지로 권한 문제로 접속이 거부되어 다운로드 할 수 없는 상태 | IP/UA 차단을 점검하거나, 접근 권한이 제한되지 않은 공개 페이지를 연결 URL로 등록 |
| 수집 실패 | 존재하지 않는 페이지 | 404 응답 코드를 반환하는 페이지로 페이지가 없어서 다운로드 할 수 없는 상태 | IP/UA 차단을 점검하거나, 존재하는 유효한 URL로 교체 |
| 수집 실패 | 리다이렉트 오류 페이지 | 3xx 응답코드를 돌려주는 페이지 중 수집에 실패한 페이지 | IP/UA 차단을 점검하거나, 정상 접속 가능한 리다이렉트 URL로 교체 |
| 수집 실패 | 서버 접근 불가로 수집에 실패한 페이지 | 5xx 응답 코드를 반환하는 페이지로 서버 접근이 불가능하여 수집에 실패 | 서버 상태를 점검하고, IP/UA 차단을 점검 |
| 수집실패 | 점검 필요한 페이지 | 특정할 수 없는 이유(접속제한, 차단, 인증 문제 등)으로 수집에 실패 | 페이지 전반적인 검토 및 IP/UA 차단 점검 |
