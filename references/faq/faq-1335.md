# 추적 기능

추적 기능은 클릭된 광고에 대한 정보를 광고주에게 제공하는 기능입니다.

광고주는 추적 기능을 이용하여 개별 광고 클릭에 대한 정보를 얻을 수 있으며, 마케팅 효율 또는 광고 효율을 높이는 데 활용할 수 있습니다.

파워컨텐츠 캠페인 유형을 제외한 모든 캠페인 유형에서 활용할 수 있으며, 캠페인별로 설정해야 합니다.

---

**추적 방법의 종류**

본 도움말에서 언급하는 추적 기능은 수동 추적(custom manual tracking) 기능입니다. 클릭된 광고에 대한 정보를 추적하는 방법에는 다음과 같은 방법이 있습니다.

자동차를 생산, 판매하는 motor-abc라는 업체가 있으며 model-a, model-b, model-c의 3가지 모델을 보유하고 있다고 가정했을 때, 이 사이트의 상황은 다음과 같습니다.

사이트: [http://www.motor-abc.com/](http://www.motor-abc.com/)

자동차 모델별 페이지의 URL

\- model-a: [http://www.motor-abc.com/model-a.html](http://www.motor-abc.com/model-a.html)

\- model-b: [http://www.motor-abc.com/model-b.html](http://www.motor-abc.com/model-b.html)

\- model-c: [http://www.motor-abc.com/model-c.html](http://www.motor-abc.com/model-c.html)

**분류 기준1: URL에 필요한 파라미터와 값을 부여하는 방법에 따른 분류**

**1.** 필요한 파라미터를 연결URL에 직접 추가하는 방법

클릭된 광고에 대한 정보를 연결URL에 바로 추가하는 방법입니다.

[http://www.motor-abc.com/model-a.html?q=모델A](http://www.motor-abc.com/model-a.html?q=%EB%AA%A8%EB%8D%B8A)

와 같이 소재의 연결 URL에 파라미터를 추가하는 방법입니다. 권장하지는 않는 방법입니다.

**2\.** 자동 추적 URL 파라미터를 추가하는 방법

네이버광고주센터 검색광고에서 미리 정의한 몇 가지의 파라미터와 값을 URL에 추가하는 방법입니다.

네이버광고주센터 검색광고의 캠페인 설정에서 \[추적 기능\]의 \[자동 추적 URL 파라미터\]를 선택하면 정해진 파라미터와 같이 클라이언트가 접속하는 연결 URL에 자동으로 추가됩니다.

예를 들어 연결 URL이 다음과 같다면

[http://www.motor-abc.com/model-a.html](http://www.motor-abc.com/model-a.html) 실제 클라이언트가 접속하는 URL은 다음과 같이 변경됩니다.

[http://www.motor-abc.com/model-a.html?n\_media=8753&n\_query=모델A&n\_rank=1&n\_ad\_group=grp-a001-01-000000000005304&n\_ad=nad-a001-01-000000000002274&n\_keyword\_id=nkw-a001-01-000000000015954&n\_keyword=모델A](http://www.motor-abc.com/model-a.html?n_media=www.naver.com&n_ad=XXXXX&n_keyword=%EB%AA%A8%EB%8D%B8A&n_query=%EB%AA%A8%EB%8D%B8A&n_rank=1&n_campaign=XXX)

**3.** URL 치환 변수를 이용하는 방법

네이버광고주센터 검색광고에서 제공하는 파라미터와 다른 파라미터 혹은 다른 구조로 광고 클릭 관련 값을 수집하고 싶은 경우 URL 치환 변수를 이용하는 방법이 있습니다.

예를 들어 다음과 같은 정보를 수집하고 싶은 경우

[ttp://www.motor-abc.com/model-a.html?q=(사용자 입력 키워드](http://www.motor-abc.com/model-a.html?q=%28%EC%82%AC%EC%9A%A9%EC%9E%90%20%EC%9E%85%EB%A0%A5%20%ED%82%A4%EC%9B%8C%EB%93%9C))

연결 URL을 다음과 같이 설정하면

[http://www.motor-abc.com/model-a.html?q={query](http://www.motor-abc.com/model-a.html?q=%7Bquery)}

사용자가 광고를 클릭할 때 광고를 보기 위해 입력했던 키워드가 {query} 부분을 대체합니다. 클라이언트는 다음과 같은 URL로 광고주의 웹 사이트에 접속합니다.

[http://www.motor-abc.com/model-a.html?q=모델A](http://www.motor-abc.com/model-a.html?q=%EB%AA%A8%EB%8D%B8A)

**분류 기준2: 별도의 광고 로그 수집 사이트 존재 여부에 따른 방법**

**1\.** 광고 로그 수집을 연결 URL 페이지에서 바로 하는 경우

사용자가 입력한 '모델A'라는 검색어로 광고가 클릭되었을 때 이에 대한 정보를 연결 URL 페이지에서 바로 수집한다면 [http://www.motor-abc.com/model-a.html?n\_query=모델A](http://www.motor-abc.com/model-a.html?n_query=%EB%AA%A8%EB%8D%B8A)와 같은 URL로 클라이언트가 광고주 사이트에 접속하게 한 다음 파라미터 n\_query를 파싱하여 '모델A'라는 키워드로 사용자가 광고를 클릭하여 접속하였다는 것을 확인할 수 있습니다.

**2\.** 광고 로그를 별도의 사이트를 경유해 수집하는 경우

광고 로그 수집을 연결 URL 페이지에서 바로 하는 것이 아니라, 로그 수집만을 위한 별도의 사이트에서 수집을 하고 연결 URL 페이지로 이동하는 경우도 있습니다.

로그 수집을 위한 별도의 사이트가 [http://www.naver.com/log.php](http://www.naver.com/log.php)라고 한다면 '모델A' 라 검색어로 광고가 클릭되었을 때 클라이언트는 다음과 같은 URL로 접속합니다.

[http://www.naver.com/log.php?n\_query=모델A&landing\_page=http://www.motor-abc.com/model-a.html](http://www.naver.com/log.php?n_query=%EB%AA%A8%EB%8D%B8A&landing_page=http://www.motor-abc.com/model-a.html)

naver.com 사이트에서는 n\_query 파라미터를 파싱하여 '모델A'라는 키워드로 사용자가 광고를 클릭하였다는 것을 수집하고, 연결 URL 페이지인[http://www.motor-abc.com/model-a.html](http://www.motor-abc.com/model-a.html)로 클라이언트가 이동하게 하면 광고 관련 로그 수집이 마무리됩니다.

**제공 기능**

**1\. URL에 필요한 파라미터와 값을 부여하는 방법 관련**

-   자동 추적 URL 파라미터를 추가하는 방법 (분류 기준 1의 2)
    
-   네이버광고주센터 검색광고에서는 자동 추적 URL 파라미터를 추가하는 방법을 제공하고 있습니다. 캠페인 설정 화면에서 \[추적기능\]의 \[자동 추적 URL 파라미터\]를 선택하면 광고 클릭 후 클라이언트가 이동하는 모든 URL에 7가지의 파라미터와 값이 자동으로 추가됩니다.
    
-   예를 들어 광고의 연결 URL이 [http://www.motor-abc.com/model-a.html](http://www.motor-abc.com/model-a.html)라면 자동 추적 URL 파라미터 기능을 사용할 때 접속하는 실제 URL은 다음과 같이 변형됩니다.
    
-   [http://www.motor-abc.com/model-a.html?n\_media=8753&n\_query=모델A&n\_rank=1&n\_ad\_group=grp-a001-01-000000000005304&n\_ad=nad-a001-01-000000000002274&n\_keyword\_id=nkw-a001-01-000000000015954&n\_keyword=모델A](http://www.motor-abc.com/model-a.html?n_media=www.naver.com&n_ad=XXXXX&n_keyword=%EB%AA%A8%EB%8D%B8A&n_query=%EB%AA%A8%EB%8D%B8A&n_rank=1&n_campaign=XXX)
    
-   자동 추적 URL 파라미터 기능은 캠페인 단위로 제공하며, 캠페인 만들기에서 \[고급 옵션\]을 클릭하고 \[자동 추적 URL 파라미터\]를 선택하면 됩니다.

**주의하세요.**

-   자동 추적 URL 파라미터 기능 사용에 따라 연결URL에 파라미터와 값이 추가되면서 사이트가 정상적으로 열리지 않을 수 있습니다. 반드시 사전에 사용 가능여부 테스트를 통해 사이트가 정상적으로 열리는지 확인해야 합니다.
    
-   [사용 가능 여부 테스트 도움말 보기](https://ads.naver.com/help/faq/1217)
    
-   URL 치환 변수를 이용하는 방법(분류 기준 1의 3)
    
-   네이버광고주센터 검색광고에서는 연결 URL 혹은 추적 경유 URL에 미리 정해진 예약어를 추가하면 광고가 클릭될 때 이를 적절한 값으로 치환하는 기능을 제공합니다. {XXX}과 같이 중괄호를 사용하며, 치환 변수로 사용할 수 있는 예약어는 파워링크 캠페인의 경우 14가지, 쇼핑 검색 캠페인의 경우 15가지, 브랜드 검색 캠페인의 경우 12가지가 있습니다.
    

**주의하세요.**

-   URL 치환 변수에는 별도의 ON/OFF 옵션이 없습니다. 연결 URL 혹은 추적 경유 사이트 URL에 사용하면 무조건 해당 값으로 치환됩니다. 따라서 사용을 원하지 않는 경우 연결 URL 혹은 추적 경유 사이트 URL에서 URL 치환 변수를 삭제해야 합니다.

**2\. 별도의 광고 로그 수집 사이트 존재 여부에 따른 방법 관련(분류 기준 2의 2)**

별도의 광고 로그 수집 사이트가 존재하여 광고 클릭 시 로그 수집 사이트를 거쳐 최종 연결 URL 페이지로 이동하도록 구성된 경우 추적 경유 사이트 기능을 이용하여 보다 편리하게 추적할 수 있습니다.

다음과 같은 상황이라고 가정합니다.

\- 로그 수집 사이트: [http://www.naver.com/log.php](http://www.naver.com/log.php)

\- 최종 연결 URL 페이지: [http://www.motor-abc.com/model-a.html](http://www.motor-abc.com/model-a.html)

\- 로그 수집 사이트에서 최종 연결 URL 페이지 정보를 얻을 수 있는 파라미터 이름: n\_final\_url(로그 수집 사이트에서는 로그 수집 후 n\_final\_url 파리미터 URL로 리다이렉션함)

\- 로그 수집 사이트에서 수집하고자 하는 정보: 캠페인 ID, 매체, 키워드, 검색어, 광고의순위 4가지

이런 경우에 캠페인의 추적 기능에서 \[추적 경유 사이트\]를 선택하고 \[추적 경유 사이트 URL\]에 다음과 같이 입력하면 됩니다.

[http://www.naver/log.php?n\_final\_url={final\_url}&n\_campaign={campaign}&n\_media={media}&n\_keyword={keyword}&n\_query={query}&n\_rank={rank](http://www.log-abc/log.php?n_final_url=%7Bfinal_url%7D&n_campaign=%7Bcampaign%7D&n_media=%7Bmedia%7D&n_keyword=%7Bkeyword%7D&n_query=%7Bquery%7D&n_rank=%7Brank)}

추적 경유 사이트 기능을 사용할 때 URL 입력을 보다 편리하게 할 수 있도록 파라미터와 URL 치환 변수를 설정하는 기능을 제공하고 있습니다. 원하는 파라미터의 \[추가\] 버튼을 클릭하면 추적 경유 사이트 URL에 파라미터와 값(value)이 포함되며, \[삭제\] 버튼을 클릭하면 해당 파라미터와 값이 삭제됩니다.

위와 같은 경우 [http://www.naver.com](http://www.naver.com/) 사이트에서는 n\_final\_url 파라미터의 값({final\_url})에 해당하는 URL로 리다이렉션 하도록 구현해야 합니다. 그렇지 않으면 사용자가 도착하는 URL이 부여되지 않아 사이트가 정상적으로 보이지 않을 수 있습니다.

**참고.**

본 도움말에서 제공되는 추적(tracking) 기능은 추적 URL 파라미터(tracking URL parameter)를 이용한 수동(manual) 추적 기능입니다. 이는 광고와 관련된 정보를

-   URL GET 방식(URL에 파라미터와 값을 추가하는 방식)을 사용함
    
-   URL을 읽어서 바로 의미를 파악할 수 있는 정보로 제공함
    

을 의미합니다. 이 경우 네이버의 역할은 위와 같은 파라미터를 전달해주는 것으로 끝납니다.

URL에서 파라미터와 값을 읽어 들이면 누구나 바로 의미를 파악할 수 있으나, 이를 모아 리포트를 보거나 (웹 로그) 분석을 하기 위해서는 광고주가 스스로 구축한(혹은 구매한) 시스템을 이용해야 합니다.

이와 반대되는 개념은 자동 추적(auto tracking) 기능으로, 이는 광고주가 별다른 노력을 하지 않더라도 네이버가 가지고 있는 웹 로그 분석 도구를 이용하여 광고주가 리포트를 보거나 (웹 로그)분석을 할 수 있는 것을 의미합니다. 네이버광고주센터 검색광고에서는 전환 추적 이라는 서비스를 제공하고 있으며, 이는 네이버광고주센터 검색광고의 자동 추적 기능을 이용하여 제공됩니다.
