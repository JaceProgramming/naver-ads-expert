# [AI작성] 광고 계정의 자동충전 금액과 기간을 설정하려면 어떻게 하나요?

자동충전 시점·1회 충전 금액·충전 한도·사용 기간을 설정할 수 있습니다.

\[광고주센터 > 우측 상단 네이버 ID > 광고 계정 관리 > 광고 계정 클릭 > 결제 > 자동충전 관리\]에서 \[수정\]을 클릭하면 '자동충전 설정' 창이 열립니다.

**설정 항목**

| **항목** | **설명** |
| --- | --- |
| 자동 충전 시점 | 계정 잠김 발생시 / 0원 / 10,000원 / 50,000원 또는 직접 입력 중 선택합니다. |
| 1회 충전금액 | 50,000 / 100,000 / 200,000 / 300,000원 또는 직접 입력합니다. |
| 일 충전 한도 | 미설정 / 100,000 / 300,000 / 500,000원 또는 직접 입력합니다. |
| 월 충전 한도 | 100,000 / 300,000 / 500,000 / 1,000,000원 또는 직접 입력합니다. |
| 사용 기간 | 자동충전을 적용할 시작일·종료일을 선택합니다. |

**입력 한도**

직접 입력 시 다음 한도를 따릅니다. 위반하면 입력란 아래에 안내 메시지가 표시되며 \[설정\]이 비활성화됩니다.

-   1회 충전 금액: 최소 10,000원 이상, 최대 100,000,000원 이하
    
-   일일 최대 충전 한도: 최소 10,000원 이상, 최대 10,000,000원 이하 (1회 충전 금액보다 작을 수 없음)
    
-   월간 최대 충전 한도: 최소 100,000원 이상, 최대 500,000,000원 이하 (일일 한도보다 작을 수 없음)
    
-   사용 기간의 시작일·종료일은 오늘 이후여야 하며, 종료일은 시작일 이후여야 합니다.
    

1.  각 항목의 값을 선택하거나 직접 입력합니다.
    
2.  요약 안내에서 자동충전 시점과 월 최대 충전 횟수를 확인합니다.
    
3.  \[설정\]을 눌러 저장합니다.
    

**알아두세요.**

설정 정보는 충전 권한이 있는 경우에만 수정할 수 있습니다.

**참고.**

문자 메시지 알림은 자동충전 관리 화면의 '문자 메시지 알림 \[설정 확인 및 변경\]'에서 관리할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
