# 웹사이트 비즈채널 등록가이드

네이버 검색광고는 웹 사이트는 물론 업체의 전화번호, 주소, 네이버 예약 페이지 등 다양한 유형의 비즈채널로 광고할 수 있습니다.

본 도움말에서는 비즈채널 중 웹 사이트 유형의 등록 가이드 및 주의사항에 대해 알아봅니다.

---

**웹 사이트**

웹 사이트를 등록할 때는 사이트를 대표하는 최상위 도메인을 표시 URL로 등록합니다.

단, 다음의 경우는 사이트 내의 하위 페이지라도 비즈채널로 등록할 수 있습니다.

1.  사이트 내 고유의 콘텐츠를 가지며 독립적으로 운영할 수 있는 하위 도메인의 경우
    
    -   [https://health.naver.com](https://health.naver.com)
        
    -   [https://ads.naver.com](https://ads.naver.com)
        
    -   [https://kin.naver.com](https://kin.naver.com)
        
2.  사이트 내의 하위 페이지인 동시에 해당 사이트 관리자, 운영자 이외의 제3자가 해당 페이지를 관리, 운영하는 경우(오픈마켓, 종합 쇼핑몰, 소셜커머스 등의 입점 업체 페이지 등)
    
    -   [http://www.auction.co.kr/ABC](http://www.auction.co.kr/ABC) (옥션의 하위 페이지이며, 입점업체가 해당 페이지를 운영)
        
    -   [http://www.lotte.com/ABC](http://www.lotte.com/ABC) (롯데닷컴의 하위 페이지이며, 입점업체가 해당 페이지를 운영)
        
    -   [http://www.coupang.com/ABC](http://www.coupang.com/ABC) (쿠팡의 하위 페이지이며, 입점업체가 해당 페이지를 운영)
        
    -   [https://cafe.naver.com/ABC](https://cafe.naver.com/ABC) (네이버의 하위 페이지이며, 카페 개설자가 해당 페이지를 운영)
        

단, 입점 업체 페이지로 웹사이트 등록 시 표시 URL 내에 광고주 아이디거나 판매자 아이디 또는 업체명을 삽입해야 하며, 연결 URL은 오픈마켓의 메인 페이지가 아닌 입점 업체 페이지로 연결이 확인되어야 합니다.

표시URL: [http://auction.co.kr/{판매자 아이디},](http://auction.co.kr/%ED%8C%90%EB%A7%A4%EC%9E%90ID) [http://gmarket.co.kr/{광고주 아이디](http://gmarket.co.kr/%EA%B4%91%EA%B3%A0%EC%A3%BCID)}, [http://auction.co.kr/{업체명](http://auction.co.kr/%7B%EC%97%85%EC%B2%B4%EB%AA%85)}

연결URL: 실제 연결되는 입점 업체 세부 페이지의 URL (키워드 또는 소재에 연결URL을 입력할 수 있습니다.)

**웹 사이트 등록 시 주의 사항**

1\. 아래의 경우는 무료 도메인 또는 하위 도메인의 형태로 광고할 수 없습니다.

1) 브랜드 제품을 판매하거나 취급(교환, 대여, 수선 등)하는 사이트

2) 사행 산업 관련 사이트

3) 채팅 서비스를 제공 또는 중개하는 사이트

2\. 아래와 같은 경우 사이트의 내용과 관계없이 광고가 제한될 수 있습니다.

1) 접속이 되지 않거나 완성이 되지 않은 사이트

2) 한글, 영어 이외의 언어로 구성된 사이트

3) 자체 콘텐츠가 충분하지 않은 사이트(타 사이트를 단순 링크시켜 놓은 경우 포함)

4) 사용자의 동의없이 ActiveX 컨트롤을 설치하는 등 사용자의 웹 서비스 이용을 방해하는 경우

3\. 회원제로 운영되는 사이트이거나 성인 사이트인 경우 내부 콘텐츠를 확인할 수 있도록 테스트 계정의 아이디와 비밀번호를 함께 등록해야 합니다.

4\. 사이트를 대표할 수 있는 '사이트이름' 을 등록해야 합니다.

1) 사이트 이름은 노출영역에 포함됩니다.

2) 사이트 이름이 없어도 광고 노출에는 영향을 주지 않습니다.

3)사이트 이름의 노출은 파워링크의 [운영기준](https://ads.naver.com/adguide/1356)을 따릅니다.
