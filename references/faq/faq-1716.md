# [AI작성] 디스플레이광고 전환 추적 관리 화면은 어떻게 구성되어 있나요?

전환 추적 관리는 디스플레이광고 계정에서 웹사이트·모바일 앱·MAT 연동의 전환 데이터를 수집하기 위한 도구입니다. 광고주센터에 로그인한 뒤 광고 계정을 선택하고 \['디스플레이광고' > '도구' > '전환 추적 관리'\]로 이동하면 진입합니다.

**화면 구성**

화면 상단의 세 개 탭으로 영역이 나뉩니다.

| **탭** | **설명** |
| --- | --- |
| 웹사이트 | 웹사이트 전환 추적 태그를 조회·등록·수정·삭제합니다. 화면 진입 시 기본으로 선택됩니다. |
| 모바일 앱(beta) | 모바일 앱 전환 추적 설정을 조회·등록·수정·삭제합니다. |
| MAT 연동 | 모바일 앱 분석 도구(MAT) 연동 정보를 조회·관리합니다. |

각 탭의 목록에는 '전환 추적 대상', '상태', '전환 추적 기간', '최종 변경 일시'가 표시되며, 상태는 '신청중', '설치중', '설치완료', '미설치 종료'로 구분됩니다.

**참고.**

신청 절차, 신청 익일 안내 메일 발송, 대행 설치·직접 설치 분기 등 세부 안내는 각 탭의 안내 사항 영역에서 확인할 수 있습니다.

**주의하세요.**

검색광고의 프리미엄 로그 분석을 사용 중이더라도 디스플레이광고 전환 추적은 별도로 신청해야 합니다. 오픈마켓·카페·블로그 등 HTML을 직접 수정할 수 없는 사이트에서는 설치가 불가능합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
