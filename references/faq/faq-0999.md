# 플랫폼에서 오류가 발생하는 이유가 뭔가요?

네이버광고주센터는 최신 브라우저에 최적화되어 있습니다.

만약 이전 버전의 브라우저를 사용하신다면 최신 버전으로 업데이트하거나, Chrome 브라우저를 이용할 수 있습니다.

네이버광고주센터의 기능이 제대로 작동하지 않거나, 페이지가 제대로 보이지 않는다면 아래 도움말을 확인하여 최신 버전의 브라우저를 사용하는 것이 좋습니다.

---

**Internet Explorer에서 오류가 발생하는 경우**

Internet Explorer의 보안 설정으로 인해 로그인하지 못할 수도 있습니다.

이런 경우 아래 가이드를 참고하여 설정을 변경하면 네이버광고주센터를 이용할 수 있습니다.

**신뢰할 수 있는 사이트로 추가**

1.  브라우저의 \[도구\] 메뉴에서 \[인터넷 옵션\]을 클릭합니다.
    
2.  \[보안\] 탭을 클릭합니다.
    
3.  \[신뢰할 수 있는 사이트\] 아이콘을 클릭합니다.
    
4.  \[사이트\] 버튼을 클릭합니다.
    
5.  \[영역에 웹 사이트 추가\] 입력란에 "https://ads.naver.com/"을 입력하여 추가합니다.
    

**보안을 ‘보통’으로 설정**

1.  브라우저의 \[도구\] 메뉴에서 \[인터넷 옵션\]을 클릭합니다.
    
2.  \[보안\] 탭을 클릭합니다.
    
3.  보안 슬라이더가 보이지 않으면 \[기본 수준\]을 클릭하여 슬라이더가 나타나게 만듭니다.
    
4.  슬라이더를 \[보통\]으로 조정하여 적용합니다.
    

**인터넷 임시 파일과 쿠키삭제**

1.  브라우저의 \[도구\] 메뉴에서 \[인터넷 옵션\]을 클릭합니다.
    
2.  \[검색 기록\]에서 \[삭제\] 버튼을 클릭합니다. 이때 \[즐겨찾기 웹 사이트 데이터 보존\] 확인란이 선택되어 있으면 임시 인터넷 파일 및 쿠키 삭제 작업이 정상적으로 수행되지 않을 수 있습니다. 선택을 해제하고 삭제를 진행합니다.
    
3.  브라우저를 모두 종료한 뒤 다시 접속합니다.
    

---

**다른 브라우저에서 오류가 발생하는 경우**

Internet Explorer의 보안 설정으로 인해 로그인하지 못할 수도 있습니다.

이런 경우 아래 가이드를 참고하여 설정을 변경하여 이용 할 수 있습니다.

**Chrome**

1.  Chrome 브라우저 오른쪽의 \[≡\] 버튼을 클릭하고 메뉴에서 \[설정\]을 클릭합니다.
    
2.  \[설정\]화면에서 \[고급 설정 표시\]를 클릭합니다.
    
3.  아래 그림과 같이 \[인터넷 사용 정보 삭제\] 버튼을 클릭하여 쿠키 및 캐시된 파일을 삭제합니다.
