# [AI작성] 디스플레이광고 성과 보고서에 필터를 추가하려면 어떻게 하나요?

**성과 보고서 필터 추가**

성과 보고서 조회 조건 영역에서 \[필터 추가\]를 클릭하면 분석 단위에서 사용할 수 있는 필터를 추가해 결과를 좁힐 수 있습니다.

**추가 방법**

1.  조회 조건 영역에서 \[필터 추가\]를 클릭합니다.
    
2.  필터 항목을 선택합니다. 선택 가능한 항목은 현재 분석 단위에 따라 달라집니다.
    
3.  조건('제외', '일치')을 선택합니다.
    
4.  값을 입력하고 \[확인\]을 클릭해 필터를 적용합니다.
    

필터를 추가하면 결과 표가 새로고침되어 조건에 맞는 데이터만 표시됩니다.

**주의하세요.**

분석 단위(그룹핑 기준)를 변경하면 기존에 설정한 필터는 삭제됩니다. 분석 단위를 먼저 정한 뒤 필터를 추가하는 것을 권장합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
