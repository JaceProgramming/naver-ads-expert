# 디지털 옥외광고는 어떻게 하나요?

**디지털 옥외광고 특징**

| **항목** | **설명** |
| --- | --- |
| 광고주 조건 | 스마트 플레이스를 보유한 광고주만 이용 가능 |
| 노출 영역 | 지역 기반의 오프라인 동영상 옥외광고 매체 |
| 소재 유형 | 동영상 소재 (네이버 플레이스에 등록된 클립 활용) |
| 과금 방식 | 재생당 고정가(CPV) — 고정가이므로 입찰가를 직접 입력하지 않음 |

| **알아두세요.** 디지털 옥외광고는 플레이스 캠페인 내에서 설정할 수 있습니다. PC/모바일 네트워크 입찰 가중치는 적용되지 않습니다. |
| --- |

**스마트플레이스에 등록되어 있으신가요?**

디지털 옥외광고를 하기 위해서는 반드시 스마트플레이스에 등록되어 있어야 하며,

스마트플레이스는 네이버 아이디로 가입하실 수 있습니다.

**스마트플레이스에서 광고 소재를 제작하셨나요?**

**소재 입력 항목**

| **항목** | **설명** |
| --- | --- |
| 클립 그룹 선택 | 해당 플레이스의 클립 그룹 목록에서 광고에 사용할 클립 그룹 선택 |
| 레이아웃 | 가로형(16:9) 세로형(9:16) 동영상 제작 |
| 클립 미리보기 | 선택한 클립 그룹의 동영상을 레이아웃에 맞춰 미리 확인 |

| **알아두세요.** 클립 그룹은 네이버 플레이스에서 등록합니다. 클립 그룹이 없는 경우 안내와 함께 플레이스 등록 링크가 표시됩니다. |
| --- |

| **참고.** 검수에는 2~5영업일이 소요될 수 있으며, 검수 완료 후 옥외 매체에 광고가 노출됩니다. |
| --- |

**지역 타겟팅**

디지털 옥외광고는 지역 타겟팅이 필수입니다. 광고를 노출할 지역을 동 단위로 설정할 수 있으며, 설정한 지역을 기준으로 옥외 광고 재생 기기가 설치된 장소에서만 광고가 노출됩니다.

디지털 옥외광고는 스마트플레이스에서 제작한 소재로 광고가 노출됩니다.

스마트플레이스에서 입력된 업체 정보를 바탕으로, 간편하게 디지털옥외광고 소재를 제작할 수 있습니다.
