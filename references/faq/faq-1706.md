# [AI작성] 디스플레이광고 시너지 보고서 목록 화면 안내

**시너지 보고서란**

브랜드서치 시너지 보고서는 디스플레이 광고의 네이버 검색 시너지 효과를 전달하는 보고서로, 디스플레이 광고에 노출된 사용자가 특정 키워드를 검색하거나 검색광고 상품을 클릭한 성과에 대해 확인하실 수 있습니다.

**진입 경로**

광고계정 선택 후 '보고서' > '시너지 보고서'에서 확인합니다. 브랜드서치 시너지 보고서는 'Beta'로 제공되며, 목록 화면에는 브랜드서치 시너지 분석이 가능한 캠페인이 표시됩니다.

**목록 구성**

목록에는 다음 항목이 컬럼으로 표시됩니다.

| **컬럼** | **설명** |
| --- | --- |
| 보고서명 | 해당 시너지 보고서의 이름입니다. |
| 캠페인 | 시너지 분석 대상 캠페인입니다. |
| 분석 기간 | 시너지 데이터의 분석 대상 기간입니다. |
| 상태 | 보고서의 현재 상태입니다. |

목록에서 원하는 캠페인 행을 클릭하면 해당 캠페인의 시너지 상세 보고서 화면으로 이동합니다.

**알아두세요.**

데이터를 불러오는 동안에는 목록 영역에 로딩 표시가 나타나며, 데이터 조회에 실패하면 오류 안내가 표시됩니다.

**참고.**

시너지 분석이 가능한 캠페인이 없는 경우 '시너지 분석 가능한 캠페인이 없습니다' 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
