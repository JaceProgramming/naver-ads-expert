# [AI작성] 브랜드/신제품검색 계약 관리 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 도구 > 브랜드/신제품검색 계약 관리\]에서 브랜드검색·신제품검색의 계약을 신청·관리합니다. 화면 상단의 안내 박스, 2개 탭, 계약 목록 표로 구성됩니다.

**화면 구성**

-   **안내 영역**: '브랜드 검색 계약이란?' 안내문이 표시되며 \[닫기\]로 숨길 수 있습니다.
    
-   브랜드 검색광고는 계약 기간 동안 정해진 광고비를 지불하는 정액제 상품입니다.
    
-   광고비는 1회에 최소 100만 원이며, 템플릿·광고 노출 기간 및 광고 가능한 키워드의 기간 조회수(최근 30일 조회수)를 합산해 책정됩니다.
    
-   광고 기간은 최소 7일에서 최대 90일까지 자유롭게 선택할 수 있습니다.
    
-   계약 종료 후 5년이 지난 계약은 자동 삭제됩니다.
    
-   **탭**: 브랜드 검색형 / 신제품 검색형 2개 탭이 제공됩니다.
    
-   **관리 버튼**: \[새 계약\], \[다운로드\], \[열 맞춤 설정\] (등록 일시 외 9개)
    
-   **브랜드 검색형 표 컬럼**: 계약 상태 / 관리 / 계약 이름 / 등록 일시 / 현재 연결 광고 그룹 / 계약 가능 검색수 / 키워드 검색수 / 계약 기간 / 계약 광고비 / 환급액 / 노출수 / 클릭수 / 클릭률(%)
    
-   **신제품 검색형 표 컬럼**: 계약 상태 / 계약 이름 / 관리 / 등록 일시 / 집행 회차 / 낙찰 발표일 / 현재 연결 광고 그룹 / 키워드 그룹 이름 / 계약 기간 / 입찰가 / 낙찰가 / 계약 광고비 / 환급액 / 노출수 / 클릭수 / 클릭률(%)
    
-   **계약 상태 예시**: 집행 전 취소 / 종료 / 입찰 중 취소 등
    

**알아두세요.**

브랜드검색은 정액제, 신제품검색은 입찰제 상품입니다. 계약을 체결하려면 검토가 통과된 소재와 키워드가 있어야 합니다.

**알아두세요.**

계약 종료 후 5년이 지나면 계약 정보가 자동으로 삭제되므로, 필요한 자료는 \[다운로드\]로 미리 보관해 주세요.

**참고.**

등록한 계약이 없으면 '등록한 계약이 없습니다.' 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
