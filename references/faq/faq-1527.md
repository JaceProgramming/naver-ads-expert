# [AI작성] 새 파워링크 소재를 만들려면 어떻게 하나요?

파워링크 광고그룹 상세의 '소재' 탭에서 \[새 소재\]를 클릭하면 소재 유형을 선택하고 광고 문안·URL·태그·이미지 등을 입력해 새 소재를 등록할 수 있습니다.

**소재 만들기 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 파워링크\]에서 광고그룹을 클릭해 상세로 이동합니다.
    
2.  '소재' 탭에서 \[새 소재\]를 클릭합니다.
    
3.  '소재 유형'을 선택하고 아래 입력 항목을 작성합니다.
    
4.  창 우측의 PC/모바일 미리보기로 노출 형태를 확인합니다.
    
5.  \[검토 요청\] 후 \[저장\]하면 소재가 등록되며, 검토가 완료되어야 광고가 노출됩니다.
    

**소재 유형**

| **유형** | **설명** |
| --- | --- |
| 단일형 소재 | 제목 1개와 설명 1개가 노출되는 광고입니다. |
| 반응형 소재 | 여러 개의 제목과 설명을 등록하면 시스템이 자동으로 조합해 노출하는 광고입니다. 제목은 3개 이상(최대 15개), 설명은 2개 이상(최대 4개) 입력해야 합니다. 의료(병의원) 업종은 반응형 소재를 등록할 수 없습니다. |
| 병의원 업종 특화 소재 | 병의원 광고주 전용으로 의료심의를 받은 소재가 노출되는 광고입니다. 의료 업종 비즈채널이 연결된 광고그룹에서만 선택할 수 있습니다. |

기본형 소재는 필수 등록 항목이며, \[이미지 확장형 등록\]으로 이미지 확장형을 추가할 수 있습니다. 기본형과 이미지 확장형이 모두 등록된 소재는 노출 상황에 따라 1개 유형만 노출됩니다.

**입력 항목**

| **항목** | **설명** |
| --- | --- |
| 사이트 이름 | 광고에 표시되는 사이트 이름을 10자 이내로 입력합니다. |
| 표시 URL / 연결 URL | PC·모바일별로 표시 URL과 클릭 시 이동할 연결 URL을 입력합니다. |
| 제목 | 광고 제목을 15자 이내로 입력합니다. 반응형 소재는 3개 이상(최대 15개) 등록합니다. |
| 설명 | 광고 설명을 20자 이상 45자 이내로 입력합니다. 반응형 소재는 2개 이상(최대 4개) 등록합니다. |
| 태그 | 3개를 필수 입력합니다. 각 태그는 3~6자이며 중복할 수 없고 등록 순서대로 노출됩니다. |
| 파비콘 (선택) | \[이미지 라이브러리에서 불러오기\] 또는 직접 업로드해 등록합니다. |
| 이미지 (선택) | 소재에 사용할 이미지를 등록합니다. \[이미지 확장형 등록\]으로 이미지 확장형을 추가할 수 있습니다. |
| 의료광고 심의필 번호 | 병의원 업종 특화 소재에서만 표시됩니다. 기본형·이미지 확장형 의료광고 심의필 번호(예: 의123445)를 입력합니다. |

**미리보기와 AI 추천**

소재 정보를 입력하면 창 우측에서 PC·모바일 노출 모습을 미리 확인할 수 있습니다. 반응형 소재를 만들 때 광고그룹에 등록된 키워드가 충분하면 AI 추천 영역이 표시되어, 추천된 제목·설명 중 원하는 항목을 선택해 추가하거나 불필요한 추천 카드를 삭제할 수 있습니다.

**알아두세요.**

-   소재 등록 후 검토가 완료되어야 광고가 노출됩니다.
    
-   선택한 소재 유형에 따라 입력 항목이 달라집니다.
    
-   병의원 업종 특화 소재는 의료 업종 채널 광고그룹에서만 노출되며, 의료(병의원) 업종은 반응형 소재를 등록할 수 없습니다.
    

**참고.**

AI 추천은 광고그룹에 등록된 키워드를 기반으로 제안됩니다. 키워드가 부족하면 추천 영역이 표시되지 않습니다.

**주의하세요.**

의료광고 소재를 등록할 때는 의료광고 심의필 번호를 입력하고 \[검토요청\]에서 심의필증 등 서류를 함께 제출해야 합니다. 심의를 받지 않았거나 심의 내용과 다른 의료광고 소재는 노출이 제한되며 광고주가 법적 책임을 지게 될 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
