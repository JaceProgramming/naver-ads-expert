# [AI작성] 참여 유도 캠페인도 예산 최적화(CBO)를 사용할 수 있나요?

네, 참여 유도 캠페인은 캠페인 예산 최적화(CBO)를 지원합니다. 광고주님께서 캠페인 만들기 화면에서 예산 최적화를 활성화하시면, 캠페인 예산이 하위 광고그룹별로 자동 분배됩니다.

**참여 유도 캠페인의 예산 최적화 지원**

디스플레이광고 목적 중 일부는 예산 최적화를 지원하지 않지만, 참여 유도는 지원 대상에 포함됩니다. 따라서 참여 유도 캠페인 만들기 화면에는 예산 최적화 설정 카드가 노출됩니다.

| **구분** | **내용** |
| --- | --- |
| 지원 여부 | 참여 유도 캠페인은 예산 최적화(CBO)를 지원합니다. |
| 기본 상태 | 새 캠페인을 만들 때 예산 최적화는 기본적으로 꺼져 있습니다. |
| 활성화 시 | 활성화하면 캠페인 예산이 광고그룹별로 자동 분배되며, 입찰 전략과 입찰 목표를 함께 설정합니다. |

**참고.**

예산 최적화의 구체적인 설정 절차(켜기/끄기, 입찰 전략·입찰 목표 선택)는 모든 디스플레이광고 목적이 동일하므로, '디스플레이광고 캠페인 예산 최적화(CBO)를 설정하려면 어떻게 하나요?' 도움말을 참고해 주시기 바랍니다.
