# [AI작성] 디스플레이광고 여러 광고그룹을 한 번에 관리하려면 어떻게 하나요?

**적용 대상:** 디스플레이광고(웹사이트 전환·앱 전환·인지도 및 트래픽·동영상 조회·카탈로그 판매·쇼핑 프로모션·참여 유도)

캠페인 상세 화면의 광고그룹 목록에서 여러 광고그룹을 선택하면, 일괄로 켜고 끄거나 삭제할 수 있습니다.

**일괄 ON/OFF·삭제**

1.  캠페인 상세 화면의 광고그룹 목록에서 관리할 광고그룹을 1개 이상 선택합니다.
    
2.  1개 이상 선택하면 하단에 일괄 작업 버튼이 나타납니다.
    
3.  원하는 작업을 실행합니다.
    

| **버튼** | **동작** |
| --- | --- |
| \[ON\] | 선택한 광고그룹을 일괄 활성화합니다. |
| \[OFF\] | 선택한 광고그룹을 일괄 일시정지합니다. |
| \[삭제\] | 선택한 광고그룹을 일괄 삭제합니다. 삭제 전 확인 안내가 표시됩니다. |
| \[다운로드\] | 선택한 광고그룹을 파일로 내려받습니다. |
| \[닫기\] | 선택을 해제하고 일괄 작업 영역을 닫습니다. |

**참고.**

삭제된 광고그룹이 포함되어 있으면 해당 광고그룹은 일괄 작업에서 제외됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
