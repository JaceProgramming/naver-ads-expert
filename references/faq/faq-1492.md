# 디스플레이광고 노출 빈도 ‘자동’과 ‘상세(상한)’ 설정은 무엇이 다른가요?

자동 설정은 효율이 높아지는 방향으로 별도 상한 없이 동작하는 개념이며,

수동(상세) 설정은 상한선을 두는 형태로 최대 노출 횟수 제한 방향으로 동작할 수 있습니다.

상한을 두고 싶지 않다면 자동, 상한이 필요하면 수동(상세)을 활용해 주세요.
