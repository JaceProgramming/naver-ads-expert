# [AI작성] 관리 계정 권한 관리 화면은 어떻게 구성되어 있나요?

권한 관리에서는 관리 계정의 회원 권한과 계정 연동을 조회·관리할 수 있습니다. 로그인 후 관리 계정을 선택하고 좌측 메뉴에서 설정 > '권한 관리'를 선택해 진입합니다.

**탭 구성**

화면은 다음 세 개의 탭으로 구성됩니다.

| **탭** | **설명** |
| --- | --- |
| 회원 관리 | 관리 계정 회원의 권한을 관리합니다. 하위에 '권한 받은 회원'·'초대 중인 회원' 탭이 있습니다. |
| 광고 계정 연동 | 관리 계정에 연동된 광고 계정을 관리합니다. |
| 관리 계정 연동 | 상위·하위 관리 계정 연동을 관리합니다. |

**회원 목록 컬럼**

회원 관리 탭의 목록은 다음 5개 컬럼으로 구성되며, 상단에 '권한 받은 회원 N' 카운터와 \[회원 초대\] 버튼이 표시됩니다.

| **컬럼** | **설명** |
| --- | --- |
| 회원 ID | 회원의 네이버 ID입니다. 본인 행에는 '본인' 표시가 부착됩니다. |
| 권한 레벨 | '계정 책임자', '운영 관리', '운영 조회' 중 하나로 표시됩니다. |
| 가입 일자 | 회원이 관리 계정에 등록된 일자입니다. |
| 회원 상태 | 회원의 상태입니다. |
| 관리 | 권한 레벨에 따라 \[권한 이전\], \[권한 수정\], \[권한 해제\] 등 액션이 표시됩니다. |

**알아두세요.**

\[회원 초대\], \[권한 이전\] 등 책임자 전용 액션은 계정 책임자가 아닌 회원에게는 표시되지 않거나 비활성화됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
