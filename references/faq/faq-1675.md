# [AI작성] 직접 입력형 비즈채널(웹사이트·전화번호·콘텐츠)을 등록하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 구성요소 관리 > 비즈채널\]에서 \[비즈채널 생성\]을 클릭하면 비즈채널 유형 선택 영역이 표시됩니다. 직접 입력형 유형(웹사이트·전화번호·콘텐츠)을 선택해 정보를 입력하고 등록합니다.

**비즈채널 유형 (11종)**

웹사이트 / 쇼핑몰 / 콘텐츠 / 전화번호 / 네이버 톡톡 / 네이버 예약 / 쇼핑 제조사 / 플레이스 / 네이버 TV / 브랜드스토어(브랜드존) / 쇼핑검색(브랜드형)

**웹사이트 등록 (직접 입력)**

1.  \[비즈채널 생성\] > \[웹사이트\] 선택
    
2.  '비즈채널 생성 : 웹사이트' 창 입력
    

-   비즈채널 이름 (필수, 30자)
    
-   사이트 이름 (필수, 10자) — 노출가능 영역, 신중히 입력
    
-   URL (필수, https://)
    
-   '등록하시는 비즈채널이 성인사이트 혹은 비회원은 이용할 수 없는 회원전용 사이트입니까?' — 네/아니오
    

1.  \[저장 후 닫기\]
    

**전화번호 등록**

1.  \[비즈채널 생성\] > \[전화번호\] 선택
    
2.  '비즈채널 생성 : 전화번호' 창 입력
    

-   비즈채널 이름 (필수, 30자)
    
-   전화번호 — 02 등 지역번호 포함
    

1.  주의사항 확인 후 '위 내용을 모두 읽고 확인했습니다.' 선택 항목 선택
    
2.  \[저장 후 닫기\]
    

**콘텐츠 등록**

1.  \[비즈채널 생성\] > \[콘텐츠\] 선택
    
2.  '비즈채널 생성 : 콘텐츠' 창 입력
    

-   비즈채널 이름 (필수, 30자)
    
-   **URL 소유 확인** (필수) — '등록하신 URL이 직접 운영하는 본인 또는 광고를 집행할 업체 소유의 블로그(또는 카페) 인가요?' '네, 직접 운영하는 URL입니다.' / '아니요, 제3자(창작자) 제공의 URL입니다.'
    
-   **URL** (필수) — 블로그 / 카페 https://
    
-   **업체 URL** (필수) — https://
    

1.  안내: '등록한 URL은 수정할 수 없습니다. 선택한 광고 그룹 유형과 입력한 URL을 반드시 확인한 다음 등록해 주세요.'
    
2.  \[저장 후 닫기\]
    

**주의하세요.**

전화번호는 등록 후 수정이 불가능하며, 수정이 필요한 경우 삭제 후 재등록해야 합니다. 콘텐츠 비즈채널의 URL은 등록 후 수정이 불가능합니다. 사이트 이름·URL은 노출가능 영역이므로 광고품질이 낮거나 부적절한 사이트 이름은 노출제어될 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
