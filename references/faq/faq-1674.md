# [AI작성] 검색광고 비즈채널 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 구성요소 관리 > 비즈채널\]에서 광고에 사용할 비즈채널을 등록·관리합니다. 비즈채널은 웹사이트·쇼핑몰·전화번호·네이버 예약 등 잠재 고객에게 상품 정보를 전달하고 판매하기 위한 모든 채널을 의미합니다.

**목록 구성**

비즈채널 목록은 다음 항목으로 구성됩니다.

| **항목** | **설명** |
| --- | --- |
| 채널 유형 | 웹사이트·쇼핑몰·전화번호 등 비즈채널의 유형입니다. |
| 채널 정보 | 유형에 따라 URL·전화번호·플레이스 주소 등 채널 정보가 표시됩니다. |
| 상태 | 운영 가능 / 검토중 / 노출제한 / 노출제한(연결안됨) 등 검토·노출 상태가 표시되며, 일부 유형은 PC·모바일 노출 가능 여부가 함께 표시됩니다. |
| 비즈채널 ID | 비즈채널의 고유 식별 번호입니다. |

\[열 맞춤 설정\]에서 목록에 표시할 컬럼을 조정할 수 있습니다.

**채널 유형 (11종)**

비즈채널은 다음 11종 중에서 선택해 등록합니다.

-   웹사이트 / 쇼핑몰 / 콘텐츠 / 전화번호 / 네이버 톡톡 / 네이버 예약 / 쇼핑 제조사 / 플레이스 / 네이버 TV / 브랜드스토어(브랜드존) / 쇼핑검색(브랜드형)
    

**주요 기능**

-   **비즈채널 생성**: \[비즈채널 생성\]을 클릭하고 유형을 선택하면 유형별 등록 화면이 열립니다.
    
-   **다운로드**: \[다운로드\]로 비즈채널 목록을 내려받습니다.
    
-   **안내 영역**: '비즈채널이란?' 안내문과 도움말 링크가 표시되며 \[닫기\]로 숨길 수 있습니다.
    

**알아두세요.**

광고를 집행하려면 캠페인 유형에 맞는 비즈채널을 반드시 등록해야 합니다. 비즈채널은 확장 소재의 구성요소로도 활용할 수 있으며, 등록 후 확장 소재 탭에서 노출 여부를 선택할 수 있습니다.

**참고.**

비즈채널을 삭제하려면 해당 채널을 사용 중인 캠페인이 없어야 합니다. 사용 중이면 삭제가 제한되니 캠페인을 먼저 정리해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
