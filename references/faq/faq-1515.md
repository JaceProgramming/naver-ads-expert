# [AI작성] 상품 그룹을 등록하거나 수정하려면 어떻게 하나요?

쇼핑검색 광고그룹 상세 화면에서 상품 탭의 \[새 상품\]을 클릭하면 상품 그룹을 등록하거나 수정할 수 있습니다.

**알아두세요.**

이 기능은 쇼핑 브랜드 유형의 광고그룹에서만 사용할 수 있습니다.

**상품 그룹 등록 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 쇼핑검색\]에서 캠페인 > 광고그룹 상세의 상품 탭으로 이동합니다.
    
2.  \[새 상품\]을 클릭합니다.
    
3.  브랜드 정보를 확인합니다. 광고그룹에 등록된 브랜드가 자동으로 표시됩니다.
    
4.  등록 방식을 선택합니다.
    
5.  제품을 추가한 후 상품 그룹 이름을 입력합니다.
    
6.  \[등록\]을 클릭합니다.
    

**등록 방식**

| **방식** | **설명** |
| --- | --- |
| 카테고리 기반 | 카테고리를 선택하면 해당 카테고리에 속한 제품이 자동으로 추가됩니다. |
| 개별 제품 선택 | 제품을 검색하여 원하는 제품을 개별적으로 선택합니다. |

**입력 규칙**

| **항목** | **규칙** |
| --- | --- |
| 상품 그룹 이름 | 1자 이상 30자 이하. 동일한 이름의 상품 그룹이 이미 존재하면 등록이 거부됩니다. |
| 제품 | 1개 이상의 제품이 선택되어야 합니다. |
| 브랜드 | 광고그룹에 등록된 브랜드가 필요합니다. |

**참고.**

수정 시에도 동일한 화면에서 상품 그룹 이름, 등록 방식, 포함 제품 등을 변경할 수 있습니다.

**여러 광고그룹에 연결된 상품 그룹 수정**

같은 상품 그룹이 2개 이상의 광고그룹에 연결되어 있는 상태에서 \[수정\]하면, 변경 사항을 어떻게 적용할지 선택하는 창이 나타납니다. 다음 중 하나를 선택할 수 있습니다.

| **선택** | **설명** |
| --- | --- |
| 연결된 모든 광고그룹에 적용 | 해당 상품 그룹이 연결된 모든 광고그룹에 변경 사항이 동일하게 반영됩니다. |
| 현재 광고그룹에만 사본으로 적용 | 현재 광고그룹에만 변경 사항이 반영된 사본이 만들어지고, 다른 광고그룹의 상품 그룹은 그대로 유지됩니다. |

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
