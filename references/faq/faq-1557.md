# [AI작성] 검색광고 즐겨찾기 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 광고 관리 > 즐겨찾기\]에서 즐겨찾기에 추가한 광고 정보를 한 곳에서 조회·관리할 수 있습니다. 좌측 LNB에 즐겨찾기 그룹별로 화면이 구성됩니다.

**화면 구성**

-   **즐겨찾기 그룹 LNB**: 사용자가 만든 즐겨찾기 그룹(예: 즐겨찾기-1) 목록을 표시합니다. 그룹을 클릭하면 해당 그룹에 포함된 광고 정보가 표시됩니다.
    
-   그룹 컨텍스트 메뉴: 그룹 옆 아이콘으로 \[그룹 만들기\] / \[그룹 이름 수정\] 가능
    
-   **광고 정보 탭**: 광고그룹 / 소재 / 키워드 / 확장 소재 4개 탭으로 구성되며, 탭별 즐겨찾기 등록 개수가 함께 표시됩니다 (예: 광고그룹(9) / 소재(6) / 키워드(5) / 확장 소재(3)).
    
-   **조회 기간 선택 영역**: 화면 상단에서 데이터 조회 기간을 선택합니다.
    
-   **관리 버튼**: 선택한 \[광고그룹/소재/키워드/확장 소재\] 관리 / 대량관리(확장소재) / 다운로드 / 열 맞춤 설정 / 상세 데이터
    
-   **광고 정보 표**: 탭별 컬럼 구성 (ON/OFF, 캠페인 이름, 광고그룹 이름, 상태, 노출수, 클릭수, 클릭률(%), 평균 CPC, 총비용 등)으로 즐겨찾기에 추가한 광고 정보를 표시합니다. 필터·페이지네이션 지원.
    
-   **빈 상태**: 즐겨찾기 등록 항목이 없을 때 '즐겨찾기로 등록한 {탭명}이 없습니다.' 메시지가 표시됩니다.
    

**알아두세요.**

광고그룹·소재·키워드·확장 소재 목록 화면에서 \[선택한 '광고그룹·소재·키워드·확장 소재' 관리\]에서 '즐겨찾기' 클릭하면 항목을 즐겨찾기에 추가/해제할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
