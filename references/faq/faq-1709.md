# [AI작성] 디스플레이광고 시너지 차트를 확인하려면 어떻게 하나요?

**시너지 차트 보는 방법**

조회를 실행하여 데이터가 존재하면 시너지 상세 보고서 화면 중단에 시너지 차트가 표시됩니다. 시너지 차트는 디스플레이광고 지표와 브랜드서치 지표를 함께 보여주는 양축 시계열 선 차트로, 두 영역 간의 상관관계를 직관적으로 파악할 수 있습니다.

**차트 구성**

-   좌측 축에는 디스플레이광고 지표(노출수·클릭수 등)가 표시됩니다.
    
-   우측 축에는 브랜드서치 지표(추가검색 등)가 독립된 기준으로 표시됩니다.
    
-   일별 데이터 포인트가 선으로 연결되어 기간별 추이를 나타냅니다.
    
-   차트의 데이터 지점에 마우스를 올리면 해당 날짜의 양축 지표값을 확인할 수 있습니다.
    

**지표 표시 전환**

차트 하단의 범례에는 지표별 색상과 이름이 표시됩니다. 범례의 항목을 선택하면 해당 지표의 차트 선을 표시하거나 숨길 수 있어, 원하는 지표만 비교해 볼 수 있습니다.

**알아두세요.**

데이터를 불러오는 동안에는 차트 영역에 로딩 표시가 나타나며, 조회에 실패하면 오류 안내가 표시됩니다.

**참고.**

조회 결과 데이터가 없으면 차트와 범례 대신 '조회 결과가 없습니다' 안내가 표시됩니다. 이 경우 기간이나 캠페인 조건을 변경하여 다시 조회해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
