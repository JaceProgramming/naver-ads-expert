# 대량 데이터를 다운로드/추가/삭제/변경하는 기능이 있나요?

키워드, 제외 검색어, 소재를 대량으로 등록하거나 키워드의 입찰가, URL, ON/OFF 상태를 대량으로 변경하는 경우 \[도구 > 대량 관리\] 메뉴를 이용하여 보다 편리하게 작업을 진행할 수 있습니다.

---

**광고 다운로드**

대량 관리 작업을 시작하기 전 먼저 광고 다운로드 통해 대량 작업 필요한 광고 그룹 ID와 키워드 ID를 확인합니다.

**참고.**

광고그룹ID와 키워드ID 정보는 광고그룹과 키워드 관리 페이지에서 확인 가능합니다.

\[열 맞춤 설정\]에서 '광고그룹ID', '키워드ID' 항목을 설정하면 관리 페이지에서 정보를 확인할 수 있습니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMjMx/MDAxNzc0OTE4NTIwNjg0.1sXHHV8vfg27YjYjPE1Y5lA3m7s--zST5JV7JSNKVoMg.HeXz3jyghgsPGTP19ecIv_z-qPth3jFWjkFIvAYduZkg.PNG/image.png)

1\. 다운로드하고자 하는 캠페인을 선택한 후 \[다운로드\] 버튼을 클릭합니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfNjQg/MDAxNzc0OTE4NTMwODA1.X9WC5EVcAlu3APwCyXZgLO7PNHYHaBysAV9VBYu3Z6Qg.hBW66CjCoIsq22rt9dSNa9MPi-a9jxljv3sjGiFyDHMg.PNG/image.png)

2\. \[대량 작업 신청 목록\]에서 작업 내역 및 작업상태를 확인할 수 있습니다.

3\. 작업 상태가 \[대기중\]인 경우에는 해당 작업을 취소할 수 있습니다. 작업 상태가 \[완료\]인 경우에는 파일을 다운로드할 수 있습니다. 목록 위의 \[새로 고침\] 버튼을 클릭하면 업데이트된 작업 상태를 확인할 수 있습니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMTk4/MDAxNzc0OTE4NTQxMzUz.jR8Dzs4ZpRiXTaCTNt2828hx6bnbnR3kZ5R7ENl77NAg.zIgYg7TzctYVLqGrLw5wivcyKsvxUYDCE1pCbCzNyxkg.PNG/image.png)

**대량 등록/수정/삭제**

작업 유형에 맞는 템플릿을 사용하여 등록 또는 변경할 내용을 정리한 후 파일을 업로드합니다.

캠페인 유형에 따라 제공되는 대량 등록/수정/삭제 기능이 다릅니다.

1\. 작업 유형을 선택한 후 \[템플릿 다운로드\] 버튼을 클릭하여 템플릿을 다운로드합니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMTMx/MDAxNzc0OTE4NTUwODQ2.o_BRNGQomYgLhyQs5yyZBppnYbGpRfZkkW-gJv-T6sMg.7ODCr6yFbloPerz5hliyTPHaHG31v4WAVd2WW6SR3d4g.PNG/image.png)

2\. 작업 유형에 맞는 템플릿을 사용하여 대량으로 작업할 내용을 작성합니다.

| **참고.** 작업유형별 사용 템플릿<br>• 키워드 등록 : ko\_add\_keyword\_template<br>• 키워드 입찰가 수정 : ko\_edit\_keyword\_bid\_template<br>• 키워드 URL 수정 : ko\_edit\_keyword\_url\_template<br>• 키워드 On-Off 수정 : ko\_edit\_keyword\_onoff\_template<br>• 제외 검색어 등록 : ko\_add\_negative\_search\_term<br>• 반응형 소재 등록 : ko\_add\_rsa\_ad\_template<br>• 단일형 소재 등록 : ko\_add\_ad\_template<br>• 키워드 견적 : ko\_keyword\_estimate\_template<br>• 소재 On-Off 수정 : ko\_edit\_ad\_onoff\_template<br>• 애셋 삭제: ko\_delete\_asset\_template |
| --- |

**주의하세요.**

-   -   템플릿에 기재할 광고그룹 ID와 키워드 ID는 '광고 다운로드' 작업을 통해 확인할 수 있습니다.
        
    -   템플릿에 기재할 애셋 ID는 '애셋 삭제' 작업유형을 선택하면 노출되는 '애셋 전체 다운로드' 를 통해 확인할 수 있습니다.
        
    -   업로드 할 파일의 7행 부터의 입력값이 시스템에 반영되므로, 템플릿에서 1~6행을 삭제해서는 안됩니다.
        
    -   키워드 대량 등록 및 수정은 한 번에 최대 1만 개까지 가능합니다.
        
    -   키워드 입찰가 변경 시 입찰가는 '키워드 입찰가'로 저장되며, '기본 입찰가'가 있더라도 변경된 '키워드 입찰가'로 광고가 진행됩니다.
        
    -   키워드 입찰가는 쉼표나 '원' 표시를 제외하고 숫자만 입력해야 합니다.
        
    -   키워드 URL 수정 시 광고그룹의 웹사이트 URL이 1개이면 PC URL과 모바일 URL에 동일한 URL을 2번 입력해야 합니다.
        
    -   제외 검색어 대량 등록은 동일한 광고그룹 ID 당 '일치(유사검색어)' 유형 최대 50개, '확장검색' 유형 최대 950개까지 입력 가능합니다.
        
    -   광고그룹의 유형 당 등록 가능한 제외 검색어 개수는 이미 등록된 제외 검색어의 수까지 포함하며, 입력한 순서대로 제외 검색어 등록에 반영됩니다. (ex. 광고그룹에 기존 50개의 '확장검색' 유형 제외 검색어 등록, 동일 광고그룹에 '확장검색' 유형 제외 검색어 950개 입력하여 업로드 시, 상위 900개 제외 검색어 등록 성공, 초과 50개 제외 검색어 등록 실패)
        
    -   제외 검색어 대량 등록에 있어 '유형'은 일치(유사검색어)(1), 확장검색(2)로, 괄호 안 숫자만을 입력해주시길 바랍니다.
        
    -   파워링크 소재 등록 시 광고그룹에 이미 소재가 등록되어 있으면 새로 등록하는 소재 중 일부는 등록되지 않을 수 있습니다. 한 광고 그룹당 등록 가능한 소재 유형별 최대 개수는 단일형 5개, 반응형 3개 입니다.
        

3\. 작업 이름을 입력한 후, 파일 업로드에서 \[찾아보기\] 버튼을 클릭하여 업로드할 파일을 선택합니다.

**주의하세요.**

\- CSV 형식의 파일만 업로드할 수 있습니다.

\- 파일 선택 후 \[등록하기\] 버튼을 클릭하면 하단 \[대량 작업 신청 목록\]에서 신청 내용 및 작업 상태를 확인할 수 있습니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMjIw/MDAxNzc0OTE4NTYyNjIz.FOY6N5yejs1nfsMcvm4eciCcFfRT8wfsKuxiK2B7jpIg.1P7JGmR9hjzQKtnrhwqeg-QISXv9H5PIeaB46yHlM4Yg.PNG/image.png)

\- 작업 상태가 \[대기중\]인 경우에는 해당 작업을 취소할 수 있습니다. 작업 상태가 \[완료\]인 경우에는 파일을 다운로드할 수 있습니다. 목록 오른쪽 위의 \[새로고침\] 버튼을 클릭하면 업데이트 된 작업상태를 확인할 수 있습니다. 작업이 완료된 경우 성공 건수와 실패 건수가 표시됩니다.

**대량 광고 그룹 복사**

1.  복사하고자 하는 캠페인의 광고그룹을 선택합니다.
    
2.  광고그룹의 키워드, 소재도 함께 복사할 지 선택한 후 복사할 캠페인을 선택합니다.(여러 캠페인 선택 가능, 총 100개까지 복사)
    
3.  \[대량 복사하기\] 버튼을 클릭합니다.
    

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMjEy/MDAxNzc0OTE4NTkxMzEy.PKYNvZK1uH7Enlgi8WRM0hqD87dIDnlVzl76S9R2-wkg.1QRUiZ7cLiIz4p6S1uCgPv9KqjR97mGnc8p43iTiSeog.PNG/image.png)

**주의하세요.**

\- 광고그룹의 모든 정보(기본 입찰가, 매체, 지역설정 등)가 함께 복사됩니다.

\- 복사할 광고그룹의 개수가 복사되는 캠페인에 등록할 수 있는 광고그룹 개수보다 많으면 등록 가능한 만큼의 광고그룹만 복사되고 나머지는 실패로 처리 됩니다. (예: 캠페인 내 등록 가능 광고그룹 수가 30개일 경우, 50개의 광고그룹을 복사하면 목록 상위의 30개만 등록하고 나머지는 실패)

\- 광고그룹의 키워드를 포함하여 등록하는 경우, 등록 제한 개수를(캠페인당 키워드 10만 개)를 초과하면 해당 그룹은 생성되지 않습니다.

\- 복사된 광고그룹이 다른 광고그룹과 구별되도록 복사된 광고그룹 이름 뒤에 임의의 번호가 자동으로 입력됩니다. (광고그룹 이름은 광고관리 화면에서 수정할 수 있습니다.)
