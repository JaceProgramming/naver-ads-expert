# [AI작성] 등록한 IP의 노출제한을 해제(삭제)하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 도구 > 광고 노출제한 관리\]의 '관리목록' 표에서 해제할 IP를 선택해 삭제합니다. 삭제한 IP는 더 이상 광고 노출이 제한되지 않습니다.

**삭제 절차**

1.  \[광고주센터 > 검색광고 > 도구 > 광고 노출제한 관리\]에 진입합니다.
    
2.  화면 하단의 '관리목록 (등록수/600)' 표에서 해제할 IP를 선택합니다.
    
3.  표 상단의 삭제 버튼을 클릭합니다.
    
4.  확인 창에서 삭제를 확정합니다.
    

**알아두세요.**

삭제한 IP는 즉시 광고 노출제한에서 해제되며, 이후 해당 IP에서 광고가 정상 노출되고 클릭 시 과금됩니다. 등록한 데이터가 없을 때에는 표에 '등록한 데이터가 없습니다.' 메시지가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
