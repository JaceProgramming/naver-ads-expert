# [AI작성] 디스플레이광고 캠페인 목적을 선택하려면 어떻게 하나요?

**적용 대상:** 웹사이트 전환 · 앱 전환 · 인지도 및 트래픽 · 동영상 조회 · ADVoost 쇼핑 · 카탈로그 판매 · 쇼핑 프로모션 · 참여 유도 (디스플레이광고 전 유형)

캠페인 목적은 광고를 본 사람들에게 유도하고자 하는 행동이며, 목적에 따라 옵션이 다르게 제공될 수 있습니다. 캠페인 만들기의 첫 단계에서 목적을 선택합니다.

**선택할 수 있는 캠페인 목적**

| **목적** | **설명** |
| --- | --- |
| 웹사이트 전환 | 웹사이트 내 전환 행동 유도. 전환 또는 전환 매출을 발생시킬 가능성이 높은 사용자에게 광고를 노출합니다. |
| 앱 전환 | 앱 설치 및 앱 내 전환 행동 유도. 앱 설치 또는 구매 전환 가능성이 높은 사용자에게 광고를 노출합니다. |
| 인지도 및 트래픽 | 웹사이트·앱 방문을 최대화하기 위해 광고 이미지를 노출합니다. |
| 동영상 조회 | 동영상을 네이버의 다양한 영역에 노출해 더 많은 조회를 유도합니다. |
| ADVoost 쇼핑 | 최적의 유저와 지면에 상품을 자동 노출시켜 판매 성과를 극대화합니다. |
| 카탈로그 판매 | 카탈로그 제품 판매 유도. 내 제품에 반응한 사용자의 구매 전환을 최대화합니다. |
| 쇼핑 프로모션 | 스토어의 프로모션·혜택 소식을 네이버 쇼핑 영역 등에 노출합니다. |
| 참여 유도 | 타겟의 설문 참여를 유도합니다. |

**알아두세요.**

캠페인을 수정할 때는 캠페인 목적을 변경할 수 없습니다.

**주의하세요.**

캠페인 목적을 선택하지 않으면 \[다음\]으로 진행할 수 없습니다. 목적을 선택하지 않은 경우 '캠페인 목표를 선택해 주세요'라는 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
