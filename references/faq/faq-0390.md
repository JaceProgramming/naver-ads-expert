# 파워링크 성인사이트 가이드

**주의하세요.**

외국 사업자의 성인 사이트는 광고가 불가합니다.

국내 사업자의 성인 사이트는 광고할 수 있습니다.

단, 성인 사이트는 청소년유해매체물 표시와 청소년 접근 제한 조치(성인 인증)를 통해 청소년의 접근을 제한해야 합니다.

만약 일부 메뉴 및 카테고리에서만 성인 콘텐츠를 제공한다면 해당 메뉴 및 카테고리에 대해 청소년유해매체물 표시와 청소년 접근 제한 조치를 해야 하며, 성인 콘텐츠를 홍보하는 내용이 성인 인증 이전에 노출되어서는 안됩니다.

청소년유해매체물 표시 및 청소년 접근 제한 조치와 관련된 자세한 가이드는 [여기](https://ads.naver.com/adguide/282)에서 확인할 수 있습니다.

네이버 검색광고에서는 다음과 같은 사이트를 성인 사이트로 보며, 성인 사이트는 사이트에서 제공하는 모든 콘텐츠를 확인할 수 있도록 비즈채널 등록 시 ‘테스트계정의 아이디와 비밀번호'를 제공해야 합니다.

1.  청소년유해매체물로 고시된 사이트
    
    -   청소년유해물건 목록에 등록된 성기구(5종)를 판매 또는 대여하는 사이트(고시 제2000-31호)
        
    -   게임아이템의 거래를 소개, 알선, 중개, 매개하는 사이트(고시 제2009-24호)
        
2.  네이버 검색광고가 성인 사이트로 판단한 사이트
    
    -   성인 동영상 제공 사이트
        
    -   유흥업소 홍보 사이트
        
    -   콘돔 판매 사이트
        
    -   전자담배 기기장치류 관련 사이트(고시 제2011-57호)
        
    -   기타 청소년에게 유해하다고 판단하여 공지한 사이트
        
3.  자율적으로 청소년유해매체물 표시를 한 사이트
    

**주의하세요.**

자위 기구와 관련된 내용이 사이트의 메인 페이지 또는 광고의 랜딩 페이지에서 확인되는 경우 광고가 제한됩니다.
