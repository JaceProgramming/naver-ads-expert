# 검색광고에 더 많은 정보를 노출하려면 어떻게 해야 하나요?

혹시 다른 광고에는 나오는데, 내 광고에는 안 나왔던 문구, 이미지가 있을 경우 기본 소재 뿐 아니라, 확장소재를 추가할 수 있습니다.

대표적으로 많이 등록하는 확장소재를 알려드립니다.
