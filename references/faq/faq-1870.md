# [AI작성] ADVoost 쇼핑 캠페인의 추적 URL과 부스트 업을 설정하려면 어떻게 하나요?

ADVoost 쇼핑 캠페인의 추가 설정에서는 광고 성과 분석을 위한 추적 URL을 설정할 수 있습니다. 광고 노출 영역을 넓히는 부스트 업은 캠페인 설정 안의 옵션이 아니라 별도 캠페인으로 자동 제공됩니다. 추적 URL은 ADVoost 쇼핑과 카탈로그 판매 유형에서만 제공됩니다.

**추적 URL**

랜딩 URL에 개별 광고 성과 분석을 위한 파라미터를 추가하여, 클릭된 광고에 대한 정보를 제공합니다. 다음 4가지 방식 중 하나를 선택합니다.

| **옵션** | **설명** |
| --- | --- |
| 설정하지 않음 | 추적 URL을 사용하지 않습니다. |
| 파라미터 등록 | 랜딩 URL에 추가할 파라미터를 등록합니다. |
| URL 등록 | 추적용 URL을 직접 등록합니다. |
| URL 파라미터 값 변경 | URL의 파라미터 값을 변경합니다. |

**추적 URL 설정 순서**

1.  캠페인 추가 설정 영역을 펼칩니다.
    
2.  추적 URL 방식을 선택하고 필요한 값을 입력합니다.
    

**부스트 업**

부스트 업은 기본 게재 위치 외에 확장된 광고 영역까지 ADVoost 쇼핑 광고를 노출하는 기능입니다. ADVoost 쇼핑 캠페인 설정 안의 옵션이 아니라, ADVoost 쇼핑 캠페인과 1:1로 자동 생성되는 별도의 부스트 업 캠페인으로 제공됩니다. 광고 노출 여부는 부스트 업 캠페인 자체의 ON/OFF로 제어합니다.

**알아두세요.**

부스트 업 캠페인은 ADVoost 쇼핑 캠페인을 만들면 자동으로 함께 생성되며, 전환 추적 대상·입찰·예산·기간 등은 수정할 수 없는 고정값으로 운영됩니다.

**주의하세요.**

추가된 파라미터의 영향으로 랜딩 오류가 발생할 수 있으니, 정상적으로 동작 되는지 반드시 테스트하시기 바랍니다.
