# 초대 받은 광고 계정은 어디서 확인하나요?

초대받은 회원은 이메일의 초대 링크 또는 \[광고주센터 > 광고 계정 관리\] 메뉴에서 '초대 받은 광고 계정' 탭에서 요청을 확인하고 승인 또는 거절할 수 있습니다.

**목록 컬럼 안내**

| **컬럼** | **설명** |
| --- | --- |
| 광고계정(ID) | 초대한 광고 계정 이름과 ID |
| 권한 레벨 | 초대 시 부여된 권한 ('운영 관리' / '운영 조회') |
| 초대 일자 | 초대받은 날짜 |
| 관리 | \[승인\] / \[거절\] 버튼 |

| **알아두세요.** 받은 초대가 없으면 "초대받은 광고 계정이 없습니다." 메시지가 표시됩니다. |
| --- |

초대받은 멤버가 권한 요청을 승인해야 최종적으로 권한이 부여됩니다.
