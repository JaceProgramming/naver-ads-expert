# 검색광고 비즈채널은 어떻게 추가하나요?

비즈채널을 추가하는 방법 및 계정당 추가할 수 있는 비즈채널 개수 한도에 대해 알아봅니다.

---

**비즈채널 추가하기**

비즈채널의 추가는 \[네이버광고주센터 > 검색광고\]의 ‘구성요소 관리 > 비즈채널’\] 메뉴에서 \[+채널 추가\] 드롭다운 목록 상자를 클릭하여 진행합니다.

**웹사이트 채널 추가하기**

1\. \[+채널 추가\] 드롭다운 목록 상자에서 '웹 사이트'를 클릭합니다.

2\. '비즈채널 추가(웹사이트)' 대화 상자에서 웹 사이트의 이름을 입력합니다.

3\. 웹 사이트의 URL을 입력합니다. URL 입력 시 먼저 프로토콜(http:// 혹은 https://)을 선택합니다.

**주의하세요.**

이미 등록된 URL은 중복으로 처리되어 등록이 불가합니다. 프로토콜 구분없이 URL이 동일하면 중복된 URL로 처리됩니다.

4\. 테스트 계정을 입력합니다. 테스트 계정은 회원제로 운영되는 사이트 또는 성인 사이트의 경우에 입력하며, 사이트 검토 시 내부 콘텐츠를 확인하는 용도로 사용됩니다.

**주의하세요.**

회원제 사이트 또는 성인 사이트 추가 시 테스트 계정을 입력하지 않는 경우 웹 사이트 검토가 지연될 수 있습니다.

**참고.** 웹 사이트 이미지 수집 방식

웹 사이트의 채널 정보에 노출되는 이미지는 비즈채널 등록 시 시스템이 자동으로 캡처하여 수집하며(3 영업일 이내), 이후 일정 주기로 자동으로 캡처합니다.

해당 이미지는 광고 더보기 영역, 쇼핑몰 키워드 검색 결과의 미리보기 등에서 사용됩니다.

소정의 검토가 완료된 이미지만 노출이 가능하며, 사이트 이미지 검토 결과에 대해서는 별도로 안내하지 않습니다. 또한 이미지는 임의로 수정할 수 없습니다.

이미지가 검토 전이거나 수집되지 않은 경우 혹은 검토에서 보류된 경우에는 "이미지가 없습니다"로 표시됩니다.

**쇼핑몰 채널 추가하기**

1\. \[+채널 추가\] 버튼을 클릭한 후 '쇼핑몰'을 선택합니다

**참고.**

‘쇼핑몰’ 비즈채널이란, 광고의 대상이 되는 상품을 판매하는 쇼핑몰 사이트 정보를 등록하는 것으로 '쇼핑검색광고'를 집행하기 위한 비즈채널 유형입니다.

'쇼핑몰' 비즈채널은 네이버 쇼핑에 입점된 쇼핑몰이 있는 경우에만 추가할 수 있으며 네이버 쇼핑 계정을 연동하여 등록할 수 있습니다.

2\. '비즈채널 추가(쇼핑몰)' 추가 창에서 비즈채널 이름을 입력한 후 하단의 \[동의 후 인증하기\] 버튼을 클릭합니다.

3\. 네이버 쇼핑 계정 인증 창에서 네이버 쇼핑에 임점되어있는 쇼핑 ID를 입력한 후 \[인증하기\] 버튼을 클릭합니다.

**참고.**

쇼핑의 계정이 '서비스중'인 경우에만 연동 가능합니다.

쇼핑 계정 연동이 실패되는 경우, 아래 도움말을 참고하여 문제를 해결 할 수 있습니다.

[네이버 쇼핑 ID 입력 시 인증 실패가 됩니다. 왜그런가요?](https://ads.naver.com/help/faq/806) 

4\. 연동정보 확인 후 \[저장 후 닫기\] 버튼 클릭합니다.

**콘텐츠 채널 추가하기**

1\. \[+채널 추가\] 버튼을 클릭한 후 '콘텐츠'를 선택합니다

**참고.**

‘콘텐츠’ 비즈채널이란, 파워컨텐츠 광고에 노출되는 사이트 정보를 등록하는 것으로 '파워컨텐츠'를 집행하기 위한 비즈채널 유형입니다.

2\. '콘텐츠' 비즈채널은 블로그, 포스트, 카페를 가지고 있을 경우에만 추가할 수 있습니다. 비즈채널 이름과 표시 URL, 업체 URL을 작성합니다.

-   -   표시 URL은 광고와 함께 노출되는 URL이며,
        
    -   업체 URL은 홍보하고자 하는 업체의 URL 입니다.
        
    -   [표시 UR](https://ads.naver.com/help/faq/1199)[L 등록기](https://ads.naver.com/help/faq/1199)[준 보기](https://ads.naver.com/help/faq/1199)
        

3\. 연동정보 확인 후 \[저장 후 닫기\] 버튼 클릭합니다.

**플레이스 채널 추가하기**

1\. \[+채널 추가\] 버튼을 클릭한 후 '플레이스'를 선택합니다

**참고.**

‘플레이스’ 비즈채널이란, 지역소상공인 광고와 플레이스광고에 노출되는 업체정보를 등록하는 것으로 '플레이스광고'와 지역소상공인광고'를 집행하기 위한 비즈채널 유형입니다.

'플레이스' 비즈채널은 네이버 스마트플레이스에 등록된 업체정보를 선택하여 등록할 수 있습니다.

업체정보를 등록하려면 네이버 스마트 플레이스에서 업체정보의 상태가 ‘정상 반영중’이어야 합니다.

업체정보는 네이버 스마트 플레이스에서 무료로 등록할 수 있습니다. ([네이버 스마트플레이스 바로가기](https://smartplace.naver.com/) )

2\. \[동의 후 인증하기\]를 클릭한 후, 네이버 아이디/비밀번호를 입력하여 로그인 합니다.

3\. 채널 이름과 업체명을 선택하여 연동정보 확인 후 \[저장 후 닫기\] 버튼 클릭합니다.

**쇼핑제조사 채널 추가하기**

1\. \[+채널 추가\] 버튼을 클릭한 후 '쇼핑제조사'를 선택합니다

**참고.**

‘쇼핑 제조사’ 비즈채널이란, 광고의 대상이 되는 제품 카탈로그의 제조사 정보를 등록하는 것으로 '쇼핑검색광고-제품 카탈로그형'을 집행하기 위한 비즈채널 유형입니다.

2\. '비즈채널 추가(쇼핑 제조사)' 추가 창에서 비즈채널 이름을 입력한 후 하단의 '위의 내용을 확인하였습니다'에 체크> \[제조사 등록\] 버튼을 클릭합니다.

3\. \[제조사 조회\] 탭에서 제조사명을 입력하거나, 제조사 명을 알기 어려운 경우 \[가격비교 상품조회\] 탭에서 제품명을 입력한 후 \[검색\] 버튼을 클릭합니다.

4\. 제조사명 선택 후 \[저장 후 닫기\] 버튼 클릭합니다.

**전화번호 채널 추가하기**

1\. \[채널 추가\] 드롭다운 목록 상자에서 \[전화번호\]를 클릭합니다.

2\. '비즈채널 추가(전화번호)' 대화 상자에서 비즈채널 이름과 전화번호를 입력합니다.

3\. 하단의 안내 사항을 확인한 후 "위 내용을 모두 읽고 확인했습니다"를 체크한 뒤 저장합니다.

**네이버 예약 채널 추가하기**

1\. \[+채널 추가\] 드롭다운 목록 상자에서 \[네이버 예약\]을 클릭합니다.

2\. '비즈채널 추가(네이버 예약) 대화 상자에서 이름과 URL을 입력합니다. URL 입력 시 먼저 프로토콜(http:// 혹은 https://)을 선택합니다.

3\. URL 입력 후 \[예약 연결하기\] 버튼을 클릭합니다.

**주의하세요.**

[네](https://easybooking.naver.com)[이버 예](https://easybooking.naver.com)[약](https://easybooking.naver.com)에 등록된 URL이 있어야 네이버 예약 채널을 추가할 수 있습니다.

**네이버 톡톡 채널 추가하기**

1\. \[+채널 추가\] 드롭다운 목록 상자에서 \[네이버 톡톡\]을 클릭합니다.

**참고.**

[네이버 톡톡](https://partner.talk.naver.com)은 현재 일부 업종의 광고주에게만 제공됩니다. 네이버 톡톡이 제공되지 않는 광고주에게는 \[채널 추가\] 드롭다운 목록 상자에 \[네이버 톡톡\]이 노출되지 않습니다.

2\. '비즈채널 추가(네이버 톡톡) 대화 상자에서 URL을 입력합니다.

3\. \[연결하기\] 버튼을 클릭하면 \[네이버 톡톡 파트너센터 간편 연결\] 대화 상자가 나타납니다.

**주의하세요.**

검토 통과한 사이트가 있는 경우에만 \[연결하기\] 버튼이 노출됩니다.

4\. \[네이버 톡톡 파트너센터 간편 연결\] 대화 상자에서 네이버 아이디로 로그인합니다.

5\. 로그인 후 \[톡톡 계정 선택\] 대화 상자 팝업에서 새로운 톡톡 계정을 추가하거나 기존에 등록된 톡톡 계정을 선택합니다.

**참고.**

-   웹 사이트 채널은 새 광고 그룹을 만드는 단계에서도 추가할 수 있습니다.
    
-   전화번호 채널은 새 확장소재를 만드는 단계에서도 추가할 수 있습니다.
    
-   채널의 이름은 \[네이버광고주센터 > 검색광고\] 내에서 관리를 위한 용도로 사용되는 이름이며 실제 광고에는 노출되지 않습니다.
    

---

**비즈채널 추가 한도**

비즈채널은 모든 유형을 합쳐 계정당 총 1,000개까지 추가할 수 있습니다.

단, 네이버 톡톡 유형은 최대 5개까지만 추가할 수 있습니다.
