# [AI작성] 이미지 라이브러리에서 이미지를 삭제하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 구성요소 관리 > 이미지\]의 이미지 목록 표에서 삭제할 이미지를 선택해 삭제합니다. 삭제된 이미지는 복구할 수 없습니다.

**삭제 절차**

1.  \[광고주센터 > 검색광고 > 구성요소 관리 > 이미지\]에 진입합니다.
    
2.  이미지 목록 표(컬럼: '이미지 ID / 이미지 종류 / 파일이름 / 이미지 미리보기 / 라이브러리 등록시간')에서 삭제할 이미지를 선택합니다.
    
3.  표 상단의 삭제 버튼을 클릭합니다.
    
4.  확인 창에서 삭제를 확정합니다.
    

**주의하세요.**

삭제된 이미지는 복구할 수 없습니다. 이미지가 사용된 소재나 확장 소재가 있는 경우, 해당 소재의 노출에 영향이 있을 수 있으므로 삭제 전에 사용처를 확인하시기 바랍니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
