# [AI작성] 전체 캠페인 목록에서 새 캠페인을 만들려면 어떻게 하나요?

전체 캠페인 화면에서 \[새 캠페인\]을 클릭하면 캠페인 유형 선택 창이 열립니다. '검색광고'와 '디스플레이 광고' 두 탭에서 만들 유형을 선택한 뒤 \[다음\]을 클릭하면 해당 유형의 캠페인 만들기 화면으로 이동합니다.

**만들기 절차**

1.  \[광고주센터 > 전체 캠페인\]에서 화면 상단의 \[새 캠페인\]을 클릭합니다.
    
2.  '검색광고' 또는 '디스플레이 광고' 탭에서 만들 캠페인 유형을 선택합니다.
    
3.  \[다음\]을 클릭하면 선택한 유형의 캠페인 만들기 화면으로 이동합니다.
    

**검색광고 캠페인 유형**

| **유형** | **설명** |
| --- | --- |
| 파워링크 | 검색어에 맞춰 내 웹사이트를 검색결과 상단과 다양한 서비스에 이미지와 텍스트로 노출합니다. |
| 쇼핑검색 | 내 상품이나 서비스가 네이버쇼핑 검색 상단 등에 표시되는 쇼핑 특화 상품입니다. |
| 플레이스 검색 | 내 매장이 네이버 지도·플레이스 등에 우선 표시되어 더 많은 고객 방문을 유도합니다. |
| 브랜드검색/신제품검색 | 브랜드 키워드를 검색하면 내 브랜드가 통합검색 상단에 단독 표시되어 각인 효과가 좋습니다. |
| 파워콘텐츠 | 통합검색과 다양한 서비스에서 블로그·카페 등 고객이 선호하는 형식으로 상품을 홍보합니다. |
| 지역소상공인 광고 | 네이버 콘텐츠 서비스 지면에 업체 정보를 노출하여 지역 고객의 방문을 유도합니다. |
| 디지털 옥외광고 | 지역 기반 오프라인 디지털 옥외 매체를 통해 동영상 광고를 노출합니다. |

**디스플레이 광고 캠페인 유형**

| **유형** | **설명** |
| --- | --- |
| 웹사이트 전환 | 내 웹사이트에서 목표 행동을 할 가능성이 높은 사용자에게 광고 이미지를 노출합니다. |
| 앱 전환 | 앱 설치 및 사용 가능성이 높은 사용자에게 광고 이미지를 노출합니다. |
| 인지도 및 트래픽 | 웹사이트·앱 방문을 최대화하기 위해 광고 이미지를 노출합니다. |
| 동영상 조회 | 동영상을 네이버의 다양한 영역에 노출해 더 많은 조회를 유도합니다. |
| ADVoost 쇼핑 | 네이버 쇼핑 상품을 AI가 사용자와 지면에 자동 최적화하여 노출 및 판매 성과를 높입니다. |
| 카탈로그 판매 | 내 상품에 반응한 사용자에게 카탈로그 기반 맞춤형 상품을 노출하여 구매를 유도합니다. |
| 쇼핑 프로모션 | 스토어의 프로모션·혜택 소식을 네이버 쇼핑 영역 등 다양한 영역에 노출합니다. |
| 참여 유도 | 광고용 폼을 랜딩으로 활용하여 설문 참여를 최대화합니다. |

**참고.**

유형을 선택하지 않으면 \[다음\] 버튼을 사용할 수 없습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
