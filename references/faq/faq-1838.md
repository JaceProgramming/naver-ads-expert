# [AI작성] 전체 캠페인 목록에서 캠페인을 켜거나 끄려면 어떻게 하나요?

전체 캠페인 목록에서 검색광고와 디스플레이 광고 캠페인의 노출 상태를 한 건씩 또는 여러 건을 한 번에 켜고 끌 수 있습니다.

**한 건씩 변경**

각 캠페인 행의 ON/OFF 자리에서 노출 상태를 바꿉니다. 변경 시 확인 안내가 표시되며, 확인하면 상태가 반영됩니다.

**여러 건 한 번에 변경**

1.  테이블에서 변경할 캠페인을 선택합니다. 한 건 이상 선택하면 상단에 \[ON\] · \[OFF\] · \[삭제\] · \[닫기\] 버튼이 나타납니다.
    
2.  \[ON\] 또는 \[OFF\]를 클릭합니다.
    
3.  확인 안내에서 진행을 확인합니다. OFF로 변경할 때는 '캠페인을 OFF하면 광고가 노출되지 않습니다.' 안내가 함께 표시됩니다.
    

**처리 제한과 결과**

-   한 번에 처리할 수 있는 최대 개수는 100개입니다. 초과하면 '한 번에 처리할 수 있는 최대 개수는 100개입니다' 안내가 표시됩니다.
    
-   일부만 변경에 실패하면 성공·실패 건수가 안내됩니다.
    

**알아두세요.**

상태 변경에 실패하면 이전 상태로 되돌아가고 실패 안내가 표시됩니다.

**참고.**

\[닫기\]를 누르면 선택이 해제됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
