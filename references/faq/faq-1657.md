# [AI작성] 광고 노출제한 관리 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 도구 > 광고 노출제한 관리\]에서 광고가 노출되지 않기를 희망하는 IP 주소를 등록·관리합니다. 등록된 IP에서는 파워링크/쇼핑검색/파워컨텐츠/플레이스 캠페인의 노출이 제한됩니다.

**화면 구성**

-   **안내 영역**: '광고노출제한 관리란?' 안내문과 \[자세히 보기\] 링크가 표시됩니다. \[닫기\]로 안내를 숨길 수 있습니다.
    
-   **등록 영역**: 화면 제목 옆에 '나의 IP 주소: x.x.x.x'가 표시되며, \[접기\]로 접을 수 있습니다.
    
-   광고노출제한 IP 입력란
    
-   설명 입력란 (0/25)
    
-   사설 IP 대역 안내(10.0.0.0~10.255.255.255 / 172.16.0.0~172.31.255.255 / 192.168.0.0~192.168.255.255 — 입력 불가)
    
-   유동 IP 등록 방법 안내 (마지막 네 번째 자리에 와일드카드(\*) 사용)
    
-   \[추가하기\] 버튼
    
-   **관리목록 표**: '관리목록 (등록수/600)' 헤더 아래에 등록된 IP 목록이 표시됩니다. 컬럼은 '등록일시 / 광고노출제한 IP / 설명'입니다.
    
-   **페이지네이션**: 하단에서 페이지·페이지 크기를 설정합니다.
    

**알아두세요.**

광고노출제한 IP는 최대 600개까지 등록할 수 있으며, 유동 IP는 마지막 네 번째 자리에 와일드카드(\*)를 사용해 차단할 수 있습니다. 예: '10.255.255.\*'로 입력하면 10.255.255로 시작하는 모든 IP 주소가 차단됩니다.

**주의하세요.**

광고노출제한 IP로 등록하더라도 광고노출제한된 사용자가 즐겨찾기·사이트URL·직접입력·URL 복사 등을 통해 사이트로 접속한 경우 접속 로그는 남을 수 있으나 과금되지 않습니다. 기업·단체의 프락시(Proxy) IP는 유효 트래픽일 수 있으니 신중히 검토 후 차단하시기 바랍니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
