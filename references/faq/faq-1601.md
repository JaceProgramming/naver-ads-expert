# [AI작성] 검색광고 타겟팅을 설정하려면 어떻게 하나요?

적용 대상: 파워링크 · 쇼핑검색 · 파워컨텐츠 · 플레이스. 광고그룹에서 요일/시간대·지역·성별·연령대 타겟팅을 설정해 원하는 대상에게 광고를 노출합니다. 요일/시간대 탭이 기본 표시되며, 다른 탭은 \[타겟팅 탭 추가\]로 활성화합니다.

**타겟팅별 설정 방법**

| **타겟팅** | **설정 방법** |
| --- | --- |
| 요일/시간대 | \[요일/시간대 변경\]에서 '모든요일/시간대 노출' 또는 '노출 요일/시간대 설정'을 선택하여 추가합니다. |
| 지역 | \[지역 타겟팅 변경\]에서 노출 방식을 고르고, 시·도/시·군·구 검색 또는 좌표 기준 반경으로 노출/제외 지역을 추가합니다(지도 확인 가능). |
| 성별 | '성별' 탭에서 남성·여성·알 수 없음 항목에 \[광고 노출\]/\[노출 제외\]를 설정합니다. |
| 연령대 | \[연령대 변경\]에서 '모든 연령' 또는 원하는 연령대만 선택해 노출합니다. |

각 타겟팅 표에서 노출(ON) 상태 항목의 입찰 가중치를 직접 수정할 수 있습니다.

**알아두세요.**

입찰 가중치는 50%~500% 범위로 설정하며, 노출 상태가 ON인 항목만 변경할 수 있습니다.

**주의하세요.**

모든 성별 또는 모든 연령대를 노출 제외하면 광고가 노출되지 않으니 최소 1개 이상은 노출로 유지합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
