# [AI작성] 파워컨텐츠 키워드 목록 화면은 어떻게 구성되어 있나요?

**파워컨텐츠 키워드 목록 화면 안내**

파워컨텐츠 광고그룹 상세의 '키워드' 탭에서는 광고가 노출될 타겟 키워드를 관리합니다. 키워드별 입찰가·성과·검수 상태를 확인하고, 키워드를 추가하거나 입찰가를 변경할 수 있습니다.

**목록 구성**

키워드 목록에는 다음 항목이 표시됩니다.

| **항목** | **설명** |
| --- | --- |
| ON/OFF | 키워드의 노출 상태를 켜거나 끕니다. |
| 키워드 | 등록된 타겟 키워드입니다. |
| 상태 | 키워드의 현재 상태를 표시합니다. |
| 현재 입찰가(VAT미포함) | 키워드별 입찰가로, 부가세 미포함 기준입니다. 목록에서 바로 수정할 수 있습니다. |
| 노출수·클릭수·클릭률(%)·평균 CPC·총비용 | 조회 기간 기준 성과 지표입니다. |
| 노출현황보기 | 키워드별 노출 통계를 확인합니다. |

**주요 작업**

-   \[새 키워드\]로 키워드를 추가합니다.
    
-   키워드를 선택한 뒤 \[입찰가 변경\]으로 입찰가를 일괄 변경합니다.
    
-   \[선택한 키워드 관리\]에서 삭제·일괄 ON/OFF·재검토·복사를 진행합니다.
    

**키워드 추가 방법**

\[새 키워드\]를 클릭하면 키워드를 추가하는 화면이 열립니다. 키워드는 '추천 키워드'·'연관 키워드'·'카테고리'에서 선택하거나 '직접 입력'으로 추가할 수 있습니다. 직접 입력 시 키워드를 줄바꿈으로 구분하여 입력합니다.

**알아두세요.**

파워컨텐츠는 콘텐츠와 매칭되는 키워드를 기준으로 노출됩니다. 블로그·포스트 본문 키워드를 기반으로 매칭되므로, 콘텐츠와 어울리는 키워드를 추가해 주세요.

**알아두세요.**

등록된 키워드가 없으면 '등록된 키워드가 없습니다. 새로운 키워드를 추가해보세요' 안내가 표시됩니다. 검수가 반려된 키워드는 상태 안내에서 반려 사유를 확인한 뒤 재검토를 요청할 수 있습니다.

**주의하세요.**

키워드는 광고 그룹 별 최대 50개까지 추가할 수 있으며, 키워드별 5~25자로 입력합니다.

**주의하세요.**

키워드 입찰가는 70원 이상 100,000원 이하(부가세 미포함)로 입력합니다. 범위를 벗어나면 안내가 표시되니 값을 다시 입력해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
