# [AI작성] 웹사이트 전환 캠페인 설정에서 전환 추적 대상과 최적화 전환 유형을 지정하려면 어떻게 하나요?

웹사이트 전환 캠페인은 캠페인 설정에서 **대표 URL · 전환 추적 대상 · 최적화 전환 유형 · 브랜드** 네 가지를 모두 지정해야 다음 단계로 넘어갈 수 있습니다. 이 중 '대표 URL'과 '브랜드', '전환 추적 대상'은 디스플레이광고 공통 캠페인 설정과 동일하며, **'최적화 전환 유형'은 웹사이트 전환 목표에서만 추가로 노출되는 항목**입니다. 광고주님께서 발생시키려는 전환을 어디서·어떤 행동으로 측정할지 지정하는 단계입니다.

**전환 추적 대상 지정**

'전환 추적 대상'은 광고 효과를 측정할 전환 추적 항목을 선택하는 항목입니다.

1.  '전환 추적 대상' 영역에서 등록된 전환 추적을 선택합니다. (안내 문구: '전환추적대상을 선택해 주세요.')
    

**참고.**

소재의 랜딩 URL 도메인이 전환 추적 대상의 도메인과 일치하는지 확인해 주시기 바랍니다. (안내 문구: '소재 랜딩 URL의 도메인이 전환 추적 대상의 도메인과 일치하는지 확인해 주세요.')

**최적화 전환 유형 지정**

'최적화 전환 유형'은 광고 노출을 최적화할 기준 전환 행동을 선택하는 항목으로, 웹사이트 전환 캠페인에서 노출됩니다. (안내 문구: '최적화 전환 유형을 선택해 주세요.')

-   전환 행동 유형으로는 '구매완료' '장바구니 담기'가 제공됩니다.
    

**저장 전 확인 사항**

| **상황** | **안내** |
| --- | --- |
| 대표 URL · 전환 추적 대상 · 최적화 전환 유형 · 브랜드 중 미선택 항목이 있는 경우 | \[다음\] 버튼이 비활성 상태로 유지됩니다. 네 항목을 모두 선택해야 다음 단계로 진행됩니다. |
| 대표 URL로 선택할 비즈채널이 검토 진행 중인 경우 | 검토가 완료될 때까지 \[다음\] 버튼이 비활성화됩니다. 검토 완료 후 진행해 주세요. |
| 캠페인을 수정하는 경우 | '대표 URL'은 캠페인 생성 시 한 번 결정되어 수정할 수 없으며 잠금 상태로 표시됩니다. 나머지 항목은 수정할 수 있습니다. |

**알아두세요.**

웹사이트 전환 캠페인은 캠페인 예산을 광고 그룹에 자동 분배하는 '캠페인 예산 최적화(CBO)'를 지원합니다. CBO 설정 방법은 디스플레이광고 공통 안내를 참고해 주시기 바랍니다. 또한 웹사이트 전환 캠페인 만들기·수정 화면에는 별도의 게재 일정 설정 영역이 노출되지 않습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
