# [AI작성] 관리 계정 목록 화면은 어떻게 구성되어 있나요?

관리 계정 화면에서는 내가 생성하거나 권한을 받은 관리 계정을 조회하고 관리할 수 있습니다. \[관리 계정 관리 > 관리 계정\] 탭에서 확인하며, 상단에 보유한 관리 계정 개수가 표시됩니다.

**목록 컬럼**

| **컬럼** | **설명** |
| --- | --- |
| 관리 계정(ID) | 관리 계정 이름과 ID. 클릭하면 해당 계정 대시보드로 이동합니다. |
| 권한 레벨 | '계정 책임자' / '운영 관리' / '운영 조회' |
| 가입 일자 | 계정을 직접 생성하거나 권한 초대 요청에 수락한 일자 |
| 연동된 광고 계정 | 연동된 광고 계정 수. 연동된 광고 계정이 0개여도 행은 표시되며, 클릭하면 연동 광고 계정 목록으로 이동합니다. |
| 즐겨찾기 | 즐겨찾기 등록·해제 |
| 관리 | \[권한 탈퇴\] 버튼 |

**검색**

컬럼 머리글 필터에서 '관리 계정 이름' 또는 '관리 계정 ID'로 검색할 수 있고, 목록은 기본 10개씩 표시됩니다.

**알아두세요.**

'관리' 컬럼의 \[권한 탈퇴\]는 본인의 권한만 탈퇴하는 기능이며, 관리 계정 자체가 삭제되지는 않습니다.

**알아두세요.**

검색 결과가 없으면 "검색 결과가 없습니다.", 등록된 계정이 없으면 "등록된 계정이 없습니다." 안내가 표시됩니다. 즐겨찾기는 최대 100개까지 저장할 수 있습니다.

**참고.**

계정 생성·권한 탈퇴 등 개별 동작은 별도 도움말을 참고해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
