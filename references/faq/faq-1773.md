# [AI작성] 광고 계정의 세금계산서 발행 내역을 조회하려면 어떻게 하나요?

세금계산서 화면에서 광고 계정의 사업자 정보를 확인하고 세금계산서 발행 내역을 기간별로 조회할 수 있습니다.

\[광고주센터 > 우측 상단 네이버 ID > 광고 계정 관리 > 광고 계정 클릭 > 결제 > 세금계산서\]로 이동합니다.

**사업자 정보**

상단의 사업자 정보 박스에는 광고계정 이름, 사업자 구분, 파트너사, 세금계산서 수령 항목이 표시됩니다.

**발행 내역 조회**

1.  조회 기간을 선택합니다. 이전·다음 기간 이동과 날짜 입력을 지원하며 기본값은 1년, 최대 2년까지 조회할 수 있습니다.
    
2.  표에서 발행 내역을 확인합니다. 행을 클릭하면 상세를 볼 수 있고, '수정요청'에서 수정 발행을 요청할 수 있습니다.
    
3.  \[다운로드\]로 목록을 내려받습니다.
    

**표 구성**

| **컬럼** | **설명** |
| --- | --- |
| 작성일자 | 세금계산서가 작성된 일자를 확인할 수 있습니다. |
| 공급자 | 공급자 정보를 확인할 수 있습니다. |
| 사업자등록번호 | 공급자의 사업자등록번호를 확인할 수 있습니다. |
| 품목 | 발행된 품목을 확인할 수 있습니다. |
| 공급가액 | 공급가액을 확인할 수 있습니다. |
| 세액 | 부가가치세액을 확인할 수 있습니다. |
| 합계 | 공급가액과 부가가치세액을 합산한 금액을 확인할 수 있습니다. |
| 문서구분 | 세금계산서의 문서 구분을 확인할 수 있습니다. |
| 발행상태 | 발행 상태를 확인할 수 있으며, 정렬 및 필터를 지원합니다. |
| 신고상태 | 신고 상태를 확인할 수 있으며, 필터를 지원합니다. |
| 수정요청 | 수정요청 버튼 클릭하여 수정 발행 요청 가능하며, 수정 요청 상태를 확인할 수 있습니다. |

**알아두세요.**

세금계산서는 매월 초(일반적인 경우 매월 3일~4일 사이)에 발행되며 등록한 메일 주소로도 자동 발송됩니다. 비즈머니 충전 금액이 아니라 전체 광고 상품의 유상 소진 금액을 통합한 금액에 대해 1장으로 발행됩니다.

**주의하세요.**

세금계산서 정보 수정이 필요하면 세금계산서 수정 요청을 먼저 진행한 후 광고 계정 정보 수정을 진행해야 합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
