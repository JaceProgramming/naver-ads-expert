# [AI작성] 초대 받은 광고 계정 화면은 어떻게 구성되어 있나요?

초대 받은 광고 계정 화면에서는 다른 광고 계정에서 받은 초대를 확인하고 처리할 수 있습니다. \[광고 계정 관리 > 초대 받은 광고 계정\] 탭에서 확인합니다.

**목록 컬럼**

| **컬럼** | **설명** |
| --- | --- |
| 광고계정(ID) | 초대한 광고 계정 이름과 ID |
| 권한 레벨 | 초대 시 부여된 권한 ('계정 책임자' / '운영 관리' / '운영 조회') |
| 초대 일자 | 초대받은 날짜 |
| 관리 | \[승인\] / \[거절\] 버튼 |

**알아두세요.**

받은 초대가 없으면 "초대받은 광고 계정이 없습니다." 메시지가 표시됩니다.

**참고.**

초대를 처리하는 방법은 '광고 계정 초대를 승인하거나 거절하려면 어떻게 하나요?' 도움말을 참고해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
