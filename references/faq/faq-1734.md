# [AI작성] 디스플레이광고 키워드 목록 화면은 어떻게 구성되어 있나요?

디스플레이광고의 키워드는 브랜드서치 시너지 보고서 및 동영상 광고에 사용할 키워드를 관리하는 구성요소입니다. 광고주센터에서 \[광고주센터 > 디스플레이광고 > 구성요소 관리 > 키워드\] 경로로 이동하면 광고계정에 등록된 키워드 목록을 조회하고 관리할 수 있습니다.

**목록 테이블 구성**

| **컬럼** | **설명** |
| --- | --- |
| 키워드 ID | 키워드의 고유 식별 번호입니다. |
| 키워드 | 등록된 키워드 텍스트입니다. |
| 검토 상태 | 키워드의 현재 검토 결과를 색상 표시로 안내합니다. |
| 최종 변경 일시 | 키워드가 마지막으로 변경된 일시입니다. |
| 관리 | 키워드 삭제, 거부 사유 보기 등을 수행합니다. |

**검토 상태**

키워드마다 검토 결과에 따라 다음 상태가 부여됩니다.

-   승인
    
-   검수중
    
-   반려 — 클릭하면 거부 사유를 확인할 수 있습니다.
    

**검색·필터**

상단 검색 영역에서 키워드를 검색하거나 검토 상태로 목록을 좁혀 볼 수 있습니다. 등록된 키워드가 없으면 '등록된 키워드가 없습니다.' 안내가 표시됩니다.

**키워드 삭제**

삭제할 키워드를 선택하고 \[삭제\]를 클릭한 뒤 확인하면 영구 삭제됩니다. 삭제 시 **"해당 키워드를 삭제하시겠습니까?"** 안내가 표시됩니다.

**알아두세요.**

키워드는 광고계정당 최대 1,000개까지 등록할 수 있으며, 승인된 키워드만 시너지 보고서·동영상 광고에 적용됩니다.

**주의하세요.**

일반 명사 등 브랜드 키워드로 사용할 수 없는 경우가 있으므로, 반드시 브랜드 또는 광고주와 직접 관련이 있는 키워드만 등록해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
