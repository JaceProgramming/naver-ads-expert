# '쇼핑검색광고-제품 카탈로그형' 소재는 어떻게 관리하나요?

'쇼핑검색캠페인' > '광고그룹' 하위의 소재탭에서 ON/OFF 상태 변경, 입찰가 변경, 즐겨찾기, 복사, 재검토 요청 혹은 등록된 소재를 삭제할 수 있습니다.

등록된 소재를 관리하는 방법에 대해 알아봅니다.

**소재 목록 조회**

네이버 광고주센터 > '광고 관리' 메뉴 클릭 후, 좌측 트리 영역에서 '쇼핑검색' 클릭시 해당 광고그룹에 등록된 전체 소재의 목록을 조회할 수 있습니다. (소재 목록 조회 경로 확인 필요)

**소재 ON/OFF**

소재의 ON/OFF 상태는 소재 목록의 ON/OFF 컬럼에서 \[ON\] 혹은 \[OFF\] 버튼을 클릭하여 변경할 수 있습니다.

또는 소재 목록에서 원하는 소재를 체크박스로 선택 후 목록 상단의 \[ON|OFF\] 버튼을 클릭하면, 선택한 소재의 일괄 ON/OFF 상태 변경이 가능합니다.

**입찰가 변경**

선택한 소재의 입찰가를 일괄 변경할 수 있습니다.

소재 목록에서 입찰가를 변경할 소재를 1개 이상 선택하여 좌측 상단 \[선택한 소재 관리\] 버튼을 클릭한 후, 드롭다운 메뉴에서 '입찰가 변경'을 클릭하면 입찰가를 변경할 수 있습니다.

**다른 광고그룹으로 복사**

동일한 소재를 다른 광고그룹에서도 사용하고자 하는 경우, 복사 기능을 사용하면 편리합니다.

소재 목록에서 복사하고자 하는 소재를 1개 이상 선택하여 좌측 상단의 \[선택한 소재 관리\] 버튼을 클릭한 후, 드롭다운 메뉴에서 '다른 그룹으로 복사'를 클릭합니다.

팝업창에서 복사할 대상 '쇼핑검색캠페인' > '광고그룹'을 선택한 후 ‘OFF 상태로 등록’ 여부를 선택하고 \[복사\] 버튼을 누르면 선택한 광고그룹으로 복사가 완료됩니다.

**삭제**

광고그룹당 등록할 수 있는 소재의 개수는 최대 100개이며, 사용하지 않을 소재는 삭제하는 것이 좋습니다. 광고검토 결과에 따라 사용할 수 없는 소재나 성과가 현저히 낮은 소재 등은 삭제하고 새로운 소재를 등록해 보세요.

소재 목록에서 삭제하고자 하는 소재를 선택하고, 목록 좌측 상단의 '삭제' 버튼을 클릭하면 됩니다.

**재검토 요청**

소재 목록에서 소재를 한 개 이상 선택하여 좌측 상단의 \[선택한 소재 관리\] 버튼을 클릭한 후, 드롭다운 메뉴에서 '재검토요청'을 클릭하면 선택한 소재의 재검토 요청이 가능합니다. 상태가 '노출제한'인 소재만 재검토 요청이 가능하며, 재검토 요청 시 검토 담당자에게 전달할 내용을 작성하거나, 증빙자료 등을 첨부할 수 있습니다.
