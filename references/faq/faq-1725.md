# [AI작성] 디스플레이광고 유사 타겟을 관리하려면 어떻게 하나요?

'유사 타겟' 탭에서는 기존 타겟을 시드로 생성한 유사 타겟을 조회·생성·수정·삭제할 수 있습니다. \['도구' > '잠재고객 관리'\] 화면에서 '유사 타겟' 탭을 선택하면 진입합니다.

**목록 조회·관리**

생성된 유사 타겟이 목록으로 표시됩니다.

| **컬럼** | **설명** |
| --- | --- |
| 타겟명 | 생성한 유사 타겟의 이름입니다. |
| 시드 타겟 | 유사 타겟 생성에 사용한 원본 시드 타겟명입니다. 시드 타겟이 삭제된 경우 '-'로 표시됩니다. |

새 유사 타겟을 만들려면 패널 상단 우측의 \[유사 타겟 생성\]을 클릭합니다. 각 행의 수정으로 내용을 변경하거나, 삭제로 확인 후 제거할 수 있습니다. 각 타겟의 처리 상태(생성 중·사용 가능·만료 등)는 목록의 배지로 표시됩니다.

**참고.**

등록된 항목이 없으면 '사용 가능한 타겟 소스가 없습니다.'가 표시됩니다.

**주의하세요.**

수정 또는 삭제에 실패하면 에러 안내가 표시됩니다. 잠시 후 다시 시도해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
