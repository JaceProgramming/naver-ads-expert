# [AI작성] 상세 데이터로 성과를 분석하려면 어떻게 하나요?

캠페인 목록의 \[상세 데이터\]를 클릭하면 다양한 기준으로 성과를 세분화하여 확인할 수 있습니다.

**분석 기준**

| **분석 기준** | **설명** |
| --- | --- |
| PC/모바일 구분 | 디바이스별 성과를 확인합니다. |
| 요일 구분 | 요일별 성과를 확인합니다. |
| 시간대 구분 | 시간대별 성과를 확인합니다. |
| 지역 구분 | 시/도 단위의 지역별 성과를 확인합니다. |
| 검색/콘텐츠 매체 구분 | 검색 매체와 콘텐츠 매체별 성과를 확인합니다. |

적용된 상세 데이터를 초기화하려면 '상세 데이터 지우기'를 선택합니다. 보다 정밀한 분석이 필요한 경우 '다차원보고서로 이동'을 선택하면 다차원보고서 화면으로 이동합니다.

**알아두세요.**

상세 데이터는 한 번에 하나의 기준만 적용할 수 있습니다. 다차원보고서에서는 여러 기준을 동시에 조합하여 분석할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
