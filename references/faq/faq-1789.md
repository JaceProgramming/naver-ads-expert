# [AI작성] 관리 계정 대시보드 화면은 어떻게 구성되어 있나요?

관리 계정 대시보드에서는 관리 계정에 연동된 하위 관리·광고 계정의 현황을 한눈에 확인할 수 있습니다. 로그인 후 좌측 메뉴에서 '대시보드'를 선택해 진입합니다.

**화면 구성**

대시보드는 다음 영역으로 구성됩니다.

| **영역** | **설명** |
| --- | --- |
| 파트너사 안내 사항 | 파트너사(에이전시) 운영에 필요한 공지·안내 사항을 조회하는 영역입니다. 에이전시 또는 서브에이전시 계정에서만 노출됩니다. |
| 하위 연동 계정 | 관리 계정에 연동된 하위 관리·광고 계정을 목록으로 조회하는 영역으로, 항상 노출됩니다. |

**하위 연동 계정 목록 컬럼**

하위 연동 계정 목록은 다음 컬럼으로 표시되며, 상단에 '계정 연동을 통해 접근 가능한 총 계정수'가 함께 표기됩니다.

| **컬럼** | **설명** |
| --- | --- |
| 관리/광고 계정(ID) | 계정 번호와 이름을 함께 표시합니다. 관리 계정 행은 펼쳐서 하위 계정을 확인할 수 있습니다. |
| 계정 유형 | '관리 계정' 또는 '광고 계정'으로 표시됩니다. |
| 계정 상태 | '운영 가능' 등 계정의 상태를 표시합니다. |
| 계정 잔액 | 계정의 잔액을 통화 형식으로 표시합니다. |
| 즐겨 찾기 | 자주 사용하는 계정을 즐겨찾기로 표시합니다. |
| 광고주센터 | 광고 계정 행에서 \[바로가기\]로 해당 광고 계정의 광고주센터로 이동합니다. |

**알아두세요.**

광고 계정별 상세 운영은 \[바로가기\]를 통해 해당 계정의 광고주센터에서 진행합니다.

**참고.**

에이전시 권한을 보유한 경우 '영업 타입', '담당 에이전트' 컬럼이 추가로 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
