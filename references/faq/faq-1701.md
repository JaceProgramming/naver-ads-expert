# [AI작성] 디스플레이광고 성과 보고서에서 분석 단위별 상세 데이터를 보려면 어떻게 하나요?

**성과 보고서 행 펼쳐보기**

성과 보고서의 데이터 표에서 특정 행을 클릭하면 해당 항목의 하위 상세 데이터를 펼쳐 볼 수 있습니다. 분석 단위별로 더 세부적인 성과를 확인할 때 사용합니다.

**이용 방법**

1.  성과 보고서를 조회해 데이터 표를 표시합니다.
    
2.  상세 데이터를 확인하려는 행을 클릭합니다.
    
3.  행 아래로 상세 데이터가 펼쳐집니다. 다시 접으려면 동일한 행을 한 번 더 클릭합니다.
    

행을 펼치면 해당 항목의 상세 데이터를 별도로 불러오며, 불러오는 동안 로딩 상태가 표시됩니다.

**알아두세요.**

표시되는 컬럼은 선택한 분석 단위(그룹핑 기준)에 따라 달라집니다.

**참고.**

펼친 행의 상세 데이터를 불러오는 중 오류가 발생하면 확장 영역에 오류 안내가 표시됩니다. 이 경우 해당 행을 다시 클릭해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
