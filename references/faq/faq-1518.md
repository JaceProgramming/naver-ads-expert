# [AI작성] 새 파워링크 캠페인을 만들려면 어떻게 하나요?

파워링크 캠페인 목록에서 \[새 캠페인\]을 클릭하면 캠페인 이름·하루 예산·고급옵션을 설정해 새 캠페인을 등록할 수 있습니다. 기존 캠페인을 수정할 때에도 동일한 화면이 사용되며, 입력값이 미리 채워진 상태로 표시됩니다.

**캠페인 만들기 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 파워링크\] 캠페인 목록에서 \[새 캠페인\]을 클릭합니다. 창 좌측의 \[기존 캠페인 불러오기\]로 기존 설정을 가져올 수 있습니다.
    
2.  아래 입력 항목을 설정합니다.
    
3.  필요 시 \[고급옵션\]을 펼쳐 기간·추적기능을 설정합니다.
    
4.  \[저장\]을 클릭하면 캠페인이 등록됩니다.
    

**입력 항목**

| **항목** | **설명** |
| --- | --- |
| 캠페인 이름 | 1~30자 이내로 입력합니다. 기본값으로 '파워링크' 뒤에 순번이 자동 부여되며, 같은 광고계정 내에서 이름이 중복될 수 없습니다. |
| 하루 예산 | 50원에서 1,000,000,000원까지 10원 단위로 입력합니다. 설정하지 않으면 '제한없음'으로 운영됩니다. |
| 시간별 균등 배분 | '예산을 하루 동안 시간별로 균등하게 배분합니다.'를 선택하면 시스템이 자동으로 시간대별 노출 여부를 관리합니다. |

**고급옵션**

| **항목** | **설정 내용** |
| --- | --- |
| 기간 | '오늘부터 종료일 없이 계속노출' 또는 '시작 및 종료 날짜 설정' 중에서 선택합니다. |
| 추적기능 | '추적기능 사용하지 않음', '자동 추적URL 파라미터', '추적 경유 사이트' 중에서 선택합니다. |

**수정 시 참고사항**

-   캠페인 상세에서 \[수정\]을 클릭하면 동일한 수정 화면이 열립니다.
    
-   수정 시 캠페인 유형은 변경할 수 없으며 현재 유형 이름만 표시됩니다.
    
-   공유예산이 연결된 캠페인은 하루 예산 영역에 공유예산 이름이 표시되며, 새로운 연결은 공유예산 관리 화면에서 수행합니다.
    

**알아두세요.**

-   캠페인 이름을 입력하지 않거나 30자를 초과하면 저장할 수 없습니다.
    
-   같은 광고계정 내에서 이미 사용 중인 캠페인 이름은 사용할 수 없습니다.
    
-   하루 예산은 50원에서 1,000,000,000원 사이에서 10원 단위로만 입력할 수 있습니다.
    

**참고.**

시간별 균등 배분된 예산에 따라 시스템이 자동으로 광고의 시간대별 노출 여부를 관리합니다.

**참고.**

별도의 광고 만들기 화면에서도 캠페인을 생성할 수 있습니다. 이 경우 캠페인 유형을 직접 선택하며 1.캠페인 → 2.광고그룹 → 3.키워드/소재 → 4.광고 만들기 완료의 4단계를 순서대로 진행합니다. \[등록 캠페인 불러오기\]로 기존 캠페인을 불러올 수 있고, \[저장하고 계속하기\]로 다음 단계인 광고그룹 설정으로 이동합니다.

**주의하세요.**

'제한없음'으로 하루 예산을 운영하면 경우에 따라 예산을 초과하는 금액이 과금될 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
