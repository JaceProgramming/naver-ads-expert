# [AI작성] 파일 업로드로 광고를 대량 등록·수정·삭제하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 도구 > 대량 관리\]의 \[대량 등록/수정/삭제\] 탭에서 캠페인 유형과 작업 유형을 선택하고 템플릿을 작성해 업로드하면 광고를 한 번에 등록·수정·삭제할 수 있습니다.

**대량 작업 절차**

1.  \[대량 등록/수정/삭제\] 탭을 선택합니다.
    
2.  '캠페인 유형'을 선택합니다.
    
3.  '작업 유형'(대량 등록 / 대량 수정 / 대량 삭제)을 선택합니다. 작업 유형은 캠페인 유형에 따라 달라집니다.
    
4.  \[템플릿 다운로드\]로 선택한 작업 유형에 맞는 템플릿(엑셀)을 받아 작성합니다. 광고그룹 ID·키워드 ID 등은 광고 다운로드 파일에서 확인할 수 있습니다.
    
5.  '작업 이름'을 입력합니다(최대 30자).
    
6.  '파일 업로드'에서 \[찾아보기\]로 작성한 파일을 선택하거나 끌어다 놓습니다.
    
7.  \[등록하기\]를 클릭해 작업을 신청합니다. 선택값을 초기화하려면 \[입력값 지우기\]를 사용합니다.
    

**파일 형식과 제한**

| **항목** | **안내** |
| --- | --- |
| 지원 형식 | CSV(.csv) 파일만 가능합니다. |
| 필수 입력 | 작업 유형과 파일을 모두 지정해야 \[등록하기\]가 활성화됩니다. |
| 템플릿 | 작업 유형마다 입력 항목이 다르므로 반드시 해당 작업 유형의 템플릿으로 작성해야 합니다. |

**알아두세요.**

신청한 작업의 진행 상황과 결과는 '대량 작업 신청 목록'에서 확인할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
