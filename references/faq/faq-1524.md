# [AI작성] 파워링크 키워드 목록 화면 안내

파워링크 광고그룹 상세 화면의 '키워드' 탭에서 광고그룹에 등록된 키워드를 조회하고 관리할 수 있습니다. 키워드 목록에서는 키워드별 노출 상태, 입찰가, 성과 지표를 확인할 수 있으며, 키워드 추가·ON/OFF·입찰가 변경·일괄 관리 등의 작업을 수행할 수 있습니다.

**키워드 목록 컬럼**

| **컬럼** | **설명** |
| --- | --- |
| ON/OFF | 키워드의 노출 상태를 켜거나 끕니다. |
| '키워드' | 등록된 키워드 텍스트가 표시됩니다. |
| '상태' | '운영가능', '중지: 키워드 검토중', '중지: 키워드 노출제한', '중지: 광고그룹 OFF', '중지: 비즈채널 노출 제한' 등 키워드의 현재 상태가 표시됩니다. |
| '현재 입찰가(VAT미포함)' | 키워드의 현재 입찰가가 표시됩니다. 광고그룹 기본 입찰가를 사용하는 경우 '\[기본\]'과 함께 금액이 표시되고, 개별 설정된 경우 금액만 표시됩니다. 클릭하면 입찰가를 직접 수정할 수 있습니다. |
| '광고 연관지수' | 키워드와 광고의 적합도 지표가 표시됩니다. 데이터가 집계되지 않은 경우 '-'로 표시됩니다. |
| '클릭 기대지수' | 키워드의 클릭 발생 가능성 지표가 표시됩니다. |
| '노출현황보기' | 클릭하면 키워드의 노출 및 입찰 진단 정보를 확인할 수 있습니다. |
| '노출수' / '클릭수' / '클릭률(%)' / '평균 CPC' / '총비용' | 성과 지표가 표시됩니다. |

**주요 기능**

| **기능** | **설명** |
| --- | --- |
| \[새 키워드\] | 키워드 추가 화면이 열립니다. |
| '입찰가 변경' | 키워드를 선택한 후 입찰가를 일괄 변경할 수 있습니다. |
| '선택한 키워드 관리' | 키워드를 선택한 후 일괄 ON/OFF, 삭제, 다른 광고그룹으로 이동 또는 복사 등을 수행할 수 있습니다. |
| '다운로드' | 키워드 목록을 파일로 다운로드합니다. |
| '열 맞춤 설정' | 목록에 표시할 컬럼을 선택합니다. |
| '상세 데이터' | 키워드의 상세 성과 데이터를 조회합니다. |
| 통합 필터 | '필터를 입력해 주세요' 입력란에 조건을 입력하여 키워드를 검색합니다. |

목록 상단에 '키워드 N개 결과'와 함께 지표 합계가 표시됩니다.

**알아두세요.**

-   키워드가 없는 경우 '등록된 키워드가 없습니다. 새로운 '키워드'를 추가해보세요.' 안내가 표시됩니다.
    
-   입찰가는 70원 이상 100,000원 이하, 10원 단위로 설정할 수 있습니다 (VAT 미포함).
    
-   키워드의 ON/OFF는 편집 권한이 있으면 변경할 수 있습니다. 상위 광고그룹·캠페인이 OFF이거나 검토 중·반려 상태여도 ON/OFF 자체는 변경할 수 있으며, 그 사유는 '상태' 열에 표시됩니다.
    

**참고.**

'입찰가 변경'과 '선택한 키워드 관리'는 키워드를 1건 이상 선택해야 활성화됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
