# 광고 성과지표 이해하기

전체 캠페인 화면에서 제공되는 주요 지표의 정의와 활용 방법에 대해 안내합니다.

| **구분** | **지표** | **정의** | **활용 방법 및 참고사항** |
| --- | --- | --- | --- |
| **기본 성과지표** | 노출수 | 등록된 광고에 설정된 모든 매체에 노출된 횟수를 의미합니다. |  |
| 클릭수 | 등록된 광고에 설정된 모든 매체에 클릭된 횟수를 의미합니다. 인위적인 클릭, 중복 클릭 등의 무효 클릭은 제외하고 집계됩니다. |  |
| 클릭률(%) | 광고의 클릭수를 노출수로 나누어 백분율로 표시한 값입니다. (수식 = 클릭수 / 노출수 X 100) | 노출된 광고에 대해 이용자가 얼마나 클릭했는지를 확인할 수 있는 지표입니다. |
| 평균 CPC | 광고 클릭 1회당 과금된 평균 비용입니다. (수식 = 총비용 / 클릭수) |  |
| 총비용 | 조회 기간 동안 광고의 총 과금액으로 부가가치세(VAT)가 포함된 금액입니다. | 검색광고의 브랜드검색/신제품검색 캠페인의 경우 계약을 통한 정액제 상품으로 해당 지표를 제공하지 않습니다. |
| 평균 CPM | 노출 1,000회당 평균 비용입니다. (수식 = 총비용 / 노출수 X 1000) |  |
| **전환지표** | 총 전환수 | 전환 유형별로 발생한 전환의 총합으로, 광고주의 각 사이트 목적에 맞게 정의된 최종 도달 페이지(전환 페이지)에 도달한 횟수입니다. | '도구 > 전환 추적 관리'에서 '사용중' 상태로 등록된 사이트에 대해서만 전환이 집계됩니다. |
| 총 전환율(%) | 광고 클릭 후 전환이 발생한 비율을 의미합니다. (수식 = 총 전환수 / 클릭수 X 100) | 클릭한 광고에 대해 이용자가 설정된 활동(예 : 가입 완료, 구매 완료 등)을 얼마나 수행했는지를 가늠해 보는 지표입니다. |
| 총 전환매출액 | 전환을 통해 발생한 매출의 총 합으로, 전환 추적에 설정한 전환별 전환 가치로 계산됩니다. | 1건의 전환에서 10억 이상의 전환매출액이 발생한 경우, 10억으로 치환됩니다. [< 관련공지](https://ads.naver.com/notice/28350) |
| 총 광고수익률(%) | 전환으로 발생한 매출액 대비 총비용의 비율을 의미합니다. (수식 = 총 전환매출액 / 총비용 X 100) | 투자한 광고비 대비 발생한 매출 비율을 나타내는 지표로, 광고 효율을 점검하고 광고 운영 전략에 활용할 수 있습니다. |
| 총 전환당비용 | 전환 1회당 발생한 평균 비용입니다. (수식 = 총비용 / 총 전환수) |  |
| 구매완료 광고수익률(%) | 구매완료(및 앱 내 구매완료) 전환의 매출액 대비 총비용의 비율을 의미합니다. (수식 = 구매완료 전환매출액 / 총비용 X 100) |  |
| 기여전환수(마지막클릭) | 검색광고와 디스플레이 광고를 통합하여, 전환 직전 마지막으로 클릭한 광고에 기여도 100%를 부여하여 집계한 전환 수 입니다. | 기여전환 지표는 모두 Beta 제공 지표로, 집계 기준은 변경될 수 있습니다.<br>총 전환과는 집계 기준이 달라 차이가 있을 수 있습니다. 기여전환에 관한 상세한 내용은 '[기여전환 이란](https://ads.naver.com/help/faq/1461)' 도움말을 참고해 주세요. |
| 기여전환매출액(마지막클릭) | 검색광고와 디스플레이 광고를 통합하여, 전환 직전 마지막으로 클릭한 광고에 기여도 100%를 부여하여 집계한 전환매출액입니다. |
| 기여전환수(데이터기반) | 검색광고와 디스플레이 광고를 통합하여, 전환 전 클릭된 여러 광고의 기여도를 데이터 기반으로 분석하여 배분한 뒤 집계한 전환 수입니다. |
| 기여전환매출액(데이터기반) | 검색광고와 디스플레이 광고를 통합하여, 전환 전 클릭된 여러 광고의 기여도를 데이터 기반으로 분석하여 배분한 뒤 집계한 전환매출액 입니다. |
| **재생지표** | 총 재생수 | 광고의 동영상이 재생된 횟수를 의미합니다. | 검색광고의 경우 플레이스의 디지털 옥외광고와 파워링크 및 쇼핑검색의 동영상 확장소재가 대상입니다.<br>디스플레이 광고의 경우 자동 재생과 클릭 재생이 모두 포함된 횟수이며, 노출 1회에 여러 번 추가 재생된 동영상은 재생수를 1회만 집계합니다. |
| 평균 CPV | 재생 1회당 과금된 평균 비용입니다. (수식= 총 재생비용 / 총 재생수) |  |
