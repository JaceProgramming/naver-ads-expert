# 서칭뷰 소재는 어떻게 제작하나요?

1\. 동영상 타입 유형별 제작 가이드

1) 텍스트 메뉴형

| 구분 | 영역 명칭 | 설명 |
| --- | --- | --- |
| 1 | 상단 슬로건 | • 글자수: Max 20자 |
| 2 | 본편 영상 | • 영상 비율: 16:9<br>• 영상 길이: Min 5초, Max 180초<br>• 용량: Max 80MB<br>• 해상도: 490P 이상 |
| 3 | 하단 텍스트 메뉴 버튼(3개) | • 글자 수: 각 메뉴 Max 10자 (10자 입력시 띄어쓰기 최소 1개 포함)<br>• 링크: [http://,](http://,/) https:// 중 한 개를 선택, 광고주 사이트의 메인페이지 URL 입력<br>• 컬러: 등록 툴의 컬러 리스트에서 선택 (컬러 리스트는 본 제작 가이드 별첨 참조) |
| 4 | 영상 영역 스틸 이미지 | • 사이즈: 가로 716px, 세로 404px 이상<br>• 형식: JPG, JPEG, PNG<br>• 용량: Max 10MB<br>• 영상 소재 종료 시 노출되는 이미지로 본편 영상과 관련 있어야 함 |

2\. 이미지 타입 유형별 제작 가이드

1) 이미지 타입 소재 유형 공통 가이드

① 메인 이미지 영역 : 로고, 상품명, 슬로건 등 브랜드를 인지할 수 있는 내용이 이미지 내에 포함되어야 함

② 텍스트 영역

-   텍스트는 26~52pt 크기로, 로고 제외 최대 3줄까지 입력 가능 (폰트 색상은 최대 2가지 가능)
    
-   텍스트는 지정된 영역 내에 배치하며, 영역 좌측 선에 정렬하여 배치해야 함
    

![](https://ads-home-phinf.pstatic.net/MjAyNTA0MDhfMTM2/MDAxNzQ0MDg5MTMyMTgy.Lj7AgTzixl5CxDXx34kCza_wVq0A3JVskrWzG79dj1Ug.bTHI35J0PMah-O7VMuVN1Dd3LotLyOsvd7ZyPBc-NNMg.PNG/%EC%84%9C%EC%B9%AD%EB%B7%B0_%EC%A0%9C%EC%9E%911.png?type=w1600)

-   심의를 받아야하는 업종의 광고주의 경우, 이미지 타입 중 이미지 3개 전환형은 집행 불가
    
-   심의필 번호는 메인 이미지 하단 지정된 영역 내에 배치하며, 영역 좌측 선에 정렬하여 배치해야 함
