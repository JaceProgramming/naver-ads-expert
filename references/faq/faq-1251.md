# '검색어 없는 경우 광고 노출 제외' 설정이 뭔가요?

'쇼핑검색광고는 검색어 결과뿐만 아니라 네이버쇼핑이 제공하는 검색어 하위 카테고리/브랜드/속성 탐색에서도 광고가 노출될 수 있습니다.

이와같은 검색결과에 노출을 원하지 않을 경우 별도의 선택을 통해 키워드 검색 시에만 노출되도록 할 수 있습니다.

'검색어 없는 경우 광고 노출 제외' 설정방법은 다음과 같습니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMTU5/MDAxNzc0OTI0OTQ0NTkx.zf1E6Dv5EH-bZW43QzerLAVwLqUNwnMMEZOkJGTE4Xcg.jO6Su6kSFzzKD1rU7EF44Y6ktRo8nzg71DBhqRV258Eg.PNG/image.png)

1.  \[캠페인 > 광고그룹\]을 선택합니다.
    
2.  제외키워드 탭을 선택합니다.
    
3.  하단의 \[검색어 없는 경우 광고 노출 제외\]를 '사용'으로 선택합니다.
    
4.  \[적용\] 버튼을 클릭합니다.
    

설정한 결과는 즉시 반영되며, '사용 안함'으로 하는 경우 검색 키워드가 없을 경우에도 광고가 노출됩니다.
