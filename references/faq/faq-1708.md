# [AI작성] 디스플레이광고 시너지 데이터를 조회하려면 어떻게 하나요?

**시너지 데이터 조회 방법**

시너지 상세 보고서 화면 상단의 조회 조건 영역에서 분석할 캠페인과 기간을 설정한 뒤 조회합니다. 캠페인 선택은 필수이며, 캠페인을 선택하지 않으면 \[확인\] 버튼이 비활성화됩니다.

1.  캠페인 선택 영역에서 분석할 브랜드서치 캠페인을 검색하여 선택합니다. 캠페인명을 입력하면 자동으로 검색 목록이 표시되며, 목록에서 원하는 캠페인을 선택합니다. 여러 캠페인을 함께 선택할 수 있으며, 선택한 개수가 표시됩니다.
    
2.  조회 기간을 설정합니다. 기본값은 최근 7일(오늘 제외)이며, 달력에서 직접 기간을 지정할 수 있습니다.
    
3.  \[확인\]을 클릭하여 시너지 데이터를 조회합니다. 조회가 완료되면 하단의 시너지 차트와 데이터 테이블에 결과가 표시됩니다.
    

**조회 가능 조건**

-   캠페인을 선택하지 않으면 \[확인\] 버튼이 비활성화되어 조회할 수 없습니다.
    
-   캠페인 검색 결과가 없으면 '검색 결과 없음' 안내가 표시됩니다.
    
-   시너지 데이터는 브랜드서치 캠페인만을 대상으로 제공되므로, 선택 목록에는 브랜드서치 캠페인만 표시됩니다.
    

**알아두세요.**

조회 기간은 최대 84일까지 설정할 수 있으며, 선택한 기간은 주 단위로 자동 변환됩니다.

**참고.**

화면의 데이터 안내에서 시너지 데이터 산정 방식을 확인할 수 있습니다. 시너지 데이터는 브랜드서치 캠페인 데이터를 기반으로 하며, 동일 사용자가 디스플레이광고와 브랜드서치에 함께 노출된 경우 시너지로 집계됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
