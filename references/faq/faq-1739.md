# [AI작성] 내 정보 화면은 어떻게 구성되어 있나요?

내 정보 화면에서는 회원 본인의 기본 정보를 확인하고 변경할 수 있습니다. \[광고주센터 > 우측 상단 네이버 ID > 내 정보 관리 > 내 정보\] 경로로 이동합니다.

**표시되는 회원 정보**

다음 5개 항목이 보안을 위해 마스킹 처리되어 표시됩니다.

| **항목** | **설명** |
| --- | --- |
| ID | 로그인에 사용하는 네이버 아이디 |
| 이름 | 회원 이름 |
| 이메일 | 등록된 이메일 주소 |
| 휴대전화번호 | 등록된 휴대전화 번호 |
| 미리보기용 ID | 디스플레이 광고 소재 등록 후 기기에서 테스트 노출(미리보기)할 때 사용하는 네이버 아이디 |

**제공되는 동작**

화면 우측의 \[내 정보 확인\]과 \[내 정보 변경\] 버튼으로 정보를 확인하거나 변경할 수 있으며, 두 동작 모두 본인 인증을 거칩니다.

**참고.**

정보를 변경하기 전에는 본인 인증을 통해 마스킹이 해제됩니다. 자세한 절차는 '내 정보를 확인하거나 변경하려면 어떻게 하나요?' 도움말을 참고해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
