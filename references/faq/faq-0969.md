# 스마트스토어광고 캠페인을 중단하려면 어떻게 해야 하나요?

아래의 방법으로 캠페인을 중단할 수 있습니다.

**방법 1) '광고 관리' 페이지에서 해당 캠페인을 OFF 설정하기**

캠페인 OFF 기능은 캠페인을 임시적으로 일시정지하는 기능입니다.

**방법 2) '광고 관리' 페이지에서 해당 캠페인을 삭제하기**

삭제된 캠페인은 복구할 수 없으므로, 캠페인 삭제는 신중히 진행해 주세요.

삭제 이후 캠페인 목록에는 확인이 불가하지만, 캠페인 성과 다운로드 시에는 확인이 가능합니다.

**방법 3) '광고 관리' 페이지에서 해당 캠페인의 이름을 클릭하고, 캠페인 수정 화면에서 광고 집행 기간을 캠페인 중단 희망 일자로 수정하기**
