# 스마트스토어광고 구매 전환 매출이란 무엇인가요?

구매 전환 매출이란 광고를 클릭한 고객이 실제로 ‘구매 완료’한 주문에서 발생한 매출 금액의 합계입니다.

즉, 광고 → 클릭 → 결제 완료 이 과정을 거쳐 실제로 발생한 매출만을 모아 놓은 금액입니다.

구매 전환 매출은 광고가 실제로 매출을 만들었는 지 바로 확인 가능한 중요한 기준 지표입니다.

**무엇이 포함되고, 무엇이 제외되나요?**

1) 포함되는 것

· 광고 클릭 후 구매 완료된 주문 금액

· 여러 건 구매 시 모든 구매 금액 합산

2) 포함되지 않는 것

· 장바구니 담기만 한 경우

· 결제 시도 후 실패한 주문

· 광고를 거치지 않은 자연 유입 구매

**구매 전환 매출은 어떻게 계산되나요?**

구매 전환 매출은 광고를 통해 발생한 구매 완료 주문 금액의 합입니다.

**예시)**

광고 클릭 후 30,000원 / 50,000원 / 20,000원 3건의 구매가 발생했을 경우

→ 구매 전환 매출은 100,000원입니다.

**구매 전환과 총 전환의 차이점**

| **구분** | **의미** |
| --- | --- |
| 총 전환 | 장바구니 담기 + 구매 완료로 발생한 매출 |
| 구매 전환 | 구매 완료로 확정된 매출 |

**광고비와 함께 보면 무엇을 알 수 있나요?**

구매 전환 광고 수익률 = 구매 전환 매출 ÷ 광고비×100 입니다.

**예시)**

· 광고비 50,000원

· 구매 전환 매출 200,000원

이 경우 ROAS는 400%이며, 광고비 1원으로 4원의 수익을 냈다는 뜻입니다.

※ ROAS란? 광고비 대비 매출을 나타내는 지표입니다.
