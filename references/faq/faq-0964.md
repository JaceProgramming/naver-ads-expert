# 광고비란 무엇인가요?

광고비는 선택한 기간 동안 광고가 실제로 노출, 클릭되면서 사용된 금액이며, VAT가 포함된 최종 기준 금액입니다.

또한 광고가 실제로 노출, 클릭되면서 사용된 금액의 합계입니다. (설정한 예산이 아닌 실제로 소비된 금액)

**\[광고비에 포함되는 항목\]**

광고비는 실제 소진된 광고비+부가가치세(VAT) 금액입니다.

1) 실제 소진된 광고비

· 광고가 노출되거나 클릭되면서 실제로 차감된 금액입니다.

· 유상 충전금과 무상 충전금 소진액이 모두 포함됩니다

2) 부가 가치세(VAT)

· 광고비는 VAT가 포함된 금액으로 표시됩니다.

**\[광고비 발생 사유\]**

광고비는 조회 기간 동안 광고가 노출되거나 클릭 되었을 때 발생합니다.

**※ 참고.**

· 원활한 광고 운영을 위해서는 충전금 잔액을 주기적으로 확인해주셔야 합니다.

· 총 충전금 잔액은 \[광고관리 > 스마트스토어 광고 > [**결제관리**](https://sell.smartstore.naver.com/#/smart-ads/billing)\]메뉴에서 확인 가능합니다.
