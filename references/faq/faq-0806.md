# 네이버 쇼핑 ID 입력 시 인증 실패가 됩니다. 왜그런가요? (로그인 인증 실패)

쇼핑몰 연동을 위한 ID 인증 진행 시, 인증 실패가 발생할 수 있습니다.

알럿창의 메시지를 확인한 뒤, 실패 유형 별 가이드에 맞춰 다시 한 번 인증을 진행 해 주세요.

1.  **ID가 유효하지 않은 경우**
    
2.  네이버 쇼핑에 입점된 ID를 확인할 수 없습니다. ID를 다시 한 번 확인하여 입력해 주세요.
    
3.  네이버 아이디로 쇼핑에 입점한 경우, ID 정보를 확인하고 입력해 주세요.
    

1.  **쇼핑몰 상태가 연동불가인 경우 (서비스 가능상태 아님)**
    
2.  입력한 쇼핑몰 ID의 상태가 '입점 심사중', '가퇴점/완전퇴점' 상태일 경우 인증이 실패할 수 있습니다.
    
3.  네이버 쇼핑에서의 쇼핑몰 상태를 확인해 주세요.
    
4.  [네이버 쇼핑 파트너센터 바로가기](https://center.shopping.naver.com/) 
    

1.  **쇼핑몰 타입이 광고불가인 경우**
    
2.  현재 면세점, 해외직구, 티켓 쇼핑몰 타입은 등록이 불가능합니다. 쇼핑파트너센터를 통해 쇼핑몰 타입을 확인해 주세요.
    

1.  ※ 해외직구의 경우, 해외사업자가 소유/관리하는 쇼핑몰 등의 상품 중, 네이버 검색광고 기준 등에 따라 광고가 제한되거나 또는 쇼핑검색광고가 대응하지 않는 카테고리 상품은 광고가 불가합니다.
    

1.  **소유/권리자 확인 불일치인 경우**
    
2.  인증하려는 네이버쇼핑의 사업자정보가 검색광고 계정과 일치하지 않은 경우 네이버쇼핑 계정에 등록된 휴대폰 번호로 SMS 인증 후 연동이 가능합니다.
