# [AI작성] 검색광고 여러 캠페인의 기간이나 예산을 일괄 변경하려면 어떻게 하나요?

**적용 대상:** 파워링크 · 쇼핑검색 · 파워컨텐츠 · 플레이스

캠페인 목록에서 여러 캠페인을 선택한 뒤 \[선택한 캠페인 관리\]를 클릭하면 \[기간 변경\] / \[예산 변경\] 메뉴가 나타납니다. 각각 창에서 일괄 변경할 수 있습니다.

**상품별 \[선택한 캠페인 관리\] 메뉴**

| **상품** | **메뉴** |
| --- | --- |
| 파워링크 | \[기간 변경\] / \[예산 변경\] |
| 쇼핑검색 | \[기간 변경\] / \[예산 변경\] |
| 파워컨텐츠 | \[기간 변경\] / \[예산 변경\] |
| 플레이스 | \[기간 변경\] / \[예산 변경\] |
| 브랜드검색/신제품검색 | **\[선택한 캠페인 관리\] 메뉴 없음** — 캠페인 선택 시 작업 바에 \[ON\]/\[OFF\]/\[삭제\]/\[닫기\]만 표시 (정액제·입찰제 계약 기반이라 기간·예산 변경 불가) |

**일괄 변경 절차 (파워링크·쇼핑검색·파워컨텐츠·플레이스)**

1.  캠페인 목록에서 변경할 캠페인을 선택합니다.
    
2.  \[선택한 캠페인 관리\]를 클릭합니다.
    

**예산 변경**

1.  \[예산 변경\]을 선택하면 '예산 변경 - N개 캠페인 선택' 창이 열립니다.
    
2.  변경 방식 선택
    

-   **개별예산 설정** — 캠페인별 단일 예산. 50원~1,000,000,000원(10원 단위) 또는 '제한없음' (※ 플레이스는 50원~300,000원). 시간별 균등 배분 체크 가능
    
-   **공유예산 설정** — 선택한 캠페인들을 공유예산으로 통합 운영
    

**3\.** \[변경사항 미리보기\] → \[변경\]

**기간 변경**

1.  \[기간 변경\]을 선택하면 '기간 변경 N개 캠페인 선택' 창이 열립니다.
    
2.  변경 방식 라디오: 오늘부터 종료일 없이 계속노출 / 시작 및 종료 날짜 설정
    
3.  \[변경사항 미리보기\] → \[변경\]
    

**알아두세요.**

공유예산 설정 시 해당 캠페인들은 통합 예산으로 운영되어 종합 관리 성과를 높일 수 있습니다. 브랜드검색/신제품검색은 정액제·입찰제 계약 기반이므로 \[선택한 캠페인 관리\]를 통한 일괄 기간·예산 변경이 제공되지 않으며, 캠페인 ON/OFF·삭제만 일괄 처리 가능합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
