# 브랜드검색 광고 집행 중 키워드를 추가할 수 있나요?

광고 집행 중이라도 해당 템플릿을 계약한 시점의 단가표 상 키워드 검색수 구간을 벗어나지 않을 경우, 계약당 30개 이내에서 키워드 추가가 가능합니다. 단 추가된 키워드의 기준조회수는 계약 생성일 기준이 아닌 키워드 추가일자 기준으로 적용됩니다.

**예시.**

그룹검색수 합계(기존+추가 키워드 검색수 합계) > 광고그룹 계약 기준조회수 = 키워드 추가 불가
