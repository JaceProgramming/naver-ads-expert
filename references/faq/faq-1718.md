# [AI작성] 디스플레이광고 모바일 앱 전환 추적을 등록하거나 관리하려면 어떻게 하나요?

'모바일 앱(beta)' 탭에서는 모바일 앱 전환 추적 설정 목록을 조회하고 신규 등록, 수정, 삭제할 수 있습니다. \['도구' > '전환 추적 관리'\] 화면에서 '모바일 앱' 탭을 선택하면 진입합니다.

**등록 방법**

1.  패널 상단 우측의 \[전환 추적 등록\]을 클릭합니다.
    
2.  이동한 등록 화면에서 필요한 정보를 입력하고 저장합니다.
    

**목록 조회·관리**

등록된 모바일 앱 전환 추적이 목록으로 표시됩니다.

| **컬럼** | **설명** |
| --- | --- |
| 앱명 | 등록한 앱의 이름입니다. |
| OS 유형 | 'ANDROID' 또는 'IOS'로 표시됩니다. |

목록 행을 선택하면 우측에서 상세·수정 화면이 열립니다. 각 행의 수정으로 내용을 변경하거나, 삭제로 확인 후 제거할 수 있습니다.

**참고.**

모바일 앱 전환 추적은 베타(beta) 단계로 제공됩니다.

**주의하세요.**

수정 또는 삭제에 실패하면 에러 안내가 표시됩니다. 잠시 후 다시 시도해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
