# [AI작성] 디스플레이광고 키워드 거부 사유를 확인하려면 어떻게 하나요?

키워드 검토 결과가 '거부'인 경우, 키워드 목록에서 해당 키워드의 거부 상태 표시를 클릭하면 거부 사유를 확인할 수 있습니다. 거부 사유 안내에는 거부된 키워드와 등록일, 사유가 표시됩니다.

**거부 사유 유형**

| **유형** | **안내 내용** |
| --- | --- |
| 정책 위반 | 위반된 정책 코드와 사유가 표시됩니다. 정책 가이드를 함께 확인할 수 있습니다. |
| 중복 | 광고계정 내에 이미 동일한 키워드가 존재하는 경우로, 기존 키워드 정보가 안내됩니다. |
| 검토자 거부 | 검토자가 남긴 거부 코멘트 본문이 표시됩니다. |
| 한도 초과 | 광고계정 키워드 한도(1,000개)를 초과한 경우로, 한도 안내가 표시됩니다. |

**조치 방법**

1.  거부 사유 안내를 열어 어떤 유형에 해당하는지 확인합니다.
    
2.  정책 위반인 경우 \[정책 가이드 보기\]를 통해 기준을 확인하고 키워드를 수정해 다시 등록합니다.
    
3.  중복인 경우 기존 키워드를 사용하거나 다른 키워드로 등록합니다.
    
4.  한도 초과인 경우 사용하지 않는 키워드를 삭제한 뒤 다시 등록합니다.
    

**알아두세요.**

정책 가이드 안내는 정책 위반으로 거부된 경우에만 제공됩니다.

**참고.**

사유를 확인할 수 없는 경우 잠시 후 다시 시도하거나 고객센터로 문의해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
