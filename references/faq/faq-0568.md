# '쇼핑검색광고-쇼핑 브랜드형' 광고그룹·상품·키워드 등록 가능한 개수 제한이 있나요?

| **단위** | **최대 한도** |
| --- | --- |
| 광고 그룹 | 계정 하위 10,000개 |
| 키워드 | 키워드 유형 구분 없이 광고그룹 당 최대 1,000개 |
| 상품 | 상품 선택 등록 시, 광고그룹 당 200개<br>전체 등록 시, 제한 없음 |
| 소재 | 광고 그룹 당 5개 |
| 확장소재 | 광고 그룹 당 확장소재 유형별 2~5개<br>브랜드 동영상 2개<br>브랜드 이벤트 2개<br>브랜드 라이브 5개<br>브랜드 데이 5개 |
