# [AI작성] 검색광고 캠페인을 켜거나 끄려면 어떻게 하나요?

**적용 대상:** 파워링크 · 쇼핑검색 · 파워컨텐츠 · 플레이스 · 브랜드검색/신제품검색/서칭뷰

캠페인 목록에서 'ON/OFF' 컬럼을 클릭해 캠페인을 켜거나 끕니다. 여러 캠페인을 일괄로 변경할 때는 캠페인을 선택한 뒤 표시되는 상단 작업 바의 \[ON\] / \[OFF\] 버튼을 클릭합니다.

**변경 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리\]에서 캠페인 목록으로 이동합니다.
    
2.  **단건**: 캠페인 행의 'ON/OFF' 컬럼을 클릭합니다.
    
3.  **일괄**: 변경할 캠페인을 선택하면 상단에 'N개 선택됨' 작업 바가 표시됩니다. \[ON\] / \[OFF\] 등의 버튼이 나타나며 \[ON\] 또는 \[OFF\]를 클릭합니다.
    

**알아두세요.**

캠페인을 OFF로 설정하면 캠페인 상태가 '중지: 캠페인 OFF'로 변경되며, 캠페인에 속한 모든 광고그룹·소재가 노출되지 않습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
