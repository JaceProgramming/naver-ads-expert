# [AI작성] 다차원 보고서의 분석 결과 표를 확인하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 보고서 > 다차원 보고서\]에서 조회를 실행하면 분석 결과 표가 표시됩니다. 표의 행에는 선택한 차원 값이, 열에는 선택한 지표가 표시되어 두 기준을 교차한 성과를 한눈에 확인할 수 있습니다.

**표 구성**

-   **분석 조건 영역** — 표 상단에서 현재 적용된 차원·지표·기간을 확인하고 수정할 수 있습니다.
    
-   **헤더** — 행 헤더에는 차원명이, 열 헤더에는 지표명이 표시됩니다. 비교 기간을 사용하면 각 지표 아래에 기준·비교·증감률(%)이 추가됩니다.
    
-   **데이터 행** — 차원 값(키워드·소재·매체 등)별로 지표 수치가 표시됩니다.
    
-   **합계 행** — 전체 데이터의 합산 지표(노출수 합계·클릭수 합계·총비용·평균 클릭률·평균 CPC 등)가 표시됩니다.
    

**표 조작·관리**

-   '필터를 입력해 주세요' 입력란으로 결과를 필터링합니다.
    
-   데이터가 한 페이지(기본 20행)를 넘으면 페이지 이동 영역이 나타납니다.
    

**알아두세요.**

결과 표의 데이터는 화면 상단의 '최근 집계 완료 시간' 기준입니다. 특정 차원·지표 조합에 데이터가 없으면 해당 칸은 '—'로 표시되며, 조건에 맞는 데이터가 없으면 '선택한 조건에 지표가 확인되지 않습니다.' 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
