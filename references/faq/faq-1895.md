# [AI작성] ADVoost 쇼핑 애셋그룹 목록 화면은 어떻게 구성되어 있나요?

**적용 대상:** 디스플레이광고 > ADVoost 쇼핑 (광고그룹·소재 대신 애셋그룹 구조를 사용)

ADVoost 쇼핑은 일반 디스플레이광고와 달리 광고그룹·소재 대신 '애셋그룹' 구조로 운영됩니다. 캠페인 목록에서 캠페인 이름을 클릭하면 캠페인 상세 화면이 열리고, 화면 하단에 해당 캠페인에 속한 애셋그룹 목록이 표 형태로 표시됩니다. 광고주님께서는 이 목록에서 애셋그룹의 운영 상태와 성과를 한눈에 확인하실 수 있습니다.

**애셋그룹 목록의 주요 항목**

애셋그룹 목록 표에는 다음 항목이 표시됩니다.

| **항목** | **설명** |
| --- | --- |
| ON/OFF | 애셋그룹의 노출 여부를 켜거나 끕니다. |
| 애셋 그룹 이름 | 이름과 식별 번호가 함께 표시되며, 클릭하면 애셋그룹 상세 화면으로 이동합니다. |
| 상태 | '운영 가능', '광고집행전' 등 현재 운영 상태가 표시됩니다. |
| 성과 지표 | 결과, 결과당 비용, 총비용, 노출수, 평균 CPM, 클릭수, 평균 CPC, 클릭률 등 성과 지표가 표시됩니다. |

**목록 상단에서 할 수 있는 작업**

목록 상단에서는 다음 기능을 이용하실 수 있습니다.

-   \[+ 새 애셋그룹\]으로 애셋그룹 추가
    
-   '운영가능', '광고집행전', '광고집행종료' 등 상태 필터로 표시 범위 조정
    
-   \[다운로드\]로 현재 목록 내려받기
    
-   \[열 맞춤 설정\]으로 표에 표시할 항목 선택
    
-   필터 입력란에 검색어를 입력해 목록 좁히기
    

**참고.**

애셋그룹이 하나도 없는 경우 빈 화면과 함께 \[+ 새 애셋그룹\] 버튼이 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
