# [AI작성] 쇼핑 브랜드 상품그룹 목록 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 구성요소 관리 > 쇼핑 브랜드 상품그룹\]에서 쇼핑 브랜드 유형 광고 소재와 함께 노출될 상품 정보의 묶음(상품 그룹)을 등록·조회·관리합니다.

**목록 구성**

상품 그룹 목록은 다음 항목으로 구성됩니다.

| **항목** | **설명** |
| --- | --- |
| 상품그룹 이름 | 등록한 상품 그룹의 이름입니다. |
| 연결 그룹 수 | 해당 상품 그룹을 사용 중인 광고그룹 수입니다. |
| 등록 상품 수 | 그룹에 포함된 상품 수입니다. |
| 상품등록 방식 | 전체 상품 등록 / 상품 선택 등록 중 그룹을 만든 방식입니다. |
| 등록상품 유형 | 일반 상품 / 카탈로그 상품 중 그룹에 담긴 상품의 유형입니다. |
| 브랜드 | 상품 그룹에 연결된 브랜드입니다. |
| 등록시각 | 상품 그룹을 등록한 시각입니다. |

**주요 기능**

목록 상단의 \[새 상품 그룹\]으로 새 그룹을 만들 수 있습니다. 하단 페이지네이션에서 페이지와 페이지 크기를 설정하며, 등록된 상품 그룹이 없으면 빈 안내가 표시됩니다.

**알아두세요.**

상품 그룹의 '상품등록 방식'은 저장 후 수정할 수 없습니다. 상품 그룹은 쇼핑 브랜드 캠페인 광고그룹에 연결되어 광고 노출 대상 상품을 결정합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
