# 파워링크 캠페인·광고그룹·키워드 최대 등록 개수가 궁금해요.

광고 목적에 따라 캠페인은 계정당 최대 200개까지 만들 수 있습니다.

각 단위별 최대 한도는 다음과 같습니다.

| **단위** | **최대 한도 기준** |
| --- | --- |
| 비즈채널 | • 계정당 최대 1,000개<br>• 단, 네이버 톡톡 유형은 최대 5개까지 등록 가능 |
| 캠페인 | • 계정당 최대 200개 |
| 광고 그룹 | • 캠페인당 최대 1,000개<br>• 계정당 최대 10,000개 |
| 키워드 | • 광고 그룹당 최대 1,000개<br>• 광고 그룹당 제외 키워드(키워드확장) 최대 50개<br>• 캠페인당 전체 키워드 최대 100,000개<br>• 계정당 전체 키워드 최대 100,000개 |
| 소재 | • 광고 그룹당 전체 유형 소재 등록 가능 개수 : 8개<br>• \- 단일형 소재 : 최대 5개<br>• \- 반응형 소재 : 최대 3개<br>• 광고 그룹당 확장 소재 유형별 각 1~15개 |
| 애셋 | • 계정당 최대 100,000개 |
