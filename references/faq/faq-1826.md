# [AI작성] 광고주센터 대시보드 화면은 어떻게 구성되어 있나요?

대시보드는 검색광고와 디스플레이 광고를 통합하여 광고 성과·예산·공지를 한눈에 확인하고 관리 화면으로 빠르게 이동할 수 있는 첫 화면입니다. 광고계정을 선택한 뒤 좌측 메뉴에서 '대시보드'를 클릭하면 진입합니다.

**대시보드 구성 영역**

| **영역** | **설명** |
| --- | --- |
| 광고 성과지표 | 선택한 기간의 노출·클릭·전환 등 성과를 지표 카드와 추이 차트로 표시합니다. |
| 광고 추천 배너 | 광고주님에게 적합한 광고 상품을 제안하는 배너로, 성과지표 아래 전체 폭에 항상 노출됩니다. |
| 광고비 집중 캠페인 | 최근 7일 기준 광고비가 집중된 상위 캠페인을 보여줍니다. |
| 광고 운영에 도움이 되는 추천 | 광고 운영 현황을 바탕으로 한 추천 콘텐츠를 카드로 제공합니다. |
| 비즈머니 | 비즈머니 잔액을 유상 비즈머니·무상 비즈머니로 나누어 표시하고, 사용 가능한 쿠폰 수와 전일 대비 소진율을 함께 보여 주며 충전으로 이동합니다. |
| 공지사항 | 최신 공지 순으로 표시하며 \[전체보기\]로 전체 공지를 확인합니다. |
| 알림 | 화면 우측에 운영·프로모션 알림 메시지를 표시합니다. |

화면 좌측 상단의 \[광고 만들기\] 버튼으로 새 광고를 시작할 수 있고, 비즈니스 진단으로 적합한 광고 상품을 추천받을 수도 있습니다.

**알아두세요.**

비즈머니 잔액이 부족하면 화면 상단에 '비즈머니 잔액이 부족하여 광고가 일시 중지되었습니다. (브랜드검색/신제품검색 제외)' 안내와 \[지금 충전하기\] 버튼이 함께 표시됩니다.

**참고.**

화면 너비에 따라 영역 배치가 한 열 또는 두 열로 자동 전환되며, 우측의 '알림' 영역은 넓은 화면에서만 노출됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
