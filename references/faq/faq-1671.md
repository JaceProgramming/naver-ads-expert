# [AI작성] 검색광고 API 키를 재발급하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 도구 > SA API 사용 관리\]의 검색광고 Key 표에서 항목별 \[재발급\]을 클릭하면 '엑세스라이선스 재발급' 또는 '비밀키 재발급' 창이 열립니다. 창 내 \[재발급\] 버튼으로 재발급을 진행합니다.

**재발급 절차**

1.  광고 계정의 계정 책임자 권한으로 로그인합니다.
    
2.  \[광고주센터 > 검색광고 > 도구 > SA API 사용 관리\]에 진입합니다.
    
3.  검색광고 Key 표에서 재발급할 항목(엑세스라이선스 또는 비밀키) 행의 \[재발급\]을 클릭합니다.
    
4.  '엑세스라이선스 재발급'(또는 '비밀키 재발급') 창에서 다음 안내를 확인합니다.
    

-   '엑세스라이선스 재발급을 희망하시면 아래 \[재발급\] 버튼을 눌러주세요.'
    

1.  \[재발급\] 버튼을 클릭해 재발급을 진행합니다.
    
2.  재발급된 새 Key 값이 검색광고 Key 표에 반영되며, \[복사\]로 새 값을 복사해 사용합니다.
    

**주의하세요.**

재발급 후에는 기존 Key가 즉시 무효화됩니다. API를 사용 중인 애플리케이션이 있다면 새 Key로 즉시 교체하지 않으면 호출이 실패할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
