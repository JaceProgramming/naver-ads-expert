# [AI작성] 기존 소재를 편집해 새 소재로 등록하려면 어떻게 하나요?

브랜드검색/신제품검색 광고그룹 상세 \[소재\] 탭에서 기존 소재의 \[편집 후 새로 등록\]을 클릭하면 '소재 만들기' 창이 기존 입력값으로 채워진 상태로 열립니다. 정보를 수정한 뒤 \[저장\]하면 새 소재로 등록됩니다.

**등록 절차**

1.  광고그룹 상세 \[소재\] 탭에서 기존 소재 행의 \[편집 후 새로 등록\]을 클릭합니다.
    
2.  '소재 만들기' 창이 기존 소재의 입력값으로 채워진 상태로 열립니다.
    
3.  유형별 입력 항목(템플릿·이미지·동영상·태그·연결 URL 등)을 필요한 부분만 수정합니다.
    
4.  의료광고 심의 대상이면 의료광고 심의필 번호를 입력합니다.
    
5.  필요 시 '검토 요청'에서 \[네\] 선택 후 전달 내용·서류를 첨부합니다.
    
6.  \[저장\]을 클릭해 새 소재로 등록합니다. 기존 소재는 그대로 유지됩니다.
    

**알아두세요.**

\[편집 후 새로 등록\]은 기존 소재를 직접 수정하는 것이 아니라 새 소재로 등록하는 기능으로, 노출 중인 소재의 검토 상태에 영향을 주지 않습니다. 새 소재는 별도 검토를 받아야 하며, 검토 통과 후 노출됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
