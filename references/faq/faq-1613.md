# [AI작성] 브랜드검색/신제품검색 광고그룹을 켜거나 끄려면 어떻게 하나요?

브랜드검색/신제품검색 캠페인 상세의 광고그룹 목록 표 'ON/OFF' 컬럼을 클릭해 광고그룹을 켜거나 끕니다. 여러 광고그룹은 선택한 뒤 작업 바의 \[ON\]/\[OFF\] 버튼을 사용합니다.

**변경 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 브랜드검색/신제품검색\]에서 캠페인 이름을 클릭해 상세로 이동합니다.
    
2.  광고그룹 목록 표(컬럼: ON/OFF / 광고그룹 이름 / 상태 / 계약 이름 / 채널 정보 / 노출수 / 클릭수 / 클릭률(%))에서:
    

-   **단건** — 광고그룹 행의 'ON/OFF'를 클릭합니다.
    
-   **일괄** — 광고그룹을 선택하면 'N개 선택됨' 작업 바에서 \[ON\]/\[OFF\]/\[삭제\]/\[닫기\] 버튼이 표시됩니다.
    

**알아두세요.**

브랜드검색/신제품검색 광고그룹의 광고 노출은 ON 상태여도 '계약 이름'에 계약이 체결되어 있어야 노출됩니다. \[계약하기\] 또는 \[계약 관리\]를 통해 계약을 체결한 뒤 광고그룹을 ON으로 두어야 광고가 노출됩니다.

**알아두세요.**

광고그룹의 현재 노출 상태는 목록의 '상태' 항목에서 확인하실 수 있습니다. 상위 캠페인이 꺼져 있는 경우에는 상태 항목에 '캠페인 OFF'와 같이 그 사유가 함께 표기됩니다.

**주의하세요.**

광고그룹을 OFF로 변경하면 노출 중인 광고는 즉시 중단되며, 정액제 상품 특성상 OFF 기간에 해당하는 금액은 환불되지 않습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
