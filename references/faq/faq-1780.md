# [AI작성] 초대 중인 회원을 관리하려면 어떻게 하나요?

아직 초대를 수락하지 않은 회원은 \[광고주센터 > 우측 상단 네이버 ID > 광고 계정 관리 > 광고 계정 클릭 > 설정 > 권한 관리 > 회원 관리 > 초대 중인 회원\]에서 확인하고 관리할 수 있습니다.

**목록 구성**

초대 중인 회원 목록은 회원 ID / 권한 레벨 / 초대 일자 / 관리 항목으로 구성됩니다. '관리'에서 초대 취소와 권한 수정을 할 수 있습니다.

**초대 취소**

1.  취소할 회원 행의 \[초대 취소\]를 클릭합니다.
    
2.  확인 안내에서 동의하면 초대가 취소됩니다.
    

**권한 수정**

1.  권한을 변경할 회원 행의 \[권한 수정\]을 클릭합니다.
    
2.  변경할 권한 레벨('운영 관리' 또는 '운영 조회')을 확인하고 저장합니다.
    

**알아두세요.**

초대 취소·권한 수정은 권한 부여 권한이 있는 회원만 할 수 있습니다. 권한이 없으면 해당 버튼이 표시되지 않습니다.

**참고.**

초대 중인 회원이 없으면 "초대 중인 회원이 없습니다."가 표시됩니다. 초대 취소에 실패하면 "초대 취소에 실패했습니다."가 안내됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
