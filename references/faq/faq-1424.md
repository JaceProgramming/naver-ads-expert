# '쇼핑검색광고-쇼핑 브랜드형' 키워드는 어떻게 등록하나요?

네이버광고주센터의 ‘광고 관리’ 메뉴에서 등록된 캠페인 > 광고 그룹을 선택한 후, 하단의 ‘키워드’ 탭에서 \[새 키워드\] 버튼을 클릭하면 키워드 추가 팝업창이 노출됩니다.

키워드는 키워드 유형을 선택한 후, 유형에 맞는 키워드를 직접 입력하거나 연관키워드를 추가하여 등록할 수 있습니다.

키워드 추가하기

**1\. 키워드 유형을 선택합니다.**

-   키워드 유형(내 브랜드 키워드, 다른 브랜드 키워드, 일반 키워드)을 선택합니다.
    
-   키워드 유형 선택 시, 툴팁(좌측 상단의 물음표)과 키워드 유형별 설명(우측 상단)을 참고해 주세요.

**2\. 키워드를 선택합니다.**

**① 직접 입력하기**

-   선택한 키워드에서 직접 키워드를 입력할 수 있습니다.
    
-   키워드는 한 줄에 한 개씩 입력합니다.
    

**② 연관키워드 조회 및 선택하기**

• 연관키워드 조회

\- 광고그룹기준 연관키워드가 존재하는 경우, 기존 광고그룹 정보를 기반으로 한 연관키워드가 별도의 조회없이 제공됩니다.

\- 직접 원하는 기준을 입력하여 연관키워드를 조회할 수 있습니다.

• 연관키워드 선택

\- 연관키워드 리스트에서 '추가' 버튼을 클릭하여 키워드를 추가할 수 있습니다.

\- 연관키워드는 '키워드 유형별'로 제공되지 않습니다.

따라서 연관키워드를 확인하고, '키워드 유형'을 먼저 결정한 후에 유형에 맞는 키워드만 선택하세요.

선택한 키워드에 입력된 키워드가 키워드 유형과 맞는지 확인한 후, \[저장 후 닫기\] 버튼을 클릭합니다.

등록한 키워드는 검토 영업일 1~2일 소요되고 통과되면 광고로 노출됩니다.

연관키워드는 과거데이터 기반으로 통계시스템에서 추출한 결과로 실제 성과나 노출가능을 보장하지는 않습니다.

**알아두세요.**

-   한 번에 등록 가능한 키워드 개수는 100개 입니다.(광고그룹 내 1천개까지 등록 가능)
    
-   많은 키워드를 한 번에 등록 원하실 경우에는 '대량관리'기능을 통해 진행 가능합니다.
    
-   쇼핑검색광고- 쇼핑 브랜드형의 연관키워드는 '쇼핑브랜드형' 유형에 한정된 결과이므로
    
-   다른 유형의 캠페인이나 광고그룹유형에는 활용하지 않도록 유의해 주세요.
    
-   쇼핑검색광고-쇼핑 브랜드형의 연관키워드는 '도구 > 키워드도구(파워링크한정)'나 Open API로는 제공되지 않습니다.
