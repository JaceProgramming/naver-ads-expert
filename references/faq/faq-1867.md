# [AI작성] ADVoost 쇼핑 캠페인은 어떻게 만드나요?

ADVoost 쇼핑은 상품을 최적의 유저와 지면에 자동으로 노출시켜 판매 성과를 극대화하는 자동 쇼핑 성과 최대화 캠페인입니다. 다른 디스플레이광고 유형과 달리 **광고 그룹·소재 단계가 없고 '애셋그룹' 단계만** 거치는 점이 가장 큰 차이입니다.

**만들기 흐름**

광고주님께서는 '광고 관리 > ADVoost 쇼핑'에서 \[+ 새 캠페인\]을 클릭한 뒤 다음 2단계로 진행하십니다.

1.  **캠페인** — 캠페인 이름과 ADVoost 쇼핑 설정(전환 추적·입찰 전략·예산), 게재 일정을 입력합니다.
    
2.  **애셋그룹** — 광고에 노출할 상품(아이템 세트)과 시그널(잠재고객 타겟·성별/연령 데모그래픽)을 설정합니다.(이미지·텍스트·로고)을 직접 등록하는 단계는 없으며, 소재는 상품 기반으로 자동 생성됩니다.
    

두 단계를 마치면 '광고 만들기 완료' 화면으로 이동합니다.

**다른 유형과의 구조 차이**

| **구분** | **ADVoost 쇼핑** |
| --- | --- |
| 광고 단위 | 광고 그룹·소재 없이 **애셋그룹**이 광고 단위입니다. |
| 입찰·예산·게재 일정 | 광고 그룹이 아닌 **캠페인 단계**에서 한 번에 결정됩니다. |
| 타게팅 | 오디언스·콘텍스트 등을 직접 설정하지 않고, **자동 최적화**됩니다. |
| 소재 | 상품 정보를 토대로 다양한 형태의 소재가 자동으로 구성됩니다. |

**알아두세요.**

ADVoost 쇼핑은 자체 자동 최적화로 운영되므로 '캠페인 예산 최적화(CBO)'를 지원하지 않습니다. 예산은 캠페인 단계에서 직접 설정하시면 됩니다.

**참고.**

캠페인을 만들려면 대표 URL로 선택할 네이버 쇼핑몰 비즈채널이 먼저 등록되어 있어야 합니다.
