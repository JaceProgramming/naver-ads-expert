# [AI작성] 파워링크 광고그룹 상세 화면 안내

파워링크 캠페인 상세에서 광고그룹 이름을 클릭하면 광고그룹 상세 화면으로 진입합니다. 광고그룹 정보 관리, 키워드·제외 검색어·소재·확장 소재 관리, 타겟팅 설정을 통합적으로 수행할 수 있습니다.

**진입 경로**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 파워링크\]에서 캠페인 이름을 클릭합니다.
    
2.  캠페인 상세의 '광고그룹' 탭에서 광고그룹 이름을 클릭합니다.
    

**광고그룹 정보 영역**

화면 상단에 광고그룹 정보가 표시되며, 우측 \[수정\]으로 설정을 변경할 수 있습니다.

| **항목** | **설명** |
| --- | --- |
| 상태 | 운영 가능 / 중지: 광고그룹 OFF 등 현재 운영 상태가 표시됩니다. |
| 채널 정보 | 광고그룹에 연결된 채널 URL이 표시됩니다. |
| 기본 입찰가 | 70원~100,000원 범위로 표시되며, 광고그룹 수정에서 변경할 수 있습니다. |
| 하루 예산 | 50원~1,000,000,000원 또는 제한없음으로 표시됩니다. |
| 매체 | 모든 매체 / 일부 매체 중 설정값이 표시됩니다. |
| 소재 노출 방식 | 성과 기반 노출 / 동일 비중 노출 중 설정값이 표시됩니다. |

**탭 구성**

'키워드' 탭이 기본 선택되며 기본 탭 4개가 항상 표시됩니다. 타겟팅 탭은 \[타겟팅 탭 추가\]로 활성화한 항목만 표시됩니다.

| **탭** | **설명** |
| --- | --- |
| 키워드 (기본) | 광고그룹에 등록된 키워드를 조회·관리합니다. |
| 제외 검색어 (기본) | 광고 노출을 제외할 검색어를 관리합니다. |
| 소재 (기본) | 광고그룹에 등록된 소재를 조회·관리합니다. |
| 확장 소재 (기본) | 광고그룹 단위 확장 소재를 조회·관리합니다. |
| 타겟팅 탭 (추가) | \[타겟팅 탭 추가\]로 요일·시간대 / 지역 / 연령대 / 성별 / 이용자 세그먼트를 추가해 설정합니다. |

**관리 버튼·안내**

각 탭 우측에 \[새 키워드\]·\[선택한 키워드 관리\]·\[대량관리\]·\[다운로드\]·\[열 맞춤 설정\]·\[상세 데이터\] 등이 표시됩니다. 노출 가능한 소재가 없으면 '광고그룹에 노출할 수 있는 소재가 없습니다. 소재 탭에서 등록 또는 검토 상태를 확인해 주세요. 검토에는 영업일 기준 1~2일이 소요되며, 통과 후에 노출됩니다.' 안내가 표시됩니다. 비즈채널이 보류·노출 제한 상태이면 '비즈채널 검토가 보류되어 광고가 노출되지 않습니다.' 안내와 \[비즈채널 확인하기\]가 표시됩니다.

**알아두세요.**

광고그룹 정보 영역의 \[수정\]을 클릭하면 '광고그룹 수정' 창이 열려 광고그룹 이름·기본 입찰가·하루 예산·고급옵션을 변경할 수 있습니다. 타겟팅 탭은 \[타겟팅 탭 추가\]에서 활성화한 항목만 표시되며, 다음 진입 시에도 설정이 유지됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
