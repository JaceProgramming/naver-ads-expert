# 기여전환 이란?

**기여 전환이란 무엇인가요?**

기여 전환이란 여러 광고를 통해 유저가 유입된 후 전환 이벤트가 발생했을때, 전환 이벤트 발생에 기여한 광고에 대해서 기여 전환 모델에 따라 기여도를 분배하는 방식을 의미합니다.

기여 전환은 검색 광고와 디스플레이 광고를 통합하여, 전환 추적 기간 내에 발생된 클릭을 기준으로 집계합니다.

기여전환은 전환 측정 방식에 따라 아래 두가지 모델로 집계되며 캠페인 계위로만 제공됩니다.

-   마지막클릭 : 전환 이벤트 발생 전 마지막으로 클릭된 광고에 100% 기여를 인정해 줍니다.
    
-   데이터기반 : 전환 이벤트 발생 전 클릭된 여러 광고들의 기여도를 분석해 각 광고에 전환 기여도를 적절히 분배합니다.

**■ 참고사항 :** 총 전환과의 차이

총 전환은 검색광고와 디스플레이 광고를 구분하여, '마지막클릭' 모델을 기준으로 집계합니다. 즉, 전환이벤트 발생 전 여러 광고를 클릭했더라도 광고 유형(검색광고, 디스플레이 광고)별로 각각 마지막 클릭을 기준으로 전환이 집계됩니다.

예를 들어, 전환 추적 기간내 디스플레이 광고 클릭 후 검색광고를 클릭 하고 전환 이벤트가 발생했을 경우,

-   총 전환에서는 디스플레이 광고, 검색광고 각각 1건씩 집계됩니다. (검색광고와 디스플레이 광고를 구분 함)
    
-   기여 전환(마지막클릭)에서는 검색광고에 1건이 집계됩니다. (검색 광고와 디스플레이 광고를 구분하지 않음)
    
-   기여 전환(데이터기반)에서는 디스플레이 광고, 검색 광고의 기여도를 분석하여 전환수가 분배 되어 집계됩니다.
    

**기여전환수, 기여전환매출액 지표는 무엇이며 어디서 확인할 수 있나요?**

기여전환는 \[전체 캠페인\] 메뉴에서 캠페인 기준으로만 제공되며, '열 맞춤 설정'을 통해 확인하실 수 있습니다.

기여전환 지표의 정의는 다음과 같습니다.

| **구분** | **지표** | **정의** |
| --- | --- | --- |
| 전환 지표 | 기여전환수(마지막클릭) | 검색광고와 디스플레이 광고를 통합하여, 전환 이벤트 발생 전 마지막으로 클릭한 광고에 100% 기여를 인정하여 집계된 전환 수 입니다. |
| 기여전환매출액(마지막클릭) | 검색광고와 디스플레이 광고를 통합하여, 전환 이벤트 발생 전 마지막으로 클릭한 광고에 100% 기여를 인정하여 집계된 전환매출액(전환가치)입니다. |
| 기여전환수(데이터기반) | 검색광고와 디스플레이 광고를 통합하여, 전환 이벤트 발생 전 클릭된 여러 광고들의 기여도를 분석해 각 광고에 전환 기여도를 적절히 분배하여 집계된 전환 수 입니다. |
| 기여전환매출액(데이터기반) | 검색광고와 디스플레이 광고를 통합하여, 전환 이벤트 발생 전 클릭된 여러 광고들의 기여도를 분석해 각 광고에 전환 기여도를 적절히 분배하여 집계된 전환매출액 입니다. |

**■ 참고사항**

전환 지표를 확인하려면 전환 추적이 설정된 광고의 사이트가 \[도구 > 전환 추적 관리\]에 '사용중'인 상태로 등록되어 있어야 합니다.

Beta 제공 지표로, 집계 기준은 변경될 수 있습니다.

기여전환 지표는 2026년 3월 23일 데이터부터 조회 가능하며, 이전 기간으로 조회시 해당 지표는 모두 0으로 표시됩니다.
