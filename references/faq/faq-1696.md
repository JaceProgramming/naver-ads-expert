# [AI작성] 광고 정보를 검색하려면 어떻게 하나요?

**적용 대상:** 검색광고·디스플레이광고 (상단 통합 검색창에서 광고 정보 통합 검색)

광고주센터 상단의 통합 검색창을 사용하면 캠페인·광고그룹·소재 등 광고 정보를 한 번에 찾아볼 수 있습니다. 검색 대상으로 검색광고 또는 디스플레이 광고를 선택할 수 있으며, 선택한 상품에 따라 검색되는 광고 정보의 종류가 달라집니다.

**검색 절차**

1.  광고주센터 상단의 통합 검색창에서 검색 대상('검색광고' 또는 '디스플레이 광고')을 선택합니다.
    
2.  검색어를 입력하면 미리보기 결과가 표시됩니다.
    
3.  \[전체보기\]를 클릭하면 검색 결과 화면으로 이동합니다.
    
4.  검색 결과 화면에서 원하는 탭을 선택하여 유형별로 결과를 확인합니다.
    

**검색 결과 탭**

선택한 검색 대상에 따라 결과 탭이 다르게 표시됩니다.

| **검색 대상** | **결과 탭** |
| --- | --- |
| 검색광고 | 캠페인 · 광고그룹 · 소재 · 키워드 · 확장 소재 · 상품군 |
| 디스플레이광고 | 캠페인 · 광고그룹 · 애셋 그룹 · 광고 소재 |

**알아두세요.**

각 탭의 결과는 표 형태로 표시되며, 결과가 많을 때는 필터를 적용해 원하는 항목으로 좁혀서 확인할 수 있습니다. 애셋 그룹은 ADVoost 쇼핑 광고에서 사용합니다.

**참고.**

마지막으로 조회한 탭이 자동으로 유지되어, 재진입 시 이전에 확인했던 탭이 먼저 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
