# [AI작성] 광고그룹 공유예산 상세 화면에서는 무엇을 할 수 있나요?

\[광고주센터 > 검색광고 > 도구 > 공유예산 관리\]의 \[광고그룹 공유예산\] 탭에서 공유예산 이름을 클릭하면 광고그룹 공유예산 상세 화면으로 진입합니다. 해당 공유예산에 포함된 광고그룹을 추가·관리하고 성과 지표를 확인합니다.

**화면 구성**

-   **안내 영역**: '광고그룹 공유예산이란 계정의 여러 광고그룹에 공유하는 하나의 평균 일일 예산입니다.' 안내문이 표시됩니다.
    
-   **기간 선택 영역**: 성과 지표 조회 기간을 설정합니다.
    
-   **관리 버튼**: \[광고그룹 추가하기\] / \[전체 다운로드\] / \[열 맞춤 설정\] (광고그룹 이름 외 6개)
    
-   **연결 광고그룹 목록 표**: 컬럼은 '광고그룹 이름 / 상태 / 노출수 / 클릭수 / 클릭률(%) / 평균 CPC / 총비용'으로 구성됩니다.
    

**알아두세요.**

공유예산의 성과는 조회 기간 동안 해당 공유예산에 포함된 광고그룹의 성과의 총합으로, 광고그룹 개별의 성과와는 상이할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
