# [AI작성] 디스플레이광고 캠페인 상세 화면에서는 무엇을 확인하나요?

**적용 대상:** 디스플레이광고(웹사이트 전환·앱 전환·인지도 및 트래픽·동영상 조회·ADVoost 쇼핑·카탈로그 판매·쇼핑 프로모션·참여 유도)

디스플레이광고 캠페인 상세 화면에서는 캠페인의 성과 추이와 핵심 정보를 확인하고, 해당 캠페인에 속한 광고그룹을 관리할 수 있습니다. 캠페인 목록에서 캠페인 이름을 클릭하면 이동합니다.

**화면 구성**

| **영역** | **설명** |
| --- | --- |
| 캠페인 성과 | 선택한 기간의 성과 추이 그래프입니다. '총비용', '노출수', '클릭수', '결과' 등 지표를 선택해 볼 수 있습니다. 기본값은 최근 7일이며, 성과가 없으면 '데이터가 없습니다.'가 표시됩니다. |
| 캠페인 정보 | 화면 우측에 고정되어 캠페인의 핵심 정보와 ON/OFF, \[수정\] 진입을 제공합니다. |
| 광고그룹 목록 | 화면 하단에 해당 캠페인의 광고그룹 목록이 표시되며, 광고그룹을 추가·관리할 수 있습니다. |

**캠페인 정보 항목**

캠페인 정보 영역에는 캠페인 이름, 캠페인 목적, 대표 URL, 전환 추적 대상, 예산 최적화 등이 표시됩니다. 표시되는 항목은 캠페인 목적에 따라 다릅니다.

| **항목** | **표시 조건** |
| --- | --- |
| 대표 URL | 8개 목적 모두 표시됩니다. |
| 전환 추적 대상 | '참여 유도'를 제외한 목적에서 표시됩니다. |
| 예산 최적화 | '웹사이트 전환', '앱 전환', '인지도 및 트래픽', '쇼핑 프로모션', '참여 유도'에서 표시됩니다. |
| 설문조사 링크 | '참여 유도' 목적에서 표시됩니다. |

**참고.**

'ADVoost 쇼핑' 목적은 기간·입찰·예산 정보가 함께 표시되며, 광고그룹·소재 대신 애셋그룹으로 운영됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
