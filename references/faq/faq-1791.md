# [AI작성] 대시보드에서 계정을 즐겨찾기로 등록하거나 해제하려면 어떻게 하나요?

관리 계정 대시보드의 하위 연동 계정 목록에서 자주 사용하는 계정을 즐겨찾기로 표시할 수 있습니다.

**등록·해제 방법**

1.  대시보드 > 하위 연동 계정 목록에서 원하는 계정 행의 '즐겨 찾기' 별 아이콘을 선택합니다.
    
2.  등록 시 'ON' 상태(채워진 별), 해제 시 'OFF' 상태(빈 별)로 표시됩니다.
    
3.  해제 시 '즐겨찾기 삭제하시겠습니까?' 확인 안내에서 진행하면 즐겨찾기가 해제됩니다.
    

**즐겨찾기 정렬**

'즐겨 찾기' 컬럼 헤더의 정렬 기능을 사용하면 즐겨찾기로 등록한 계정을 우선 정렬해 확인할 수 있습니다.

**주의하세요.**

즐겨찾기 변경에 실패하면 '즐겨찾기 변경에 실패했습니다.' 안내가 표시되고 별 아이콘은 이전 상태로 되돌아갑니다. 최대 등록 가능 즐겨찾기 개수를 초과한 경우 '최대 등록 가능 즐겨찾기 개수를 초과했습니다.' 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
