# [AI작성] 쇼핑검색 캠페인 상세의 광고그룹 목록 화면은 어떻게 구성되어 있나요?

쇼핑검색 캠페인 상세 화면 하단의 '광고그룹' 영역에서 해당 캠페인에 속한 광고그룹을 조회·관리할 수 있습니다.

**진입 경로**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 쇼핑검색\] 캠페인 목록에서 캠페인 이름을 클릭합니다.
    
2.  캠페인 상세 화면에서 '광고그룹' 탭을 선택합니다.
    

**광고그룹 목록 표**

| **항목** | **설명** |
| --- | --- |
| ON/OFF | 광고그룹의 광고 노출 여부를 설정합니다. |
| 광고그룹 이름 | 광고그룹 이름을 표시합니다. 클릭하면 광고그룹 상세로 이동합니다. |
| 상태 | '운영중', '검토중', '중지: 캠페인 OFF' 등 현재 운영 상태를 표시합니다. |
| 그룹 유형 | 쇼핑몰 상품형 / 제품 카탈로그형 / 쇼핑 브랜드형 중 하나가 표시됩니다. |
| 기본 입찰가 | 광고그룹 기본 입찰가를 표시하며, 클릭해 직접 수정할 수 있습니다(50~100,000원). |
| 채널 정보 | 광고그룹에 연결된 쇼핑 채널 정보를 표시합니다. |
| 노출수 / 클릭수 / 클릭률(%) / 평균 CPC / 총비용 / 하루 예산 | 선택한 기간의 성과 데이터와 예산을 표시합니다. |

**주요 기능**

-   **\[새 광고그룹\]**: 그룹 유형을 먼저 선택한 뒤 광고그룹 정보를 입력해 생성합니다.
    
-   **\[선택한 광고그룹 관리\]**: 1개 이상 선택해 입찰가·매체·예산·PC/모바일 입찰가중치 변경, 다른 캠페인으로 복사 등 일괄 작업을 수행합니다.
    
-   **\[ADVoost 쇼핑 광고 시작하기\]**: ADVoost 통합 마케팅 서비스와 연동해 쇼핑 광고를 시작합니다.
    

그 밖에 \[다운로드\]·\[열 맞춤 설정\]·\[상세 데이터\]와 필터·페이지 이동이 제공됩니다.

**참고.**

입찰가 범위를 벗어난 금액(50원 미만 또는 100,000원 초과)을 입력하면 에러 메시지가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
