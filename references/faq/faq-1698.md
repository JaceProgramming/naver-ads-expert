# [AI작성] 캠페인 목록의 상세 데이터를 조회하려면 어떻게 하나요?

캠페인 목록에서 \[상세 데이터\]를 클릭하면 PC/모바일 구분, 요일 구분 등 다양한 기준으로 성과 데이터를 분리하여 조회할 수 있습니다. 선택한 기준에 따라 각 행 아래에 세부 데이터 행이 추가로 표시됩니다.

**조회 절차**

1.  캠페인 목록으로 이동합니다.
    
2.  테이블 상단의 \[상세 데이터\]를 클릭합니다.
    
3.  아래 메뉴 중에서 원하는 기준을 선택합니다.
    

**상세 데이터 메뉴**

| **메뉴** | **설명** |
| --- | --- |
| PC/모바일 구분 | 디바이스별(PC, 모바일) 성과 데이터를 분리하여 조회합니다. |
| 요일 구분 | 요일별(월~일) 성과 데이터를 분리하여 조회합니다. |
| 시간대 구분 | 시간대별 성과 데이터를 분리하여 조회합니다. |
| 지역 구분 | 시/도 단위 지역별 성과 데이터를 분리하여 조회합니다. |
| 검색/콘텐츠 매체 구분 | 검색 매체와 콘텐츠 매체별로 성과 데이터를 분리하여 조회합니다. |
| 상세 데이터 지우기 | 적용된 상세 데이터를 해제하고 기본 테이블로 돌아갑니다. |
| 다차원보고서로 이동 | 더 정밀한 분석이 필요한 경우 다차원보고서 화면으로 이동합니다. |

**알아두세요.**

더 다양한 조건을 조합한 분석이 필요하다면 '다차원보고서로 이동'을 선택하여 보고서를 생성할 수 있습니다.

**참고.**

여러 기준을 동시에 적용할 수는 없으며, 새로운 기준을 선택하면 이전 기준은 해제됩니다. '상세 데이터 지우기'는 상세 데이터가 적용된 상태에서만 선택할 수 있으며, 적용된 데이터가 없으면 비활성 상태로 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
