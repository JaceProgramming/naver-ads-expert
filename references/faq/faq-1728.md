# [AI작성] 디스플레이광고 비즈채널 목록 화면은 어떻게 구성되어 있나요?

**디스플레이광고 비즈채널 목록 화면 안내**

비즈채널 목록 화면에서는 광고계정에 등록된 디스플레이광고 비즈채널 전체를 조회하고, 검토 상태 확인과 상세 이동, 신규 등록을 수행할 수 있습니다.

경로: \[광고주센터 > 디스플레이광고 > 구성요소 관리 > 비즈채널\]

**목록 구성**

| **항목** | **설명** |
| --- | --- |
| 채널 ID | 비즈채널 ID 번호 |
| 비즈채널 이름 | 등록한 비즈채널 이름 / 클릭 시 수정, 삭제, 상세 이동 |
| 유형 | 웹사이트 / 모바일 앱 / 네이버 쇼핑 |
| URL | 채널의 주소 또는 앱 식별 정보 |
| 비즈채널 정보 | 비즈채널 인증정보 및 사용 앱 정보 |
| 검토 상태 | 승인, 검토 중, 반려로 표시 |
| 생성일 | 비즈채널을 등록한 날짜 |

**검색·필터와 검토 의견 확인**

상단 검색어 입력과 유형 필터, 검토 상태 필터로 목록을 좁혀 볼 수 있습니다. 검토 상태가 '반려'인 비즈채널의 상태를 누르면 검토 의견이 표시되어, 최신 반려 사유와 검토자 의견을 확인할 수 있습니다. 수정 후 재검토를 요청하라는 안내가 함께 제공됩니다. 상세 사유가 없는 경우에는 정책 가이드를 참고하라는 안내가 표시됩니다.

1.  새 비즈채널이 필요하면 \[비즈채널 추가\]를 클릭합니다.
    
2.  비즈채널 이름을 클릭하면 상세 화면으로 이동합니다.
    

**참고.**

목록은 페이지 단위로 나누어 표시됩니다. 등록된 비즈채널이 없으면 '등록된 비즈채널이 없습니다' 안내가 표시됩니다.

**주의하세요.**

\[비즈채널 추가\] 등 등록·수정 기능은 권한에 따라 비활성화될 수 있습니다. 목록 조회는 모든 권한에서 가능합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
