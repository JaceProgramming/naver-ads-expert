# 성과형 디스플레이광고 기기에서 광고가 어떻게 보이는지 궁금해요.

**■ '기기에서 미리보기' 기능 사용하기**

실제 광고가 노출되는 게재 위치에서 등록한 광고를 노출시켜 테스트하고 클릭 시 랜딩 URL 연결을 확인해 볼 수 있는 '기기에서 미리보기' 기능을 제공합니다.

**■ '기기에서 미리보기' 를 사용할 사용자 정보 등록하기**

'기기에서 미리보기' 는 사전에 등록된 유저가 해당 매체에 로그인하여 테스트로 전송한 광고를 확인할 수 있는 기능으로, 사용자 정보 등록 절차가 필요하며 방법은 다음과 같습니다.

**STEP 1.** **미리보기 기능을 사용할 사용자 식별 정보 등록**

• 기기에서 미리보기는 네이버ID 식별자 확인이 가능한 지면에서 테스트 광고를 노출시킬 수 있습니다.

• 미리보기용 네이버 ID 는 대시보드 우상단 ‘내 아이디 선택 > 내 정보 관리 > 내 정보’ 영역에 진입한 후

네이버 ID (미리보기용 ID) 에서 확인해 주세요.

• 미리보기용 네이버 ID는 가입 시 입력한 네이버 ID가 자동으로 등록되오니 기능을 실행할 네이버 ID의 변경이 필요한 경우에만 변경해 주세요.

**STEP 2.** **기기에서 미리보기 실행**

• 사용자 등록이 완료되었다면 \[기기에서 미리보기\] 버튼을 통해 실행시킬 수 있습니다. 버튼 위치는 아래와 같습니다.

◦ 광고 소재 대시보드 > 광고 소재 정보 패널 > \[기기에서 미리보기\] 선택

◦ 소재 편집 화면 > 우측 소재 미리보기 패널 > \[기기에서 미리보기\] 아이콘 선택

• 해당 버튼을 선택 후 노출시킬 경로를 선택하면 해당 광고의 테스트 노출이 실행됩니다. 광고 노출 경로는 해당 광고 소재의 노출 가능 게재 위치 정보 기준으로 표시되며, 일부 경로는 표시되지 않거나, 또는 여러 지면을 함께 포함하고 있을 수 있습니다.

• 실행된 테스트 광고는 1시간 이내까지 선택한 노출 경로에서 노출 확인이 가능하며 일반적으로 실행 후 수 분 이내에 노출될 수 있습니다.

• 기기에서 미리보기 실행 시 등록된 소재에 대한 노출 형상을 확인할 수 있으며, 광고 클릭 시 등록된 랜딩 URL 이 실행될 수 있으므로, 실제 광고 집행 전 기기에서 미리보기 기능을 통해 노출 및 랜딩에 문제가 없는지 확인해 보시기 바랍니다.

• 테스트 광고가 노출된 경우 재노출되지 않으므로, 다시 확인하시고자 하는 경우 해당 광고 소재에 대한 기기에서 미리보기를 재실행해 주시기 바랍니다.

**■ 참고 사항**

• 밴드 매체에서 '기기에서 미리보기' 실행이 필요하다면 휴대전화 번호 등록이 필요하며, 회원 가입 과정에서 입력된 번호가 표시되오니 미리보기용 번호가 상이하다면 변경해 주세요.

• 만일 기기에서 미리보기를 실행할 사용자가 밴드 서비스에 이미 가입되어 있고, 밴드 서비스에도 동일한 휴대전화 번호가 등록되어 있다면 추가 설정 없이 밴드 매체에 기기에서 미리보기를 실행할 수 있습니다.
