# 무효 클릭이 의심되는데, 조치 방법이 있나요?

네이버 검색광고에서는 안정적으로 검색광고를 이용할 수 있도록 무효 클릭 대응을 위한 전담팀이 운영되고 있으며, 무의미한 과금으로 인해 광고주들에게 피해가 발생하지 않도록 과학적인 방법을 동원해 정밀하게 필터링하고 있습니다.

그럼에도 불구하고 만약 무효 클릭으로 의심되는 과금 클릭이 있다면, 무효 클릭 문의하기를 통해 재검토 요청을 할 수 있습니다. 요청을 위해서는 4가지의 필수 정보가 필요합니다.

-   **클릭 일시:** 광고 클릭이 일어난 날짜와 시각
    
-   **키워드:** 광고 노출이 이루어진 검색 키워드
    
-   **IP:** 광고를 클릭한 기기의 IP 주소
    
-   **URL:** 광고 게재 중인 URL
    

다량의 클릭에 대한 재검토가 필요하다면, Excel 형식의 템플릿 파일로 작성하여 요청할 수 있습니다.

[무효 클릭 문의하기](https://ads.naver.com/help/cleancenter)

무효 클릭이 의심되는 IP 주소를 알고 있다면 노출 제한 IP로 등록하여 해당 IP 주소에서는 광고가 노출되지 않도록 설정할 수 있습니다.

**노출 제한 IP 설정 경로:** [광고주센터](https://ads.naver.com/manage) 접속 후, \[검색광고 > 도구 > 광고 노출제한 관리\]
