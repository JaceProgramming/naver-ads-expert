# [AI작성] 쇼핑검색 소재 상세에서 소재 정보를 확인하려면 어떻게 하나요?

쇼핑검색 소재 상세 화면의 소재 정보 카드에서 상품 또는 카탈로그에 대한 상세 정보를 확인할 수 있습니다. 소재 유형에 따라 표시되는 항목이 다릅니다.

**일반 쇼핑 소재 정보**

| **항목** | **설명** |
| --- | --- |
| 상품 이미지 | 광고에 노출되는 대표 이미지입니다. 패션의류 카테고리의 경우 대표 이미지와 서브 이미지가 함께 표시됩니다. |
| 상품명 | 쇼핑몰에 등록된 상품명입니다. |
| 가격 | 해당 상품의 판매가입니다. |
| 배송비 | 배송비 관련 정보입니다. |
| 카테고리 | 1차~4차 카테고리 정보가 표시됩니다. |
| 네이버 쇼핑 카테고리 | 네이버 쇼핑에서 분류한 카테고리 정보입니다. |
| 쇼핑몰 카테고리 | 쇼핑몰에서 지정한 카테고리 정보입니다. |
| 네이버쇼핑 상품ID | 네이버 쇼핑에서 관리되는 상품ID 입니다. |
| 쇼핑상품 ID | 쇼핑몰에서 부여한 상품 ID입니다. |
| 쇼핑상품 URL | 쇼핑몰 상품 페이지 주소입니다. |
| 브랜드/제조사 | 상품의 브랜드 및 제조사 정보입니다. |
| 구매 조건 | 상품의 구매 조건 정보입니다. |

**카탈로그 소재 정보**

| **항목** | **설명** |
| --- | --- |
| 카탈로그 이미지 | 카탈로그의 대표 이미지 목록입니다. |
| 카탈로그명 | 카탈로그의 이름입니다. |
| 카테고리 | 1차~4차 카테고리 정보가 표시됩니다. |
| 브랜드/제조사 | 카탈로그의 브랜드 및 제조사 정보입니다. |
| 최저가 | 카탈로그 내 상품의 최저가입니다. |
| 판매처 수 | 해당 카탈로그 상품을 판매하는 쇼핑몰 수입니다. |
| 구매 옵션 | 상품의 구매 옵션 정보입니다. |

**알아두세요.**

패션의류 카테고리의 일반 쇼핑 소재에서는 대표 이미지 외에 서브 이미지도 함께 확인할 수 있습니다. 그 외 카테고리에서는 단일 이미지만 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
