# 구매 전환이란 무엇인가요?

구매전환이란 광고를 클릭한 고객이 실제로 ‘구매 완료’까지 한 경우를 말합니다.

즉, 광고 → 클릭 → 상품 확인 → 결제 완료 이 흐름이 끝까지 이어진 결과가 바로 구매 전환입니다.

매출 기준으로 볼 때는 구매 전환이 가장 중요합니다.

**구매 전환은 언제 발생하나요?**

아래 조건을 모두 만족해야 구매 전환으로 집계됩니다.

1\. 고객이 광고를 클릭

2\. 광고를 통해 상품 페이지에 방문

3\. 결제까지 완료

장바구니 담기, 결제 시도, 주문서 작성은 구매 전환이 아니고 결제가 완료된 순간만 구매 전환으로 잡힙니다.

**구매 전환 수란?**

구매 전환 수는 광고를 통해 실제로 완료된 구매 횟수를 의미합니다.

**예시)**

광고 클릭: 100회

구매 완료: 3건

→ 구매 전환 수는 3입니다.

**구매 전환과 총 전환의 차이점**

| **구분** | **의미** |
| --- | --- |
| 총 전환 | 장바구니 담기 + 구매완료 |
| 구매 전환 | 구매완료만 포함 |

**구매 전환 수를 높이는 법**

· 가격 경쟁력이 높이기

· 배송비 줄이기

· 리뷰 수 / 평점 늘리기

· 상세페이지 정보 늘리기

**※ 참고.** 스마트스토어 광고는 상품별 성과 리포트를 제공하지 않습니다.
