# [AI작성] 관리 계정 변경 이력을 기간과 검색으로 조회하려면 어떻게 하나요?

관리 계정 변경 이력 화면에서는 기간 필터와 검색을 사용해 원하는 변경 내역만 조회할 수 있습니다. 조회 조건은 \[계정 관리\]·\[결제 관리\] 탭별로 독립 적용됩니다.

**조회 방법**

1.  도구 > 관리 계정 변경 이력에서 조회할 탭(\[계정 관리\] 또는 \[결제 관리\])을 선택합니다.
    
2.  상단 기간 영역에서 \[이전 기간\] / \[다음 기간\] 버튼과 날짜 범위 입력으로 조회 기간을 설정합니다.
    
3.  우측 '검색 및 필터링' 영역에 검색어를 입력해 목록을 좁힙니다.
    
4.  목록 하단의 페이지 이동으로 다음 결과를 확인하며, 페이지당 표시 건수도 선택할 수 있습니다.
    

**알아두세요.**

관리 계정 변경 이력은 관리 계정 단위 데이터를 다루며, 광고 계정 단위 변경 이력은 해당 광고 계정의 변경 이력 화면에서 확인합니다.

**참고.**

검색 결과가 없으면 '변경 이력이 없습니다.' 안내가 표시됩니다. 검색어를 초기화하면 기본 목록으로 돌아갑니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
