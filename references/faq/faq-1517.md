# [AI작성] 파워링크 캠페인 목록 화면 안내

파워링크 캠페인 목록은 검색광고(파워링크) 캠페인을 조회하고 관리하는 화면입니다. 이 화면에서 캠페인의 성과 지표를 확인하고, 캠페인을 생성·수정·관리할 수 있습니다.

**진입 경로**

\[광고주센터 > 검색광고 > 광고 관리 > 파워링크\]로 이동하면 파워링크 캠페인 목록이 표시됩니다.

**화면 구성**

파워링크 캠페인 목록 화면은 헤더 영역과 캠페인 테이블 영역으로 구성됩니다.

-   **헤더 영역**: 페이지 타이틀 '파워링크'와 함께 조회 기간을 설정할 수 있습니다. 시작일과 종료일을 캘린더에서 선택하거나, 이전/다음 기간 이동 버튼으로 기간을 변경할 수 있으며, 새로고침 버튼으로 데이터를 다시 불러올 수 있습니다.
    
-   **캠페인 테이블 영역**: 등록된 파워링크 캠페인의 성과 데이터를 테이블로 조회할 수 있습니다.
    

**캠페인 테이블 기본 컬럼**

| **컬럼명** | **설명** |
| --- | --- |
| ON/OFF | 캠페인의 노출 상태를 켜거나 끌 수 있습니다. |
| 캠페인 이름 | 캠페인 이름이 표시되며, 클릭하면 캠페인 상세 페이지로 이동합니다. |
| 상태 | 캠페인의 현재 운영 상태가 표시됩니다. '운영가능'은 정상 운영 중인 상태이며, '중지: 캠페인 OFF'는 캠페인이 OFF로 설정되어 광고가 노출되지 않는 상태입니다. |
| 노출수 | 조회 기간 내 광고 노출 횟수입니다. |
| 클릭수 | 조회 기간 내 광고 클릭 횟수입니다. |
| 클릭률(%) | 노출 대비 클릭 비율입니다. |
| 평균 CPC | 클릭 1회당 평균 비용입니다. |
| 총비용 | 조회 기간 내 총 광고 비용입니다. |
| 하루 예산 | 캠페인에 설정된 하루 예산이 표시되며, 클릭하여 바로 수정할 수 있습니다. |

**주요 기능**

-   **\[새 캠페인\]**: 새 파워링크 캠페인을 생성합니다.
    
-   **\[선택한 캠페인 관리\]**: 캠페인을 1건 이상 선택하면 활성화되며, '기간 변경'과 '예산 변경'을 일괄로 수행할 수 있습니다.
    
-   **\[열 맞춤 설정\]**: 기본 9개 컬럼 외에 전환수, 전환율, 전환매출액, 직접전환ROAS 등 추가 컬럼을 표시하거나 숨길 수 있습니다. 현재 추가로 표시 중인 컬럼 수가 '상태 외' 라벨과 함께 표시됩니다.
    
-   **\[상세 데이터\]**: PC/모바일, 요일, 시간대, 지역 등 다양한 기준으로 성과 데이터를 분리하여 조회할 수 있습니다.
    
-   **\[전체 다운로드\]**: 캠페인 목록 데이터를 Excel(.xlsx) 파일로 내려받을 수 있습니다.
    
-   **통합 필터**: 캠페인명, 상태 등 다양한 조건으로 목록을 필터링할 수 있습니다. '필터를 입력해 주세요' 안내가 표시된 입력 영역에 조건을 입력합니다.
    

**알아두세요.**

-   비즈머니 잔액이 부족한 경우 화면 상단에 '비즈머니 잔액이 부족하여 광고가 일시 중지되었습니다. (브랜드검색/신제품검색 제외)' 배너가 표시되며, \[지금 충전하기\]를 통해 충전 화면으로 이동할 수 있습니다.
    
-   등록된 파워링크 캠페인이 없으면 '등록된 파워링크 캠페인이 없습니다' 안내가 표시됩니다.
    
-   캠페인 등록 한도를 초과한 경우 '캠페인 등록 한도를 초과했습니다' 안내가 표시됩니다. 기존 캠페인을 정리한 후 다시 시도해 주세요.
    
-   다운로드에 실패한 경우 '다운로드에 실패했습니다. 잠시 후 다시 시도해 주세요' 안내가 표시됩니다.
    
-   지원하지 않는 필터를 입력하면 '지원하지 않는 필터입니다' 안내가 표시됩니다.
    
-   데이터를 불러오지 못한 경우 '데이터를 불러오지 못했습니다. 잠시 후 다시 시도해 주세요' 안내가 표시됩니다.
    
-   조회 기간을 90일보다 길게 설정하려고 하면 '조회 기간은 최대 90일입니다' 안내가 표시됩니다.
    

**참고.**

테이블 하단에 전체 캠페인 수와 각 지표의 합계가 표시됩니다. 한 페이지에 표시되는 캠페인 수는 기본 10건이며, 20, 50, 100건으로 변경할 수 있습니다. 조회 기간은 최대 90일까지 설정할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
