# [AI작성] 새 쇼핑검색 캠페인을 만들려면 어떻게 하나요?

쇼핑검색 캠페인 목록에서 \[새 캠페인\]을 클릭하면 캠페인 이름·하루 예산·고급옵션을 설정해 새 캠페인을 등록할 수 있습니다. 기존 캠페인을 수정할 때에도 동일한 입력 폼을 사용합니다.

**캠페인 만들기 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 쇼핑검색\] 캠페인 목록에서 \[새 캠페인\]을 클릭합니다. 창 좌측의 \[기존 캠페인 불러오기\]로 기존 설정을 가져올 수 있습니다.
    
2.  아래 설정 항목을 입력합니다.
    
3.  필요 시 \[고급옵션\]에서 추적 URL·광고 노출 기간을 설정합니다.
    
4.  \[저장\]을 클릭하면 캠페인이 등록됩니다.
    

**설정 항목**

| **항목** | **설명** | **입력 조건** |
| --- | --- | --- |
| 캠페인 이름 | 캠페인을 구분할 이름을 입력합니다. 앞뒤 공백은 자동 제거됩니다. | 1~30자, 중복 불가 |
| 하루 예산 | 하루 동안 소진할 최대 광고비를 설정합니다. '제한없음' 선택 시 예산 제한 없이 운영됩니다. | 50~1,000,000,000원 (10원 단위) |
| 공유예산 | 미리 생성한 공유예산이 있으면 선택해 적용할 수 있습니다. 적용 시 하루 예산 대신 공유예산이 사용됩니다. | 공유예산이 있는 경우만 |
| 추적 URL (고급옵션) | 광고 클릭 시 추적할 URL 파라미터를 설정합니다. | 선택 |
| 광고 노출 기간 (고급옵션) | 캠페인의 광고 노출 시작일·종료일을 설정합니다. | 선택 |

**캠페인 수정**

1.  캠페인 목록에서 수정할 캠페인 이름을 클릭해 상세 화면으로 이동합니다.
    
2.  캠페인 정보 영역의 \[수정\]을 클릭합니다.
    
3.  설정 항목을 변경한 뒤 \[저장\]을 클릭합니다.
    

**참고.**

캠페인 이름은 앞뒤 공백이 자동으로 제거됩니다.

**주의하세요.**

캠페인 이름이 중복되거나 예산 범위가 올바르지 않으면 에러 메시지가 표시되며, 내용을 수정한 후 다시 저장해야 합니다. '제한없음'으로 운영하면 경우에 따라 예산을 초과하는 금액이 과금될 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
