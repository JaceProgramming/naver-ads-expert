# [AI작성] 노출 제한된 검색광고 애셋의 재검토를 요청하려면 어떻게 하나요?

검토 상태가 노출 제한된 애셋은 재검토를 요청할 수 있습니다. 애셋 목록 또는 소재 상세에서 해당 애셋의 상태 안내 팝업을 열어 \[재검토요청\]을 클릭하면 됩니다.

**재검토 요청 절차**

1.  애셋 목록(또는 연결 소재 화면)에서 노출 제한 상태 애셋의 상태 안내 영역을 클릭해 '애셋 상태 안내' 팝업을 엽니다.
    
2.  팝업 상단에서 '대상 애셋 명'을 확인합니다.
    
3.  '사유'와 '재검토 요청 방법' 안내를 읽고, 필요 시 소재 등록화면에서 애셋을 수정·보완합니다.
    
4.  '검토 요청' 섹션에서 "재검토 요청에 대해 담당자에게 전달할 서류나 내용이 있나요?"에 대해 '네' 또는 '아니오'를 선택합니다.
    
5.  \[재검토요청\]을 클릭하면 요청이 접수됩니다.
    

**버튼**

-   **\[재검토요청\]**: 재검토를 접수합니다.
    
-   **\[닫기\]**: 팝업을 닫습니다.
    

**알아두세요.**

이미 재검토가 진행 중인 대상은 별도 안내가 표시됩니다. 검토 결과를 기다려 주세요. 일시적인 오류로 요청이 실패하면 안내가 표시되며, 잠시 후 다시 시도해 주세요.

**참고.**

재검토에는 영업일 기준 1~2일이 소요되며, 동일 사유로 다시 노출 제한될 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
