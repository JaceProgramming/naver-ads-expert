# 대용량 다운로드 보고서는 무엇인가요?

대용량 다운로드 보고서는 광고 계정 단위로 특정 시점의 광고 정보 또는 특정 일의 광고 성과 및 전환 보고서를 다운로드할 수 있는 기능입니다.(기본 광고에 대한 보고서는 다차원 보고서 및 광고관리 화면 내 광고 지표를 활용할 수 있습니다.)

**화면 구성 — 2개 탭**

| **탭** | **설명** |
| --- | --- |
| 광고 정보 일괄 다운로드 | 광고 계정 전체의 캠페인·광고그룹·키워드·소재 등 광고 구성 정보를 **통계 없이** 일괄 다운로드 |
| 대용량 보고서 다운로드 | 노출·클릭 등 **통계 지표를 포함**한 대용량 보고서를 신청해 다운로드 |

| **알아두세요.** 광고 구성 정보가 필요하면 '광고 정보 일괄 다운로드' 탭을, 노출·클릭 등 성과 지표가 필요하면 '대용량 보고서 다운로드' 탭을 이용하세요. 보고서는 실시간이 아니며, 화면 상단에 '최근 집계 완료 시간'이 표시됩니다. |
| --- |

다운로드 항목과 날짜를 선택하고 \[생성 요청\]버튼을 클릭하여 보고서 생성을 예약하면 일정 시간 후 보고서가 생성되어 다운로드할 수 있습니다.

데이터는 탭을 열 구분자로 하는 텍스트 파일 형식(TSV)으로 제공되며, 행 구분자는 CRLF입니다. 문자열은 UTF-8로 인코딩되어 있습니다. 또한 제공되는 데이터는 대량 처리에 용이하도록 열의 명칭이 표시되지 않으므로, 사양서의 열 순서를 참고하여 열의 정보를 확인해야 합니다.

[대용량 다운로드 보고서 데이터 사양서 다운로드](https://searchad.naver.com/File/downloadfilen/?type=10&filename=Report_MasterSpecification_02.pdf.pdf)

\*최신 마스터 리포트 사양서는 [마스터리포트](https://gist.github.com/naver-searchad/186ca42e1e8596b0e3dcf74e3a86c04f) [**github바로가기**](https://gist.github.com/naver-searchad/186ca42e1e8596b0e3dcf74e3a86c04f) (<-클릭시 이동), 를 확인해 주시기 바랍니다.

\*기타, 대용량보고서 공지 관련 내용(데이터 장애) 등은 검색광고 API 지원 페이지를 참고해 주시기 바랍니다.

**주의하세요.**

대용량 다운로드 보고서는 데이터베이스, 통계 패키지 등 네이버 네이버광고주센에서 제공하지 않는 전문 데이터 분석관리 도구를 사용하는 고급 사용자용 기능입니다.

제공되는 데이터는 별도의 합산 및 가공이 되어 있지 않으며, 스프레드시트 소프트웨어(예. Microsoft Excel 등)를 이용할 경우 데이터가 일부 누락되거나 확인되지 않을 수 있습니다.

일반적인 광고 관리의 경우 다차원 보고서나 광고 관리 화면 내 광고 지표를 활용하는 것이 효율적입니다.

**광고 정보 일괄 다운로드(마스터 기능 이용하기)**

광고 정보 일괄 다운로드는 특정 시점을 기준으로 광고 계정에 등록된 모든 광고 정보를 다운로드하는 기능입니다.

이때 노출 가능 상태와 같이 상시로 변경되는 정보는 제공되지 않으며, 사용자가 등록한 광고 정보만 제공됩니다.

**1\. 현재 기준 광고 정보 일괄 다운로드**

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfODYg/MDAxNzc0OTE4MTE3NjEw.-0hnzCNHi44jxW0bPmbu46Ivhs0mcxIZbgmWCnbEsWIg.zgwsXEJbYOP_yhPT5H-Tu9MCpwKbapQEQDFwO77GV6Qg.PNG/image.png)

필요한 항목을 선택 후 \[생성 요청\]버튼을 클릭하면 생성 예약이 진행됩니다.

생성 요청 이후 현재 시점을 기준으로 광고 정보가 생성되며, 생성 시점은 요청 목록에서 확인 가능합니다. 생성이 완료되면 상태가 '생성 완료'로 변경되며 다운로드 링크가 표시됩니다. 데이터가 존재하지 않는 경우에는 상태가 "데이터 없음"으로 표시되며, 다운로드 링크가 제공되지 않습니다.

데이터가 존재하지 않는 경우 다운로드 링크가 제공되지 않습니다.

제공되는 광고 정보는 아래와 같습니다.

-   캠페인 마스터: 광고주 계정이 가진 모든 캠페인 정보를 제공합니다.
    
-   캠페인 예산 마스터: 캠페인의 예산 설정 정보를 제공합니다(공유예산 제외)
    
-   비즈채널 마스터: 비즈채널 정보를 제공합니다.
    
-   광고그룹 마스터: 광고그룹의 정보를 제공합니다.
    
-   광고그룹 예산 마스터: 광고그룹 예산 설정 정보를 제공합니다(공유예산 제외)
    
-   등록 키워드 마스터: 키워드 등록이 필수인 광고 키워드 정보를 제공합니다(파워링크, 쇼핑검색 쇼핑브랜드형, 파워컨텐츠, 브랜드검색, 신제품검색)
    
-   파워링크 단일형 소재 마스터: 파워링크 캠페인 유형에 등록된 단일형 소재 정보를 제공합니다(반응형 소재 제외)
    
-   확장소재 마스터 : 확장 소재의 정보를 제공합니다.
    
-   품질지수 마스터: 광고 키워드의 품질지수 정보를 제공합니다(파워링크, 쇼핑검색 쇼핑브랜드형, 파워컨텐츠, 브랜드검색, 신제품검색)
    
-   즐겨찾기 마스터: 즐겨찾기 목록 정보를 제공합니다.
    
-   즐겨찾기 설정 마스터: 즐겨찾기에 설정된 소재, 광고 키워드, 광고그룹 리스트 정보를 제공합니다.
    
-   광고매체 마스터: 광고가 노출되는 매체 정보를 제공합니다.
    
-   업종코드 마스터: 키워드 도구에서 사용되는 업종코드 정보를 제공합니다.
    
-   쇼핑검색 쇼핑몰상품형 상품 마스터 : 쇼핑검색 쇼핑몰상품형 광고그룹 유형인 광고그룹에 등록된 소재 정보를 제공합니다.
    
-   파워컨텐츠 소재 마스터 : 파워컨텐츠 캠페인 유형에 등록된 소재에 대한 정보를 제공합니다.
    
-   쇼핑검색 쇼핑브랜드형 상품그룹 마스터 : 쇼핑검색 쇼핑브랜드형 광고그룹 유형인 상품을 묶은 라이브러리인 상품그룹의 구성 정보를 제공합니다.
    
-   쇼핑검색 제품카탈로그형 상품 마스터 : 쇼핑검색 제품카탈로그형 광고그룹 유형인 광고그룹에 등록된 소재 정보를 제공합니다.
    
-   쇼핑검색 쇼핑브랜드형 상품그룹관계 마스터 : 쇼핑검색 쇼핑브랜드형 광고그룹 유형에서 사용되는 상품그룹은 광고그룹과 연결을 통해 광고에 반영됩니다. 광고그룹과 상품그룹의 연결 정보를 제공합니다.
    
-   쇼핑검색 쇼핑브랜드형 썸네일소재 마스터 : 쇼핑검색 쇼핑브랜드형 광고그룹 유형의 상품에서 사용되는 썸네일 이미지형 소재 정보를 제공합니다.
    
-   쇼핑검색 쇼핑브랜드형 배너소재 마스터 : 쇼핑검색 쇼핑브랜드형 광고그룹 유형의 상품에서 사용되는 배너 이미지형 소재에 대한 정보를 제공합니다.
    
-   타겟팅 대상 마스터 : 타겟팅 대상과 타겟팅 설정 요소 정보를 제공합니다.
    
-   공유예산 마스터 : 공유 예산 정보를 제공합니다.
    
-   파워링크 애셋 마스터 : 파워링크 캠페인 유형에 등록된 반응형 소재에서 사용되는 애셋의 정보를 제공합니다.
    
-   파워링크 반응형 소재연결 마스터 : 파워링크 캠페인 유형에 등록된 반응형 소재와 애셋 간의 연결 정보를 제공합니다.
    
-   파워링크 반응형 소재 마스터 : 파워링크 캠페인 유형에 등록된 반응형 소재에 대한 정보를 제공합니다.
    
-   파워링크 병의원 소재 마스터 : 파워링크 캠페인 유형에 등록된 병의원 업종 특화 소재에 대한 정보를 제공합니다.
    

**2\. 변경분 데이터 다운로드하기**

광고 정보 일괄 다운로드 기능을 이용하면 이전에 변경 및 삭제된 광고의 정보도 확인할 수 있습니다.

단, 이력 정보와 같이 모든 변경이나 삭제를 제공하는 것은 아니며 현재 기준으로 최종 값만을 제공합니다.

변경분은 조회 기간을 과거 시점으로 선택하면 다운로드할 수 있습니다. 이때 설정한 시점부터 현재까지 변경이 발생한 정보도 함께 다운로드 됩니다.

변경분은 과거에 존재하였으나 현재는 삭제된 캠페인, 광고 그룹, 소재, 광고 등록 키워드의 정보를 확인할 때 사용할 수 있습니다.

**3\. 광고 정보의 활용**

다운로드된 광고 정보는 각각 종류별 정보만을 담고 있습니다.

<등록 키워드 마스터>

| 커스터머 ID | 광고 그룹 ID | 등록키워드 ID | 등록키워드명 | 키워드 입찰가 | 이하 생략 |
| --- | --- | --- | --- | --- | --- |

등록 키워드가 속한 캠페인이름, 광고그룹이름 등은 다운로드된 캠페인 마스터와 광고 그룹 마스터의 광고 정보 데이터를 데이터베이스의 JOIN 기능으로 결합해 확인할 수 있습니다.

**주의하세요.**

-   광고 정보 일괄 다운로드(마스터 기능 이용하기)의 최대 제공 기간은 '최근 2년(730일)'입니다.
    
-   일부 항목은 변경 분 데이터를 제공하지 않습니다.

**대용량 보고서 기능 사용하기**

대용량 보고서 다운로드는 계정 단위로 특정일에 발생한 광고 성과 및 전환 보고서를 다운로드할 수 있는 기능입니다. 일 단위로만 생성 신청할 수 있으며 기간별 조회 기능은 제공되지 않습니다.

**1\. 보고서 다운로드**

다운로드 항목에서 필요한 보고서 종류를 선택하고 생성 요청하여 사용할 수 있습니다. 조회 기간을 선택하지 않으면 자동으로 전일 데이터로 생성되며 전일 부터 최대 1년까지 선택가능합니다.

단, 보고서 유형에 따라 제공기간이 상이하오니 [검색광고 API 지원사이트](https://github.com/naver/searchad-apidoc/issues/191) 답변내용을 참고하여 주시기 바랍니다.

제공되는 광고 정보는 아래와 같습니다.

-   광고성과 보고서: 광고 키워드와 소재로 발생한 광고 성과를 제공합니다.
    
-   광고성과 상세 보고서: 광고 키워드와 소재로 발생한 광고 성과를 지역/시간대 별로 제공합니다.
    
-   전환 보고서: 광고를 통해 발생한 전환 성과를 제공합니다. 전환 성과는 전환 추적 관리 이용자에게만 제공됩니다.
    
-   전환 상세 보고서: 광고를 통해 발생한 전환 성과를 지역/시간대 별로 제공합니다. 전환 성과는 전환 추적 관리 이용자에게만 제공됩니다.
    
-   확장소재광고 성과 보고서 : 광고의 확장 소재를 통해 발생한 광고 성과를 제공합니다.
    
-   확장소재 전환 보고서: 광고의 확장 소재를 통해 발생한 전환 성과를 제공합니다. 전환 성과는 전환 추적 관리 이용자에게만 제공됩니다.
    
-   파워링크 검색어 보고서 : 파워링크 캠페인 유형의 검색어 별 광고 성과를 제공합니다.
    
-   쇼핑검색 검색어 상세 보고서 : 쇼핑검색 캠페인 유형의 검색어 별 지역/시간대 광고 성과를 제공합니다.
    
-   쇼핑검색 검색어 전환 상세 보고서 : 쇼핑검색 캠페인 유형의 검색어 별 지역/시간대 전환 성과를 제공합니다. 쇼핑검색 쇼핑몰 상품형 및 쇼핑브랜드형 광고그룹 유형에 관한 전환만 제공되며, 전환 성과는 전환 추적 관리 이용자에게만 제공됩니다
    
-   쇼핑검색 쇼핑브랜드형 상품별 성과 보고서 : 쇼핑검색 쇼핑브랜드형 광고그룹 유형에서 집행된 상품의 광고 성과만을 제공합니다. 쇼핑검색 쇼핑몰 상품형 및 제품카탈로그형 광고그룹 유형은 광고 성과 보고서를 통해 성과 확인이 가능합니다.
    
-   쇼핑검색 쇼핑브랜드형 상품별 전환 보고서 : 쇼핑검색 쇼핑브랜드형 광고그룹 유형에서 집행된 상품의 전환만을 제공합니다. 쇼핑검색 쇼핑몰 상품형 광고그룹 유형은 전환 보고서를 통해 전환 확인이 가능합니다. 전환 성과는 전환 추적 관리 이용자에게만 제공됩니다.
    
-   타게팅 성과 보고서 : 타게팅(criterion) 별 광고 성과를 제공합니다.
    
-   타게팅 전환 보고서 : 타게팅(criterion) 별 전환 성과를 제공합니다. 전환 성과는 전환 추적 관리 사용자에게만 제공됩니다.

예를 들어 광고그룹별 광고 성과를 확인하고자 하는 경우, 광고그룹 ID를 기준으로 지표 부분을 합산하여 계산할 수 있습니다.

뿐만 아니라, 동일 광고그룹의 소재별 성과를 각각 확인하는 등 다양한 목적과 용도에 따라 자유롭게 제공 자료를 가공하여 활용할 수 있습니다.

**보고서가 필요한 경우**

-   자체적인 보고서를 작성하여 활용하는 경우, 보고서의 기반 데이터를 빠르고 간단하게 다운로드할 수 있습니다.
    
-   3rd Party 솔루션이나 사내 자체 솔루션을 사용하고 있으나 API 개발을 진행하지 못하는 경우, 대량의 데이터를 한번에 다운로드하여 업로드할 수 있습니다.
    
-   통계패키지나 데이터 베이스 등을 활용하여 통계적인 광고 성과 분석이나 수리적 분석을 하고자 하는 경우, 가공이 되지 않은 RAW 데이터를 다운로드하여 다양한 형태로 분석할 수 있습니다.
