# [AI작성] 관리 계정 간 연동(상위·하위)을 관리하려면 어떻게 하나요?

권한 관리의 '관리 계정 연동' 탭에서 관리 계정 간 상위·하위 연동을 조회하고 관리할 수 있습니다.

**목록 구성**

탭은 '연동 중인'·'연동 요청 중인' 관리 계정으로 구분되며, '연동 중인 상위 관리 계정 N'과 '연동 중인 하위 관리 계정 N' 두 개의 목록을 제공합니다. 두 목록 모두 다음 컬럼으로 구성됩니다.

| **컬럼** | **설명** |
| --- | --- |
| 관리 계정(ID) | 연동된 관리 계정의 번호와 이름입니다. |
| 연동 승인자 ID | 연동을 승인한 회원의 ID입니다. |
| 연동 일자 | 연동이 이루어진 일자입니다. |
| 관리 | \[연동 해제\] 액션을 제공합니다. |

**연동 요청·해제**

1.  하위 관리 계정을 연동하려면 \[하위 관리 계정 연동 요청\]을 선택해 진행합니다.
    
2.  상위 관리 계정 연동은 상위 계정의 초대를 수락하는 방식으로 진행합니다.
    
3.  연동을 해제하려면 해당 행의 \[연동 해제\]를 선택합니다.
    

**알아두세요.**

관리 계정 연동은 상위·하위 양방향으로 구성되며, 연동 관리 액션은 권한이 없는 회원에게는 표시되지 않거나 비활성화됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
