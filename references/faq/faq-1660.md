# [AI작성] 공유예산 관리 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 도구 > 공유예산 관리\]에서 여러 캠페인 또는 광고그룹이 함께 사용하는 평균 하루 예산(공유예산)을 등록·조회·관리합니다. 개별 예산이 먼저 소진되어 광고 노출이 중단되는 상황을 줄이기 위해 사용합니다.

**화면 구성**

화면 상단에는 '캠페인 공유예산'과 '광고그룹 공유예산' 두 개의 탭이 있으며, 탭마다 공유예산 안내 배너가 표시됩니다(\[닫기\]로 숨길 수 있습니다). 조회 기간 선택 영역에서 성과 조회 기간(기본 최근 7일)을 지정합니다.

**목록 구성**

공유예산 목록 표는 다음 컬럼으로 구성됩니다.

| **컬럼** | **설명** |
| --- | --- |
| 공유예산 이름 | 클릭하면 해당 공유예산 상세 화면으로 이동합니다. |
| 상태 | 공유예산의 운영 상태입니다. |
| 하루 예산 | 공유예산에 설정된 하루 예산 금액입니다. |
| 연결된 캠페인 수(광고그룹 수) | 이 공유예산에 연결된 캠페인 또는 광고그룹의 수입니다. |
| 노출수 / 클릭수 / 클릭률(%) / 평균 CPC / 총비용 | 선택한 기간의 성과 데이터입니다. |
| 공유예산 ID | 공유예산의 고유 식별 번호입니다. |

**주요 기능**

-   \[새 공유예산\] — 공유예산 만들기 창을 엽니다.
    
-   \[선택한 공유예산액 변경\] — 목록에서 하나 이상 선택하면 활성화되며, 선택한 공유예산의 하루 예산을 한 번에 변경합니다.
    
-   \[전체 다운로드\] — 목록을 내려받습니다.
    
-   \[열 맞춤 설정\] — 표에 표시할 컬럼을 조정합니다.
    

'필터를 입력해 주세요' 입력란으로 공유예산 이름·상태 등 조건으로 목록을 걸러볼 수 있으며, 하단 페이지네이션에서 페이지와 페이지 크기를 설정합니다.

**알아두세요.**

공유예산을 사용하면 예산 제한으로 캠페인이 종료되는 것을 방지하여 실적 개선에 도움을 줄 수 있습니다. 공유예산의 성과는 조회 기간 동안 포함된 캠페인 성과의 총합으로, 캠페인 개별 성과와 상이할 수 있습니다.

**참고.**

공유예산이 하나도 없으면 '새로운 공유예산을 만들어보세요.' 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
