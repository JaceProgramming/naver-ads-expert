# [AI작성] 이미지 라이브러리 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 구성요소 관리 > 이미지\]에서 광고 소재에 사용했거나 사용하기 위해 등록한 이미지를 확인·다운로드·삭제할 수 있습니다.

**목록 구성**

이미지 목록은 다음 항목으로 구성됩니다.

| **항목** | **설명** |
| --- | --- |
| 이미지 ID | 등록된 이미지의 고유 식별 번호입니다. |
| 이미지 종류 | 이미지의 유형으로, 광고 유형과 사이즈로 표시됩니다. (예: 파워링크\_640\*640, 파워링크\_병의원소재\_파비콘\_48\*48, 쇼핑브랜드\_확장소재\_712\*401, 쇼핑브랜드 로고 등) |
| 파일이름 | 업로드한 이미지의 파일 이름입니다. |
| 이미지 미리보기 | 썸네일이며, 클릭하면 원본 크기로 확인할 수 있습니다. |
| 라이브러리 등록시간 | 이미지를 라이브러리에 등록한 시각입니다. |

**주요 기능**

목록 상단의 \[새 이미지\]로 이미지를 업로드하거나 \[전체 다운로드\]로 이미지를 내려받을 수 있습니다. 하단 페이지네이션에서 페이지와 페이지 크기를 설정하며, 등록된 이미지가 없으면 빈 안내가 표시됩니다.

**알아두세요.**

이미지 라이브러리에는 최대 400개까지 등록할 수 있습니다. 라이브러리의 이미지는 파워링크 이미지 확장 소재, 쇼핑 브랜드 소재 등에 사용됩니다.

**주의하세요.**

삭제된 이미지는 복구할 수 없습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
