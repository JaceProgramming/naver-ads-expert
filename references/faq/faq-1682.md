# [AI작성] 쇼핑 브랜드 상품그룹을 등록하거나 수정하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 구성요소 관리 > 쇼핑 브랜드 상품그룹\]에서 \[새 상품 그룹\]을 클릭하면 '새 상품 그룹 생성' 창이 열립니다. 상품그룹 이름·비즈니스 채널·상품등록 방식을 설정해 등록합니다.

**등록 절차**

1.  \[광고주센터 > 검색광고 > 구성요소 관리 > 쇼핑 브랜드 상품그룹\]에 진입합니다.
    
2.  \[새 상품 그룹\]을 클릭합니다.
    
3.  '상품그룹 이름'(필수)을 1~30자 이내로 입력합니다.
    
4.  '비즈니스 채널'에서 '쇼핑 브랜드 비즈채널을 선택하세요' 목록을 통해 비즈채널을 선택합니다.
    
5.  '상품등록 방식'을 선택합니다.
    

-   전체 상품 등록 — 선택한 비즈채널의 전체 상품을 자동으로 그룹에 포함
    
-   상품 선택 등록 — 그룹에 포함할 상품을 직접 선택
    

1.  \[저장\]을 클릭해 상품 그룹을 등록합니다.
    

**주의하세요.**

상품 그룹의 '상품등록 방식'은 저장 후 수정이 불가능합니다. '상품 선택 등록' 방식의 경우 등록 후 상품 그룹 상세에서 포함 상품을 추가·제거할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
