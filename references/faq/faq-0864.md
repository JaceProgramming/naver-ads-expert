# 디스플레이광고 추적 URL 기능이 궁금해요.

**추적 URL이란?**

추적 URL은 네이버 쇼핑에 등록된 상품 혹은 스토어 랜딩 URL에 개별 광고 성과 분석을 위한 URL 파라미터를 추가할 수 있는 기능입니다.

광고주께서는 추적 URL을 이용하여, 클릭된 광고에 대한 정보를 추가로 제공받음으로써 마케팅 및 광고 효율을 보다 상세하게 분석할 수 있습니다.

추적 URL 기능은 카탈로그 판매 및 ADVoost 쇼핑 캠페인 목적에서만 사용이 가능하며, 캠페인 단위로 설정해야 합니다.

ADVoost 쇼핑 캠페인은 상품 랜딩 URL에 대해서만 파라미터 추가가 가능합니다.

**URL 파라미터란?**

URL의 ? 뒤에 붙는 파라미터 명(Key)=파라미터 값(Value) 형태의 쌍입니다. 여러 개의 파라미터를 붙이기 위해선 각 파라미터 사이에 &를 추가하여 파라미터를 추가할 수 있습니다.

![](https://saedu.naver.com/upfile/1731395495126.png)

**추적 URL 기능 설정 방법**

**STEP 1)** **캠페인 추가 설정 > 추적 URL > 추적 방식 선택**

-   추적 URL을 통해 클릭된 광고에 대한 정보를 제공받는 방식은 다음 2가지 입니다.
    
    -   \- 파라미터 등록 : 네이버 쇼핑에 등록된 상품 혹은 스토어 URL 뒤에 특정 파라미터를 추가하는 방식
        
    -   \- URL 등록 : 별도의 광고 로그 수집 사이트가 존재하여, 광고 클릭 시 로그 수집 사이트를 거쳐 최종 랜딩 URL 페이지로 이동하는 경우 로그 수집 사이트 URL과 함께 파라미터와 값을 입력하는 방식
        
-   URL 파라미터 값 변경은 랜딩 URL에 포함된 파라미터의 값(Value)을 광고주가 입력한 값(Value)으로 변경하는 기능으로, 파라미터 등록 혹은 URL 등록을 체크해야 선택 가능합니다.
    
-   추적 URL 설정 시 반드시 사용자가 클릭한 상품 혹은 쇼핑몰로 랜딩 되어야 하며, 앱 광고를 위해 딥링크 사용 시 앱 설치 유저는 앱 내 해당 상품 페이지, 앱 미설치 유저에게는 상품 및 쇼핑몰 웹페이지로 이동될 수 있도록 설정이 필요합니다.
    
-   상품ID는 {mall\_pid}로 변경이 필요하며 네이버 쇼핑파트너센터의 ‘쇼핑몰 상품ID’로 치환됩니다.
    

![](https://saedu.naver.com/upfile/1731395662612.png)

**STEP 2)** **추적 URL 사용하기**

**A) 파라미터 등록 설정하기**

-   파라미터 등록을 선택하신 경우, 네이버 쇼핑에 등록된 상품 혹은 스토어 URL 뒤에 추가할 파라미터를 입력해주세요.
    
    -   \- 소재 랜딩 URL : 상품 랜딩 URL에 추가할 파라미터 입력
        
    -   \- 스토어 홈 URL(선택) : 스토어 랜딩 URL에 추가할 파라미터 입력
        
-   이 때, 정상적으로 파라미터를 추가하기 위해선 반드시 랜딩 URL 혹은 네이버 쇼핑 상품, 스토어 URL에 "?"가 포함되어 있는지 확인한 후, "?" 포함 여부에 따라 파라미터 입력시 ? 또는 &로 시작해야 합니다.
    
    -   \- "?"가 포함되어 있는 경우 : "&"를 추가한 다음 파라미터 추가
        
    -   \- "?"가 포함되어 있지 않은 경우 : "?" 를 추가한 다음 파라미터 추가
        
-   사용 예시)
    
    -   \- 랜딩 URL https://[www.motor-abcd.com/model-a.html](http://www.motor-abcd.com/model-a.html) 인 경우
        
        -   \* 입력 창에 ?n\_campaign={campaign} 입력
            
        -   \* 최종 랜딩URL은 https://[www.motor-abcd.com/model-a.html](http://www.motor-abcd.com/model-a.html)?n\_campaign={campaign} 로 적용됨
            
    -   \- 랜딩 URL https://[www.motor-abcd.com/model-a.html?category=model\_a](http://www.motor-abcd.com/model-a.html?category=model_a) 인 경우
        
        -   \* 입력 창에 &n\_campaign={campaign} 입력
            
        -   \* 최종 랜딩URL은 https://[www.motor-abcd.com/model-a.html?category=model\_a](http://www.motor-abcd.com/model-a.html?category=model_a)&n\_campaign={campaign} 로 적용됨

**B) URL 등록 설정하기**

-   URL 등록을 선택하신 경우, 광고 클릭시 경유할 로그 수집 사이트 URL과 함께 상품 혹은 스토어 랜딩 URL, 분석할 파라미터와 값을 포함한 전체 URL 정보를 입력해주세요.
    
    -   \- 소재 랜딩 URL : 파라미터를 포함한 전체 상품 URL 입력
        
    -   \- 스토어 홈 URL(선택) : 파라미터를 포함한 전체 스토어 URL 입력
        
-   URL 등록은 https:// 혹은 http:// 프로토콜 형식으로 시작되어야 하며, 소재 랜딩 URL은 입력 시 반드시 {mall\_pid} 혹은 {final\_url}이 포함되어야 합니다.
    
-   입력된 URL은 사용자가 클릭한 상품 혹은 스토어로 랜딩 되어야 합니다.
    
-   사용 예시)
    
    -   \- 경유 사이트를 사용하는 경우
        
        -   \* 로그 수집을 위한 별도의 경유 URL이 [http://www.log-abc.com/log.php](http://www.log-abc.com/log.php%EC%9D%B4%EA%B3%A0,)이고,
            
        -   \* 랜딩 URL(final\_url)이 https://[www.motor-abcd.com/model-a.html](http://www.motor-abcd.com/model-a.html) 일 경우
            
        -   \* 입력 창에 [http://www.log-abc/log.php?n\_final\_url={final\_url}&n\_mall\_pid={mall\_pid}&n\_campaign={campaign}](http://www.log-abc/log.php?n_final_url=%7Bfinal_url%7D&n_mall_pid=%7Bmall_pid%7D&n_campaign=%7Bcampaign%7D) 입력
            
        -   \* 단, 경유하는 로그 수집 사이트에서 반드시 {final\_url} 로 치환될 최종 랜딩 URL로 리다이렉션 하도록 구현되어야 합니다. 그렇지 않을 경우 사용자가 광고를 클릭했 을 때 최종 랜딩 URL에 해당하는 사이트가 정상적으로 보이지 않을 수 있습니다.
            
    -   \- 랜딩 URL을 그대로 사용하는 경우
        
        -   \* 랜딩 URL(final\_url)이 https://[www.motor-abcd.com/model-a.html](http://www.motor-abcd.com/model-a.html) 이고,
            
        -   \* 캠페인 및 상품 단위 광고 파라미터를 붙이고 싶을 경우
            
        -   \* 입력 창에 [https://www.motor-abcd.com/model-a.html](http://%7Bfinal_url%7D/?n_mall_pid=%7Bmall_pid%7D&n_campaign=%7Bcampaign%7D)?n\_mall\_pid={mall\_pid}&n\_campaign={campaign} 입력
            

![](https://ads-home-phinf.pstatic.net/MjAyNTAyMDZfOTEg/MDAxNzM4ODA5NDQzNjQ3.bIqFMNkREPW_3JqNAwKXOrb2NahTsT50tgVj4nbCgRYg.esGzuWABr9yh4Rle8upC4dXRb9gwV7VM9CW9VDaqrgAg.PNG/%EC%B6%94%EC%A0%81URL_%EC%B6%94%EA%B0%804.png)

**주의 사항**

-   등록한 파라미터의 영향으로 랜딩 시 오류가 발생될 수 있으므로 광고 집행 전 정상적으로 랜딩 및 파라미터가 동작 되는지 반드시 확인이 필요합니다(하기 추적 URL 정상 작동 여부 테스트하기 참고)
    
-   랜딩 URL 혹은 네이버 쇼핑 상품 및 스토어 URL 내 파라미터와 같은 명칭의 파라미터를 추가할 경우, URL 추적 기능이 정상적으로 작동하지 않을 수 있습니다.
    
-   MAT 전환 추적을 이용하시는 경우, URL 선택 후 파트너 연동을 통해 {trkcvs}가 포함된 URL 등록이 필요합니다.
    
-   추적 URL 사용을 원치 않는 경우, 설정하지 않음을 선택하거나 파라미터 등록 혹은 URL 등록에 입력한 값에서 치환 변수를 삭제해야 합니다.
    
-   성과형 디스플레이광고에서 제공되는 URL 치환 변수 목록은 아래와 같으며, 반드시 중괄호{}를 포함하여 입력해야 합니다.
    

![](https://ads-home-phinf.pstatic.net/MjAyNTA1MTZfMjUz/MDAxNzQ3MzU0NzkwMzE3.3ClZdMgOEn_x4jamz5iiYb8b5C04ryIzGdyGSteDFJgg.n4nKF2KqY5-bZynCEV5uVsTOGAMsGYi_uGbex3EvL0Eg.PNG/%EC%B9%98%ED%99%98%EB%B3%80%EC%88%98.png)

**STEP 3)** **URL 파라미터 값 변경**

-   URL 파라미터 값 변경은 소재 랜딩 URL 및 스토어 URL에 포함된 파라미터의 값을 다른 값으로 변경하는 기능으로, 파라미터 등록 혹은 URL 등록 기능을 선택한 경우 사용 가능합니다.
    
-   변경할 파라미터 추가를 통해 최대 5개까지 변경하고자 하는 파라미터 값을 입력할 수 있습니다.
    
-   URL 파라미터 값 변경에 입력된 값은 소재 랜딩 URL, 스토어 홈 URL 내 파라미터에 공통으로 적용됩니다.
    
-   사용 예시)
    
    -   1) 광고 파라미터 추가 및 랜딩 URL 내 파라미터를 바꾸고 싶을 경우
        
    -   \- 랜딩 URL이 https://[www.motor-abcd.com/model-a.html?](http://www.motor-abcd.com/model-a.html?)utm\_source=naver&n\_source=shopping 일 때,
        
    -   \- 소재(ad) 광고 파라미터를 추가하고, 파라미터 명 "n\_source"의 값 "shopping"을 "gfa"로 변경하고 싶은 경우 (n\_source=shopping → n\_source=GFA)
        
    -   \- 파라미터 등록에 다음과 같이 입력 : &ad={ad}
        
    -   \- URL 파라미터 값 변경 입력창에 아래와 같이 입력
        
        -   \* 파라미터 명 : n\_source
            
        -   \* 값 : GFA
            
    -   \- 최종 랜딩 URL : https://[www.motor-abcd.com/model-a.html?utm\_source=naver&ad=](http://www.motor-abcd.com/model-a.html?utm_source=naver&ad=)151676&n\_source=GFA
        
    -   2) 별도 광고 파라미터 추가 없이, 랜딩 URL 내 파라미터만 변경하고 싶은 경우
        

\- 랜딩 URL이 https://[www.motor-abcd.com/model-a.html?category=model\_a](http://www.motor-abcd.com/model-a.html?category=model_a) 일 때,

-   -   \- 파라미터 명 "category"의 값 "model\_a"를 "gfa"로 변경하고 싶은 경우 (category=model\_a → category=gfa)
        
    -   \- 파라미터 등록에 다음과 같이 입력 : {final\_url}
        
    -   \- URL 파라미터 값 변경 입력창에 아래와 같이 입력
        
        -   \* 파라미터 명 : category
            
        -   \* 값 : gfa
            
    -   \- 최종 랜딩 URL : https://[www.motor-abcd.com/model-a.html?](http://www.motor-abcd.com/model-a.html?)category=gfa
        

![](https://ads-home-phinf.pstatic.net/MjAyNTAyMDZfMTgz/MDAxNzM4ODA5NDgyMDU0.W19DTLsAVIcMb9WCp9_bLweElaUkY_CfRPiPgEtaNOMg.4UdAZ3qF10Pj2KX2K_zpOvy-IJDTYY-A_90P8PE4KF8g.PNG/%EC%B6%94%EC%A0%81URL_%EC%B6%94%EA%B0%805.png)

**주의 사항**

-   최종 랜딩 URL에 있는 파라미터 값은 URL 파라미터 찾아 바꾸기에 입력한 값을 기준으로 변경됩니다.
    
-   파라미터 명과 값의 특수 문자는 “-”, “\_”만 입력이 가능하며, 중복된 파라미터 명은 입력할 수 없습니다.
    

**STEP 4)** **스토어 홈 추적 URL 사용하기**

-   스토어 홈 추적 URL은 스토어로 랜딩되는 영역에 광고 성과 구분을 할 수 있도록 파라미터를 추가하는 기능입니다.
    
-   카탈로그 판매 캠페인만 사용 가능합니다.
    

![](https://ads-home-phinf.pstatic.net/MjAyNTAyMDZfMTcx/MDAxNzM4ODAxMDU2NjI1.OA8nrTywy_wH9o4HqhwtMOJOIUwgX1qSTxmMyzTGz9Mg.jjXlUMoHVB4HYr--o8NyzsckrM2zY7rFAJwG6P2ZKCcg.PNG/%EC%B6%94%EC%A0%81URL_%EC%B6%94%EA%B0%80.png)

-   파라미터 등록/URL 등록 선택 시 선택 옵션으로 입력 가능하며, {mall\_pid}는 입력이 불가합니다.
    

![](https://ads-home-phinf.pstatic.net/MjAyNTAyMDZfMjYy/MDAxNzM4ODAxMDg4Njk1.Hu1Tgm_5riV-9aeB-Ir9lY3oVPaeAr2SQTXRPCuFjSwg.4kZt58frH8KAEz4Fmtral9u2jOjaqoVYbbFJYN7J0nwg.PNG/%EC%B6%94%EC%A0%81URL_%EC%B6%94%EA%B0%802.png)

-   사용 예시)
    
    -   1) 소재 랜딩 URL, 스토어 홈 URL(선택)에 각각 파라미터 추가할 경우
        
    -   \- 쇼핑 등록 랜딩 URL이 아래와 같을 때
        
        -   \* 소재 랜딩 URL : [https://brand.naver.com/naver\_test/products/11111111](https://brand.naver.com/naver_test/products/11111111)
            
        -   \* 스토어 URL : [https://brand.naver.com/naver\_test/](https://brand.naver.com/naver_test/)
            
    -   \- 소재 랜딩 URL 입력 창에 ?n\_campaign={campaign} 입력, 스토어 홈 URL(선택) 입력 창에 ?n\_campaign\_home={campaign} 입력
        
    -   \- 최종 랜딩 URL은 아래와 같이 적용됨
        
        -   \* 소재 랜딩 URL : [https://brand.naver.com/naver\_test/products/11111111](https://brand.naver.com/naver_test/products/11111111)?n\_campaign=155534
            
        -   \* 스토어 URL : [https://brand.naver.com/naver\_test/](https://brand.naver.com/naver_test/)?n\_campaign\_home=155534
            

-   -   2) 소재 및 스토어 URL에 광고 파라미터 추가 및 랜딩 URL 내 파라미터를 바꾸고 싶을 경우
        
    -   \- 쇼핑 등록 랜딩 URL이 아래와 같을 때
        
        -   \* 소재 랜딩 URL : [https://brand.naver.com/naver\_test/products/11111111?](https://brand.naver.com/naver_test/products/11111111?)ad\_source=naver\_sa
            
        -   \* 스토어 URL :[https://brand.naver.com/naver\_test/](https://brand.naver.com/naver_test/)?ad\_source=sa
            
    -   \- 소재 랜딩 URL 입력 창에 &n\_campaign={campaign} 입력, 스토어 홈 URL(선택) 입력 창에 &n\_campaign\_home={campaign} 입력
        
    -   \- 파라미터 명 "ad\_source"의 값을 "gfa"로 변경하고 싶은 경우 (ad\_source=naver\_sa, ad\_source=sa→ ad\_source=gfa)
        
    -   \- URL 파라미터 값 변경 입력창에 아래와 같이 입력
        
        -   \* 파라미터 명 : ad\_source
            
        -   \* 값 : gfa
            
    -   \- 최종 랜딩 URL은 아래와 같이 적용됨
        
        -   \* 소재 랜딩 URL : [https://brand.naver.com/naver\_test/products/11111111](https://brand.naver.com/naver_test/products/11111111)?ad\_source=gfa&n\_campaign=155534,
