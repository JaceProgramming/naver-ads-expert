# 파워링크 키워드 입찰가 변경은 어떻게 하나요?

네이버광고주센터의 '키워드 탭'에서 키워드별로 '입찰가를 직접 입력'하거나 '입찰가 변경 기능'을 활용하여 예산과 광고 목적에 따라 입찰가를 관리할 수 있습니다.

**변경 방식 안내**

| **방식** | **설명** |
| --- | --- |
| 직접 입력 | 입찰가를 직접 입력합니다. |
| 증액 | 현재 입찰가에 입력한 금액만큼 더합니다. (10만원 초과 시 10만원으로 설정) |
| 감액 | 현재 입찰가에서 입력한 금액만큼 뺍니다. (70원 미만 시 70원으로 설정) |
| 비율 | 현재 입찰가에 입력한 비율(%)을 적용합니다. |
| 자동입찰 | 목표 값을 설정하면 시스템이 자동으로 입찰가를 조정합니다. |

**변경 결과 확인**

변경 실행 후 결과 화면에서 성공 건수와 실패 건수가 요약됩니다. 실패한 키워드가 있으면 '실패 상세'에서 키워드별 실패 사유(상태 불가, 최소 입찰가 미달 등)가 표시됩니다.

**1\. 입찰가 변경 기능 활용하기**

1) 입찰가 개별 변경 : 키워드마다 다른 기준을 적용하여 입찰가를 각각 변경하는 조회 기능

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMjc2/MDAxNzc0OTE0NjU1NjEx.1l9S2H33SS1UjNmUELHDecegcLl5pON2Zr_qv4rzPIQg.obZ1cCYjC26dEwecOr7qCzaVkrv8UizidPIyKXuX3r0g.PNG/image.png)

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMTY1/MDAxNzc0OTE0NjY0MjE5.dnacQD2n2c-AsQkxhF6-rsiwgpRawMbWtl1UVIyYFJog.KFMLcTF8Q8GnPdby2BylXoahOVk-TY3dG95TEHmIkgkg.PNG/image.png)

원하는 조건을 선택한 후, \[조회하기\] 버튼을 클릭 > 하단의 '변경할 입찰가' 항목의 금액을 확인 합니다.

(조회된 금액이 아닌 원하는 금액으로 수정하여 입력할 수 있습니다.)

\[선택한 키워드 입찰가 저장\]을 클릭하면 입찰가 변경이 완료됩니다.

2) 입찰가 일괄 변경 : 선택한 키워드 모두 동일한 기준으로 조회된 금액으로 변경하는 조회 기능

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMjQy/MDAxNzc0OTE0NjcyMzQ3.1-1AM6OP1iYduFn_I_dqfqRVdrI8shjGNH3kme3YvtMg._F2H0yBTvEy_jUCVSHKMUZawEPOG0x9tXoksag9cKMQg.PNG/image.png)

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMjYz/MDAxNzc0OTE0NjgwMjEw.sE-p9YtEQIYZn6tDM0_8wVZ-iZwX-B9LV3UTWvdpUTIg.z3-ctDKz-btp5np6k0ThzjMjeP2wUwE9e0Xq7WLeIy4g.PNG/image.png)

① 입찰가를 직접 입력하여 변경합니다.

입찰가는 최소 70원부터 최대 10만원(VAT 제외 금액)까지 10원단위로 입력할 수 있습니다.

② 광고그룹의 기본 입찰가로 변경합니다.

③ 입찰가를 일정 비율 혹은 원 단위로 증액합니다. 증액한 입찰가가 10만원을 초과할 경우 10만원으로 설정됩니다.

④ 입찰가를 일정 비율 혹은 원 단위로 감액합니다. 감액한 입찰가가 70원 미만일경우 70원으로 설정됩니다.

⑤ 최소 노출 입찰가: 최근 4주간 검색을 통해 노출된 광고 중에서 최하위에 노출되었던 광고의 입찰가 중 가장 큰 값으로 광고의 순위와 무관하게 광고 노출 여부가 중요한 경우 참고할 수 있는 정보 입니다.

중간입찰가: 최근 4주간 검색을 통해 노출된 모든 광고의 입찰가를 큰순서대로 나열했을 때 중간에 위치한 값으로

중앙값(Median)이라는 통계적 방식으로 계산된 값입니다. 중간 입찰가를 이용해 키워드들 간의 입찰가를 비교해볼 때 참고할 수 있는 정보입니다.

⑥ OO위 평균 입찰가: 최근 4주간 해당 순위에 노출되었던 입찰가의 평균값입니다.

**주의하세요.**

-   최대 입찰가에 체크한 경우, 조회되는 입찰가가 설정된 최대 입찰가보다 큰 경우 최대 입찰가로 조회 됩니다.
    
-   특정 순위에 노출할 수 있는 실시간 입찰가는 제공하지 않습니다.
    
-   지난 4주간의 순위별 노출되었던 평균 입찰가를 확인하여 지불 가능한 적정 금액으로 조정할 수 있습니다.
    

변경사항 확인 및 변경하기

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMjg4/MDAxNzc0OTE0Njg5OTUw.2wNlp98mrmPUrd5SXu1KzlsZzAM1NzAHxm5sSj1vzxEg.q08UyKyQ4PKVngdxLND--OjbSb5ie6MpnIAuL5Sx85Mg.PNG/image.png)

위 6가지 입찰도구 중 한 가지를 선택한 후, \[변경사항 확인\] 버튼을 클릭한 후 '새로운 설정'의 금액을 확인합니다.

\[변경\] 버튼을 클릭하면 입찰가가 변경됩니다.

(입찰가를 다시 조정하려면 \[변경사항 확인\]버튼도 다시 클릭해야 합니다)

**2\. 입찰가 직접 입력하기**

\[키워드\] 탭에서 입찰가를 직접 입력하여 변경할 수 있습니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMTYg/MDAxNzc0OTE0NzAwNDIz.Jpbdb9PU5RBw9_ap54r3aFbmoqRoX2cOVKZLASZuIXkg.Fd856lRlsVPO3o_d2K4J8WeHULGkH5Pnlp6yNg5do_Mg.PNG/image.png)

입찰가는 최소 70원부터최대 10만원(VAT 별도)까지입력할 수 있습니다. \[변경\] 버튼을 클릭하면 입찰가가 변경됩니다.

**주의하세요.**

-   광고 노출 순서는 검색어와 사이트 콘텐츠의 연관성, 입찰가(자동입찰), 소재 품질 등의 종합적인 결과를 바탕으로 결정됩니다.
    
-   최소노출 입찰가, 중간 입찰가, 순위별 평균 입찰가는 지난 4주간의 노출된 광고들의 입찰가를 기반으로 통계적으로 계산된 값들로 광고노출이나 특정 순위 노출을 보장하지 않습니다.
    
-   입찰가는 한번 클릭 당 금액이며, 지불 가능한 예산을 고려하여 설정해주세요.
    
-   변경한 입찰가는 네이버광고주센터 화면에는 즉시 반영되나 실제 광고 노출에 반영 되기까지 일반적으로 수 분 정도 소요됩니다. (단, 사용자가 많은 상황에서는 수십 분까지 소요될 수 있음)
