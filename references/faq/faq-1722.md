# [AI작성] 디스플레이광고 내 데이터 타겟을 관리하려면 어떻게 하나요?

'내 데이터 타겟' 탭에서는 내 데이터를 기반으로 한 타겟을 조회·등록·삭제할 수 있습니다. \[광고주센터 > 디스플레이광고 > 도구 > 잠재고객 관리\] 화면에서 '내 데이터 타겟' 탭을 선택하면 진입합니다.

**데이터 유형**

탭 안의 서브탭으로 네 가지 데이터 유형을 전환할 수 있습니다.

| **서브탭** | **설명** |
| --- | --- |
| 고객 파일 | 고객 파일(CRM)을 업로드해 만든 타겟입니다. |
| MAT 타겟 | MAT 연동 데이터를 기반으로 한 타겟입니다. |
| 웹사이트 타겟 | 웹사이트 방문 데이터를 기반으로 한 타겟입니다. |
| 외부 오디언스 | 외부에서 연동한 오디언스 데이터 기반 타겟입니다. |

**등록·관리**

1.  관리할 서브탭을 선택하면 해당 유형의 타겟 목록이 자동으로 조회됩니다.
    
2.  상단의 타겟 등록을 클릭하면 해당 유형의 생성 화면으로 이동합니다.
    
3.  각 행의 삭제로 확인 후 타겟을 제거할 수 있습니다.
    

각 타겟의 처리 상태는 목록의 배지로 표시됩니다.

**참고.**

등록된 항목이 없으면 빈 목록 안내가 표시됩니다.

**주의하세요.**

조회 또는 삭제에 실패하면 에러 안내가 표시됩니다. 잠시 후 다시 시도해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
