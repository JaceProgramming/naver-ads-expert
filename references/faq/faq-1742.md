# [AI작성] 결제 알림 수신을 설정하려면 어떻게 하나요?

결제 관련 알림의 수신 여부를 이메일·문자 채널별로 설정할 수 있습니다. \[내 정보 관리 > 알림 관리\]에서 '결제 알림 설정' 탭을 선택합니다.

**결제 알림 항목**

다음 5개 항목을 각각 이메일·문자로 받을지 설정합니다. 상단의 수신 설정으로 5개 항목을 한 번에 켜거나 끌 수 있습니다.

| **항목** | **설명** |
| --- | --- |
| 계정 잔액 부족 알림 | 계정 잔액이 부족할 때 안내 |
| 비즈머니 잔액 도달 알림 | 설정한 비즈머니 잔액에 도달했을 때 안내 |
| 비즈머니 충전 알림 | 비즈머니가 충전되었을 때 안내 |
| 미사용 쿠폰 알림 | 사용하지 않은 쿠폰이 있을 때 안내 |
| 환불계좌 등록 및 삭제 알림 | 환불계좌가 등록되거나 삭제되었을 때 안내 |

**알아두세요.**

계정·광고 관리 관련 알림은 '알림 수신 설정' 탭에서 따로 설정합니다.

**참고.**

항목을 변경하면 '저장되었습니다' 안내가 표시됩니다. 저장에 실패하면 설정이 이전 상태로 돌아가며, 다시 시도해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
