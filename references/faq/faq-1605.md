# [AI작성] 검색광고 확장 소재의 상태를 변경하려면 어떻게 하나요?

적용 대상: 파워링크 · 쇼핑검색 · 플레이스. 광고그룹·캠페인 상세 '확장 소재' 탭에서 확장 소재의 'ON/OFF'를 변경해 노출을 중지하거나 재시작합니다.

**상태 변경 절차**

1.  광고그룹 또는 캠페인 상세의 '확장 소재' 탭으로 이동합니다.
    
2.  단건: 확장 소재 행의 'ON/OFF'를 클릭합니다.
    
3.  일괄: 변경할 확장 소재를 선택해 작업 바의 \[ON\]/\[OFF\]를 클릭하거나 \[선택한 확장 소재 관리\]에서 일괄 변경합니다.
    

**알아두세요.**

확장 소재를 중지해도 입력 내용은 유지되며, 재시작하면 검토 결과에 따라 다시 노출됩니다. 비즈채널 검토 중이거나 검토 거절된 확장 소재는 켜도 노출되지 않으며 상태·사유가 '상태'에 표시됩니다. 보류·노출 제한 상태는 \[재검토요청\] 창으로 재검토를 요청해야 합니다. 확장 소재가 OFF이면 본 소재가 노출돼도 확장 소재 영역은 노출되지 않습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
