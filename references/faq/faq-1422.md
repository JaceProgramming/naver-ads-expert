# Easy 대량관리는 어떻게 사용하나요?

**지원하는 작업 유형 (9종)**

-   추가 제목 등록 / 추가 설명 등록 / 홍보 문구 등록
    
-   서브 링크 등록 / 계산 등록 / 파워링크 이미지 등록
    
-   이미지형 서브링크 등록 / 확장 소재 삭제 / 파워링크 병의원 특화소재 등록
    

**등록 방법**

1\. 작업 유형을 선택합니다.

2\. 입력 방식을 '시트에 바로 넣기', 'csv', 'xlsx' 중에서 고릅니다.

3\. 파일을 업로드하는 경우, 한글이 깨지면 인코딩을 'EUC-KR' 또는 'UTF-8'로 바꿔 다시 시도합니다.

4\. 직접 입력하는 경우, 스프레드시트에 데이터를 입력합니다.

5\. 입력 내용을 확인한 뒤 \[전송하기\]를 클릭합니다.

Easy 대량 관리(beta) 는 파워링크 캠페인의 새로운 확장 소재(추가 제목, 추가 설명, 홍보문구, 서브 링크, 계산, 파워링크 이미지, 이미지형 서브링크) 및 파워링크 병의원 업종 특화 소재 등록에만 적용됩니다. 기존의 대량 관리는 엑셀 템플릿을 다운로드하여 내용을 입력하고, 파일을 업로드하는 방식으로 진행했지만, Beta 버전에서는 ‘입력 시트’ 형태로 제공됩니다.

단, Beta 버전에서는 화면 하단에 ‘대량 작업 신청 목록’은 별도로 제공하지 않으며 확장 소재 대량 등록 작업 내역은 ‘네이버광고주센터 > 검색광고 > 도구 > 변경 이력 관리’ 에서 확인 가능합니다.

**Easy 대량 관리(beta) 알아보기**

1\. 도구 > 대량 관리 메뉴에 ‘Easy 대량 관리(beta) 탭을 클릭합니다.

2\. 작업 유형을 선택하면 하단에 각 유형에 맞는 입력 시트가 생성됩니다.

3\. 작업 유형에 따라 등록된 확장 소재 엑셀다운로드가 가능하며, 등록할 확장 소재를 엑셀 파일 가져오기 또는 엑셀 붙여 넣기 등으로 입력 시트에 추가할 수 있습니다.

**입력 시트 알아보기**

입력 시트는 대량 관리 화면에서 직접 입력 및 수정이 가능한 기능입니다. 엑셀처럼 '붙여 넣기, 행 추가, 행 삭제, 셀 복사' 등의 작업이 가능합니다.

1\. 입력 시트 메뉴 설명

2\. 대량 관리 탭에서 작업 유형을 선택하면 하단에 각 유형에 맞는 입력 시트가 생성됩니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzBfODgg/MDAxNzc0ODY0Njk0MTM0.F0793T-eCv-dX9H-3rWiaR5hc19xkDk5DnUw-8inhEkg.j0dTWWpuBnm98CAMH_H0zP0arQe-RFI9TaPneDwQoSwg.PNG/image.png)

-   -   작업 유형 : 확장 소재 작업 유형을 선택합니다.
        
    -   확장 소재 다운로드 : 작업 유형에서 선택한 유형에 대해 계정에 등록된 확장 소재를 엑셀로 다운로드 합니다.
        
    -   파일 가져오기 : CSV 파일을 업로드하면 하단 입력 시트에 보여집니다.
        
    -   처리 상태 : 작업 전송 후의 결과를 표시합니다. (등록 시 빈칸으로 둡니다)
        
    -   전송하기 버튼 : 입력 시트에 등록한 내용을 시스템으로 전송합니다.
        
    -   성공행 제거 : 클릭하면 결과 화면에서 ‘처리 상태’ 에 ‘성공’ 한 값들은 화면에서 삭제합니다.
        
    -   (실패케이스만 보고싶거나, 수정작업 시 성공한 작업을 입력시트에서 제거할 수 있는 편의 기능입니다)
        
    -   행 추가 : 버튼을 클릭하면 ‘1행 / 10행 / 100행’ 중 설정된 값으로 자동으로 행이 추가됩니다.
        
    -   엑셀 저장 : 입력 시트 내용을 엑셀로 다운로드 합니다. (Mac 환경에서는 지원되지 않습니다)
        

3\. 확장 소재 다운로드

4\. 작업 유형에서 확장 소재 유형을 선택하면 해당 확장 소재를 엑셀로 다운받을 수 있습니다.

7.기간 설정

\- 기간은 직접입력 및 기간 셀 오른쪽의 '▼(아래 화살표)' 를 클릭하면 캘린더가 노출되며 원하는 기간을 선택하여 등록할 수 있습니다. 직접 입력할 경우 2017-04-01 또는 17-4-1 또는 2017-4-1 의 형식으로 입력하며 '2017/04/01', '4/1' 등 '/'는 등록 되지 않으므로 형식에 맞게 입력해야합니다.

\- 시작일만 입력하고, 종료일을 입력하지 않는 경우, 확장 소재 전송은 성공하지만 기간은 모든 기간으로 설정되므로 반드시 '시작 – 종료일'을 정확하게 입력하셔야 합니다.

\- 기간 설정 완료 후, 해당 셀을 선택하여 마우스를 아래로 끌거나(드래그), 기간 셀을 복사하여 다른 셀에 붙여 넣으면 기간 설정 복사가 가능합니다.

**참고.** 대량 등록에서는 ‘기간’ 설정만 지원하고 ‘요일/시간대’ 설정은 지원하지 않습니다.

**파워링크 병의원 업종 특화 소재 등록 안내**

1\. 등록 방법

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzBfMTI3/MDAxNzc0ODY0Nzc5NDQ1.IdN7aWivUFcs--DgwwHu20E3a8-l_ocq3DDyCiykegMg.G8377PNMaHfCHjZW7PdnEd2GIbBqAC7uZBAvBWwKarcg.PNG/image.png)

a. 기존에 등록한 소재가 있는 경우

i. 등록된 소재 전체 다운로드 클릭 > 입력시트에 조회된 소재 정보를 참고하여 소재 등록

b. 새로 등록하는 경우

i.입력시트에 직접 입력하거나 csv 파일에 정리하여 업로드

2\. 유의 사항

대량 등록을 이용하여 병의원 특화 소재를 등록하시려면 **네이버광고주센터 > 검색광고 > 구성요소 관리 > 비즈채널 > 웹사이트 유형에 '사이트 이름' 이 있고, 비즈채널 검가 통과된 병의원 업종 광고주인 경우에만** 소재를 등록 할 수 있습니다.

1) 필수값 입력

-   광고 그룹 ID / 사이트 이름/ 표시 url (PC) / 표시 url (MO) /연결 url (PC) / 연결 url (MO) / 제목 / 설명 문구 / 태그 1/태그 2/ 태그 3 / 기본형 의료광고 심의필 번호 / 확장형 등록하는 경우\_ 확장형 이미지 1/2/3 이미지 id 또는 Path /확장형 의료광고 심의필 번호
    
-   **'사이트 이름/ 표시 url (PC) / 표시 url (MO)'** 은 입력 시트에서 편집 할 수 없습니다. 등록할 광고 정보를 입력 후 '전송하기' 를 클릭하면 등록하려는 광고 그룹에 연결된 비즈 채널 의 '사이트 이름' 과 표시 URL 이 입력시트에 표시됩니다. (사이트 이름이 없거나, 비즈채널 검수 통과된 병의원 업종 광고주가 아니면 대량 등록은 실패 처리 됩니다.)
    

2) 파비콘 및 이미지 등록 방법

-   네이버광고주센터 > 검색광고 > 구성요소 관리 > 이미지 > **파워링크\_640\*640 / 파워링크\_병의원소재\_파비콘\_48\*48** 선택하여 이미지 등록
    
-   이미지 라이브러리에서 조회되는 이미지 ID 또는 **Easy 대량관리 > 등록된 소재 다운로드 리스트에서** 등록된 이미지의 Path 값 확인 하여 등록

**확장 소재 등록 방법 (공통)**

확장 소재는 광고그룹 한 개 당 유형별로 2개씩 등록이 가능하며 이미 광고 그룹에 확장 소재가 등록되어 있는 경우, 입력한 새 소재 일부가 등록되지 않을 수 있습니다. (전화번호, 위치, 네이버 예약과 같은 기존 확장소재는 유형별로 1개만 등록 가능)

**예시.** 광고그룹에 1개의 확장 소재가 등록된 상태에서, 추가로 3개를 등록하면, 입력한 순서대로 맨 위의 1개 소재만 등록되고 나머지 확장 소재 등록은 실패 처리 됩니다.

확장 소재 입력은 최대 만개 까지 가능하며 입력 데이터가 많으면 입력 시트 조회 속도가 느려질 수 있습니다. 기간 입력 순서는 ‘연도-월-일’ 형식으로 입력해야 하며, (2017년 4월 1일 -> 2017-04-01로 입력) 기간을 별도로 지정하지 않는 경우, 모든 기간에 노출됩니다.

입력 시트 작업 중 ‘작업 유형’을 변경하거나, 다른 메뉴로 이동 하면 입력 시트 내용은 삭제됩니다.

**참고.** 확장 소재 허용 문자 : 한글, 영어(대/소문자), 숫자, ~!#$%&():;?=+-\\/.,\\"'x

1\. 파일 가져오기

파일 가져오기를 이용하여 CSV 파일을 불러올 수 있습니다. 가져온 파일은 하단 입력 시트에 보여지며 수정 및 편집이 가능합니다. 단, 입력 시트에서 ‘파일 가져오기’는 별도의 템플릿을 지원하지 않습니다. 엑셀 파일 가져오기를 이용할 경우 \[광고 그룹ID / 기간 시작일 / 기간 종료일 / 추가 제목\] 등 유형별 입력 시트 순서대로 엑셀 파일에 입력해야하며, 엑셀의 1행은 제목으로 간주하여 2행부터 입력 시트에 조회되므로 1행은 빈칸으로 두거나 제목을 넣고 엑셀 2행부터 확장 소재 내용을 입력 후 파일을 업로드 합니다. (파일 형식은 CSV만 지원)

3\. 엑셀파일에서 작업한 내용을 복사하여 입력 시트에 붙여 넣을 수 있습니다. 엑셀파일에서 복사할 내용 셀 선택 -> 복사하기 (Ctrl +C) -> 입력 시트 ‘광고 그룹ID’ 셀에 마우스 커서 놓고 붙여 넣기(Ctrl + V) 를 실행합니다. (셀 단위 및 영역 복사도 가능) 엑셀 붙여 넣기 후 기간 및 입력내용 수정이 가능합니다.
