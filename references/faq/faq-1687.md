# [AI작성] 검색광고 애셋 목록 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 구성요소 관리 > 애셋\]에서 광고 계정에 등록된 애셋의 정보와 검토 상태를 확인할 수 있습니다. 애셋을 삭제하려면 \[대량 관리\] 기능을 사용합니다.

**조회 조건**

화면 상단의 조회 조건 영역에서 다음을 설정한 뒤 \[조회하기\]를 클릭합니다.

| **조건** | **선택 값** |
| --- | --- |
| 정렬 | 등록순 / 검토 요청 순 |
| 상태 | 모든상태 / 애셋 검토중 / 노출 가능 / 에셋 노출제한 |
| 조회 기간 | 기간을 직접 지정할 수 있습니다. |

**목록 구성**

애셋 목록은 다음 항목으로 구성됩니다.

| **항목** | **설명** |
| --- | --- |
| 상태 | 애셋의 검토 상태가 표시됩니다. |
| 애셋 ID | 애셋의 고유 식별 번호입니다. |
| 애셋 | 애셋명과 유형별 미리보기가 표시됩니다. |
| 애셋 유형 | 애셋의 유형입니다. |

조회 결과가 없으면 '검색된 결과가 없습니다.' 안내가 표시됩니다.

**알아두세요.**

본 화면은 조회 전용입니다. 애셋을 등록하거나 삭제하려면 화면 상단의 \[대량 관리 바로가기\]를 통해 \[도구 > 대량 관리\]에서 처리해 주세요.

**참고.**

애셋은 반응형 검색광고 소재의 제목·설명 텍스트 후보 등으로 사용되는 항목으로, 광고그룹·소재와는 구분됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
