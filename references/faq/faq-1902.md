# [AI작성] 쇼핑 프로모션 광고그룹의 입찰 목표는 어떻게 설정하나요?

쇼핑 프로모션 광고그룹에서 입찰 전략을 설정할 때, 입찰 목표는 쇼핑 프로모션 캠페인 목적에 맞는 값으로 노출됩니다. 입찰 목표는 광고그룹 만들기 흐름의 입찰 전략 영역에서 선택합니다.

**쇼핑 프로모션 입찰 목표**

쇼핑 프로모션 광고그룹에서 선택할 수 있는 입찰 목표는 다음과 같습니다.

| **입찰 목표** | **설명** |
| --- | --- |
| 전환 수 최대화 | 전환이 많이 발생하도록 입찰을 최적화합니다. |
| 클릭 수 최대화 | 광고 클릭이 많이 발생하도록 입찰을 최적화합니다. |
| 전환 가치 최대화 | 전환 가치가 높아지도록 입찰을 최적화합니다. |

자동 입찰을 선택하면 '자동입찰은 하루예산 내에서 광고주의 목표 달성을 위한 방향으로 입찰가 및 광고 노출 여부를 관리합니다.'라는 안내가 표시됩니다.

**알아두세요.**

입찰 전략 선택, 청구 기준, 비용 관리, 하루 예산 입력 등 공통 입찰 설정은 디스플레이광고 광고 그룹 입찰 전략·예산 안내를 참고해 주시기 바랍니다.

**참고.**

캠페인 예산 최적화(CBO)가 켜져 있는 캠페인 하위의 광고그룹에서는 입찰 목표와 예산이 캠페인 설정 값으로 자동 동기화되며, 광고그룹 예산은 캠페인 예산에서 자동 분배됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
