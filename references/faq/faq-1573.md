# [AI작성] 동영상을 업로드하려면 어떻게 하나요?

**적용 대상:** 검색광고 > 파워링크 (홍보 영상 확장 소재)

파워링크 확장 소재 중 '홍보 영상'을 등록할 때 '동영상 업로드'에서 동영상 파일을 직접 업로드할 수 있습니다.

**동영상 업로드 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 파워링크\]에서 광고그룹 상세의 '확장 소재' 탭으로 이동합니다.
    
2.  \[새 확장 소재\]에서 '홍보 영상' 유형을 선택해 등록 화면을 엽니다.
    
3.  동영상 영역에서 '동영상 업로드'를 선택하고 동영상 파일을 끌어다 놓거나 파일을 선택합니다.
    
4.  업로드가 완료되면 동영상 이름과 설명을 입력합니다.
    
5.  \[등록\]을 클릭하면 동영상이 등록됩니다.
    

**입력 항목**

| **항목** | **설명** |
| --- | --- |
| 동영상 파일 | 파일을 끌어다 놓거나 클릭하여 업로드합니다. 업로드 진행률이 표시됩니다. |
| 동영상 이름 | 동영상의 이름을 입력합니다. 최대 50자까지 입력할 수 있습니다. |
| 설명 | 동영상에 대한 설명을 입력합니다. 최대 100자까지 입력할 수 있습니다. |

**알아두세요.**

동영상 파일은 코덱, 해상도, 길이, 파일 크기 등의 조건을 충족해야 합니다. 조건에 맞지 않으면 업로드할 수 없습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
