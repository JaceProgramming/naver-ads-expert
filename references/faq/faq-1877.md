# [AI작성] 쇼핑 프로모션 캠페인도 예산 최적화(CBO)를 사용할 수 있나요?

네, 쇼핑 프로모션 캠페인은 캠페인 예산 최적화(CBO)를 지원합니다. 광고주님께서는 캠페인 만들기 과정에서 '캠페인 예산 최적화' 영역을 통해 이를 설정하실 수 있으며, 켜면 캠페인 예산이 하위 광고그룹에 자동으로 분배됩니다. 켜지 않으면 광고그룹마다 예산을 직접 설정하게 됩니다.

**쇼핑 프로모션의 예산 최적화 지원**

| **구분** | **내용** |
| --- | --- |
| 지원 여부 | 쇼핑 프로모션 캠페인은 캠페인 예산 최적화(CBO)를 사용할 수 있습니다. |
| 기본 상태 | 새 캠페인을 만들 때 예산 최적화는 꺼진 상태로 시작합니다. 필요 시 직접 켭니다. |
| 켰을 때 | 입찰 전략과 입찰 목표를 함께 선택하며, 캠페인 예산이 하위 광고그룹에 자동으로 분배됩니다. |

**참고.**

예산 최적화를 켜고 끄는 구체적인 설정 절차는 디스플레이광고 공통 안내인 '디스플레이광고 캠페인 예산 최적화(CBO)를 설정하려면 어떻게 하나요?'를 참고하시기 바랍니다.

**주의하세요.**

캠페인을 수정하면서 예산 최적화를 끄는 경우, 기존에 분배되어 있던 광고그룹 예산이 있으면 저장 직전에 광고그룹 예산을 입력하는 창이 나타납니다. 값을 입력해 분배하거나 취소할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
