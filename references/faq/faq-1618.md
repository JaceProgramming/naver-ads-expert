# [AI작성] 브랜드검색에 노출 검색어(키워드)를 추가하려면 어떻게 하나요?

브랜드검색 광고그룹 상세 \[키워드\] 탭에서 \[새 키워드\]를 클릭하면 '새 키워드 생성' 창이 열립니다. 키워드를 입력하고 \[키워드 정보 확인\]으로 검색수·계약가능여부를 확인한 뒤 \[저장하고 계속하기\]로 등록합니다.

**추가 절차**

1.  광고그룹 상세의 \[키워드\] 탭으로 이동합니다.
    
2.  \[새 키워드\]를 클릭합니다.
    
3.  '새 키워드 생성' 창에서 다음을 진행합니다.
    

-   '키워드 추가하기' 영역에 광고하려는 키워드를 입력합니다.
    
-   '선택한 키워드(N / 30)' — 한 계약에 최대 30개까지 등록 가능
    
-   \[키워드 정보 확인\]을 클릭해 키워드별 검색수·계약가능여부(5개월)를 확인합니다.
    
-   '입력한 키워드(N/30)' 표 (컬럼: 키워드 / 키워드 검색수 / 계약가능여부(5개월)) — 행별 \[삭제\] 가능
    
-   합계: '신규 추가 키워드 검색수 합계' / '그룹 검색수 합계'
    

1.  '검토 요청'에서 \[네\] 선택 시 검토 담당자에게 전달할 내용을 입력합니다.
    
2.  \[저장하고 계속하기\]를 클릭해 등록합니다.
    

**알아두세요.**

브랜드검색 키워드는 한 계약에 최대 30개까지 등록 가능하며, 검색수가 많은 키워드일수록 계약 광고비가 높아집니다. 계약 가능 여부는 향후 5개월간의 계약 가능성을 보여줍니다.

**알아두세요.**

정액제 상품이므로 검색어별 입찰가를 입력하지 않습니다. 계약을 체결하기 전이라도 검색어 등록과 검토는 진행할 수 있으며, 실제 노출은 계약 체결 후 시작됩니다. 키워드 목록에는 월 단위 예상 검색수를 보여 주는 '키워드 검색수' 항목이 함께 표시됩니다.

**주의하세요.**

입력한 검색어가 브랜드명·제품명과 일치하지 않으면 추가되지 않으며, 정확히 일치하는 검색어로 수정하라는 안내가 표시됩니다. 광고그룹당 등록 가능한 검색어 수를 초과하면 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
