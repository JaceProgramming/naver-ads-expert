# [AI작성] 대시보드에서 비즈머니 잔액과 소진율을 확인하려면 어떻게 하나요?

대시보드의 '비즈머니' 영역에서 비즈머니 잔액, 사용 가능한 쿠폰 수, 전일 대비 소진율을 한 번에 확인하고 바로 충전하거나 쿠폰을 관리할 수 있습니다.

**표시 항목**

| **항목** | **설명** |
| --- | --- |
| 총 비즈머니 잔액 | 현재 사용 가능한 비즈머니 잔액을 원 단위로 표시합니다. 잔액이 없으면 '0원'으로 표시됩니다. |
| 사용 가능한 쿠폰 | 보유한 쿠폰 수를 표시하며, \[쿠폰관리\]로 쿠폰 화면으로 이동합니다. |
| 전일 대비 비즈머니 소진율 | 오늘 소진 금액과 어제 대비 변화율을 게이지와 함께 표시합니다. |

**충전 방법**

\[충전하기\] 버튼을 클릭하면 비즈머니 충전 화면이 새 탭으로 열립니다.

**참고.**

어제 소진 내역이 없으면 소진율 대신 '어제 소진 내역이 없습니다.' 문구가 표시되고 게이지는 노출되지 않습니다.

**주의하세요.**

잔액 충전과 결제 정보 입력은 광고주님이 직접 진행하셔야 합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
