# [AI작성] 쇼핑검색 캠페인 상세 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 광고 관리 > 쇼핑검색\]에서 캠페인 이름을 클릭하면 캠페인 상세 화면으로 진입합니다. 상단에 '캠페인 정보' 영역이, 하단에 광고그룹 목록 표가 표시됩니다.

**화면 구성**

-   **캠페인 정보 영역** (우측 \[수정\] 버튼 제공)
    
-   상태 — 운영가능 / 중지: 캠페인 OFF / 광고 집행 종료 등
    
-   캠페인 유형 — 쇼핑검색
    
-   기간 — 계속노출 / 종료일 설정
    
-   하루 예산 — 50원~1,000,000,000원 또는 제한없음
    
-   예산배분 — 균등노출 / 일반노출
    
-   **관리 버튼**: \[새 광고그룹\], \[선택한 광고그룹 관리\], \[다운로드\], \[열 맞춤 설정\] (상태 외 N개), \[상세 데이터\]
    
-   **광고그룹 목록 표**: 컬럼은 'ON/OFF / 광고그룹 이름 / 상태 / 그룹 유형 / 기본 입찰가 / 채널 정보 / 노출수 / 클릭수 / 클릭률(%) / 평균 CPC / 총비용 / 하루 예산'으로 구성됩니다.
    
-   **그룹 유형 컬럼**: 쇼핑몰 상품형 / 제품 카탈로그형 / 쇼핑 브랜드형
    

**알아두세요.**

\[새 광고그룹\]을 클릭하면 그룹 유형 (쇼핑몰 상품형·제품 카탈로그형·쇼핑 브랜드형) 선택 단계가 먼저 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
