# [AI작성] 쇼핑검색 광고그룹 상세 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 광고 관리 > 쇼핑검색\]에서 광고그룹 이름을 클릭하면 광고그룹 상세 화면으로 진입합니다. 상단에 '광고그룹 정보' 영역이, 하단에 소재·확장 소재·제외 검색어·타겟팅 탭이 표시됩니다.

**광고그룹 정보 영역 (그룹 유형별 차이)**

| **항목** | **쇼핑몰 상품형** | **제품 카탈로그형** | **쇼핑 브랜드형** |
| --- | --- | --- | --- |
| 채널 정보 | 쇼핑몰 (URL) | 제조사 | 쇼핑 브랜드 + 상품 그룹 |
| 기본 입찰가 | 50~100,000원 \[직접 설정\]/\[자동입찰 설정\] | 50~100,000원 | **300~100,000원** (최소 입찰가 다름) |
| 하루예산 | 50원~10억 또는 사용 안 함 | 50원~10억 또는 제한없음 | 50원~10억 또는 제한없음 |
| 매체 | 모든 매체 / 노출 매체 유형 선택 | 모든 매체 / 노출 매체 유형 선택 | 모든 매체 / 노출 매체 유형 선택 |

**광고그룹 \[수정\] 창 공통 항목**

1.  광고그룹 유형 (읽기 전용)
    
2.  광고 그룹 이름 (30자)
    
3.  채널 정보 (쇼핑몰/제조사/쇼핑 브랜드 - 읽기 전용)
    
4.  상품 그룹 (쇼핑 브랜드형만, 수정 가능)
    
5.  기본 입찰가 (\[직접 설정\]/\[자동입찰 설정\] - 쇼핑몰 상품형만)
    
6.  하루 예산
    
7.  고급옵션: 매체 / 추천/콘텐츠 지면 전용 입찰가(콘텐츠 입찰가 금액·비율) / PC/모바일 입찰가중치
    

**탭 구성**

-   **기본 탭**: 소재 / 확장 소재 / 제외 검색어 (※ 키워드 탭 없음)
    
-   **타겟팅 탭**: 요일/시간대 · 지역 · 성별 · 연령대
    
-   **소재 목록 표 컬럼**: ON/OFF / 소재 / 상태 / 소재 ID / 현재 입찰가(VAT미포함) / 품질지수 / 노출수 / 클릭수 / ... / 구매완료 전환수 / 구매완료 전환매출액 / 구매완료 광고수익률(%) (총 18+ 컬럼)
    

**알아두세요.**

쇼핑 브랜드형은 최소 입찰가가 300원으로 다른 유형(50원)보다 높습니다. 쇼핑검색은 키워드를 별도 등록하지 않고 상품(소재) 기반으로 노출됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
