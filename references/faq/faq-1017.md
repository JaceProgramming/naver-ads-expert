# 파워링크 네이버 ID 로그인 아이콘이 어디에 노출되는지 궁금해요.

네이버 아이디로 로그인은 유입된 사용자가 광고주님 사이트의 아이디가 없더라도 네이버 아이디를 이용하여 간편하게 회원으로 가입하거나 로그인 할 수 있도록 하는 서비스입니다.

네이버 아이디로 로그인을 적용한 후 일정 수준의 사용자가 발생되면 검색광고에서 네이버 아이디로 로그인 아이콘이 노출됩니다.

---

**노출 위치 및 형태**

-   PC/모바일 : 검색광고의 표시 URL 뒤

**네이버 아이디로 로그인 적용 방법**

주요 호스팅 업체(카페24, 메이크샵, 퍼스트몰, 후이즈몰 등)의 주요 기능으로 제공되고 있으며, 광고주님의 사이트 관리자 페이지에서 간편하게 적용할 수 있습니다.

만약, 홈페이지를 개별적으로 개발하였더라도 쉽게 네이버 아이디로 로그인 서비스를 이용할 수 있도록 친철한 소개와 개발 가이드를 제공하고 있습니다. [네이버 개발자센터](https://developers.naver.com/products/login/api)를 방문하시면 보다 자세한 내용 확인할 수 있습니다.

**네이버 아이디로 로그인 효과**

복잡하고 번거로운 회원 가입 절차가 제거되므로 유입된 사용자의 이탈이 줄어듭니다. 이는 전환율 상승으로 이어져 광고 효율이 좋아집니다.
