# [AI작성] 다차원 보고서 분석 조건(차원·지표·기간)을 설정하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 보고서 > 다차원 보고서\]에서 \[새 보고서\]를 클릭하면 보고서 카테고리(기본·전환·시간·지역·매체) 5종이 표시됩니다. 카테고리를 선택해 사전 정의 보고서를 빠르게 시작하거나 직접 차원·지표·기간을 조합합니다.

**새 보고서 카테고리 (5종)**

| **카테고리** | **주요 사전 정의 보고서** |
| --- | --- |
| 기본 | 계정 보고서 / 캠페인 보고서 / 그룹 보고서 / 키워드 보고서 / 검색어 보고서 / 소재 보고서 / 확장소재 보고서 |
| 전환 | 전환 보고서 / 전환 유형별 세부 지표 |
| 시간 | 시간대 보고서 / 일별·주별·월별, 요일별 보고서 |
| 지역 | 지역 보고서 / 시/도·시/군/구 단위 |
| 매체 | 매체 보고서 / 매체별 세부 성과 (기타 매체 세부는 대용량 보고서) |

**설정 절차**

1.  \[새 보고서\]를 클릭하고 카테고리에서 보고서를 선택합니다.
    
2.  분석 조건을 설정합니다.
    

-   **차원**: 좌측 '보고서 항목 목록'에서 우측 '보고서 설정하기'로 드래그앤드롭
    
-   **지표**: 노출수·클릭수·총비용·전환수 등 표시할 지표 선택
    
-   **기간**: 절대 일자 또는 '최근 N일(오늘 제외)'·'지난 주'·'지난달' 등 상대 기간
    

1.  \[조회\]를 클릭하면 분석 결과 표가 표시됩니다.
    

**알아두세요.**

조회기간을 상대 기간(지난 7일·지난 주 등)으로 저장해두면 매번 기간을 수정하지 않아도 최신 데이터를 자동으로 확인할 수 있습니다. 데이터가 없는 경우 '선택한 조건에 지표가 확인되지 않습니다.' 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
