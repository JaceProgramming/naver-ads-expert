# [AI작성] 디스플레이광고 프로필을 등록하거나 수정하려면 어떻게 하나요?

**디스플레이광고 프로필 등록·수정**

디스플레이광고 프로필은 이미지와 이름, 링크 URL을 입력해 등록하거나 수정합니다. \[광고주센터 > 디스플레이광 >구성요소 관리 > 프로필\]에서 프로필 정보를 확인하고 관리할 수 있습니다.

**등록·수정 절차**

1.  프로필 화면에서 \[편집정보\]를 클릭해 편집 화면으로 이동합니다.
    
2.  \[이미지 변경\]으로 프로필 이미지를 업로드합니다. JPG/JPEG/PNG 형식, 200KB 미만, 정사각형 300x300 이상을 권장하며 이미지는 정사각형으로 자동 조정됩니다.
    
3.  프로필 이름을 1~19자로 입력합니다. (필수)
    
4.  링크 URL을 입력합니다. http 또는 https 형식이며 선택 사항입니다.
    
5.  \[저장\]을 클릭해 변경 내용을 저장합니다.
    

저장이 완료되면 안내가 표시되고 조회 화면으로 돌아갑니다.

**알아두세요.**

\[저장\]은 이름이 유효하고 내용이 변경된 경우에만 활성화됩니다. 편집 기능은 권한에 따라 비활성화될 수 있습니다.

**주의하세요.**

입력값에 따라 다음과 같이 안내됩니다.

-   JPG/JPEG/PNG 형식이 아니면 안내가 표시됩니다. 다른 파일을 선택해 주세요.
    
-   이미지 용량이 200KB를 초과하면 안내가 표시됩니다. 용량을 줄여 주세요.
    

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
