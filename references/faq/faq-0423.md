# 파워링크 광고 그룹에 복수 소재(문안)를 넣으려면 어떻게 해야 하나요?

한 광고 그룹당 소재는 최대 8개(단일형 : 최대 5개 / 반응형 : 최대 3개)까지 등록할 수 있습니다. 소재를 2개 이상 등록한 경우 성과가 우수한 소재의 노출 비율을 자동적으로 조절하여 노출됩니다.

만약, A라는 광고 그룹에 소재를 3개 등록하였다면 성과가 우수한 소재가 더 많이 노출될 수 있습니다.

다수의 소재를 등록하여 성과를 비교/분석하면서 광고 진행할 수 있습니다.

---

광고그룹에 소재를 등록하는 방법은 다음과 같습니다.

1.  소재를 추가하고자 하는 광고 그룹을 클릭합니다.
    
2.  \[소재\] 탭에서 \[새 소재\] 버튼을 클릭하면 \[새 소재\] 대화 상자가 나타니다.
    
3.  \[새 소재\] 대화 상자에서 우선 소재 유형을 선택합니다.
    

1) 반응형 소재 : 비즈채널에 사이트이름이 등록되어 있지 않은 경우, 사이트이름을 입력합니다.

표시 URL이 제대로 입력됐는지 확인하고, 연결 URL을 입력합니다. 연결 URL은 해당 광고그룹 등록 시 입력한 웹사이트 URL을 자동으로 불러옵니다.

세부 연결 URL로 설정하고자 하는 경우 수정할 수 있습니다. 제목(최대 15자) 최소 3개 이상, 설명(20~45자) 최소 2개 이상을 입력합니다.

제목 최대 15개, 설명 최대 4개까지 입력 가능합니다. 단, 의료업종의 경우 반응형 소재가 등록 불가합니다.

**Tip.** 제목과 설명 작성 시 '키워드 삽입' 기능을 활용하면 보다 효과적으로 소재를 만들 수 있습니다.

2) 단일형 소재 : 비즈채널에 사이트이름이 등록되어 있지 않은 경우, 사이트이름을 입력합니다.

표시 URL이 제대로 입력됐는지 확인하고, 연결 URL을 입력합니다. 연결 URL은 해당 광고그룹 등록 시 입력한 웹사이트 URL을 자동으로 불러옵니다.

세부 연결 URL로 설정하고자 하는 경우 수정할 수 있습니다. 제목(최대 15자), 설명(20~45자) 각각 1개씩 입력합니다.

**Tip.** 제목과 설명 작성 시 '키워드 삽입' 기능을 활용하면 보다 효과적으로 소재를 만들 수 있습니다.

4\. 소재의 제목과 설명을 작성한 후 대화 상자 오른쪽의 미리보기 영역에서 입력한 소재의 내용이 PC 또는 모바일에서 어떻게 보이는지 확인합니다. 키워드 삽입 기능을 사용했다면 입력한 대체 키워드가 해당 부분에 보입니다.

5\. \[저장 후 닫기\] 버튼을 클릭합니다. 만약 \[저장 후 닫기\] 버튼을 클릭하였을 때 오류 메시지가 나타나면 대화 상자의 안내 메시지를 참고하여 조치하시기 바랍니다.

**Tip.** 동일한 캠페인 유형이라면 기존에 등록된 소재를 활용하여 소재를 작성할 수 있습니다.

대화 상자 오른쪽 위의 \[기존 소재 불러오기\] 버튼을 클릭한 후 불러올 소재가 속해 있는 캠페인과 광고 그룹을 선택하면 해당 광고 그룹의 소재를 확인할 수 있습니다. \[적용\] 버튼을 클릭하여 소재를 불러올 수 있으며, 불러온 소재는 편집하여 추가할 수 있습니다.
