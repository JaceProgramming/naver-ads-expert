# [AI작성] 광고 계정 정보를 조회하고 수정하려면 어떻게 하나요?

광고 계정의 기본 정보는 \[광고주센터 > 우측 상단 네이버 ID > 광고 계정 관리 > 광고 계정 클릭 > 설정 > 광고 계정 정보\]에서 조회하고 수정할 수 있습니다. 진입 시 정보는 마스킹된 상태로 표시됩니다.

**표시 항목**

다음 9개 항목이 표시됩니다.

| **항목** | **수정 가능 여부** |
| --- | --- |
| 계정 상태 | 수정 불가 |
| 광고 계정 ID | 수정 불가 |
| 광고 계정 이름 | 수정 가능 |
| 계정 유형 | 수정 불가 |
| 사업자 등록번호 | 수정 가능(사업자 유형) |
| 상호(법인명) | 수정 가능 |
| 대표자명 | 수정 가능 |
| 사업자 주소 | 수정 가능 |
| 운영 유형 | 수정 불가 |

**조회·수정 방법**

1.  \[계정 정보 확인/변경\]을 클릭합니다. 권한이 없으면 \[계정 정보 확인\]으로 표시됩니다.
    
2.  회원 정보 인증(휴대전화 또는 이메일)을 완료하면 마스킹이 해제되고, 수정 권한이 있으면 편집 모드로 전환됩니다.
    
3.  수정 가능한 항목을 입력하고 저장합니다.
    

**알아두세요.**

변경 사항이 없으면 저장 버튼이 활성화되지 않습니다. 인증 단계에서 취소하면 편집 모드로 전환되지 않고 읽기 전용 상태가 유지됩니다.

**주의하세요.**

인증번호가 일치하지 않거나 유효 시간이 지나면 다시 인증을 진행해 주시기 바랍니다. 수정에 실패하면 "광고계정 수정에 실패하였습니다."가 안내됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
