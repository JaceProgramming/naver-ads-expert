# [AI작성] 즐겨찾기 화면에서 조회 기간을 설정하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 광고 관리 > 즐겨찾기\] 화면 상단의 기간 선택 영역을 클릭해 조회 기간을 설정합니다. 설정한 기간 동안의 광고 정보 성과 지표가 표에 표시됩니다.

**설정 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 즐겨찾기\]에 진입합니다.
    
2.  왼쪽 LNB에서 조회할 즐겨찾기 그룹을 선택합니다.
    
3.  화면 상단의 기간 선택(예: 2026.05.29. ~ 2026.06.04.)를 클릭합니다.
    
4.  달력에서 시작일과 종료일을 선택하거나 사전 정의된 기간(오늘·어제·최근 7일 등)을 선택합니다.
    
5.  적용하면 광고그룹 / 소재 / 키워드 / 확장 소재 탭의 표에 해당 기간의 성과 지표가 표시됩니다.
    

**알아두세요.**

기간 설정은 각 탭에 공통으로 적용되며, 표 상단의 \[열 맞춤 설정\]을 통해 표시할 컬럼을 선택할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
