# [AI작성] 새 키워드를 추가하려면 어떻게 하나요?

파워링크 광고그룹 상세의 '키워드' 탭에서 \[새 키워드\]를 클릭하면 키워드를 직접 입력하거나 연관 키워드를 활용해 추가할 수 있습니다.

**키워드 추가 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리\]에서 광고그룹 이름을 클릭해 광고그룹 상세로 이동합니다.
    
2.  '키워드' 탭에서 \[새 키워드\]를 클릭합니다.
    
3.  좌측 '키워드 추가하기'에 키워드를 직접 입력하거나, 우측 연관 키워드 영역에서 선택해 추가합니다.
    
4.  '선택한 키워드(N / 100)'에서 추가 결과를 확인합니다.
    
5.  필요 시 \[추가 실적 예상하기\]로 예상 실적을 확인하고, \[지우기\]로 입력값을 초기화할 수 있습니다.
    
6.  \[저장하고 계속하기\]를 클릭하면 키워드가 등록됩니다.
    

**입력 구성**

| **영역** | **설명** |
| --- | --- |
| 키워드 추가하기 (좌측) | 한 줄에 하나씩 키워드를 입력해 추가합니다. '선택한 키워드(N / 100)'에 한 번에 최대 100개까지 담을 수 있습니다. |
| 연관 키워드 (우측) | \[광고그룹기준 연관키워드\] / \[키워드기준 연관키워드\] 탭에서 추천 키워드를 확인합니다. 키워드별 월간 검색수(PC / 모바일)가 표시됩니다. 더 다양한 키워드가 필요하면 \[키워드 도구\]로 이동합니다. |
| 실적 예상 / 초기화 | \[추가 실적 예상하기\]로 예상 실적을 확인하고, \[지우기\]로 선택한 키워드를 전체 삭제합니다. |

**입찰가 설정**

| **방식** | **설명** |
| --- | --- |
| 그룹 기본 입찰가 사용 | 광고그룹에 설정된 기본 입찰가가 적용됩니다. |
| 개별 입찰가 설정 | 키워드별 입찰가를 직접 입력합니다. 70원에서 100,000원까지 10원 단위로 입력할 수 있습니다. |

**알아두세요.**

-   키워드는 한 번에 최대 100개까지 추가할 수 있으며, 광고그룹당 최대 1,000개까지 등록할 수 있습니다.
    
-   이미 광고그룹에 등록된 키워드는 중복 추가할 수 없습니다.
    
-   키워드는 한글·영문·숫자 조합으로 입력하며, 광고법규·운영정책에 어긋나는 키워드는 검토 단계에서 노출이 제한될 수 있습니다.
    

**참고.**

'내 비즈니스에 관심이 있는 잠재 고객이 검색할 만한 키워드를 선택하세요.' 안내의 \[자세히 보기\]에서 키워드 선택 도움말을, \[키워드 도구\]에서 더 다양한 연관 키워드를 확인할 수 있습니다. 연관 키워드가 없으면 '연관 키워드가 없습니다. 이미 등록된 키워드인지 확인하거나 키워드를 직접 입력해 연관 키워드를 조회해 보세요.' 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
