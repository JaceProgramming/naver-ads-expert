# [AI작성] 광고 계정의 자동충전을 켜거나 끄려면 어떻게 하나요?

자동충전 관리 화면에서 자동충전 기능을 켜거나 끌 수 있습니다.

\[광고주센터 > 우측 상단 네이버 ID > 광고 계정 관리 > 광고 계정 클릭 > 결제 > 자동충전 관리\]로 이동합니다.

**켜고 끄는 방법**

1.  '자동 충전 기능' 영역에서 ON/OFF를 전환합니다.
    
2.  "자동 충전 기능을 ON/OFF 하시겠습니까?" 확인 안내에서 \[확인\]을 누릅니다.
    

OFF에서 ON으로 전환할 때 결제 수단이 등록되어 있지 않으면 결제 수단 등록 절차가 먼저 진행됩니다. 사용 기간이 만료된 경우 "자동 충전 사용 기간이 만료됐습니다. 자동 충전 설정을 수정하시겠습니까?" 안내가 표시되어 설정 수정으로 이어집니다.

**설정 정보 확인**

ON/OFF와 무관하게 일·월 누적 충전액과 충전 한도, 자동 충전 시점, 1회 충전 금액, 사용 기간, 문자 메시지 알림 설정 정보가 표시됩니다. 자동 충전 시점이 '계정 잠김 발생시'로 설정된 경우 해당 문구로 표시됩니다.

**알아두세요.**

자동충전 켜기/끄기와 \[수정\]은 충전 권한이 있는 경우에 표시됩니다. 자동충전 실패로 '금일 결제 불가'가 표시되는 경우에는 익일부터 다시 자동충전이 가능합니다.

**참고.**

자동충전은 브랜드검색/신제품검색을 제외한 네이버 광고에 해당됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
