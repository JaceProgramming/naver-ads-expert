# 검색광고 API를 사용하고 싶어요.

네이버 검색광고 API(application program interface)는 네이버 검색광고의 광고 및 데이터 조회/관리 기능을 제공하는 서비스로 네이버 검색광고 API를 사용하여 광고 및 보고서를 관리하는 애플리케이션을 구축할 수 있습니다. 네이버 검색광고 API는 네이버 검색광고 상품 중 일부 상품(파워링크)에 대한 기능 및 데이터를 제공합니다.

네이버 검색광고 API는 직접 애플리케이션을 개발할 수 있는 경우에 사용 가능하며, 솔루션 업체나 파트너사의 설루션을 통해서도 간접적으로 사용할 수 있습니다. [API 사용 매뉴얼 사이트 바로가기](https://naver.github.io/searchad-apidoc/#/guides)

---

**네이버 검색광고 API 서비스 신청**

네이버 검색광고 회원(광고주 혹은 파트너사)이면 누구나 API 서비스를 사용할 수 있습니다.

1.  네이버광고주센터에 로그인 합니다.
    
2.  \[검색광고>도구>SA API 사용 관리\] 메뉴를 클릭합니다.
    
3.  \[네이버 검색광고 API 서비스 신청\]버튼을 클릭한 다음 약관을 확인합니다.
    
4.  \[위 내용을 모두 읽고 확인했습니다\]를 선택한 다음 \[저장하기\] 버튼을 클릭합니다.
    
5.  엑세스라이선스와 비밀키가 자동을 발급됩니다.
    
6.  엑세스라이선스와 비밀키로 API를 호출하면 됩니다.
    

---

**엑세스라이선스와 비밀키 관리**

비밀키는 재발급이 가능하며, 엑세스라이선스는 네이버 검색광고 API 서비스 탈퇴 후 재가입 시 재발급됩니다.

1.  네이버광고주센터에 로그인 합니다.
    
2.  \[검색광고>도구>SA API 사용 관리\] 메뉴를 클릭합니다.
    
3.  \[네이버 검색광고 API 서비스 해지\]버튼을 클릭합니다.
    

---

**네이버 검색광고 API 서비스 탈퇴**

네이버 검색광고 API 서비스에서 탈퇴하더라도 설루션 업체나 파트너사의 API 기반 애플리케이션을 사용할 수 있습니다.

1.  네이버광고주센터에 로그인합니다.
    
2.  \[검색광고>도구>SA API 사용 관리\] 메뉴를 클릭합니다.
    
3.  API 라이선스를 삭제합니다. 비밀키도 함께 삭제됩니다.
    

**주의하세요.**

계정에 대한 권한을 타 회원(광고주)에게 부여한 경우, API를 이용해 본인의 계정에 접근할 수 있으므로 권한 부여 시 주의해야 합니다.
