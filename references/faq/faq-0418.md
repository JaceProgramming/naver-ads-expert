# 파워링크 키워드와 소재에 연결 URL을 다르게 설정하면 어떤 게 적용되나요?

키워드에 입력한 연결 URL이 우선으로 적용됩니다.

만약 키워드에 연결 URL을 등록하면 소재가 바뀌어 노출되어도 키워드의 연결URL로 이동되지만, 키워드에 연결 URL을 따로 등록하지 않는다면 해당 키워드로 검색 시 성과가 좋은 소재에 설정된 연결 URL로 이동됩니다.
