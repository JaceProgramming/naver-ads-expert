# 알림 수신 설정을 어떻게 하나요?

**회원 및 광고 운영에 대한 알림 수신 설정은 아래 3가지 방식으로 설정할 수 있습니다.**

---

**1\. 광고계정/관리계정 관련 알림, 결제 알림, 홍보성 알림 수신 설정은** **회원단위****로 설정할 수 있습니다.**

• \[경로\] 광고주센터 > 내 정보 관리 > 알림 관리

**참고**

결제 알림 중 '비즈머니 잔액 도달 알림' 의 잔액 기준은 광고계정 단위로 설정됩니다.

**2\. 정보성 알림 중, '성과형 디스플레이 광고 관리 알림'은** **회원단위****로 설정할 수 있습니다.**

• \[경로\] 광고주센터 > 내 정보 관리 > 알림 관리

**3\. 정보성 알림 중, '검색광고 광고 관리 알림'과 기타 캠페인 별 알림설정은** **광고계정** **단위로 설정이 가능합니다.**

• \[경로\] 광고주센터 > 광고계정 1개 선택하여 광고계정관리 페이지 진입 > 설정 > 알림관리

**참고**

검색광고 캠페인 광고관리 알림은 회원 단위 알림 설정과는 별도로 동작합니다. 알림 설정 시 즉시 적용 됩니다.

---

**알림 그룹 구분**

알림은 아래 4개 그룹으로 구분됩니다. 그룹 머리행 설정으로 하위 항목을 한 번에 켜거나 끌 수 있고, 각 항목을 개별로 설정할 수도 있습니다.

| **그룹** | **포함 항목** |
| --- | --- |
| 광고계정 | 광고계정 권한 변경 / 회원 초대 상태 변경 / 회원 권한 변경 / 광고 계정 정보 변경 (이메일·문자) |
| 관리 계정 관리 | 관리계정 권한 변경 / 회원 초대 상태 변경 / 회원 권한 변경 / 계정 연동 상태 변경 / 관리 계정 정보 변경 (이메일·문자) |
| 광고 관리 | 검수 결과(승인) / 검수 결과(반려/코멘트) / 캠페인 지출·예산 한도 도달 / 잠재고객 상태 변경 / 대행권 이관 요청 및 해제 (이메일·문자) |
| 홍보성·정보성 알림 수신 | 홍보성 알림 / 정보성 알림 + 톡톡 심야 시간(21시~익일 8시) 정보성 알림 문자 수신 (이메일·문자·톡톡) |

| **알아두세요.**<br>• '광고 관리' 그룹은 디스플레이 광고 캠페인의 알림을 설정합니다.<br>검색광고 캠페인의 광고 관리 알림은 각 광고 계정의 관리 페이지에서 설정하세요.<br>• 심야 시간 정보성 알림 문자 수신은 정보성 알림 수신이 활성화되어 있어야 사용할 수 있습니다.<br>• 설정 변경에 실패하면 변경 실패 안내가 표시되고 이전 상태로 돌아갑니다. |
