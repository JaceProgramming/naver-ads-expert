# 특정 IP에 광고 노출을 제한하는 기능이 있나요?

원치 않는 클릭으로 인해 비용이 발생하고 있거나 기타 다른 사유로 특정 IP 주소에 대해 광고를 노출하고 싶지 않다면 광고 노출 제한 기능을 사용할 수 있습니다.

---

**광고 노출 제한이란**

광고 노출 제한이란 광고가 노출되지 않기를 희망하는 IP 주소를 등록하여 해당 IP 주소에서는 내 광고의 노출을 제한하는 기능입니다.

최대 600개까지 등록이 가능하며, 광고 노출 제한 IP로 등록하면 등록한 IP 주소에서는 내 파워링크 광고의 노출이 제한됩니다.

---

**광고 노출 제한 설정 시 주의 사항**

1\. 광고 노출 제한 IP 등록으로 인해 유효한 트래픽까지 차단될 수 있으니 신중히 판단하여 등록해야 합니다.

2\. 기업 혹은 단체에서는 한정된 IP 주소 대역을 프락시(Proxy) 서버를 통해 사내 혹은 기관 내에서 공유하는 경우가 대부분입니다. 이 경우에 서로 다른 사용자의 클릭이 동일한 IP 주소의 클릭으로 분석될 수 있습니다.

3\. 또 일반 가정의 인터넷 사용자는 유동 IP를 사용하는 경우가 대부분입니다. 이 경우에 서로 다른 사용자의 클릭이 동일한 IP 주소의 클릭으로 보일 수 있습니다.

4\. 따라서 신중히 판단하여 광고 노출 제한 IP를 등록해야 합니다.

5\. 광고 노출 제한 IP로 등록 하더라도 해당 IP 주소를 통한 사이트 접속은 가능합니다.

6\. 광고 노출 제한은 키워드 검색을 통한 광고 노출을 제한하는 기능입니다. 해당 IP 주소에서 즐겨찾기, 사이트 URL 직접 입력, URL 복사 등을 통해 사이트에 접속한 경우 접속 로그는 남을 수 있으나 과금과 무관합니다.

**광고 노출 제한 IP 등록하기**

1\. 광고 노출 제한 IP를 등록하기 위해서는 \[도구 > 광고 노출 제한 관리\] 메뉴를 클릭합니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMjgy/MDAxNzc0OTE4MjY4NTAz.G95Yv2OjEqlSeCtQmEm1pfrDaVLWDcyRmO5HI1zW_1Mg.YjJSucyhp5wV7orqWfm1DQu2xgFfRR1cbXFWRaRIvyog.PNG/image.png)

2\. \[IP 입력\]에 광고 노출을 제한하려고 하는 IP 주소를 입력합니다. 최대 600개까지 입력이 가능합니다. 해당 IP 주소를 설명할 내용을 입력한 뒤 \[추가하기\] 버튼을 클릭합니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMTgy/MDAxNzc0OTE4Mjc3NjM4.wbnKmqNBDUSGrPoq_psd-B9zQ_LjBdR0d-XDZIhVGqog.KYiJwqf9GIIClmbcS3EmuQD5bznIBAje9FLbz-o9Ny4g.PNG/image.png)

**주의하세요.**

-   사설 IP 주소는 등록해도 광고 노출이 차단되지 않으므로 입력할 수 없습니다.
    
    -   10.0.0.0~10.255.255.255
        
    -   172.16.0.0~172.31.255.255
        
    -   192.168.0.0~192.168.255.255
        
-   유동 IP를 차단하고자 할 경우에는 IP 주소의 마지막 네 번째 자리에 와일드카드 문자(\*)를 이용하여 차단할 수 있습니다. 예를 들어 '210.145.41.\*'과 같이 마지막 자리에 와일드카드 문자(\*)를 입력하면 '210.145.41'로 시작하는 모든 IP 주소에 광고가 노출되지 않도록 차단할 수 있습니다.
    

---

**광고 노출 제한 IP 삭제하기**

등록된 광고 노출 제한 IP를 삭제하기 위해서는 \[도구 > 광고 노출 제한 관리\] 메뉴를 클릭한 다음 삭제하고자 하는 광고 노출 제한 IP를 선택하고 \[선택 삭제\] 버튼을 클릭합니다.
