# [AI작성] 쇼핑 프로모션 캠페인 설정에서는 어떤 항목을 입력하나요?

쇼핑 프로모션 캠페인은 캠페인 만들기 과정에서 '캠페인 설정' 영역에 쇼핑 프로모션 목적에만 필요한 항목을 입력합니다. 대표 URL과 브랜드 외에, 전환 추적 대상과 최적화 전환 유형을 함께 지정하며, 네이버쇼핑 비즈채널을 대표 URL로 선택하면 쇼핑 연동 정보가 자동으로 반영됩니다. 광고주님께서 입력하시는 항목은 다음과 같습니다.

**쇼핑 프로모션 캠페인 설정 항목**

| **설정 항목** | **설명** |
| --- | --- |
| 대표 URL | 광고의 기준이 되는 비즈채널을 선택합니다. 네이버쇼핑 비즈채널을 선택하면 쇼핑몰 정보가 캠페인에 자동으로 연동됩니다. 등록된 비즈채널이 없으면 \[비즈채널 관리 바로가기\]에서 먼저 등록합니다. |
| 브랜드 | 쇼핑 프로모션 캠페인의 필수 항목입니다. '여러 브랜드를 보유하신 경우, 본 캠페인의 대상 브랜드를 선택해 주세요.' 등록된 브랜드가 없으면 \[브랜드 설정하기\]에서 먼저 등록합니다. |
| 전환 추적 대상 | 성과를 측정할 전환 추적 대상을 선택합니다. '소재 랜딩 URL의 도메인이 전환 추적 대상의 도메인과 일치하는지 확인해 주세요.' 필요 시 \[전환 추적 관리 바로가기\]에서 등록합니다. |
| 최적화 전환 유형 | 전환 추적 대상을 선택하면 활성화되며, 선택한 전환 추적 대상이 보유한 전환 유형 중에서 최적화 기준이 될 유형을 선택합니다. |

**설정 방법**

1.  캠페인 만들기에서 '캠페인 설정'으로 이동합니다.
    
2.  대표 URL로 광고에 사용할 비즈채널을 선택합니다.
    
3.  대상 브랜드를 선택합니다.
    
4.  전환 추적 대상과 최적화 전환 유형을 차례로 선택합니다.
    
5.  모든 필수 항목을 입력한 뒤 \[다음\]을 클릭합니다.
    

**참고.**

대표 URL로 네이버쇼핑 비즈채널을 선택하면 쇼핑몰 정보가 자동으로 매핑되어 이후 소재 단계에서 랜딩 URL이 해당 쇼핑몰 도메인과 일치하는지 확인됩니다.

**주의하세요.**

대표 URL은 캠페인 수정 시 변경할 수 없습니다. 또한 선택한 네이버쇼핑 쇼핑몰이 폐점 상태이면 캠페인 수정이 제한됩니다. 비즈채널이 검토 대기 상태이면 모든 필수 항목을 입력해도 \[다음\] 버튼이 비활성화됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
