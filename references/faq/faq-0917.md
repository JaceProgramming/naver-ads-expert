# 디스플레이광고 광고 노출이 줄어든 이유가 궁금해요. 

디스플레이광고 집행 중 광고 노출이 하락하거나 기대 대비 노출이 저조하다면 아래 항목들을 순차적으로 점검해주세요.

점검 이후에도 계속 노출이 되지 않을 경우 '채팅 상담하기"를 통해 문의해 주시기 바랍니다.

**1\. 캠페인 설정값이 노출 가능한 상태인가요?**

캠페인, 광고그룹 또는 애셋그룹, 소재 상태가 노출 가능한 상태인지 점검해주세요.

• 캠페인, 광고그룹/애셋그룹, 소재 상태가 모두 ON인지 확인

• 캠페인 또는 광고그룹의 종료 일시가 경과하지 않았는지 확인

• 광고그룹에 요일/시간 타겟팅 설정한 경우, 현재 노출 가능한 시간인지 확인

• 광고 소재의 검토 상태가 '보류' 가 아닌지 확인

• 여러 타겟팅 설정으로 인해 타겟 도달 범위가 좁아지지 않았는지 확인

(입찰 경쟁 상황에 따라 차이가 있으나 통상적으로 500만 이하인 경우 노출이 원활하지 않을 수 있음)

**2\. 예산이 충분한 상황에서 적정 입찰가로 입찰하고 있나요?**

디스플레이광고에서는 원활한 노출 뿐 아니라 과소진 예방하면서 안정적으로 광고를 전송하기 위해 노력합니다.

그러므로 입찰가가 너무 낮아도 입찰 경쟁에서 밀려 노출이 되지 않을수 있지만, 반대로 노출이 원활하지 않아서 입찰가를 계속 높이면 남은 예산 또는 비즈머니 대비 입찰가가 높아질 경우 과소진 방지 로직에 의해 오히려 노출이 제한될 수 있습니다.

적정한 입찰가를 설정하시고, 설정하신 입찰가로 충분히 노출될 수 있는 예산 또는 비즈머니인지 체크해주세요.

• 광고계정의 비즈머니 잔액이 없거나 부족하지 않은지 확인

• 하루예산 또는 총예산에 도달했거나 이미 초과하지 않았는지 확인

• 광고그룹의 예산과 별개로, 캠페인 > 캠페인 추가 설정 > 캠페인 지출 한도 금액에 도달하였는지 확인

• 광고그룹 > 예산 > 총예산으로 집행 중 기간을 연장한 경우, 집행 기간 대비 남은 예산이 부족하지 않은지 확인

• 입찰가 대비 예산 또는 비즈머니 잔액이 부족하지 않은지 확인

• 수동 입찰 입찰가 또는 자동입찰의 입찰가 한도 금액이 너무 낮지 않은지 확인

**3\. 오랫동안 광고를 중단했다가 다시 집행하셨나요?**

디스플레이광고는 캠페인 종료일시 미지정으로 광고 집행이 가능합니다.

다만 캠페인/광고그룹/소재를 명시적으로 OFF하지 않고 예산 도달 또는 비즈머니 잔액 부족으로 광고 노출이 중지된 후 90일 이상 경과했을 경우 비즈머니를 충전하시거나 집행 기간을 변경하셔도 바로 노출이 재게 되지 않을 수 있습니다.

오랜 시간 광고 노출이 중지된 캠페인을 다시 집행하고자 하실 경우, 반드시 캠페인 하위 승인된 소재 상태를 OFF로 변경하신 후 다시 ON 상태로 변경해주세요.

**4\. 잠재고객 타겟팅에 설정한 각 타겟 상태가 정상인가요?**

광고 그룹 > 타겟팅 설정 > 잠재고객에 설정하신 타겟이 정상 상태이고 충분한 모수를 보유하고 있는지 확인해주세요.

잠재고객에 등록된 다양한 타겟들은 정기적으로 모수가 갱신되기 때문에 캠페인 집행중에 모수가 감소되거나 타겟 상태가 '사용 불가'로 변경될 수 있으며, 그럴 경우 광고 노출이 감소하거나 완전히 중지될 수 있습니다.
