# [AI작성] 검색광고 소재의 상태를 변경하려면 어떻게 하나요?

**적용 대상:** 파워링크 · 쇼핑검색 · 파워컨텐츠 · 플레이스 · 브랜드검색/신제품검색/서칭뷰

광고그룹 상세 \[소재\] 탭의 소재 목록 표 'ON/OFF' 컬럼을 클릭해 소재의 노출 상태를 변경합니다. 여러 소재를 일괄로 변경할 때는 소재를 선택한 뒤 작업 바의 \[ON\] / \[OFF\] 버튼을 클릭합니다.

**변경 절차**

1.  광고그룹 상세 \[소재\] 탭으로 이동합니다.
    
2.  **단건**: 소재 행의 'ON/OFF' 컬럼을 클릭합니다.
    
3.  **일괄**: 변경할 소재를 선택하면 'N개 선택됨' 작업 바에서 \[ON\] / \[OFF\] / \[삭제\] / \[닫기\] 버튼이 표시됩니다.
    

**알아두세요.**

소재를 OFF로 설정하면 광고가 노출되지 않습니다. 보류·노출 제한 상태의 소재는 ON으로 두어도 노출되지 않으며, \[재검토 요청\]을 통해 검토를 다시 요청해야 합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
