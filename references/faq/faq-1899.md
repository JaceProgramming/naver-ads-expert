# [AI작성] ADVoost 쇼핑 애셋그룹 상세 화면에서는 무엇을 확인하나요?

**적용 대상:** 디스플레이광고 > ADVoost 쇼핑 (광고그룹 대신 애셋그룹 구조를 사용)

캠페인 상세 화면의 애셋그룹 목록에서 애셋그룹 이름을 클릭하면 애셋그룹 상세 화면이 열립니다. 이 화면에서 광고주님께서는 애셋그룹의 성과와 설정 정보를 확인하실 수 있습니다.

**애셋그룹 상세 화면 구성**

| **영역** | **설명** |
| --- | --- |
| 애셋그룹 성과 | 총비용·노출수·클릭수·결과 등 지표를 선택해 기간별 추세를 그래프로 확인합니다. 데이터가 없으면 '데이터가 없습니다.'로 표시됩니다. |
| 애셋그룹 정보 | 화면 우측에 애셋그룹 이름, 기간, 게재 위치, 타게팅 유형, 입찰, 예산 정보가 표시되며 ON/OFF와 \[수정\] 버튼이 함께 제공됩니다. |
| 애셋그룹 보고서 | 화면 하단에 해당 애셋그룹의 성과가 보고서(결과·결과당 비용·총비용·노출수·평균 CPM·클릭수·평균 CPC·클릭률·총 전환율·총 광고수익률) 표 형태로 표시됩니다. |

**알아두세요.**

애셋그룹 정보를 변경하시려면 \[수정\]을 클릭해 수정 화면으로 이동합니다. 삭제된 애셋그룹은 ON/OFF가 비활성화되며 \[수정\] 버튼이 표시되지 않습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
