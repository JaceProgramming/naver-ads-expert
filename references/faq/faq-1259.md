# 입점 신청이 승인된 후에는 무엇을 해야 하나요?

네이버 가격비교에 입점 승인이 완료된 경우, 상품 DB URL을 등록하여 광고에 노출할 상품을 등록해야합니다.

상품등록을 위해서는 웹 프로그램 코딩작업으로 DB URL을 제작해야 하며 네이버 쇼핑 파트너 제휴사로 지정된 호스팅 업체를 이용하고 있다면 해당 업체를 통해 DB URL 생성을 도움 받을 수 있습니다.

만약 제휴 파트너사를 이용하지 않는 경우 아래 도움말을 활용하여 직접 DB URL 을 제작할 수 있습니다.

[DB URL 작성요령 및 예제](https://join.shopping.naver.com/misc/download/ep_guide.nhn)

완성된 DB URL을 등록하면 검수가 진행되며 검수 통과 후 충전금을 충전하면 서비스 시작 가능 상태가 됩니다. 서비스 시작 가능상태라면 쇼핑검색광고를 이용할 수 있습니다.

DB URL 등록과 관련한 보다 자세한 내용은 아래 도움말을 참조하세요.

[입점 신청이 승인되었습니다. 그 다음으로는 무엇을 해야 하나요?](https://join.shopping.naver.com/faq/list.nhn?catgCd=F10001)

**참고.** 네이버 가격비교 입점 신청 시, 정보입력단계에서 ‘쇼핑검색광고’ 으로 입점 목적을 선택 한 경우, 충전금을 충전하지 않아도 쇼핑검색광고 등록이 가능합니다. 단, 네이버 가격비교에 별도로 상품노출을 원하시는 경우, 일반 ‘네이버 가격비교’ 유형으로 입점 목적을 선택 하여 입점 신청바랍니다.
