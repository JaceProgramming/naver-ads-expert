# [AI작성] 대시보드의 '광고비 집중 캠페인'은 무엇을 보여주나요?

'광고비 집중 캠페인'은 최근 7일(오늘 제외) 동안 광고비가 집중된 상위 캠페인을 모아 보여 주는 영역으로, 예산 배분 상황을 빠르게 파악하는 데 도움이 됩니다. 대시보드 진입 시 항상 표시됩니다.

**표시 항목**

| **항목** | **설명** |
| --- | --- |
| 캠페인 이름 | 캠페인명과 운영 상태를 함께 표시합니다. |
| 총비용 | 최근 7일간 해당 캠페인의 총 광고비입니다. |
| 평균 대비 지출 | 평균 지출 대비 증감 비율을 표시합니다. |
| 전환율 | 해당 캠페인의 전환율을 표시합니다. |

최대 12개 캠페인이 한 화면에 4개씩 표시되며, 캠페인이 5개 이상이면 좌우 이동으로 페이지를 넘겨 볼 수 있습니다. 캠페인 이름을 클릭하면 해당 캠페인 관리 화면으로 이동합니다.

전체 캠페인을 보려면 \[전체 캠페인 보기\] 버튼을 클릭합니다.

**알아두세요.**

데이터를 불러오는 동안에는 임시 화면이 표시되며, 잠시 후 캠페인 목록으로 전환됩니다.

**참고.**

최근 7일간 지출이 없으면 '최근 7일 데이터가 충분하지 않아요. 데이터가 수집되면 알려드릴게요!' 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
