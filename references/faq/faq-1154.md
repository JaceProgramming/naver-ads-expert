# 검색광고 검토는 얼마나 걸리나요?

광고 검토는 '광고 등록 완료'시점부터 영업일 기준으로 1~2일 이내 진행됩니다.

비즈채널(웹사이트, 쇼핑몰 등), 키워드, 소재가 순차적으로 검토가 진행되며,

광고가 계속 검토중일 경우 '광고 등록'일시를 확인해 주세요.

**주의하세요.**

-   비즈머니 잔액이 0원이거나 부족할 경우, 검토는 진행되지 않습니다.
    
-   다량의 광고 등록, 추가 검토가 필요한 경우 검토 시간이 더 소요될 수 있습니다.
