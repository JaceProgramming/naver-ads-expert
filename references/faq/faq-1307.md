# 변경이나 검토 이력을 한 번에 조회할 수 있나요?

**변경 이력 관리란?**

광고주께서 네이버 광고주센터 내 각종 변경/검토 이력을 선택적으로 조회 및 다운로드 할 수 있는 기능입니다.

**변경 이력 관리 접속 방법**

\[네이버 광고주센터 > 검색관리 > 도구 > 변경 이력 관리\] 메뉴에서 확인할 수 있습니다.

**변경 이력 관리 사용 방법**

**1\. 캘린더**

화면 우측 상단의 캘린더를 클릭하여 조회기간을 선택할 수 있습니다.

조회기간 선택을 통해 해당 기간 내에 발생한 이력을 조회할 수 있습니다.

최근 2년 내에 발생했던 이력에 대해서 조회할 수 있으며, 최대 조회가능 기간은 92일간 입니다.

**2\. 조회대상**

변경 유형과 캠페인 및 광고그룹을 선택해 관련된 이력을 조회할 수 있습니다.

캠페인 및 광고그룹 선택 시, 1) 해당 캠페인 및 광고그룹의 변경 항목 뿐만 아니라, 2) 해당 캠페인 및 광고그룹 하위의 모든 변경항목(소재, 키워드 등) 또한 노출됩니다.

-   광고그룹 선택은 캠페인 선택 이후에 가능합니다.
    
-   변경 유형을 '검토이력'으로 선택 시, 캠페인 및 광고그룹 선택은 불가합니다.
    

변경유형은 '모든항목 > 대분류 > 소분류' 로 구분되어 있으며, 각 단계별로 조회 대상 선택이 가능합니다.

EX. 캠페인 이력 선택 시- 캠페인 추가, 캠페인 변경, 캠페인 ON/OFF, 캠페인 삭제 4가지 유형을 모두 조회할 수 있습니다.

변경 유형은 아래와 같습니다.

| **대분류** | **소분류** |
| --- | --- |
| 캠페인 이력 | 캠페인 추가, 캠페인 변경, 캠페인 ON/OFF, 캠페인 삭제 |
| 광고그룹 이력 | 광고그룹 추가, 광고그룹 변경, 광고그룹 ON/OFF, 광고그룹 삭제 |
| 확장소재 이력 | 확장소재 추가, 확장소재 변경, 확장소재 데이터 연동, 확장소재 재검토요청,<br>확장소재 ON/OFF, 확장소재 삭제 |
| 소재 이력 | 소재 추가, 소재 변경, 소재 연동, 소재 ON/OFF, 소재 삭제 |
| 애셋 이력 | 애셋 추가, 애셋 삭제 |
| 키워드 이력 | 키워드 추가, 키워드 변경, 키워드 재검토 요청, 키워드 on/off, 키워드 삭제 |
| 전환 추적 이력 | 서비스 신청, Modoo!연동, 해지 요청, 전환추적 기간 변경, 서비스 담당자 변경 |
| 공유예산 이력 | 공유예산 추가, 공유예산 변경, 공유예산 삭제 |
| 타겟팅 이력 | 타겟팅 추가, 타겟팅 변경 |
| 광고노출제한 이력 | 광고노출제한 추가, 광고노출제한 변경, 광고노출제한 삭제 |
| 검토 이력 | 소재 검토, 애셋 검토, 확장소재 검토, 비즈채널 검토, 키워드 검토 |
| 광고 중단/재개 | 계정 비즈머니 중단, 계정 비즈머니 재개, 광고그룹 하루예산 중단,<br>광고그룹 하루예산 재개, 캠페인 하루예산 중단, 캠페인 하루예산 재개<br>공유예산 중단, 공유예산 재개, 광고그룹 하루예산 중단 |
| 대상URL 수집/진단 요청 | 재수집 요청, 현황 진단 요청 |

**3\. 조회 결과 테이블 및 다운로드**

1)캘린더와 2)조회대상 조건에 부합하는 이력을 테이블 형식으로 노출합니다.

이력은 최근 발생한 순서대로 노출됩니다.

조회 결과 테이블은 다음과 같은 컬럼으로 구성되어 있습니다.

-   변경일자 : 해당 이력이 발생한 시간입니다.
    
-   변경 유형 : 해당 이력의 유형입니다.
    
-   변경자 : 해당 이력을 실행한 계정입니다.
    
-   캠페인 : 변경 대상이 속해 있는 상위 캠페인입니다.
    
-   광고그룹 : 변경 대상이 속해 있는 상위 광고그룹입니다. 캠페인 단위의 이력일 경우 '-' 값으로 표기됩니다.
    
-   변경 내용 : 변경 대상과 변경된 내용입니다. 우측의 v 버튼을 통해 상세이력을 확인할 수 있습니다.
    

**참고.**

변경 유형이 '검토이력'인 경우, 변경자,캠페인,광고그룹 컬럼은 '-' 값으로 표기됩니다.

'캠페인', '광고그룹', '변경 내용' 컬럼의 조회 결과를 클릭 시, 광고관리로 이동하여 대상을 변경할 수 있습니다.

(검토 이력의 경우, 상세이력에서 클릭이 가능합니다.)

-   '변경 내용' 컬럼의 조회 결과 우측의 v 버튼을 통해 상세이력을 확인할 수 있습니다.
    
-   하단의 행표시 버튼을 통해 한 페이지에 볼 수 있는 이력의 행 수를 설정할 수 있습니다.
    
-   열 맞춤 설정 버을 통해 조회 결과 테이블의 컬럼을 변경할 수 있습니다.
    
-   <다운로드> 버튼을 통해 현재 조건에 부합하는 조회 결과를 xlsx파일로 다운로드 할 수 있습니다.
