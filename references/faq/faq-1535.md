# [AI작성] 파워컨텐츠 광고그룹 상세 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 광고 관리 > 파워컨텐츠\]에서 광고그룹 이름을 클릭하면 광고그룹 상세 화면으로 진입합니다. 선택한 광고그룹의 성과 추이와 하위 키워드·소재·타겟팅을 관리합니다.

**광고그룹 정보 영역**

화면 상단에 광고그룹 정보가 표시되며, 우측 \[수정\]으로 설정을 변경하고 ON/OFF로 노출 상태를 전환할 수 있습니다.

| **항목** | **설명** |
| --- | --- |
| 상태 | 운영 가능 / 중지: 그룹 OFF 등 현재 운영 상태가 표시됩니다. |
| 채널 정보 | 연결된 블로그·포스트·카페 URL이 표시됩니다. |
| 기본 입찰가 | 70원~100,000원 범위로 표시되며, 부가세(VAT) 미포함 기준입니다. |
| 하루 예산 | 50원~1,000,000,000원 또는 사용 안 함으로 표시됩니다. |
| 매체 / 소재 노출 방식 | 모든 매체 / 노출 매체 유형 선택, 성과 기반 노출 / 동일 비중 노출 중 설정값이 표시됩니다. |

**탭 구성**

광고그룹 상세는 6개 탭으로 구성됩니다(제외 검색어·확장 소재 탭은 제공되지 않습니다).

| **탭** | **관리 내용** |
| --- | --- |
| 키워드 | 광고가 노출될 타겟 키워드를 추가·관리하고 입찰가·검토 상태를 확인합니다. |
| 소재 | 블로그·카 콘텐츠 소재를 등록·관리합니다. |
| 요일/시간대 | 요일·시간대별 노출 여부와 입찰 가중치를 설정합니다. |
| 지역 | 지역별 노출 여부와 입찰 가중치를 설정합니다. |
| 성별 | 성별별 노출 여부와 입찰 가중치를 설정합니다. |
| 연령대 | 연령대별 노출 여부와 입찰 가중치를 설정합니다. |

**키워드 목록 표**

키워드 탭의 표 컬럼은 'ON/OFF / 키워드 / 상태 / 현재 입찰가(VAT 미포함) / 노출수 / 클릭수 / 클릭률(%) / 노출현황보기 / 평균 CPC / 총비용 / 품질지수'로 구성됩니다. 관리 버튼으로 \[새 키워드\]·\[입찰가 변경\]·\[선택한 키워드 관리\]·\[다운로드\]·\[열 맞춤 설정\]·\[상세 데이터\]가 제공됩니다.

**알아두세요.**

파워컨텐츠는 파워링크와 달리 키워드 표에 '품질지수' 컬럼이 표시되며, 제외 검색어·확장 소재 탭은 제공되지 않습니다. 입찰가 관련 금액은 부가세(VAT) 미포함 기준으로 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
