# [AI작성] 디스플레이광고 시너지 데이터를 다운로드하려면 어떻게 하나요?

**시너지 데이터 다운로드 방법**

시너지 상세 보고서 화면 하단의 시너지 데이터 테이블에서 조회한 데이터를 파일로 내려받을 수 있습니다. 데이터 테이블에는 일별 시너지 상세 데이터가 행 단위로 표시됩니다.

1.  분석할 캠페인과 기간을 설정하고 확인을 클합니다.
    
2.  데이터 테이블 영역의 다운로드 버튼을 클릭합니다.
    
3.  현재 조회 조건에 해당하는 시너지 데이터가 파일로 내려받아집니다.
    

**데이터 테이블 구성**

데이터 테이블은 상위 구분과 하위 항목으로 나뉜 2단 헤더로 구성되며, 다음 컬럼이 표시됩니다.

-   일 · 노출수 · 클릭수 · 클릭률
    
-   키워드 · 추가검색 · 추가검색 증가율 · 검색광고 추가클릭 · 검색광고 추가클릭 증가율
    
-   검색광고 추가클릭 발생(브랜드검색) · 검색광고 추가클릭 발생(파워링크) · 검색광고 추가클릭 발생(쇼핑검색)
    

검색광고 추가클릭 발생은 브랜드검색 · 파워링크 · 쇼핑검색 채널별로 구분됩니다.

**참고.**

데이터가 없으면 다운로드 버튼이 표시되지 않고 '조회된 내역이 없습니다.' 안내가 나타납니다. 다운로드에 실패하면 오류 안내가 표시되므로 다시 시도해 주세요.

**주의하세요.**

다운로드 파일에는 화면의 열 맞춤 설정이 반영되지 않으며, 전체 컬럼이 고정된 형태로 내려받아집니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
