# [AI작성] 플레이스 광고그룹을 생성하려면 어떻게 하나요?

플레이스 캠페인 상세에서 \[새 광고그룹\]을 클릭하면 그룹 유형을 선택하고 정보를 입력해 광고그룹을 생성합니다.

**그룹 유형 선택**

먼저 그룹 유형을 선택합니다. 선택한 유형은 생성 후 변경할 수 없습니다.

| **유형** | **노출 지면 / 과금** | **설명** |
| --- | --- | --- |
| 플레이스검색 | 네이버 통합검색 등 검색 지면 / 클릭당 과금(CPC) | 스마트 플레이스 업체를 검색 지면에 노출하며 기본 입찰가를 직접 입력합니다. |
| 지역소상공인광고 | 네이버 콘텐츠 서비스 지면 / 노출당 고정가(CPM) | 업체를 콘텐츠 지면에 노출하며 노출가로 과금되어 입찰가를 입력하지 않습니다. |
| 디지털 옥외광고 | 오프라인 디지털 옥외 매체 / 재생당 고정가(CPV) | 지역 기반 오프라인 옥외 매체에 동영상을 노출하며 재생당 고정가로 과금됩니다. |

**만들기 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 플레이스\]에서 캠페인 이름을 클릭해 상세로 이동합니다.
    
2.  \[새 광고그룹\]을 클릭하고 '그룹 유형'을 선택합니다. 창 좌측의 \[기존 광고그룹 설정 불러오기\]로 기존 설정을 가져올 수 있습니다.
    
3.  광고그룹 이름(1~30자)을 입력하고, 연결할 스마트 플레이스 업체를 업체명·URL로 검색해 선택합니다.
    
4.  플레이스검색은 기본 입찰가(50~5,000원)를 입력합니다. 지역소상공인광고·디지털 옥외광고는 고정가로 과금되어 입찰가를 입력하지 않습니다.
    
5.  하루 예산을 입력하거나 제한없음으로 둡니다.
    
6.  필요 시 고급옵션에서 매체·가중치를 설정한 뒤 \[저장\]을 클릭합니다.
    

**알아두세요.**

광고그룹 유형은 생성 후 변경할 수 없습니다. 광고 등록 전에 네이버 스마트 플레이스에 업체가 등록되어 있어야 하며, 검색 결과가 없으면 올바른 업체명·URL을 확인해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
