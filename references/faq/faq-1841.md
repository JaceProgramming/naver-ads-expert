# [AI작성] 디스플레이광고를 만드는 전체 흐름은 어떻게 되나요?

**적용 대상:** 웹사이트 전환 · 앱 전환 · 인지도 및 트래픽 · 동영상 조회 · ADVoost 쇼핑 · 카탈로그 판매 · 쇼핑 프로모션 · 참여 유도 (디스플레이광고 전 유형)

디스플레이광고는 '캠페인 → 광고 그룹 → 광고 소재 → 광고 만들기 완료'의 4단계 흐름으로 만듭니다. 단, ADVoost 쇼핑은 광고 그룹·소재 대신 애셋그룹·자산으로 구성되어 '캠페인 → 애셋그룹 → 완료' 흐름을 따릅니다. 각 단계는 화면 좌측의 단계 표시 영역에 순서대로 나타나며, 한 단계를 저장하면 다음 단계로 자동 이동합니다.

**광고 만들기 4단계**

아래 4단계 흐름은 광고 그룹·소재 구조를 사용하는 유형 기준이며, ADVoost 쇼핑은 '광고 그룹' 대신 '애셋그룹', '광고 소재' 대신 '아이템'으로 진행합니다.

| **단계** | **설정 내용** |
| --- | --- |
| 캠페인 | 캠페인 목적, 캠페인 이름, 캠페인 설정(대표 URL·브랜드 등)을 입력합니다. |
| 광고 그룹 | 광고 그룹 이름, 입찰 전략, 타게팅 설정, 게재 일정 및 방식을 설정합니다. |
| 광고 소재 | 소재 유형, 소재 이름, 소재 콘텐츠, 검토 메모 및 문서를 입력합니다. |
| 광고 만들기 완료 | 모든 단계가 완료되면 광고 만들기가 마무리됩니다. |

**광고 만들기를 시작하려면**

1.  '광고 관리' 메뉴에서 만들려는 디스플레이광고 목적을 선택합니다.
    
2.  상단의 \[+ 새 캠페인\]을 클릭하면 캠페인 만들기 화면으로 이동합니다.
    
3.  먼저 캠페인 목적을 선택한 뒤, 화면 안내에 따라 단계별로 입력하고 저장합니다.
    

**알아두세요.**

광고를 만드는 도중 화면 좌측의 단계 표시에서는 이전 단계로 이동할 수 있으며, 아직 진행하지 않은 다음 단계로는 건너뛸 수 없습니다.

**참고.**

캠페인 목적과 대표 URL 등 일부 항목은 캠페인 저장 후 수정할 수 없으므로 광고 목적에 따라 정확히 설정해 주시기 바랍니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
