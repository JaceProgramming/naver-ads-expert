# [AI작성] 검색광고 제외 검색어 목록 화면 안내

**적용 대상:** 파워링크 · 쇼핑검색(상품형·카탈로그형) · 플레이스

광고그룹 상세 화면의 '제외 검색어' 탭에서 광고그룹에 등록된 제외 검색어를 조회하고 관리할 수 있습니다. 제외 검색어는 특정 검색어로 검색했을 때 광고가 노출되지 않도록 설정하는 기능입니다.

**제외 검색어 목록 컬럼**

| **컬럼** | **설명** |
| --- | --- |
| '검색어' | 등록된 제외 검색어 텍스트가 표시됩니다. |
| '유형' | 제외 방식이 표시됩니다. (예: '일치(유사검색어)', '확장 검색') |
| '설명' | 등록 시 입력한 설명이 표시됩니다. 입력하지 않은 경우 '-'로 표시됩니다. |
| '등록시각' | 제외 검색어가 등록된 날짜와 시간이 표시됩니다. |

**주요 기능**

| **기능** | **설명** |
| --- | --- |
| 제외 검색어 추가 | 제외 검색어 추가 버튼을 클릭하면 추가 화면이 열립니다. 검색어와 유형을 입력하여 등록할 수 있습니다. |
| '다른 그룹으로 복사' | 제외 검색어를 선택한 후 다른 광고그룹으로 복사할 수 있습니다. (파워링크 만) |
| 통합 필터 | '필터를 입력해 주세요' 입력란에 조건을 입력하여 제외 검색어를 검색합니다. (파워링크 만) |

**알아두세요.**

-   등록된 제외 검색어가 없는 경우 비어 있다는 안내가 표시됩니다.
    
-   동일한 검색어와 유형 조합이 이미 등록된 경우 중복 등록할 수 없습니다.
    
-   한 번에 처리할 수 있는 최대 개수는 100개입니다. (쇼핑검색광고와 플레이스는 최대 70개 등록 가능)
    

**참고.**

'다른 그룹으로 복사'는 제외 검색어를 1건 이상 선택해야 활성화됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
