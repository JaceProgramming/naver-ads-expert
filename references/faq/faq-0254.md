# 쇼핑 광고노출을 제한할 수 있나요?

쇼핑검색광고에서는 광고노출제한관리와 제외검색어 기능으로 광고노출을 제한할 수 있습니다.

광고노출제한관리는 광고가 노출되지 않기를 희망하는 IP 주소를 등록하여 해당 IP 주소에서는 내 광고의 노출을 제한하는 기능으로 광고 노출 제한 IP로 등록하면 등록한 IP 주소에서는 내 쇼핑검색광고의 노출이 제한됩니다.

[광고 노출 제한이란 도움말 보기](https://ads.naver.com/help/faq/1279) 

또한, 제외검색어 기능을 사용하여 자동 매칭된 검색어 중 광고노출을 제한하고 싶은 경우 직접 광고 노출을 제외할 검색어를 설정하는 '제외검색어 추가'기능을 이용하시거나, 검색어 없이 쇼핑 카테고리 선택 시 노출되는 광고를 제한하는 '검색어 없는 경우 광고 노출 제외' 기능을 이용하여 2가지 방법으로 제외검색어 설정이 가능합니다.
