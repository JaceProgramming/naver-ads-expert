# 파워링크 소재(문안)는 어떻게 만드나요?

'소재(문안)'는 파워링크 영역에서 고객이 최초로 접하는 내 상품이나 서비스에 대한 정보입니다. 따라서, 노출되는 여러 개의 파워링크 중 내 광고를 클릭하게 만들기 위해서는 무엇보다 소재의 내용이 중요합니다. 내 상품과 서비스가 가지고 있는 차별성이 최대한 잘 드러나도록 소재를 작성하는 것이 좋습니다.

한 광고 그룹당 소재는 최대 8개까지 등록할 수 있으며(단일형 : 5개 / 반응형 : 3개) , 소재를 2개 이상 등록할 경우 성과가 우수한 소재의 노출 비율을 자동적으로 조절하여 노출됩니다.

---

**소재(문안) 만들기**

소재 만들기는 아래 단계에 따라 진행합니다.

1\. 소재를 등록하고자 하는 캠페인의 광고 그룹을 선택한 다음 \[소재\] 탭을 클릭합니다.

2\. \[소재\] 탭에서 \[새 소재\] 버튼을 클릭하면 \[새 소재\] 대화 상자가 나타납니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzBfNzEg/MDAxNzc0ODY2NjEwMzg1.5GnKD-YiFywYR0aTVN23QQevlNbZnTn6FfuGGJ_vTaog.ECCBoMFBQiHMIjevEzYdR049-M51osltiVda4K6a-RYg.PNG/image.png)

3\. \[새 소재\] 대화 상자에서 소재 유형을 선택합니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzBfNjEg/MDAxNzc0ODY2NjE2MzE3.p9JmU4qSZfheCFB6qkbycNl-OLYlXX6KygMhijtVfJ0g.tWDacTHqU-Jcee5rSRvlHx1_SWDrGVN47BtDvwJp2GAg.PNG/image.png)

4-1. **반응형 소재** : 비즈채널에 사이트이름이 등록되어 있지 않은 경우, 사이트이름을 입력합니다.

표시 URL이 제대로 입력됐는지 확인하고, 연결 URL을 입력합니다.

연결 URL은 해당 광고그룹 등록 시 입력한 웹사이트 URL을 자동으로 불러옵니다. 세부 연결 URL로 설정하고자 하는 경우 수정할 수 있습니다.

제목(최대 15자) 최소 3개 이상, 설명(20~45자) 최소 2개 이상을 입력합니다. 제목 최대 15개, 설명 최대 4개까지 입력 가능합니다. 단, 의료업종의 경우 반응형 소재가 등록 불가합니다.

**Tip.**

제목과 설명 작성 시 '키워드 삽입' 기능을 활용하면 보다 효과적으로 소재를 만들 수 있습니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzBfNjAg/MDAxNzc0ODY2NjI3ODA4.5yphd6pSJCn4eAjlM_vo_fEyOWOIJHJUOWIM_zPVQNcg.-qRbQ1afu2dHO1wZ66bRmLCT4n5FqlLXeZVsyP_VSDAg.PNG/image.png)

4-2. **단일형 소재** : 비즈채널에 사이트이름이 등록되어 있지 않은 경우, 사이트이름을 입력합니다.

표시 URL이 제대로 입력됐는지 확인하고, 연결 URL을 입력합니다.

연결 URL은 해당 광고그룹 등록 시 입력한 웹사이트 URL을 자동으로 불러옵니다. 세부 연결 URL로 설정하고자 하는 경우 수정할 수 있습니다.

제목(최대 15자), 설명(20~45자) 각각 1개씩 입력합니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzBfODMg/MDAxNzc0ODY2NjQxNTQx.wsINT8effxXmz1ZN5d1bh0b--Vm9M478PL-bhnrUZ_Ig.Zwlvm4iaChR-v7n9WttQbhXujJjAtG1Ex3i-5NC4oG4g.PNG/image.png)

5\. 만약 기존에 등록한 소재를 활용하여 소재를 만들고 싶다면, '편집후 새로 등록' 또는 '기존 소재 불러오기' 기능을 사용할 수 있습니다.

1) 편집후 새로 등록 : 소재 목록에서 활용하고자 하는 소재 칼럼 위에 마우스 포인터를 올리면 소재 아래에 \[편집 후 새로 등록\] 버튼이 노출됩니다. 버튼을 클릭하여 \[새 소재\] 대화 상자에서 소재를 수정한 후 저장합니다.

**주의하세요.** 해당 기능은 기존 소재가 수정되는 것이 아니라, 기존 소재를 편집하여 새로운 소재를 등록하는 기능입니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzBfOTkg/MDAxNzc0ODY2NjQ5NDU1.-Oq1lNqCrCsF62TvoAfWYcfTw51oLjxDCvHCcbx1Aa0g.Y08groOU5yk_Xc-fvd_wyT740uoPSLMVB33o6BwXFFYg.PNG/image.png)

2) 기존 소재 불러오기: \[새 소재\] 대화 상자 오른쪽 위의 \[기존 소재 불러오기\] 버튼을 클릭한 후 불러올 소재가 속해있는 캠페인의 광고 그룹을 선택하면 불러올 소재를 선택할 수 있습니다. 단, 기존 소재 불러오기는 동일한 캠페인 유형 및 동일한 유형의 소재만 불러올 수 있습니다.

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzBfNDcg/MDAxNzc0ODY2NjU1MDQ3.PTkt6y_hPPPKuruwh8dZu2OD7AY7p2Ubuo4_M4lMET0g.XK9IcCR_Zge-KIgS610KpaBKSiqIAixK9odBJ4GYZHkg.PNG/image.png)

6\. 소재 작성을 완료한 후, 대화 상자 오른쪽에 제공되는 '미리보기'를 통해 입력한 소재의 내용이 PC 또는 모바일에서 어떻게 보이는지를 확인합니다. 키워드 삽입 기능을 사용했다면 해당 부분에는 입력한 대체 키워드가 보입니다.

**주의하세요.** 실제 노출되는 광고는 노출매체, 기기 및 확장소재 설정 등에 따라 미리보기와 동일하지 않을 수도 있습니다.

7\. \[저장 후 닫기\] 버튼을 클릭합니다. 만약 \[저장 후 닫기\] 버튼을 클릭하였을 때 오류 메시지가 나타난다면, 다음에 안내되는 '소재 등록 시 유의 사항'을 참고하여 조치하세요.

**소재(문안) 등록 시 유의사항**

소재는 가이드 맞게 작성되어야 합니다. 등록하고자 하는 소재가 가이드에 맞지 않는 경우 소재 등록 후 검토단계에서 안내가 되기도 하지만, 아예 소재 등록 단계에서 '등록 불가' 혹은 '소명 필요'에 대한 안내 메시지가 노출되는 경우도 있습니다. 이 경우 안내 메시지에 따라 문제가 되는 부분을 수정하거나 소명 자료 등을 함께 등록해야 합니다.

-   **'등록 불가' 메시지가 노출되는 경우**
    
-   아래 4가지 유형에 해당되는 경우 '등록 불가' 안내 메시지가 나타납니다. 이 경우 해당 부분을 수정하여 다시 등록해야 합니다.
    
    -   과도하게 사용된 특수 문자 확인: 제목, 설명 문구에 \[~@#!$%^&\*()|\\:;?><=\] 등의 특수 문자가 과도하게 사용된 경우
        
    -   {키워드} 삽입 사용 횟수 확인: 제목 1회, 설명 2회를 초과하는 <키워드> 삽입이 있을 경우
        
    -   금칙어 사용 확인: 제목, 설명 문구에 사용이 불가능한 금칙어가 사용된 경우
        
    -   띄어쓰기 확인: 설명 문구에 띄어쓰기가 없는 경우
