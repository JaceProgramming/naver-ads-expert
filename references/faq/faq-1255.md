# 네이버 가격비교에 어떻게 입점하나요?

쇼핑검색광고 상품을 이용하기 위해 네이버 가격비교에 입점 및 상품등록이 되어야 합니다.

별도의 쇼핑몰 사이트가 있다면 ‘네이버 가격비교’에 바로 입점이 가능하며 홈페이지가 없더라도 ‘스마트스토어’ 판매자 가입 시 네이버 가격비교에 입점하여 쇼핑검색광고를 할 수 있습니다.

이 도움말에서는 네이버 가격비교 입점 방법에 대해 알아봅니다.

---

**CPC Package 입점하기**

CPC 유형으로 네이버 가격비교에 입점하는 경우, 아래와 같은 순서로 진행됩니다.

입점 후 상품을 등록하여 네이버 가격비교에도 노출 할 수 있지만, 만약 쇼핑검색광고만을 집행하기 위한 가입이라면 입점신청서 작성 시 별도의 선택을 통해 네이버가격비교에는 노출하지 않을 수 있습니다.

네이버 가격비교로는 입점할 수 있으며, 상세한 입점 요건은 아래 링크를 통해 확인할 수 있습니다.

\>> [CPC Package 입점 안내](https://join.shopping.naver.com/join/cpc/guide.nhn) 

입점부터 상품 등록까지의 절차는 아래와 같습니다.

![](https://saedu.naver.com/upfile/1475130069440.png)

1.  입점신청서 작성
    
2.  네이버 가격비교의 \[입점 신청서 작성하기 \]를 통해 네이버 가격비교 입점신청서를 작성합니다.
    
3.  회원가입의 단계이며 이용하고 있는 호스팅사의 \[입점신청\] 버튼을 클릭합니다.
    
4.  정보입력 시 입점을 위한 관련 서류가 모두 첨부되어야만 입점심사를 받을 수 있습니다.
    

1.  입점심사
    
2.  입점관련 서류가 모두 접수되어야 입점심사가 진행되며, 심사는 영업일 기준 1~2일 소요됩니다.
    
3.  심사 결과는 쇼핑파트너센터에 등록된 이메일 또는 쇼핑파트너센터 로그인 시 팝업으로 확인할 수 있습니다.
    
4.  현재 입점비는 받고 있지 않아 별도의 결제는 필요하지 않습니다.
    

1.  상품 DB URL 등록
    
2.  상품 DB URL
    
3.  상품 등록 및 네이버 가격비교 서비스를 위해서는 웹 프로그램 코딩작업으로 DB URL을 제작해야 합니다.
    
4.  네이버 쇼핑 파트너제휴사로 지정된 호스팅을 이용하고 있다면 DB URL 생성을 도움 받을 수 있습니다.
    
5.  완성된 DB URL을 네이버 쇼핑 쇼핑파트너센터에 등록하여 상품을 등록 할 수 있습니다.
    

1.  만약 제휴 파트너사를 이용하지 않는 경우 아래 도움말을 활용하여 직접 DB URL 을 제작할 수 있습니다.
    
2.  \>> [DB URL 작성요령 및 예제](https://join.shopping.naver.com/misc/download/ep_guide.nhn) 
    

1.  **참고.** 네이버 가격비교에서는 쇼핑 영역 노출을 위해 충전금을 결제해야합니다.
    
2.  만약 가격비교의 노출을 원하지 않는다면, 별도의 선택을 통해 결제를 진행하지 않습니다.
    

1.  상품등록
    
2.  상품 DB URL의 검수가 완료되면 쇼핑파트너센터에서 판매할 상품을 등록해야합니다.
    

1.  서비스 시작
    
2.  상품등록이 완료되면 해당 상품의 네이버 가격비교 노출이 시작됩니다.
    
3.  만약 네이버 가격비교의 노출을 원하지 않는다면 광고를 OFF 하길 바랍니다.
    

서비스 시작 가능상태라면 이제 쇼핑검색광고를 이용할 수 있습니다.

**스마트스토어 입점하기**

스마트스토어로 네이버 가격비교에 입점하는 경우, 스마트스토어센터 가입 시 네이버 가격비교 약관에 동의하여 동시에 입점이 가능합니다.

이미 스마트스토어 판매자로 가입된 경우, 이후 \[스마트스토어센터> 회원정보 조회/수정\] 페이지에서 하단의 '네이버 가격비교 입점 신청'을 클릭하여 신청 가능하며 네이버 가격비교 광고주로 이미 입점하신 경우 해당 내용은 보이지 않습니다

스마트스토어 입점에 대한 자세한 내용은 아래 '스마트스토어 안내' 페이지를 확인해 주세요.
