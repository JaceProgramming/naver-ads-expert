# 상품EP(=DB URL) 제작과 등록 방법이 궁금해요.

CPC 유형의 입점 심사 승인이 완료 되면 다음의 절차인 상품 EP(=DB URL)를 제작하여 등록해야 합니다.

EP(=DB URL)는 상품 정보를 요약한 파일로 상품명/가격/배송비/제조사 등 판매하는 상품 정보를 네이버 가격비교와 약속된 형태로 구성하여 쇼핑파트너센터에 등록해야 하며 작성하신 상품 EP를 통해 상품 정보를 수집/처리하여 광고에 노출됩니다.

---

**EP(=DB URL) 제작**

이용하시는 쇼핑파트너사(호스팅업체)나 사이트 관리자에게 EP(=DB URL) 작업을 의뢰하여 주시고 완료되면 쇼핑파트너센터에 (DB URL 관리 페이지 확인 후 수정) 등록해주시면 됩니다.

DB URL 등록과 관련한 보다 자세한 내용은 아래 가이드를 참조하세요.

[DB URL 작성요령 및 예제](https://join.shopping.naver.com/misc/download/ep_guide.nhn)

---

**DB URL 등록 방법**

DB URL은 \[쇼핑파트너센터 > 상품관리 > 상품정보 수신현황 > 쇼핑몰 상품DB URL > 관리\] 페이지에서 '등록요청' 버튼을 클릭 하여 입력할 수 있습니다.

![](https://saedu.naver.com/upfile/1709618236415.png)

상품 DB URL 검수는 1~2 영업일이 소요되며 검수가 완료 되면 \[쇼핑파트너센터 > 상품관리 > 상품현황 및 관리 > 미서비스 상품\]에서 대분류 검색 후 쇼핑몰의 전체 상품 리스트가 보여지게 됩니다.

만일 EP가 거부가 되면 \[쇼핑파트너센터 > 상품관리 > 상품정보 수신현황 > 쇼핑몰 상품DB URL > 관리\]에서 '재요청' 버튼 클릭 후 비고란에서 거부 사유를 확인할 수 있습니다. EP가 거부 시 사유를 확인하여 수정해주시기 바랍니다.
