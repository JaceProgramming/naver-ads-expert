# [AI작성] 디스플레이광고 소재 상세 화면에서는 무엇을 확인하나요?

**적용 대상:** 디스플레이광고(웹사이트 전환·앱 전환·인지도 및 트래픽·동영상 조회·카탈로그 판매·쇼핑 프로모션·참여 유도)

디스플레이광고 소재 상세 화면에서는 소재의 성과와 정보를 확인하고, 소재를 수정하거나 미리볼 수 있습니다. 광고그룹 상세 화면에서 소재 이름을 클릭하면 이동합니다.

**화면 구성**

| **영역** | **설명** |
| --- | --- |
| 소재 성과 | 선택한 기간의 소재 단위 성과 추이 그래프입니다. |
| 소재 정보 | 화면 우측에 고정되어 소재 정보와 ON/OFF, \[수정\], \[기기에서 미리보기\]를 제공합니다. |
| 광고 소재 보고서 | 화면 하단에 소재 단위 성과 지표가 표시됩니다. |

**소재 정보 항목**

| **항목** | **설명** |
| --- | --- |
| 광고 소재 이름 | 소재의 이름입니다. |
| 소재 타입 | 소재의 유형입니다(예: '네이티브 이미지', '컬렉션', '네이티브 동영상', '카탈로그', '이미지 배너'). |
| 소재 상태 | '승인', '검토중', '반려', '삭제' 등 검토·운영 상태입니다. 반려된 경우 사유가 함께 안내됩니다. |
| 노출 가능 게재 위치 | 소재가 노출될 수 있는 게재 위치입니다. |

**광고 소재 보고서 지표**

광고 소재 보고서에는 다음 지표가 표시됩니다.

-   결과 / 결과당 비용
    
-   평균 CPM / 클릭수 / 평균 CPC
    
-   클릭률(%) / 총 전환수 / 총 전환매출액
    

**참고.**

데이터가 없는 지표는 '-' 또는 '₩ 0'으로 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
