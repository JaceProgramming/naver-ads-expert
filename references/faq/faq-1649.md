# [AI작성] 전환 추적 서비스를 신청하려면 어떻게 하나요?

전환 추적 서비스는 광고계정 단위로 신청하며, 신청하면 'NaPm='으로 시작하는 전환 추적용 URL 파라미터가 연결 URL 뒤에 자동으로 붙어 전환이 측정됩니다. \[광고주센터 > 검색광고 > 도구 > 전환 추적 관리\]에서 \[전환 추적 신청\]을 클릭하면 '전환 추적 서비스 신청' 창이 열립니다. 신청은 약관 확인과 정보 입력 2단계로 진행됩니다.

**1단계. 약관 확인**

1.  'NaPm=' 파라미터 안내를 확인합니다. 신청하면 연결 URL 뒤에 'NaPm='으로 시작하는 파라미터가 붙습니다. (예: http://www.example.com → http://www.example.com/?NaPm=...)
    
2.  신청 후 광고를 통한 사이트 접속이 정상적으로 이루어지는지 확인해야 하며, '위 내용을 모두 읽고 확인했습니다.'에 체크합니다. 체크해야 \[다음\]이 활성화됩니다.
    
3.  \[다음\]을 클릭합니다.
    

**2단계. 정보 입력 및 신청**

1.  '신청사이트'에서 전환을 추적할 웹사이트를 선택합니다.
    
2.  '기술 담당자' 정보(담당자명·이메일 주소·휴대폰)를 입력합니다.
    
3.  '설치 구분'을 선택합니다. (대행 / 자가)
    
4.  '사이트 유형'을 선택합니다. (일반웹사이트 / 임대형 쇼핑몰 / 카페24 / 분류불가)
    
5.  '개인정보 수집 및 이용 동의'에 체크한 뒤 \[확인\]을 클릭해 신청을 완료합니다.
    

**알아두세요.**

신청 완료 후 1~3일 이내(최대 7일)에 입력한 기술 담당자 메일로 '설치안내메일'이 발송되니 반드시 확인해 주세요. 대행 설치는 설치안내메일에 사이트 접속 정보를 추가 입력해야 하며 신청 후 1~7일 내 설치가 완료됩니다. 자가 설치는 설치안내메일의 매뉴얼을 참고해 직접 설치합니다.

**참고.**

입력한 담당자 정보(이름·메일주소·휴대폰번호)는 전환 추적 서비스 제공을 위해 수집되며, 미입력 시 서비스 제공이 어려울 수 있습니다. 전환 추적은 무료로 제공되며, 사용하면 광고를 통해 발생한 전환수와 전환 매출액 등이 광고 보고서에 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
