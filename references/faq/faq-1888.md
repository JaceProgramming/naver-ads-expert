# [AI작성] 디스플레이광고 광고그룹 상세 화면은 어떻게 구성되어 있나요?

**적용 대상:** 디스플레이광고(웹사이트 전환·앱 전환·인지도 및 트래픽·동영상 조회·카탈로그 판매·쇼핑 프로모션·참여 유도)

디스플레이광고 광고그룹 상세 화면에서는 광고그룹의 성과와 설정 정보를 확인하고, 해당 광고그룹에 속한 소재를 관리할 수 있습니다. 캠페인 상세 화면에서 광고그룹 이름을 클릭하면 이동합니다.

**화면 구성**

| **영역** | **설명** |
| --- | --- |
| 광고그룹 성과 | 선택한 기간의 성과 추이 그래프입니다. '총비용', '노출수' 등 지표를 선택해 볼 수 있습니다. |
| 광고그룹 정보 | 화면 우측에 고정되어 광고그룹의 정보와 ON/OFF, \[수정\] 진입을 제공합니다. |
| 소재 목록 | 화면 하단에 해당 광고그룹의 소재 목록이 표시되며, 소재를 추가·관리할 수 있습니다. |

**광고그룹 정보 항목**

광고그룹 정보 영역에는 다음 항목이 표시됩니다.

| **항목** | **설명** |
| --- | --- |
| 광고그룹 이름 | 광고그룹의 이름입니다. |
| 기간 | 광고그룹의 게재 기간입니다. |
| 게재 위치 | 광고가 노출되는 게재 위치입니다. |
| 타게팅 유형 | '오디언스', 'ADVoost 오디언스', '콘텍스트' 등 적용된 타게팅 유형입니다. |
| 입찰 | 입찰 목표와 입찰 전략입니다(예: '전환 수 최대화', '입찰가 한도 없음'). |
| 예산 | 하루 예산 또는 총 예산입니다. |

**참고.**

'ADVoost 쇼핑' 캠페인은 광고그룹 대신 애셋그룹 구조로 운영되며, 애셋그룹 정보와 미리보기가 제공됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
