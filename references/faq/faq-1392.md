# ‘빠르게 광고 시작하기’와 ‘목적 선택하고 시작하기’는 무엇이 다른가요?

**\[빠르게 광고 시작하기\]**

광고를 빠르게 시작하고 싶은 경우 추천됩니다.

광고 유형을 바로 선택해 빠른 등록이 가능한 방식입니다.캠페인을 선택하고 다음 버튼을 클릭하면 간편모드의 광고 등록을 이용하실 수 있습니다 .

**\[목적 선택하고 시작하기\]**

어떤 광고를 해야 할지 고민되는 경우 적합합니다.

-   광고를 통해 이루고 싶은 목적 기준으로 캠페인을 선택합니다.
    
-   선택한 목적에 매핑된 광고 정보(캠페인) 리스트가 노출됩니다.
    
-   목적 → 캠페인 선택 → \[다음\] 클릭 시
    
-   → 해당 캠페인의 등록 화면으로 이동합니다.
