# [AI작성] 파워컨텐츠 캠페인 목록 화면은 어떻게 구성되어 있나요?

파워컨텐츠 캠페인 목록 화면은 블로그·포스트 형태의 콘텐츠를 활용하는 파워컨텐츠 캠페인을 모아 보고 관리하는 화면입니다. 캠페인별 노출 상태와 성과 지표를 한눈에 확인하고, 새 캠페인을 만들거나 캠페인 상세로 이동할 수 있습니다.

**진입 경로**

\[광고주센터 > 검색광고 > 광고 관리 > 파워컨텐츠\]를 선택하면 파워컨텐츠 캠페인 목록 화면이 열립니다.

**화면 구성**

| **영역** | **설명** |
| --- | --- |
| 헤더 영역 | 화면 제목 '파워컨텐츠'과 조회 기간 영역(달력·이전/다음 기간 이동)이 표시됩니다. |
| 액션 영역 | \[새 캠페인\], \[선택한 캠페인 관리\], \[열 맞춤 설정\], \[상세 데이터\], \[전체 다운로드\]가 제공됩니다. |
| 필터 영역 | '필터를 입력해 주세요' 입력란으로 목록을 좁힐 수 있습니다. |
| 캠페인 테이블 | 등록된 파워컨텐츠 캠페인의 성과 데이터를 표로 표시합니다. |

**기본 컬럼**

| **컬럼** | **설명** |
| --- | --- |
| ON/OFF | 캠페인의 광고 노출 상태를 켜거나 끕니다. |
| 캠페인 이름 | 캠페인 이름이 표시되며 클릭하면 캠페인 상세로 이동합니다. |
| 상태 | 캠페인의 현재 운영 상태를 표시합니다. (예: '운영가능', '중지: 캠페인 OFF', '광고 집행 종료' 등) |
| 노출수 | 조회 기간 내 광고 노출 횟수입니다. |
| 클릭수 | 조회 기간 내 광고 클릭 횟수입니다. |
| 클릭률(%) | 노출 대비 클릭 비율입니다. |
| 평균 CPC | 클릭 1회당 평균 비용입니다. |
| 총비용 | 조회 기간 내 총 광고 비용입니다. |
| 하루 예산 | 캠페인에 설정된 하루 예산이 표시됩니다. |

**참고.**

\[열 맞춤 설정\]에서 표시할 추가 컬럼을 선택할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
