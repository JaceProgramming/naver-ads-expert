# [AI작성] 쇼핑 검색광고 노출 진단과 현황을 조회하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 도구 > 광고 노출 진단\]에서 캠페인 유형을 '쇼핑검색 (노출현황진단)' 또는 '쇼핑검색 (노출현황보기)'로 선택하면 키워드 단위로 쇼핑 검색광고의 노출 진단 결과와 노출 현황을 확인할 수 있습니다.

**조회 절차**

1.  '캠페인 유형 선택'을 '쇼핑검색 (노출현황진단)' 또는 '쇼핑검색 (노출현황보기)'로 선택합니다.
    
2.  검색 입력란에 조회할 키워드를 입력합니다.
    
3.  필요 시 성별·연령대 조건을 선택해 해당 타겟 기준으로 결과를 확인합니다.
    
4.  조회를 실행하면 노출 진단 결과와 노출 현황이 표시됩니다.
    

**타겟 조건**

| **조건** | **선택 값** |
| --- | --- |
| 성별 | 남 / 여 / 알 수 없음 |
| 연령대 | 14~18 / 19~24 / 25~29 / 30~34 / 35~39 / 40~44 / 45~49 / 50~54 / 55~59 / 60대 이상 / 알 수 없음 |

성별·연령대는 검색 이용자가 등록한 정보와 AI 기술로 판단된 정보로, 실제와 다를 수 있으며 판단이 어려운 이용자는 '알 수 없음'으로 표시됩니다.

**알아두세요.**

노출 현황 진단은 키워드 상태가 '노출 가능'인 경우에만 확인할 수 있습니다. 노출 현황 보기는 광고주가 등록한 키워드에 한해 확인할 수 있습니다. '알 수 없음' 이용자를 노출하지 않도록 설정한 소재는 조회되지 않을 수 있으니 조건별로 조회해 보시기 바랍니다.

**참고.**

쇼핑 브랜드형 광고의 노출 현황은 '쇼핑브랜드 (노출현황보기)'를 선택해 확인합니다. 검색한 키워드는 최근 검색어 목록에 저장됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
