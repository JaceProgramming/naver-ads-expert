# [AI작성] 광고 정보를 즐겨찾기에 추가하거나 해제하려면 어떻게 하나요?

광고그룹·소재·키워드·확장 소재 목록 화면의 \[선택한 OOO관리\] 에서 즐겨찾기를 클릭하면 추가할 수 있습니다.

**추가/해제 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리\]에서 광고그룹·소재·키워드·확장 소재 목록 화면으로 이동합니다.
    
2.  목록 표에서 추가할 대상을 선택한 뒤 \[선택한 OOO관리\] 클릭합니다.
    
3.  즐겨찾기 그룹을 선택하고 \[적용\]을 클릭합니다.
    
4.  즐겨찾기에 추가된 광고 정보는 \[광고 관리 > 즐겨찾기\] 화면의 해당 탭(광고그룹 / 소재 / 키워드 / 확장 소재)에서 한 곳에서 조회할 수 있습니다.
    

**알아두세요.**

즐겨찾기 그룹별로 광고 정보를 묶어 관리할 수 있으며, 등록된 광고 정보의 수가 각 탭 옆에 표시됩니다(예: 광고그룹 (9) / 소재 (6) / 키워드 (5) / 확장 소재 (3)).

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
