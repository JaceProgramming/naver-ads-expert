# [AI작성] 브랜드검색/신제품검색 계약을 확인하고 관리하려면 어떻게 하나요?

\[도구 > 브랜드/신제품검색 계약 관리\]에서 계약 목록 표에 표시되는 계약을 확인하고 \[관리\] 컬럼을 통해 계약을 관리합니다. 캠페인 상세의 \[계약 관리\] 버튼으로도 진입할 수 있습니다.

**확인·관리 절차**

1.  \[도구 > 브랜드/신제품검색 계약 관리\]에 진입합니다.
    
2.  \[브랜드 검색형\] 또는 \[신제품 검색형\] 탭을 선택합니다.
    
3.  계약 목록 표에서 계약을 확인합니다.
    

-   브랜드 검색형 컬럼: 계약 상태 / 관리 / 계약 이름 / 등록 일시 / 현재 연결 광고 그룹 / 계약 가능 검색수 / 키워드 검색수 / 계약 기간 / 계약 광고비 / 환급액 / 노출수 / 클릭수 / 클릭률(%)
    
-   신제품 검색형 컬럼: 계약 상태 / 계약 이름 / 관리 / 등록 일시 / 집행 회차 / 낙찰 발표일 / 현재 연결 광고 그룹 / 키워드 그룹 이름 / 계약 기간 / 입찰가 / 낙찰가 / 계약 광고비 / 환급액 / 노출수 / 클릭수 / 클릭률(%)
    

1.  각 행의 '관리' 컬럼에서 계약 수정·취소·결제 등 작업을 수행합니다.
    
2.  필요 시 표 상단의 \[다운로드\]로 계약 목록을 내려받을 수 있습니다.
    

**알아두세요.**

계약 종료 후 5년이 지난 계약은 자동 삭제됩니다. 필요 시 \[다운로드\] 기능을 이용해 미리 계약 정보를 보관해 두시기 바랍니다.

**알아두세요.**

계약 정보가 없는 광고그룹은 \[계약 관리\] 버튼이 비활성화됩니다. 이 경우 먼저 \[계약하기\]로 노출 계약을 신청해 주세요.

**참고.**

통과된 키워드와 소재가 있어야 계약이 가능하며 검토에는 영업일 기준 1~2일이 소요됩니다.

신제품검색형은 입찰 가능한 회차가 배정되어 있어야 계약을 관리할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
