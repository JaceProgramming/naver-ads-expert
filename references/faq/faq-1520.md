# [AI작성] 파워링크 광고그룹 목록 화면 안내

파워링크 캠페인 상세 화면의 '광고그룹' 탭에서 해당 캠페인에 등록된 광고그룹 목록을 조회하고 관리할 수 있습니다.

**진입 경로**

\[광고주센터 > 검색광고 > 광고 관리 > 파워링크\] 캠페인 목록에서 캠페인 이름을 클릭한 후, '광고그룹' 탭을 선택합니다. '광고그룹' 탭은 기본으로 활성화되어 있습니다.

**광고그룹 테이블 컬럼**

| **컬럼명** | **설명** |
| --- | --- |
| ON/OFF | 광고그룹의 노출 상태를 켜거나 끌 수 있습니다. |
| 광고그룹 이름 | 광고그룹 이름이 표시되며, 클릭하면 광고그룹 상세 페이지로 이동합니다. |
| 상태 | 광고그룹의 현재 운영 상태가 표시됩니다. |
| 기본 입찰가 | 광고그룹에 설정된 기본 입찰가가 표시되며, 클릭하여 바로 수정할 수 있습니다. |
| 채널 정보 | 연결된 비즈채널 URL 또는 표시명이 표시됩니다. 비즈채널이 연결되지 않은 경우 '-'로 표시됩니다. |
| 노출수 | 조회 기간 내 광고 노출 횟수입니다. |
| 클릭수 | 조회 기간 내 광고 클릭 횟수입니다. |
| 클릭률(%) | 노출 대비 클릭 비율입니다. |
| 평균 CPC | 클릭 1회당 평균 비용입니다. |
| 총비용 | 조회 기간 내 총 광고 비용입니다. |

**주요 기능**

-   **\[새 광고그룹\]**: 새 파워링크 광고그룹을 생성합니다.
    
-   **\[선택한 광고그룹 관리\]**: 광고그룹을 1건 이상 선택하면 활성화됩니다. 상태 변경, 복사, 삭제, 비즈채널 재검토 요청, 확장 검색 옵션 변경 등을 수행할 수 있습니다.
    
-   **\[다운로드\]**: 광고그룹 목록 데이터를 파일로 내려받을 수 있습니다.
    
-   **\[열 맞춤 설정\]**: 기본 컬럼 외에 추가 컬럼을 표시하거나 숨길 수 있습니다. 현재 추가로 표시 중인 컬럼 수가 '상태 외' 라벨과 함께 표시됩니다.
    
-   **\[상세 데이터\]**: PC/모바일, 요일, 시간대 등 다양한 기준으로 성과 데이터를 분리하여 조회할 수 있습니다.
    
-   **통합 필터**: '필터를 입력해 주세요' 입력 영역에 조건을 입력하여 목록을 필터링할 수 있습니다.
    

**광고그룹 상태 라벨**

| **상태 라벨** | **설명** |
| --- | --- |
| '운영가능' | 정상 운영 중인 상태입니다. |
| '중지: 비즈채널 노출 제한' | 비즈채널 노출이 제한되어 광고가 중지된 상태입니다. 클릭하면 비즈채널 확인 안내가 표시됩니다. |
| '중지: 캠페인 OFF' | 상위 캠페인이 OFF 상태여서 광고그룹이 중지된 상태입니다. |
| '검토중' | 검수가 진행 중인 상태입니다. |
| '노출 제한' | 특정 사유로 광고 노출이 제한된 상태입니다. |

**알아두세요.**

-   등록된 광고그룹이 없으면 빈 상태 안내가 표시됩니다.
    
-   광고그룹 등록 한도를 초과한 경우 '광고그룹 등록 한도를 초과했습니다' 안내가 표시됩니다. 기존 광고그룹을 정리한 후 다시 시도해 주세요.
    
-   운영 중인 광고그룹을 일괄 삭제하려고 하면 '운영 중인 광고그룹은 삭제할 수 없습니다. ON 해제 후 삭제해 주세요' 안내가 표시됩니다.
    

**참고.**

테이블 하단에 전체 광고그룹 수와 각 지표의 합계가 표시됩니다. 광고그룹 이름을 클릭하면 해당 광고그룹의 상세 페이지로 이동하여 키워드, 소재, 확장 소재 등을 관리할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
