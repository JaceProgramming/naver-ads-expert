# 광고용 웹수집 검색로봇 'Ads-Naver'가 뭔가요?

네이버 검색광고에서는 광고주님의 사이트 품질을 측정하고, 최종 연결 페이지의 내용과 연관성이 높은 사용자 검색어에 광고를 효과적으로 노출하기 위해 '**Ads-Naver'** 라는 User-Agent 이름을 사용하는 광고용 웹수집 검색로봇을 운영하고 있습니다.

개별 광고그룹 내 키워드나 소재에 등록하신 **최종 연결 URL**을 대상으로,

광고용 검색로봇이 주기적으로 방문하여 효과적인 광고 노출을 위한 웹페이지 내 기본 노출된 콘텐츠들을 수집합니다.

광고용 검색로봇이 수집하는 과정은 다음과 같습니다.

-   수집 : 네이버 광고 검색로봇이 등록한 연결URL의 웹페이지를 방문해 HTML, 콘텐츠, 메타 정보 등을 읽어옵니다
    
-   색인 : 수집 단계에서 읽어온 정보들을 기반으로 웹페이지 내용을 분석합니다.
    
-   광고 노출 : 색인까지 완료된 웹페이지 중 검색어와의 연관성 및 품질, 경쟁 환경 등을 고려하여 순위에 따라 광고를 노출합니다.
    

단, 광고 그룹내 모든 키워드에 연결 URL이 등록되어 있고 해당 URL이 광고 소재에 등록된 URL과 다르다면, 이 때 광고 소재에 등록된 연결 URL은 수집대상에서 제외 됩니다.

네이버광고주센터에 등록된 광고 대상 URL의 경우, 등록만으로도 정상적인 광고 매칭 및 순위화를 위해 대상 웹페이지 내용 수집을 허용하는 것으로 간주하여 robots.txt 내의 규칙을 내의 규칙을 참조하지 않습니다.

즉, 네이버 광고용 검색로봇은 아래와 같이 모든 검색로봇에게 수집을 허용하지 않는 robots.txt규칙이 지정된 경우에도 해당 웹페이지의 공개된 컨텐츠를 수집합니다.

| User-agent: \*<br>Disallow: / |
| --- |

광고용 웹수집 검색로봇 Ads-Naver는 아래와 같은 방법으로 확인할 수 있습니다.

**User-Agent 이름으로 확인**

광고용 웹수집 검색로봇 Ads-Naver는 아래와 같은 User-Agent 이름을 사용합니다. 세부 버전 등은 사전 예고 없이 변경될 수 있습니다.

문서 수집과 리소스 수집 모두 동일한 User-Agent 를 사용하게 됩니다.

| Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko; compatible; Ads-Naver/1.1; +https://naver.me/adsn) Chrome/130.0.0.0 Safari/537.36 |
| --- |

User-Agent 정보만으로 네이버 서버로부터의 접근인지 확신할 수 없다면, IP 정보로 확인할 수 있습니다.

상세 내용은 링크된 도움말을 참고해주세요.

**Q. 웹수집 검색로봇이란 무엇인가요?**

웹수집 검색로봇은 검색광고 대상이 되는 웹페이지를 자동으로 방문하여, 해당 웹페이지의 콘텐츠를 수집하는 소프트웨어로서 자기 자신만의 이름을 [User-Agent](https://www.w3.org/WAI/UA/work/wiki/Definition_of_User_Agent)에 명시합니다.

**Q. robots.txt 규칙이란?**

robots.txt는 검색로봇에게 사이트 및 웹페이지를 수집할 수 있도록 허용하거나 제한하는 [국제 권고안](http://www.robotstxt.org/robotstxt.html)입니다. robots.txt 파일은 항상 사이트의 루트 디렉터리에 위치하며, [로봇 배제 표준](https://ko.wikipedia.org/wiki/%EB%A1%9C%EB%B4%87_%EB%B0%B0%EC%A0%9C_%ED%91%9C%EC%A4%80)을 따르는 일반 텍스트 파일로 작성합니다.

**Q. 광고용 검색로봇이 robots.txt 규칙을 참조하지 않는다는 게 어떤 의미인가요?**

광고주님이 등록한 연결 웹페이지가 속한 사이트 루트 디렉토리에 올려진 robots.txt 파일에 위와 같이 모든 User Agent에 대해 수집을 불허(Disallow)하도록 설정하더라도, 네이버광고주센터에 연결 페이지로 등록이 되어있으면 광고로서 효과적으로 매칭되고 랭킹되서 나갈 수 있도록 robots.txt 기재해주신 룰과 별개로 수집이 진행된다고 보시면 됩니다.

**Q. 광고용 검색로봇은 얼마나 자주 내 사이트 웹문서를 수집하는 건가요?**

검색로봇이 광고 대상 연결 페이지를 자동으로 방문하면서 수집함으로, 정확히 정해진 주기가 있지는 않습니다.

연결 페이지와 관련된 다양한 특징을 파악해서 자동으로 방문합니다.

광고주님의 서버에 Ads-Naver User-Agent(UA)로 접근한 로그 기록 등을 통해서 확인할 수 있습니다.

**Q. 광고용 검색로봇의 웹수집을 중지하게 하려면 어떻게 해요?**

광고용 웹수집은 네이버광고주센터에 소재나 키워드에 등록한 게재 대상 연결 페이지의 품질 상태를 자동적으로 점검하고 적절한 사용자 검색어에 보다 잘 매칭해서 노출하기 위해 꼭 필요한 작업입니다.

다만, 일부 웹수집을 원하지 않는 광고주의 경우 광고 고객센터를 통해서 수집하지 않았으면 하는 URL을 함께 제출하시면 영업일 기준 1~2일 내로 수집 중지 처리가 가능합니다.
