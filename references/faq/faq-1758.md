# [AI작성] 즐겨찾기에서 계정을 해제하거나 바로가려면 어떻게 하나요?

계정 설정의 즐겨찾기 화면에서 등록된 계정을 해제하거나 해당 계정으로 바로 이동할 수 있습니다.

**즐겨찾기 해제**

1.  해제할 계정 행의 별 표시를 선택하면 "즐겨찾기 삭제하시겠습니까?" 확인 화면이 표시됩니다.
    
2.  "즐겨찾기 삭제 시 즐겨찾기 한 계정 목록에 더 이상 표시되지 않습니다. 계정 관리 메뉴에서 다시 즐겨찾기 등록이 가능합니다." 확인 후 해제됩니다.
    

**바로가기**

각 행의 \[바로가기\]를 클릭하면 해당 계정으로 이동합니다.

**참고.**

즐겨찾기 해제에 실패하면 "즐겨찾기 삭제에 실패했습니다." 안내가 표시되니 다시 시도해 주세요.

**주의하세요.**

해당 계정에 대한 권한이 삭제된 경우 \[바로가기\] 시 "즐겨찾기한 계정으로 이동할 수 없습니다." 안내가 표시됩니다. 안내 내용은 "해당 계정에 대한 권한이 삭제되어 즐겨찾기로 이동할 수 없습니다. 즐겨찾기한 계정을 삭제하시고 계정 권한 확인 후 다시 등록해주세요."입니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
