# 파워링크 제외검색어는 무엇인가요?

노출을 원하지 않는 일치 이외 검색어는 제외 검색어로 추가하여 미노출 할 수 있습니다.

아래와 같이 '확장 검색'과 '일치(유사검색어)' 영역 간 관리 방식은 상이하지만 제외 검색어 적용은 통합 적용됩니다.

\[제외 검색어 > + 제외 검색어 추가\] 메뉴를 통해 ‘확장 검색’ 또는 ‘일치(유사검색어)’에서 제외하고 싶은 검색어를 추가할 수 있습니다.

제외 검색어는 검색어를 직접 입력하거나, 하단 검색어 보고서 좌측의 ‘+추가’ 버튼을 통해 제외 검색어 추가할 수 있습니다.

• '확장 검색' 최대 950개, '일치(유사 검색어)' 최대 50개 등록 가능

1) ‘확장 검색’ 제외 검색어 등록 방법

• 제외 검색어 추가 화면에서 **좌측 입력창 '확장 검색'**에 검색어 직접 입력

• 검색어 보고서에서 검색 유형이 **'확장'**이고, 매체이름이 **'네이버 통합검색 - 모바일'** 혹은 '**네이버 통합검색 - PC'**인 검색어의 '+추가' 버튼 클릭

2) ‘일치(유사검색어)’ 제외 검색어 등록 방법

• 제외 검색어 추가 화면에서 **우측 입력창 ‘일치(유사검색어)’**에 검색어 직접 입력

• 검색어 보고서에서 검색 유형이 **‘일치(유사검색어)’**인 검색어의 '+추가' 버튼 클릭
