# [AI작성] 내 정보를 확인하거나 변경하려면 어떻게 하나요?

내 정보는 본인 인증을 거친 후 확인하거나 변경할 수 있습니다. 보안을 위해 평소에는 마스킹 상태로 표시됩니다.

**정보 확인하기**

1.  \[내 정보 관리 > 내 정보\]에서 \[내 정보 확인\]을 클릭합니다.
    
2.  '회원 정보 인증' 화면에서 이메일 또는 휴대전화로 발송된 인증 코드를 입력하고 인증합니다.
    
3.  인증이 완료되면 마스킹이 해제되어 원본 정보가 표시됩니다.
    

**정보 변경하기**

1.  \[내 정보 변경\]을 클릭하고 '회원 정보 인증'을 완료하면 변경 모드로 전환됩니다.
    
2.  변경할 항목 옆 \[변경\]을 클릭하면 항목별 인증 화면이 열립니다. 항목에 따라 '이메일 인증', '휴대전화번호 인증', '미리보기용 ID 인증' 화면이 표시됩니다.
    
3.  새 값을 입력하고 인증한 뒤 저장합니다. 이메일은 도메인을 함께 선택할 수 있고, 휴대전화는 국가번호가 함께 표시됩니다.
    

**참고.**

인증 코드가 만료되거나 일치하지 않으면 인증을 다시 요청한 뒤 시도해 주세요.

**주의하세요.**

이미 사용 중인 이메일이나 휴대전화번호로는 변경할 수 없으며, 형식이 올바르지 않으면 입력란에 안내가 표시됩니다. 다른 값으로 다시 시도해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
