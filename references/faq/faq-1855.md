# [AI작성] 디스플레이광고 소재 이름을 입력하고 미리보기로 확인하려면 어떻게 하나요?

**적용 대상:** 웹사이트 전환 · 앱 전환 · 인지도 및 트래픽 · 동영상 조회 · 카탈로그 판매 · 쇼핑 프로모션 · 참여 유도 (ADVoost 쇼핑은 애셋그룹 별도 운영)

소재 유형과 콘텐츠를 입력한 뒤 소재를 식별하는 이름을 입력하고, 화면 우측의 미리보기로 노출 형상을 확인합니다.

**소재 이름 입력**

1.  '소재 이름' 영역에 소재를 구분할 수 있는 이름을 입력합니다. 입력란에 글자 수가 함께 표시됩니다.
    
2.  이름을 비워 두면 저장 시 해당 입력란으로 이동하므로, 이름을 입력한 뒤 진행합니다.
    

**미리보기 확인**

| **요소** | **설명** |
| --- | --- |
| 플랫폼 | 기본적으로 모바일(Mobile) 환경 기준으로 미리보기가 표시됩니다. |
| 이미지 넘기기 | 이미지가 여러 장인 경우 '1/4'와 같이 순서가 표시되며 넘겨 가며 확인할 수 있습니다. |
| 게재 위치 | 미리보기에는 예시 게재 위치가 함께 표시됩니다. |

**참고.**

사용자의 디바이스 환경 및 노출 지면에 따라 실제 노출 결과는 다를 수 있습니다. 소재 등록 후 광고 소재 화면의 '기기에서 미리보기'를 통해 실제 단말기에서 노출 형상과 랜딩 URL의 정상 동작 여부를 확인해 주시기 바랍니다. 일부 지면은 미리보기가 지원되지 않습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
