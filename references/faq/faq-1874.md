# [AI작성] 카탈로그 판매에서 선택할 수 있는 소재 유형은 무엇인가요?

카탈로그 판매 소재를 만들 때 '소재 유형 선택' 단계에서는 카탈로그 판매에서 사용 가능한 소재 유형만 표시됩니다. 카탈로그 판매에서 제공되는 소재 유형은 다음과 같습니다.

**가용 소재 유형**

| **소재 유형** | **설명** |
| --- | --- |
| 카탈로그 | 캠페인에 연동한 카탈로그(제품 피드)의 제품 데이터를 기반으로 하는 소재입니다. 광고주님이 개별 이미지를 직접 만드는 대신, 카탈로그의 제품 정보를 활용해 소재를 구성합니다. |

소재 유형을 선택하면 이후 미디어 입력 영역이 해당 유형에 맞게 표시됩니다.

**알아두세요.**

선택 가능한 소재 유형은 광고그룹의 입찰·타게팅 설정과 캠페인 구성에 따라 결정됩니다. 사용할 수 있는 소재 유형이 표시되지 않을 경우, 앞 단계의 광고그룹 설정을 다시 확인해 주십시오. 캠페인을 수정하는 경우에는 기존에 사용 중인 소재 유형만 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
