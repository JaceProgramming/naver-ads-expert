# 광고 시작 전에는 무엇을 준비해야 하나요?

광고를 시작할 때, 꼭 챙겨야 하는 '광고 시작 전 준비사항'을 알려드립니다.

광고 유형별로 확인하시어, 쉽고 빠르게 광고를 시작해보세요~

| **광고 상품 유형** | **필수 준비 사항은?** |
| --- | --- |
| **파워링크** | **광고를 연결할 홈페이지**<br>• **홈페이지를 제작**하거나 **블로그, 카페, 스마트스토어 또는 일반 오픈마켓 페이지를 광고로 등록**할 수 있어요.<br>• 사이트 메인 페이지에는 **검색광고에 가입한 사업자 정보가 기재**되어 있어야 해요<br>• [\> 광고 운영기준 알아보기](https://ads.naver.com/adguide/28) |
| **쇼핑검색**<br>**\- 쇼핑몰 상품형** | **네이버 쇼핑에 입점된 쇼핑몰**<br>• **네이버 쇼핑에 입점신청**을 해주세요.<br>• 입점심사가 완료되어 네이버 쇼핑에 상품이 노출되는 쇼핑몰을 광고로 등록할 수 있어요.<br>• [\> 네이버 쇼핑 입점하기](https://join.shopping.naver.com/)<br>• 스마트스토어는 간편하게 네이버 쇼핑에 연동할 수 있습니다. |
| **쇼핑검색**<br>**\- 제품 카탈로그형** | **네이버 쇼핑에 등록된 카탈로그(가격비교 페이지)**<br>• 카탈로그는 **네이버 쇼핑에서 브랜드 패키지 가입하여 제작**할 수 있어요.<br>• 브랜드 권한이 있어야, 카탈로그 제작 및 수정이 가능합니다.<br>• [\> 브랜드 패키지 가입하기](https://center.shopping.naver.com/brand-info)<br>• 브랜드 패키지 가입, 카탈로그 요청은 [네이버 쇼핑 고객센터](https://talk.naver.com/ct/wc3n30)에서 상담 받으실 수 있습니다. |
| **쇼핑검색**<br>**\- 쇼핑 브랜드형** | **브랜드패키지에 가입된 브랜드사**<br>• **브랜드패키지**에 가입해 주세요..<br>• 브랜드패키지에 가입된 브랜드사가 브랜드스토어, 스마트스토어, 자사몰로 광고를 등록할 수 있어요.<br>• [\> 브랜드페키지 가입하기](https://center.shopping.naver.com/brand-info)<br>• 광고할 키워드(내 브랜드, 다른 브랜드, 일반)를 등록할 수 있습니다. |
| **파워컨텐츠** | **광고를 노출할 키워드 체크**<br>• 파워컨텐츠는 **광고 할 수 있는 키워드가 지정**되어 있어요.<br>• 키워드 목록을 다운받아 광고로 노출할 키워드를 확인해 주세요.<br>• [\> 파워컨텐츠 키워드 목록 다운로드](http://searchad.naver.com/File/downloadfilen/?type=10&filename=powercontents_keyword.xlsx)<br>• 파워컨텐츠는 **네이버 블로그, 카페, 포스트로만 광고**할 수 있습니다. |
| **브랜드검색** | **브랜드명/브랜드 관련 키워드**<br>• 브랜드검색은 **일반 명사가 아닌 '브랜드 관련 키워드'로 광고**를 할 수 있어요.<br>• 광고할 키워드를 준비해 주세요.<br>• 브랜드 검색은 텍스트, 이미지/동영상으로 구성되어 노출할 정보를 미리 준비하는 것도 좋습니다.<br>• 브랜드검색 제작 가이드<br>\- [PC 바로가기](https://ads.naver.com/adguide/1646)<br>\- [모바일 바로가기](https://ads.naver.com/adguide/1625) |
| **지역소상공인** | • 지역소상공인 노출 정보는 스마트플레이스에서 등록해야 합니다.<br>• [\> 스마트플레이스 소재 정보 설정 방법](https://ads.naver.com/help/faq/721) |
| **플레이스광고** | **스마트플레이스에 등록된 업체정보**<br>• 스마트플레이스에 업체정보를 등록해 주세요.<br>• 심사가 완료된 업체정보를 연동하여 광고로 등록할 수 있어요.<br>• [\>](https://join.shopping.naver.com/) [스마트플레이스 업체정보 등록하기](https://new.smartplace.naver.com/)<br>• 광고로 노출할 사진을 미리 준비하시는 것도 좋습니다. |
