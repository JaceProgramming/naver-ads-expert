# 쇼핑검색광고 광고그룹과 소재에 모두 입찰가를 설정한 경우 어떻게 반영이 되나요?

광고그룹과 소재(상품)에 모두 입찰가를 설정하신 경우 소재에 설정된 입찰가가 우선 적용됩니다.

단, 이때 광고그룹에 PC, 모바일 입찰가 가중치를 설정하신 경우 광고가 노출되는 매체에 따라 소재에 설정한 입찰가에 PC, 모바일 입찰가 가중치가 적용 되어 PC, 모바일 매체에 각각 입찰 됩니다.

| **예시.**<br>기본 입찰가를 300원으로 설정하고 PC가중치 - 100%, 모바일가중치 - 200%로 설정 한 경우.<br>• 소재 A : 소재 입찰가 업음<br>• \- PC 통합검색 : 300원 (기본입찰가 X PC가중치 100%)<br>• \- 모바일 통합검색 : 600원 (기본입찰가 X 모바일가중치 200%)<br>• 소재 B : 소재입찰가 200원<br>• \- PC 통합검색 : 200원 (기본입찰가 X PC가중치 100%)<br>• \- 모바일 통합검색 : 400원 (기본입찰가 X 모바일가중치 200%) |
