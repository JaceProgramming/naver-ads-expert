# 비즈니스 진단 결과는 어디에 활용할 수 있나요?

진단 결과 화면에서 \[**추천결과로 광고 만들기**\]를 클릭하면, 추천 캠페인 설정이 자동으로 반영되어 즉시 광고가 생성됩니다.

직접 캠페인 유형이나 예산을 입력하지 않아도, 진단 결과가 자동으로 적용된 상태에서 ‘빠르게 광고 시작하기’ 화면으로 이동합니다.

‘빠르게 광고 시작하기’ 기능에 대한 자세한 내용은 아래 도움말을 참고하시기 바랍니다.

-   [빠르게 광고 시작하기\_'플레이스광고'](https://ads.naver.com/help/faq/1482)
    
-   [빠르게 광고 시작하기 'ADVoost 쇼핑'](https://ads.naver.com/help/faq/1463)
    
-   [빠르게 광고 시작하기\_'파워링크'](https://ads.naver.com/help/faq/1462)
