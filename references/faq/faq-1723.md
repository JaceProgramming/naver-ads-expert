# [AI작성] 디스플레이광고 맞춤 타겟을 관리하려면 어떻게 하나요?

'맞춤 타겟' 탭에서는 검색 키워드를 기반으로 한 맞춤 타겟을 조회·등록·수정·삭제할 수 있습니다. \['도구' > '잠재고객 관리'\] 화면에서 '맞춤 타겟' 탭을 선택하면 진입합니다.

**등록 방법**

1.  패널 상단 우측의 \[맞춤 타겟 등록\]을 클릭합니다.
    
2.  이동한 등록 화면에서 검색 키워드 등 필요한 정보를 입력하고 저장합니다.
    

**목록 조회·관리**

등록된 검색 키워드 맞춤 타겟이 목록으로 표시됩니다.

| **컬럼** | **설명** |
| --- | --- |
| 타겟 이름 | 등록한 맞춤 타겟의 이름입니다. |
| 타겟 모수 | 최근 30일 내에 광고를 본 식별자 일부를 샘플링한 추정 모수입니다.타겟 등록 후 24시간 이내에 모수가 표시됩니다. |
| 상태 | 각 타겟의 처리 상태가 배지로 표시됩니다. |
| 생성일 | 타겟을 등록한 일자입니다. |

각 행의 수정으로 내용을 변경하거나, 삭제로 확인 후 제거할 수 있습니다.

**참고.**

등록된 항목이 없으면 빈 목록 안내가 표시됩니다.

**주의하세요.**

수정 또는 삭제에 실패하면 에러 안내가 표시됩니다. 잠시 후 다시 시도해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
