# [AI작성] 디스플레이광고 변경 이력의 상세 변경 내용을 확인하려면 어떻게 하나요?

변경 이력 목록에서 행에서 '상세 보기'를 선택하면 해당 변경 건의 항목별 변경 전·후 값을 비교하는 상세 화면이 열립니다.

**표시 정보**

상세 화면은 세 부분으로 구성됩니다.

-   **메타 정보** — 대상 광고정보, 변경 일시
    
-   **변경 내용 비교** — 변경된 필드만 '변경 항목 /변경 전 / 변경 후' 형태로 나란히 표시합니다.
    

**참고.**

변경된 필드가 없으면 '상세 보기' 표시가 없습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
