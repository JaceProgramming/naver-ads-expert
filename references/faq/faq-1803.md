# [AI작성] 관리 계정의 계정 책임자를 다른 회원에게 이전하려면 어떻게 하나요?

계정 책임자 이전은 관리 계정의 계정 책임자 권한을 다른 회원에게 넘기는 절차입니다. 현재 계정 책임자만 진행할 수 있습니다.

**이전 절차**

1.  설정 > 권한 관리에서 \[계정 책임자 이전하기\]를 선택합니다.
    
2.  대상 목록에서 이전할 회원 한 명을 선택합니다.
    
3.  \[이전 요청\]을 선택하면 대상 회원에게 승인 요청이 전달됩니다.
    
4.  선택한 회원이 권한 이전을 승인하면 계정 책임자가 변경됩니다.
    

**참고.**

안내 문구는 '계정 책임자로 이전할 회원을 선택하세요. 계정 책임자는 본 계정의 '운영관리' 권한 회원에게만 이전할 수 있습니다. 선택한 회원이 권한 이전을 승인하면 계정 책임자가 변경됩니다.'입니다.

**주의하세요.**

이전 대상은 '운영관리' 권한 회원만 선택할 수 있습니다. 대상 회원이 없으면 먼저 회원을 초대해 주세요. 이미 진행 중인 이전 요청이 있으면 기존 요청을 처리한 뒤 다시 시도해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
