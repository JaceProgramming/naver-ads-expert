# [AI작성] 검색광고 비즈채널의 검수 상태와 검수 의견을 확인하려면 어떻게 하나요?

검색광고(SA) 비즈채널 목록에서 상태 부분에 검수 상태와 노출제한 사유를 확인할 수 있습니다. \[광고주센터 > 구성요소 관리 > 비즈채널\]에서 검토중 또는 노출제한 상태로 보여집니다.

노출제한 글씨를 클릭하면 사유 화인이 가능합니다.

**표시 정보**

-   채널명·유형 등 채널 기본 정보
    
-   검수 결과와 검수자 의견
    
-   웹사이트 유형의 경우, PC/모바일 검수 결과와 검수자 의견
    
-   노출제한 된 경우 제한 사유와 정책 가이드 링크
    

**검수 상태별 표시**

| **상태** | **의미** |
| --- | --- |
| 승인(둘 다) | PC와 모바일 모두 승인된 상태 |
| 일부 승인 | PC·모바일 중 한쪽만 승인되고 다른 쪽은 사유가 표시되는 상태 |
| 노출제한(둘 다) | PC와 모바일 모두 노출제한 되어 사유와 검수자 의견이 표시되는 상태 |
| 검토중 | 검수 대기 상태 |

**알아두세요.**

노출제한 된 경우 \[재검토 요청\]을 클릭하면 검토 요청 메시지 입력 및 재검토를 받을 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
