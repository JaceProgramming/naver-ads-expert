# [AI작성] 검색광고 키워드 입찰가를 변경하려면 어떻게 하나요?

**적용 대상:** 파워링크 · 쇼핑검색(쇼핑 브랜드형) · 파워컨텐츠

광고그룹 상세 \[키워드\] 탭에서 키워드를 체크하고 \[입찰가 변경\] > \[입찰가 일괄 변경\]을 클릭하면 '입찰가 변경' 창이 열립니다. 6가지 변경 방식 중 하나를 선택해 입찰가를 일괄 변경합니다.

**변경 절차**

1.  광고그룹 상세 \[키워드\] 탭에서 변경할 키워드를 선택합니다.
    
2.  \[입찰가 변경\]을 클릭하고 목록에서 \[입찰가 일괄 변경\]을 선택합니다.
    
3.  '입찰가 변경 (N개 키워드 선택키워드: 고구마 외 N개)' 창에서 변경 방식 중 하나를 선택합니다.
    
4.  \[변경사항 미리보기\]로 결과를 확인한 뒤 \[변경\]을 클릭해 적용합니다.
    

**변경 방식 (6종)**

| **방식** | **설명** |
| --- | --- |
| 선택한 키워드들의 입찰가를 \[원\]으로 변경 | 직접 금액 입력 (70원~100,000원) |
| 선택한 키워드들의 입찰가를 각 그룹의 기본 입찰가로 변경 | 각 키워드가 속한 광고그룹의 기본 입찰가를 적용 |
| 선택한 키워드들의 입찰가를 \[%\] 증액 | 현재 입찰가를 입력한 비율만큼 증액 |
| 선택한 키워드들의 입찰가를 \[%\] 감액 | 현재 입찰가를 입력한 비율만큼 감액 |
| 선택한 키워드들의 입찰가를 PC 최소노출 입찰가로 변경 | PC 최소노출 입찰가를 조회해 적용 |
| 선택한 키워드들의 입찰가를 PC 통합검색 1위 평균 입찰가로 변경 | PC 통합검색 1위 평균 입찰가를 조회해 적용 |

**알아두세요.**

입찰가는 70원~100,000원(10원 단위, VAT 제외) 범위 내에서 적용됩니다. 조회된 순위별 평균 입찰가가 최대 입찰가 이상일 경우 최대 입찰가로 입찰됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
