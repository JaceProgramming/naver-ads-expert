# [AI작성] 검색광고 확장 소재를 삭제하려면 어떻게 하나요?

**적용 대상:** 파워링크 · 쇼핑검색 · 플레이스

광고그룹 상세 화면의 '확장 소재' 탭에서 더 이상 사용하지 않는 확장 소재를 삭제할 수 있습니다. 한 번에 여러 확장 소재를 선택하여 삭제할 수도 있습니다. 삭제는 노출 중지와 달리 확장 소재 자체를 영구적으로 제거하는 작업입니다.

**삭제 절차**

1.  광고그룹 상세 화면의 '확장 소재' 탭으로 이동합니다.
    
2.  삭제할 확장 소재를 1건 이상 선택한 뒤 \[선택한 확장 소재 관리\]에서 삭제를 선택합니다.
    
3.  삭제 대상 목록과 경고 메시지를 확인합니다.
    
4.  \[삭제\]를 클릭하면 선택한 확장 소재가 삭제됩니다.
    

**알아두세요.**

일시적으로 노출만 멈추려면 삭제 대신 해당 확장 소재를 중지(OFF) 상태로 변경해 주세요. 중지한 확장 소재는 입력 내용이 유지되어 언제든 다시 노출할 수 있습니다.

**주의하세요.**

삭제된 확장 소재는 복구할 수 없습니다. 광고에 노출 중인 확장 소재를 삭제하면 해당 정보가 더 이상 광고에 표시되지 않으니, 삭제 전에 대상을 반드시 확인해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
