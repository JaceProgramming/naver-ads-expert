# [AI작성] 파워링크 광고그룹에 등록할 수 있는 확장 소재 유형은 무엇인가요?

파워링크 광고그룹의 '확장 소재' 탭에서는 기본 소재 외에 추가 정보를 함께 노출하는 확장 소재를 등록할 수 있습니다. \[새 확장 소재\]를 누르면 등록 가능한 유형 목록이 표시되며, 유형을 선택하면 등록 화면이 열립니다. 확장 소재 유형은 광고 상품에 따라 다르며, 아래는 파워링크 광고그룹에서 등록할 수 있는 유형입니다.

**파워링크 광고그룹 확장 소재 유형**

| **유형** | **설명** |
| --- | --- |
| 웹사이트정보 | 웹사이트 관련 추가 정보를 노출합니다. |
| 쇼핑정보 | 쇼핑 비즈채널과 연결하여 상품 정보를 노출합니다. |
| 전화번호 | 전화번호 비즈채널과 연결하여 전화 정보를 노출합니다. |
| 네이버 예약 | 네이버 예약 비즈채널과 연결하여 예약 정보를 노출합니다. |
| 톡톡 상담 | 네이버 톡톡 비즈채널과 연결하여 톡톡 상담 정보를 노출합니다. |
| 계산 | 계산 도구 관련 정보를 노출합니다. |
| 추가제목 | 광고에 추가 제목을 노출합니다. |
| 추가설명 | 광고에 추가 설명 텍스트를 노출합니다. |
| 홍보문구 | 광고에 홍보문구를 노출합니다. |
| 서브링크 | 광고 하단에 추가 링크를 노출합니다. |
| 파워링크 이미지 | 광고에 이미지를 함께 노출합니다. |
| 이미지형 서브링크 | 이미지와 함께 추가 링크를 노출합니다. |
| 플레이스 정보 | 플레이스 비즈채널과 연결하여 매장 정보를 노출합니다. |
| 홍보 영상 | 광고에 홍보 영상을 함께 노출합니다. |
| 블로그 리뷰 | 블로그 리뷰 콘텐츠를 광고와 함께 노출합니다. |

**알아두세요.**

유형별 등록 한도를 초과한 경우 해당 유형을 선택할 수 없습니다. 기존 확장 소재를 정리한 후 다시 시도해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
