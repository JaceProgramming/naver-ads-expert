# [AI작성] 검색광고 API 키를 발급하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 도구 > SA API 사용 관리\]에 진입해 'API 이용약관' 동의 후 검색광고 Key(엑세스라이선스·비밀키)를 발급받습니다.

**발급 절차**

1.  광고 계정의 계정 책임자 권한으로 로그인합니다.
    
2.  \[광고주센터 > 검색광고 > 도구 > SA API 사용 관리\]에 진입합니다.
    
3.  최초 진입 시 'API 이용약관'에 동의하고 API 서비스 사용을 신청합니다.
    
4.  신청 완료 후 검색광고 Key 표에 '엑세스라이선스'와 '비밀키' 두 항목이 발급되어 표시됩니다.
    
5.  각 행의 \[복사\]를 클릭해 Key 값을 복사한 뒤 API 호출 시 사용합니다.
    

**알아두세요.**

계정 책임자 권한이 없는 사용자는 API 키 발급이 불가능합니다. 서비스 상세 사항은 \[네이버검색광고API 매뉴얼\] 사이트를 참고합니다.

**주의하세요.**

검색광고 Key는 외부에 노출되지 않도록 안전하게 관리해야 하며, 노출이 의심되는 경우 즉시 \[재발급\]을 통해 새 Key를 발급받아야 합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
