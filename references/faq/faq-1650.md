# [AI작성] 전환 추적 서비스를 해지(종료)하려면 어떻게 하나요?

운영 중인 전환 추적 서비스는 \[광고주센터 > 검색광고 > 도구 > 전환 추적 관리\]의 전환 추적 대상 표에서 해지할 채널의 \[해지 신청\]을 클릭해 해지(종료)할 수 있습니다.

**해지 신청 절차**

1.  \[광고주센터 > 검색광고 > 도구 > 전환 추적 관리\]에 진입합니다.
    
2.  전환 추적 대상 표에서 해지할 채널의 '상태'가 '사용중'인지 확인합니다.
    
3.  해당 행의 '관리' 컬럼에서 \[해지 신청\]을 클릭합니다.
    
4.  '전환 추적 서비스 해지' 창에서 해지 안내를 확인하고 '위의 내용을 정확히 숙지했으며, 전환 추적 서비스를 해지합니다.'에 체크한 뒤 \[확인\]을 클릭합니다.
    

해지 처리 중에는 상태가 '해지중'으로 표시되고, 해지 완료 후 '미사용'으로 변경됩니다. '최근 변경이력' 컬럼에는 '신규 서비스 해지 신청'·'신규 서비스 해지 신청 완료' 등 변경 내용이 기록됩니다.

**참고.**

전환 추적을 해지하더라도 연결 URL 뒤에 붙은 'NaPm=' 파라미터는 그대로 남아 있습니다. 삭제를 원하면 NHN Data (1877-7035)로 요청해 주세요.

**주의하세요.**

서비스 해지 신청 후 7일이 지나면 해지 처리가 완료되며, 처리 완료 이후에는 웹로그분석 데이터 확인이 불가능합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
