# [AI작성] 웹사이트 전환 캠페인에서는 어떤 소재 유형을 선택할 수 있나요?

웹사이트 전환 캠페인의 소재를 만들 때 '소재 유형 선택' 단계에서는, 광고주님의 광고 그룹·타게팅·캠페인 설정 조합에 따라 노출 가능한 소재 유형이 자동으로 표시됩니다. 웹사이트 전환 캠페인에서 선택할 수 있는 대표적인 소재 유형은 아래와 같습니다.

**웹사이트 전환에서 선택 가능한 소재 유형**

| **소재 유형** | **주요 미디어 구성** |
| --- | --- |
| 이미지 배너 | 1250×560 규격의 단일 이미지 배너로 구성되며, 행동 유도 버튼의 노출 위치에는 제약이 있습니다. |
| 네이티브 이미지 | 단일 이미지와 광고 메시지로 구성됩니다. |
| 컬렉션 | 여러 장의 이미지와 제목으로 구성됩니다. |
| ADVoost 소재 | ADVoost가 AI로 소재를 자동 최적화하는 유형으로, ADVoost 권한 및 캠페인 조건이 충족될 때 선택할 수 있습니다. |

위 네 가지 외의 소재 유형은 웹사이트 전환 캠페인에서 제공되지 않습니다. 카탈로그 소재는 카탈로그 판매 캠페인 전용이므로 웹사이트 전환 캠페인에서는 노출되지 않습니다.

**소재 유형 선택 방법**

1.  소재 만들기 화면의 '소재 유형 선택' 단계에서 노출된 유형 중 하나를 선택합니다.
    
2.  유형을 선택하면 해당 유형의 세부 템플릿이 표시되며, 선택한 유형에 맞는 미디어 입력 영역으로 화면이 전환됩니다.
    

**소재 유형이 표시되지 않을 때**

| **상황** | **화면 동작과 조치** |
| --- | --- |
| 선택 가능한 소재 유형이 없는 경우 | 소재 유형 선택 화면 전체가 비활성화됩니다. 광고 그룹과 캠페인 설정을 점검해 주시기 바랍니다. |
| 기존 소재를 수정하는 경우 | 기존에 사용한 소재 유형과 동일한 템플릿만 노출됩니다. |
| 수정 시 더 이상 제공되지 않는 템플릿을 사용 중이거나 소재가 '검토중' 상태인 경우 | 소재 유형을 변경할 수 없으며, 소재 이름만 변경할 수 있습니다. |

**참고.**

소재를 저장하면 등록하신 이미지·동영상별, PC·모바일별로 소재가 각각 생성될 수 있으며, 각 소재별로 검토가 진행됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
