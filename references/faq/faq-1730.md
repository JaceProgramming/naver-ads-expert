# [AI작성] 디스플레이광고 비즈채널 상세 화면에서 정보를 확인하거나 수정하려면 어떻게 하나요?

**디스플레이광고 비즈채널 상세 화면 안내**

비즈채널 상세 화면에서는 디스플레이광고 비즈채널의 기본 정보와 검토 현황을 확인하고 정보를 수정할 수 있습니다. 목록에서 채널명을 클릭하면 진입합니다.

**상세 구성**

| **영역** | **내용** |
| --- | --- |
| 기본 정보 | 이름, URL, 유형, 등록일, 마지막 검토일 |
| 유형별 확장 정보 | 웹사이트는 인증 정보, 모바일 앱은 플랫폼·앱 ID, 네이버 쇼핑은 스토어 플랫폼과 연동 상태 |
| 검토 이력 | 최근 검토 처리 5건의 일시·상태·코멘트 |

**수정 방법**

1.  상세 화면 상단의 \[정보 변경\]을 클릭합니다.
    
2.  정보를 변경한 뒤 저장합니다.
    

검토가 진행 중인 경우 \[정보 변경\]은 사용할 수 없으며, 반려 상태에서는 수정 후 재등록할 수 있습니다.

**알아두세요.**

수정 기능은 권한에 따라 비활성화될 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
