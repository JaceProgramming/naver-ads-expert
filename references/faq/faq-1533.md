# [AI작성] 파워컨텐츠 캠페인 상세 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 광고 관리 > 파워컨텐츠\]에서 캠페인 이름을 클릭하면 캠페인 상세 화면으로 진입합니다.

**화면 구성**

-   **캠페인 정보 영역** (우측 \[수정\] 버튼 제공)
    
-   상태 — 운영가능 / 중지: 캠페인 OFF / 광고 집행 종료 등
    
-   캠페인 유형 — 파워컨텐츠
    
-   기간 — 계속노출 / 종료일 설정
    
-   하루 예산 — 50원~1,000,000,000원 또는 제한없음
    
-   예산배분 — 균등노출 / 일반노출
    
-   **관리 버튼**: \[새 광고그룹\], \[선택한 광고그룹 관리\], \[다운로드\], \[열 맞춤 설정\] (상태 외 7개), \[상세 데이터\]
    
-   **광고그룹 목록 표**: 컬럼은 'ON/OFF / 광고그룹 이름 / 상태 / 기본 입찰가 / 채널 정보 / 노출수 / 클릭수 / 클릭률(%) / 평균 CPC / 총비용'으로 구성됩니다.
    

**알아두세요.**

파워컨텐츠는 블로그·포스트·카페 비즈채널을 광고그룹에 연결해 콘텐츠 소재로 광고를 노출합니다. 광고그룹의 '채널 정보' 컬럼에 연결된 콘텐츠 URL이 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
