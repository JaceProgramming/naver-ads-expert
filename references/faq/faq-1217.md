# 광고 연결 URL 파라미터 추가 시 정상 작동 여부를 테스트 해야해요.

네이버광고주센터 검색광고 내 자동 추적 기능, 전환 추적, 파라미터 자동 추가 기능을 사용하면 광고 클릭 시 연결 URL 뒤에 일정 규칙에 따라 몇 가지 파라미터와 값이 붙게 추가됩니다.

이때 **단축URL을 사용하거나**, 웹 서버 혹은 보안 시스템의 설정에 따라서 사이트가 열리지 않는 경우가 있으므로 반드시 정상 작동 여부를 테스트해야 합니다.

테스트 방법은 다음과 같습니다.

1\. 실제 광고 클릭시 연결되는 연결 URL을 준비합니다.

2\. 연결 URL에 "?"가 포함되어 있는지에 따라 아래와 같이 테스트를 진행합니다.

a. 연결 URL에 "?"가 포함되어 있는 경우: 연결 URL 끝에 "&"를 추가한 다음 아래 \[테스트 파라미터\]의 내용을 추가하고, 그 내용을 복사하여 브라우저의 주소창에 입력해서 접속이 되는지를 살펴봅니다.

b. 연결 URL에 "?"가 포함되어 있지 않은 경우: 연결 URL 끝 "?" 를 추가한 다음 아래 \[테스트 파라미터\]의 내용을 추가하고, 그 내용을 복사하여 브라우저의 주소 창에 입력해서 접속이 되는지를 살펴봅니다.

3\. 자동 추적 기능을 사용하시는 경우 2번의 내용에 따라 다음의 테스트 파라미터를 URL 뒤에 추가합니다.

**주의하세요.**

자동 추적 기능, 전환 추적, 파라미터 자동 추가 기능을 사용 중인 상태에서 광고 클릭 시 오류가 발생하는 원인은 대부분 하위 디렉터리(subdirectory)에서 끝나는 연결 URL을 사용하기 때문입니다.

\> URL 예: [http://www.motor-abcd.com/category](http://www.motor-abcd.com/category)

위와 같은 연결 URL을 사용하면서 추적 기능을 사용하는 경우 사용자가 접속하는 URL이 다음과 같은 형태가 됩니다.

\> [http://www.motor-abcd.com/category?a=b](http://www.motor-abcd.com/category?a=b)

일반적인 웹 서버는 위와 같은 URL로 연결되어 오류 없이 정상으로 작동합니다. 하지만 웹 서버의 종류와 설정에 따라서 위와 같은 URL 형태가 작동하지 않는 경우가 있습니다. 따라서 개발 업체나 호스팅 업체를 통해 위와 같은 URL 형태로 정상 작동이 가능한지 웹 서버 설정을 확인하신 후 자동 추적 기능 또는 전환 추적 서비스를 신청하시기 바랍니다.

일반적으로 다음과 같이 접근하는 사이트의 페이지 주소까지 포함하는 전체 URL을 입력하면 자동 추적 기능 전환 추적 관리 이용에 문제가 발생하지 않습니다. 하지만 만약의 경우를 대비하여 반드시 테스트해 보시기 바랍니다.

\> [http://www.motor-abcd.com/category/index.html](http://www.motor-abcd.com/category/index.html)
