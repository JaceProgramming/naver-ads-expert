# [AI작성] 상품그룹에서 상품을 삭제하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 구성요소 관리 > 쇼핑 브랜드 상품그룹\]에서 상품그룹 이름을 클릭해 상세로 진입한 뒤, 등록된 상품 목록에서 삭제할 상품을 선택해 제거합니다.

**삭제 절차**

1.  \[광고주센터 > 검색광고 > 구성요소 관리 > 쇼핑 브랜드 상품그룹\]에 진입합니다.
    
2.  '상품등록 방식'이 '상품 선택 등록'인 상품그룹의 이름을 클릭해 상세로 이동합니다.
    
3.  상세에서 등록된 상품 목록 중 삭제할 상품을 선택합니다.
    
4.  표 상단의 삭제 버튼을 클릭하고 확인 창에서 삭제를 확정합니다.
    

**알아두세요.**

'전체 상품 등록' 방식의 상품 그룹은 선택한 비즈채널의 상품이 자동으로 포함되므로 개별 상품을 삭제할 수 없습니다. 비즈채널의 상품을 제거하면 자동으로 그룹에서도 제외됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
