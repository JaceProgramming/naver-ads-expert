# [AI작성] 디스플레이광고 잠재고객 관리 화면은 어떻게 구성되어 있나요?

잠재고객 관리는 디스플레이광고 계정에서 광고에 활용할 타겟 오디언스를 생성·관리하는 도구입니다. 광고주센터에 로그인한 뒤 광고 계정을 선택하고 \['도구' > '잠재고객 관리'\]로 이동하면 진입합니다.

**화면 구성**

화면 상단의 네 개 탭으로 타겟 유형이 나뉩니다.

| **탭** | **설명** |
| --- | --- |
| 내 데이터 타겟 | 고객 파일(CRM)·MAT 타겟·웹사이트 타겟·외부 오디언스 등 내 데이터 기반 타겟을 관리합니다. 화면 진입 시 기본으로 선택됩니다. |
| 맞춤 타겟 | 검색 키워드 기반 맞춤 타겟을 관리합니다. |
| 네이버 쇼핑 타겟 | 쇼핑 스토어·고객여정(AIPL)·알림받기·CRM 마케팅 타겟을 관리합니다. |
| 유사 타겟 | 기존 타겟을 시드로 생성한 유사 타겟을 관리합니다. |

각 탭에서 만든 타겟은 광고세트·애셋그룹의 타겟팅에 활용할 수 있습니다.

**알아두세요.**

잠재고객 관리는 디스플레이광고(성과형 디스플레이광고) 계정 단위 도구입니다.

**참고.**

각 타겟 목록에는 타겟 이름, 데이터 소스, 크기, 생성일, 상태가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
