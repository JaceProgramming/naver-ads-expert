# 파워링크 광고 그룹과 키워드에 입찰가를 모두 설정하는 경우

기본 입찰가를 설정하더라도 키워드별로 입찰가를 설정할 수 있습니다. 이 경우 키워드 입찰가가 우선으로 적용됩니다.

| **예.** 기본 입찰가를 300원으로 설정하고 키워드 입찰가를 400원으로 설정한 경우, 해당 키워드는 400원으로 입찰에 참여합니다. |
| --- |

**참고.**

키워드 입찰가를 설정하더라도 광고그룹의 기본 입찰가는 그대로 남아 있으며, 언제든 다시 설정할 수 있습니다. 키워드 목록에서 키워드를 선택하고 \[선택 키워드 입찰가 변경\] 드롭다운 목록 상자에서 \[입찰가 일괄 변경\]을 클릭한 다음 \[선택한 키워드의 입찰가를 기본 입찰가(000원)(으)로 변경\]을 선택하여 입찰가를 변경합니다.
