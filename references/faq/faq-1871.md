# [AI작성] ADVoost 쇼핑 애셋그룹을 만들거나 수정하려면 어떻게 하나요?

애셋그룹은 ADVoost 쇼핑 캠페인에서 광고가 노출되는 단위입니다. 다른 디스플레이광고 유형의 광고 그룹·소재를 대신하며, 광고주님께서 선택하신 상품(아이템 세트)과 시그널을 바탕으로 다양한 형태의 소재가 자동 구성됩니다. 캠페인 저장 후 자동으로 애셋그룹 만들기 화면으로 이동하며, 등록한 애셋그룹은 이후 동일한 화면에서 수정할 수 있습니다.

**입력 항목**

| **항목** | **설명** |
| --- | --- |
| 애셋그룹 이름 | 애셋그룹을 식별할 이름입니다. 새로 만들 때 기본 이름이 자동으로 채워지며 원하는 이름으로 변경할 수 있습니다. |
| 상품 세트(아이템 세트) | 캠페인의 카탈로그를 기준으로, 광고에 노출할 아이템 세트를 선택합니다. |
| 시그널 | 잠재고객 타겟과 성별·연령 등 데모그래픽 시그널을 설정합니다. 이미지·텍스트·로고 등 자산을 직접 등록하는 단계는 없습니다. |
| 미리보기 | 선택한 아이템 세트의 상품이 다양한 게재 위치에서 어떻게 노출되는지 화면 우측에서 미리 확인할 수 있습니다. 카탈로그 기반으로 자동 변형된 소재가 미리보기로 표시됩니다. |

**만들기 방법**

1.  애셋그룹 이름을 확인하거나 변경합니다.
    
2.  광고에 노출할 상품 세트를 선택합니다.
    
3.  잠재고객 타겟·성별·연령 등 시그널과 필요한 추가 설정을 입력합니다.
    
4.  우측 미리보기로 노출 형태를 확인한 뒤 \[저장\]을 클릭합니다.
    

새로 만든 경우 저장하면 광고 만들기 완료 화면으로 이동하며, 수정한 경우 애셋그룹 상세 화면으로 이동합니다. 캠페인 설정을 다시 변경하려면 \[이전\]을 클릭해 캠페인 단계로 돌아갈 수 있습니다.

**알아두세요.**

대표 URL로 연결된 네이버 쇼핑몰이 더 이상 운영되지 않는 경우, 해당 애셋그룹은 수정할 수 없습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
