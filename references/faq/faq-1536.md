# [AI작성] 파워컨텐츠 콘텐츠 소재를 만들려면 어떻게 하나요?

파워컨텐츠 광고그룹 상세 \[소재\] 탭에서 \[새 소재\]를 클릭하면 '소재 만들기' 창이 열립니다. 제목·설명·URL·이미지·업체(브랜드)명·콘텐츠 발행일 등을 입력해 소재를 등록합니다.

**만들기 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 파워컨텐츠\]에서 광고그룹 이름을 클릭해 상세로 이동합니다.
    
2.  \[소재\] 탭에서 \[새 소재\]를 클릭합니다.
    
3.  창 좌측의 \[기존 소재 불러오기\]로 기존 소재 설정을 가져올 수 있습니다.
    
4.  다음 필수 항목을 입력합니다.
    

-   제목 — 7자 이상 28자 이내
    
-   설명 — 80자 이상 110자 이내
    
-   URL — 광고그룹 비즈채널에서 선택
    
-   연결 URL — URL에 설정한 사이트에 있는 페이지 URL (http://)
    
-   이미지 — BMP·JPG·JPEG·PNG, 400×400~2,000×2,000 픽셀
    
-   업체(브랜드)명 — 1~20자
    
-   프로필 이미지 연동 — 네 / 아니오
    
-   콘텐츠 발행일 — 날짜 입력
    

1.  의료광고 심의 대상이면 '의료광고 심의필 번호'(예: 의12345, 5~14자)를 입력합니다.
    
2.  '검토 요청'에서 \[네\] 선택 시 검토 담당자에게 전달할 내용(200자 이내)과 서류를 첨부합니다.
    
3.  창 우측의 PC/모바일 소재 미리보기에서 노출 형태를 확인합니다.
    
4.  \[저장\]을 클릭해 소재를 등록합니다.
    

**알아두세요.**

선택한 이미지는 노출매체·기기에 따라 정사각형 파란 실선 바깥의 흐림처리된 부분이 표시되지 않을 수 있습니다. 의료광고 심의대상 비즈채널의 경우 '콘텐츠 내 이미지 불러오기'는 적용되지 않고 대표 썸네일 1개만 노출됩니다.

**주의하세요.**

이미지 강조형 연동 소재의 콘텐츠 이미지는 랜딩페이지에 직접 첨부해 등록한 이미지만 불러올 수 있으며, 외부 도메인에서 붙여넣기한 이미지는 표시되지 않을 수 있습니다. 연결 URL에서 이미지를 수정하면 새로 소재를 등록해야 합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
