# [AI작성] 플레이스 캠페인 목록 화면은 어떻게 구성되어 있나요?

플레이스 캠페인 목록 화면에서 네이버 스마트 플레이스에 등록된 업체의 검색광고 캠페인을 조회·관리합니다. \[광고주센터 > 검색광고 > 광고 관리 > 플레이스\]로 진입합니다.

**화면 구성**

| **영역** | **설명** |
| --- | --- |
| 헤더 영역 | 화면 제목 '플레이스'와 조회 기간(달력·이전/다음 이동, 프리셋: 오늘·어제·이번주·지난주·최근 7일·최근 30일 등)이 표시됩니다. |
| 액션 영역 | \[새 캠페인\]·\[선택한 캠페인 관리\]·\[열 맞춤 설정\]·\[상세 데이터\]·\[전체 다운로드\]가 제공됩니다. |
| 필터 영역 | '필터를 입력해 주세요' 입력란으로 목록을 좁히고, 상태·캠페인명으로 검색합니다. |
| 캠페인 테이블 | 등록된 플레이스 캠페인의 성과 데이터를 표로 표시합니다. |

**캠페인 테이블 컬럼**

| **컬럼** | **설명** |
| --- | --- |
| ON/OFF | 캠페인의 광고 노출 상태를 켜거나 끕니다. |
| 캠페인 이름 | 클릭하면 캠페인 상세(광고그룹 목록)로 이동합니다. |
| 상태 | '운영가능', '중지: 캠페인 OFF', '광고 집행 종료' 등 운영 상태를 표시합니다. |
| 노출수 / 클릭수 / 클릭률(%) / 평균 CPC / 총비용 | 조회 기간 내 성과 지표입니다. |
| 하루 예산 | 캠페인에 설정된 하루 예산이 표시됩니다. |

**참고.**

\[선택한 캠페인 관리\]는 캠페인을 1개 이상 선택하면 활성화되며 '기간 변경'·'예산 변경' 일괄 작업을 제공합니다. \[열 맞춤 설정\]에서 표시할 추가 컬럼을 선택할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
