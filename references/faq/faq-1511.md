# [AI작성] 제품 카탈로그 소재를 등록하려면 어떻게 하나요?

카탈로그 유형 광고그룹에서는 카탈로그를 검색하여 소재로 등록할 수 있습니다. 일반 쇼핑 소재가 개별 상품 단위인 것과 달리, 카탈로그 소재는 카탈로그(상품 그룹) 단위로 광고를 생성합니다.

**카탈로그 소재 등록 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 쇼핑검색\]에서 카탈로그 유형 캠페인의 광고그룹 상세 화면으로 이동합니다.
    
2.  소재 탭에서 \[새 소재\]를 클릭합니다.
    
3.  카탈로그 ID 또는 이름으로 검색합니다.
    
4.  검색 결과에서 등록할 카탈로그를 선택합니다. 선택한 카탈로그는 장바구니 영역에 추가됩니다.
    
5.  장바구니에 1개 이상의 카탈로그가 담기면 \[저장\]를 클릭합니다.
    

**검색 결과 항목**

| **항목** | **설명** |
| --- | --- |
| 카탈로그 ID | 카탈로그의 고유 식별 번호입니다. |
| 카탈로그 이름 | 카탈로그의 이름입니다. |
| 상품 수 | 해당 카탈로그에 포함된 상품의 개수입니다. |

**참고.**

검색 결과가 없으면 검색어를 변경해 주세요. 장바구니에 카탈로그가 없으면 저장할 수 없습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
