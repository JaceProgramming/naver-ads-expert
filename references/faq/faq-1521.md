# [AI작성] 새 파워링크 광고그룹을 만들려면 어떻게 하나요?

파워링크 캠페인 상세에서 \[새 광고그룹\]을 클릭하면 광고그룹 이름·URL·기본 입찰가·하루 예산·고급옵션을 설정해 새 광고그룹을 등록할 수 있습니다. 기존 광고그룹을 수정할 때에도 동일한 화면이 사용됩니다.

**광고그룹 만들기 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 파워링크\]에서 캠페인 이름을 클릭해 상세로 이동합니다.
    
2.  '광고그룹' 탭에서 \[새 광고그룹\]을 클릭합니다. 창 좌측의 \[기존 광고그룹 설정 불러오기\]로 같은 유형의 기존 설정을 가져올 수 있습니다.
    
3.  아래 입력 항목을 설정한 뒤 \[저장\]을 클릭하면 광고그룹이 등록됩니다.
    

**입력 항목**

| **항목** | **설명** |
| --- | --- |
| 광고 그룹 이름 | 1~30자 이내로 입력합니다. 같은 캠페인 내에서 이름이 중복될 수 없습니다. |
| URL | 광고 클릭 시 연결될 비즈채널(웹사이트)을 선택하거나 새로 등록합니다. |
| 기본 입찰가 | 키워드·소재별 입찰가가 설정된 경우를 제외한 모든 키워드·소재에 적용되는 입찰가입니다. '직접 설정' 또는 '자동입찰 설정' 중 선택합니다. |
| 하루 예산 | 50원~1,000,000,000원(10원 단위)으로 입력하거나 '제한없음'으로 둡니다. |

**기본 입찰가 설정**

| **방식** | **설명** |
| --- | --- |
| 직접 설정 | 70원에서 100,000원까지 10원 단위로 직접 입력합니다. |
| 자동입찰 설정(beta) | 광고 성과 목표에 맞춰 입찰가가 자동으로 조정됩니다. 사용 시 추천/콘텐츠 지면 전용 입찰가·PC/모바일 입찰가중치·각종 타겟팅 입찰가중치·광고그룹 기본 입찰가·소재 현재 입찰가는 실제 입찰에 사용되지 않습니다. |

**확장 검색 설정**

'확장 검색 by ADVoost' 영역에서 검색어 매칭 방식을 선택합니다.

| **방식** | **설명** |
| --- | --- |
| 확장 검색 |  | 등록 키워드와 일치하는 검색어뿐 아니라 광고 콘텐츠와 연관도가 높은 검색어에도 노출합니다. 예산 상한 비율(1~100%)을 설정할 수 있으며, 확장검색 예산은 광고그룹 예산과 별개로 동작합니다. |
| ADVoost Max | ADVoost Max는 네이버 광고 AI 에이전트가 AI 지면 콘텐츠에 맥락에 맞게 광고를 노출할 수 있는 기능입니다. 키워드 등록 여부를 확인하지 않으므로, 모두 확장검색과 동일하게 간주됩니다. |
| 일치 검색 |  | 등록 키워드와 정확히 일치하거나 의미상 일치에 준하는 유사 검색어에만 노출합니다. |

**고급옵션**

| **항목** | **설명** |
| --- | --- |
| 매체 | 광고를 노출할 매체를 선택합니다. |
| 추천 및 콘텐츠 지면 전용 입찰가 | 추천·콘텐츠 지면 전용 입찰가를 설정합니다. 설정하지 않으면 기본 입찰가가 적용됩니다. |
| PC/모바일 입찰가 가중치 | PC와 모바일 영역에 적용할 입찰가 가중치를 설정합니다. |

**수정 시 참고사항**

-   캠페인 상세 또는 광고그룹 상세에서 \[수정\]을 클릭하면 동일한 수정 화면이 열립니다.
    
-   수정 시 광고그룹 유형과 비즈채널은 변경할 수 없으며 현재 값이 읽기 전용으로 표시됩니다.
    

**알아두세요.**

-   광고그룹 이름은 1~30자까지 입력할 수 있으며, 같은 캠페인 내에서 중복될 수 없습니다.
    
-   기본 입찰가를 직접 설정할 때 70원 미만이거나 100,000원을 초과하는 금액, 10원 단위가 아닌 금액은 저장할 수 없습니다.
    
-   비즈채널 URL을 선택하지 않으면 저장할 수 없습니다.
    

**참고.**

'기존 광고그룹 설정 불러오기'로 같은 캠페인 유형의 기존 광고그룹 설정을 불러와 적용할 수 있습니다.

**주의하세요.**

광고 최종 입찰가는 (기본 입찰가 × 각 타겟팅 입찰 가중치 × 매체 입찰 가중치)로 결정되며, 최대 10만 원(VAT 제외)입니다. 자동입찰은 광고그룹의 하루예산이 설정되지 않았거나 전환 로그가 충분하지 않으면 정상 동작하지 않을 수 있습니다.

**주의하세요.**

'제한없음'으로 하루 예산을 운영하면 경우에 따라 예산을 초과하는 금액이 과금될 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
