# [AI작성] 이미지 라이브러리에 이미지를 업로드하거나 수정하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 구성요소 관리 > 이미지\]에서 \[새 이미지\]를 클릭하면 '새 이미지 등록' 창이 열립니다. 이미지 종류를 선택하고 파일을 업로드해 등록합니다.

**업로드 절차**

1.  \[광고주센터 > 검색광고 > 구성요소 관리 > 이미지\]에 진입합니다.
    
2.  \[새 이미지\]를 클릭합니다.
    
3.  '새 이미지 등록' 창에서 '이미지종류'를 선택합니다. (예: 파워링크\_640\*640 등)
    
4.  이미지를 드래그하거나 클릭하여 등록하거나 \[이미지 업로드\]를 통해 파일을 업로드합니다.
    
5.  \[저장\]을 클릭해 이미지를 라이브러리에 등록합니다.
    

**업로드 사양**

| **항목** | **사양** |
| --- | --- |
| 파일 형식 | BMP, JPG, JPEG, PNG |
| 최대 사이즈 | 2000 × 2000 |
| 최대 용량 | 5MB |
| 병의원 파비콘 | 너비·높이 동일한 정사각형, 최소 16px 이상 (예: 30×30, 48×48) |
| 파일 이름 | 한글 최대 25자 / 영문 최대 75자 이하 |

**주의하세요.**

이미지 종류에 따라 사용할 수 있는 이미지의 크기가 다릅니다. 인물 사진이나 타인이 제작한 이미지 등 제삼자의 권리(초상권·저작권 등)와 관련된 사진을 업로드하려면 권리자에게 사전 승낙을 얻어야 합니다. 분쟁 발생 시 회사가 해당 광고의 노출을 중단시킬 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
