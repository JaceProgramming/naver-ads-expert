# [AI작성] 전체 캠페인 목록에서 여러 캠페인을 한 번에 삭제하려면 어떻게 하나요?

전체 캠페인 목록에서 선택한 캠페인을 한 번에 삭제할 수 있습니다. 삭제한 광고 정보는 복구할 수 없으므로 주의사항을 확인한 뒤 진행해 주세요.

**삭제 방법**

1.  테이블에서 삭제할 캠페인을 선택합니다.
    
2.  상단에 나타나는 \[삭제\] 버튼을 클릭합니다.
    
3.  '다음 주의 사항을 확인하고 캠페인을 삭제해 주세요.' 안내와 주의사항을 확인한 뒤 동의에 체크하면 \[확인\] 버튼이 활성화됩니다.
    
4.  \[확인\]을 클릭하면 선택한 캠페인이 삭제됩니다.
    

**삭제 시 주의사항**

-   선택된 캠페인 하위의 광고 그룹, 광고 소재가 삭제됩니다.
    
-   캠페인에 따라 하위의 확장소재, 애셋 그룹, 키워드가 있는 경우 함께 삭제됩니다.
    
-   삭제된 광고 정보는 복구할 수 없습니다.
    
-   삭제된 광고 성과 데이터는 보고서 메뉴에서 조회할 수 있습니다.
    
-   삭제된 캠페인이 속해있던 공유예산의 하루 예산은 그대로 유지되니, 삭제 후 예산을 확인해주시기 바랍니다.
    

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
