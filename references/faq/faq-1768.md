# [AI작성] 광고 계정의 비즈쿠폰 사용 내역을 조회하려면 어떻게 하나요?

비즈쿠폰 관리 화면에서 광고 계정에 지급된 비즈쿠폰의 사용 이력을 조회할 수 있습니다.

\[광고주센터 > 우측 상단 네이버 ID > 광고 계정 관리 > 광고 계정 클릭 > 결제 > 비즈쿠폰 관리\]로 이동합니다. 진입 시 SA 비즈쿠폰 목록이 표시됩니다.

**표 구성**

| **컬럼** | **설명** |
| --- | --- |
| 쿠폰번호 | 쿠폰 식별 번호입니다. |
| 쿠폰명 | 쿠폰 이름입니다. |
| 유/무상 구분 | 유상 또는 무상으로 구분됩니다. |
| 금액 | 쿠폰 금액입니다. |
| 발행일 | 쿠폰이 발행된 날짜입니다. |
| 유효 기간 | 쿠폰 사용 가능 기간입니다. |
| 사유 | 쿠폰 발급 사유입니다. |
| 상태 | 사용 가능 / 사용 완료 / 기간 만료 등으로 표시됩니다. |
| 사용하기 | 쿠폰 사용 액션입니다. |
| 사용일 | 쿠폰을 사용한 날짜입니다. |

디스플레이광고 충전쿠폰은 충전쿠폰 이력이 있는 경우에 별도로 조회됩니다.

**비즈쿠폰 이용 안내**

-   비즈쿠폰 사용 시 쿠폰이 발급된 계정으로 유무상 구분에 따라 유상 또는 무상 충전금으로 전환됩니다.
    
-   비즈쿠폰의 유효 기간 만료 시 충전금으로 자동으로 전환될 수 있습니다.
    
-   비즈쿠폰은 발급된 계정 외 다른 계정으로의 이관이나 사용이 불가합니다.
    
-   비즈쿠폰은 충전금으로 전환 후에는 복원 또는 변경이 불가합니다.
    
-   유상 쿠폰을 충전금으로 전환하는 시점의 일자가 포함된 월에 설정된 결제 계정으로 세금계산서에 마이너스된 금액으로 반영됩니다.
    

**참고.**

조회된 내역이 없으면 "해당 기간에 조회된 내역이 없습니다."가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
