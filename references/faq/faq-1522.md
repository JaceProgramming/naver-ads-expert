# [AI작성] 파워링크 확장 검색 옵션을 변경하려면 어떻게 하나요?

파워링크 광고그룹의 검색어 매칭 방식을 '확장 검색'과 '일치 검색' 중에서 선택해 변경합니다. 광고그룹 수정 화면의 \[고급옵션\] > '확장 검색 by ADVoost'에서 설정합니다.

**변경 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 파워링크\]에서 광고그룹을 클릭해 상세로 이동합니다.
    
2.  '광고그룹 정보' 영역의 \[수정\]을 클릭합니다.
    
3.  '광고그룹 수정' 창에서 \[고급옵션\]을 펼쳐 '확장 검색 by ADVoost' 영역에서 매칭 방식을 선택합니다.
    
4.  '확장 검색' 선택 시 '확장 검색 예산 상한 비율'을 설정합니다.
    
5.  \[저장\]을 클릭하면 변경 사항이 저장됩니다.
    

**확장 검색 by ADVoost**

| **옵션** | **설명** |
| --- | --- |
| 확장 검색 | 등록한 키워드와 일치하거나 유사한 검색어뿐 아니라, 광고 클릭 시 연결되는 콘텐츠와 연관도가 높은 검색어에도 광고를 노출합니다. 예산 상한 비율(1~100%)을 설정할 수 있습니다. |
| 일치 검색 | 등록한 키워드와 정확히 일치하거나 의미상 일치에 준하는 유사 검색어에만 광고를 노출합니다. |

**예산 상한 비율**

'확장 검색'을 선택하면 광고그룹 예산 중 확장 검색에만 사용할 예산의 상한 비율을 1%에서 100%까지(1% 단위) 설정할 수 있으며, 기본값은 100%입니다.

**알아두세요.**

-   확장 검색 예산은 광고그룹 예산과 별개로 동작하며, 설정한 예산 상한 비율을 초과하여 과금되지 않습니다.
    
-   확장 검색에 적용되는 자동입찰은 '기본 입찰가'의 \[자동입찰 설정(beta)\] 사용 여부와 무관하게 확장 검색 광고에만 적용되며, 입찰가를 직접 설정할 수 없습니다.
    
    -   \- 단, ADVoost Max 기능은 실시간 경쟁 입찰 방식이 아닌, 광고 노출 기회의 가치와 예상 광고 성과 등을 대로 자동으로 가격이 책정됩니다.
        
-   확장 검색으로 노출 가능한 검색어가 이미 등록 키워드에 있으면 해당 검색어는 일치 검색으로 노출됩니다.
    
    -   \- ADVoost Max는 등록 키워드 여부를 확인하지 않으므로, 모두 확장검색과 동일하게 간주됩니다.
        
-   확장 검색 노출을 원하지 않는 검색어는 \[제외 검색어\]로 별도 등록합니다.
    
    -   \- ADVoost Max는 제외 검색어 기능을 제공하지 않습니다.
        

**참고.**

광고그룹의 하루 예산이 '제한없음'으로 설정된 경우 예산 상한 비율을 설정할 수 없습니다. 먼저 광고그룹에 하루 예산을 설정해 주세요.

**주의하세요.**

예산 상한 비율이 1% 미만이거나 100%를 초과하면 '확장 검색 예산 상한 비율은 최소 1% 이상 최대 100% 이하로 입력하셔야 합니다' 안내가 표시되며 저장할 수 없습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
