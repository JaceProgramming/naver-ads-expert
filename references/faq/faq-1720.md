# [AI작성] 디스플레이광고에서 새 MAT를 추가하려면 어떻게 하나요?

전환 추적 관리의 'MAT 연동' 탭에서 \[MAT 추가\]를 클릭하면 모바일 앱 분석 도구(MAT)를 새로 연동할 수 있습니다. MAT 이름만 입력하는 간단한 등록 단계입니다.

**추가 방법**

1.  'MAT 연동' 탭에서 \[전환 Key 생성\]을 클릭합니다.
    
2.  연동할 전환Key 의 이름을 입력합니다. 등록 후 인스톨 추적 ID가 발급됩니다.
    
3.  \[등록\]을 클릭해 연동을 완료합니다.
    

**입력 조건**

-   이름은 필수 입력이며 최대 128자까지 입력할 수 있습니다. 공백만으로는 입력할 수 없습니다.
    
-   이름이 입력되어야 \[등록\]이 활성화됩니다.
    

**참고.**

등록이 완료되면 안내가 표시되고 MAT 목록이 갱신되며 추적 ID가 표시됩니다.

**주의하세요.**

이미 사용 중인 이름을 입력하면 '이미 사용 중인 이름' 안내가 표시됩니다. 다른 이름으로 입력해 주세요. 128자를 초과하면 입력란에 오류가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
