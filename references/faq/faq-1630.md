# [AI작성] 다차원 보고서를 삭제하려면 어떻게 하나요?

더 이상 사용하지 않는 다차원 보고서는 삭제할 수 있습니다. 삭제한 보고서는 복구할 수 없으므로 신중하게 진행해 주세요.

**삭제 절차**

1.  \[광고주센터 > 검색광고 > 보고서 > 다차원 보고서\]에서 삭제할 보고서를 엽니다.
    
2.  보고서 화면 상단의 \[삭제\]를 클릭합니다.
    
3.  확인 창에서 삭제 대상을 확인하고 삭제를 확정합니다.
    

**주의하세요.**

확인 창에는 '선택한 보고서를 삭제하시겠어요? 삭제된 보고서는 복구할 수 없습니다.' 안내가 표시됩니다. 자주 사용하는 보고서는 \[다른 이름으로 저장\]으로 백업한 후 삭제하시기 바랍니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
