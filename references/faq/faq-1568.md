# [AI작성] 검색광고 키워드 입찰가를 개별 수정하려면 어떻게 하나요?

적용 대상: 파워링크 · 쇼핑검색(쇼핑 브랜드형) · 파워컨텐츠. 광고그룹 상세 '키워드' 탭에서 여러 키워드의 입찰가를 각각 다른 값으로 수정할 수 있습니다.

**개별 수정 절차**

1.  광고그룹 상세 '키워드' 탭에서 입찰가를 수정할 키워드를 1건 이상 선택합니다.
    
2.  \[입찰가 변경\] > \[입찰가 개별 변경\]을 클릭합니다(또는 표의 '현재 입찰가(VAT 미포함)' 컬럼을 직접 클릭).
    
3.  창에서 키워드별로 새 입찰가를 직접 입력합니다.
    
4.  \[변경\]을 클릭해 적용합니다.
    

**수정 화면 구성**

| **항목** | **설명** |
| --- | --- |
| 광고그룹 정보 | 캠페인명·광고그룹명·기본 입찰가가 표시됩니다. |
| 키워드 목록 | 선택한 키워드별로 현재 입찰가와 새 입찰가 입력란이 표시됩니다. |

**알아두세요.**

'현재 입찰가(VAT 미포함)' 컬럼에 '\[기본\]' 표시가 있으면 광고그룹 기본 입찰가가 적용된 상태이며, 개별 입찰가를 설정하면 '\[기본\]' 표시가 사라집니다. 입찰가는 70원~100,000원(10원 단위, VAT 제외) 범위이며 광고그룹 유형에 따라 범위가 다를 수 있습니다.

**참고.**

일괄 입찰가 변경과 달리, 이 화면에서는 키워드별로 서로 다른 입찰가를 동시에 입력할 수 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
