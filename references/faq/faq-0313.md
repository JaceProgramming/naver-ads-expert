# 광고주가 제품 카탈로그를 직접 만들거나 수정할 수 있나요?

카탈로그 생성 및 수정은 광고주가 직접 할 수 없습니다.

네이버 쇼핑파트너센터에서 브랜드 패키지 소개 페이지 통해 브랜드 권한을 신청하여, 가격비교 페이지를 수정할 수 있습니다.

[네이버쇼핑 브랜드 패키지 신청 바로가기](https://center.shopping.naver.com/brand-info)

또는 카탈로그 페이지 내 '정보수정요청' 버튼을 통해서도 가능합니다.
