# 전화번호, 업체명 등 내 정보를 수정하고 싶어요.

회원 정보와 광고계정 정보는 모두 네이버광고주센터에서 수정하실 수 있습니다.

**\[ 회원 정보 \]**

• 수정 경로: **\[네이버광고주센터 > 상단 로그인 아이디 클릭 > 내 정보\]**

• 수정 가능 항목: 이메일, 휴대전화번호, 미리보기용 ID

※ 회원 정보는 광고 집행과 관련된 다양한 안내를 받는 주요 채널이므로 반드시 실제 회원 본인의 정보를 입력해야 합니다.

**\[ 광고계정 정보 \]**

• 수정 경로: **\[광고주센터 > 광고계정 관리 페이지 > 설정 > 광고 계정 정보\]**

• 광고계정 유형별 수정 가능 항목:

◦ 개인: 광고계정 이름

◦ 사업자: 광고계정 이름, 상호명, 대표자명, 사업자 주소, 사업자등록번호

◦ 해외 광고주: 광고계정 이름, 상호명, 대표자명, 사업자 주소

※ 사업자등록번호 변경 방법은 아래 \[사업자등록번호 변경하기\] 항목을 참고해 주세요.

---

**\[ 사업자등록번호 변경하기 \]**

• 광고계정은 새로운 사업자등록번호로 전환이 가능하며, **개인 → 사업자 전환**도 할 수 있습니다.

• 변경은 광고계정의 **계정책임자**만 진행할 수 있습니다.

**변경 절차**

1\. \[광고주센터 > 광고계정 관리 페이지 > 설정 > 광고 계정 정보\] 에 접속

2\. **\[계정정보 확인/변경\]** 버튼 클릭

3\. 회원 정보 인증 진행

4\. 개인 광고주 → **\[사업자 광고주 유형 변경하기\]** 버튼 클릭

사업자 광고주 → **\[사업자등록번호 변경\]** 버튼 클릭

5\. 변경할 사업자등록번호 입력

**변경 불가 조건**

• 등록된 환불계좌 정보가 있는 경우

• 입력한 사업자등록번호가 유효하지 않은 경우

※ 기존 사업자등록번호로 발행된 세금계산서 수정이 필요한 경우, 반드시 세금계산서 수정 요청을 완료한 후 사업자등록번호 변경을 진행해 주세요.
