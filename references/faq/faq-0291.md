# 파워링크 기본 입찰가에서 월 예상 클릭수와 비용은 무엇인가요?

입력한 클릭 비용으로 광고를 진행할 경우 해당 광고 그룹에서 발생될 것으로 예상되는 테이터입니다.

실제 집행된 광고의 과거 데이터를 기반으로 **앞으로의 4주 동안 예상되는 성과**를 나타냅니다.

단, 과거를 기준으로 하는 예측이기 때문에 실제 광고 집행 시 성과는 달라질 수 있습니다. 해당 데이터는 참고용으로 사용하시기 바랍니다.
