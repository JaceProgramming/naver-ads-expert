# [AI작성] 브랜드검색/신제품검색 캠페인 목록 화면은 어떻게 구성되어 있나요?

브랜드검색/신제품검색 캠페인 목록은 광고 관리에서 등록한 브랜드 검색·신제품 검색 캠페인을 조회하고 관리하는 화면입니다. \[광고주센터 > 검색광고 > 광고 관리 > 브랜드검색/신제품검색\]으로 진입합니다.

**화면 구성**

| **영역** | **설명** |
| --- | --- |
| 헤더 영역 | 화면 제목 '브랜드검색/신제품검색'과 조회 기간 영역(달력·이전/다음 기간 이동)이 표시됩니다. |
| 액션 영역 | \[새 캠페인\], \[열 맞춤 설정\], \[상세 데이터\], \[전체 다운로드\]가 제공됩니다. |
| 필터 영역 | '필터를 입력해 주세요' 입력란으로 목록을 좁힐 수 있습니다. |
| 캠페인 테이블 | 등록된 캠페인의 성과 데이터를 표로 표시합니다. |

**기본 컬럼**

| **컬럼** | **설명** |
| --- | --- |
| ON/OFF | 캠페인의 노출 상태를 켜거나 끕니다. |
| 캠페인 이름 | 캠페인 이름을 표시하며 클릭하면 캠페인 상세로 이동합니다. |
| 상태 | 캠페인의 현재 운영 상태(예: '운영가능', '중지: 캠페인 OFF', '광고 집행 종료' 등)가 표시됩니다. |
| 노출수 | 조회 기간 내 광고 노출 횟수입니다. |
| 클릭수 | 조회 기간 내 광고 클릭 횟수입니다. |
| 클릭률(%) | 노출 대비 클릭 비율입니다. |

**참고.**

\[열 맞춤 설정\]에서 표시할 추가 컬럼을 선택할 수 있습니다.

**참고.**

노출 계약은 광고그룹 화면의 '계약하기' 또는 '계약 관리'에서 진행하며, 캠페인 목록은 노출·클릭 성과를 확인하는 화면입니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
