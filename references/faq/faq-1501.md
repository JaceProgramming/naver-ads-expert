# 파워링크 확장소재 '톡톡 상담' 등록 방법

**톡톡 상담 확장소재란?**

톡톡 파트너센터에 등록한 상담요청서를 파워링크 광고의 확장소재로 연동하는 기능입니다.

광고를 본 이용자가 톡톡 상담 영역을 클릭하면 상담 신청 화면으로 바로 연결되어, 별도의 페이지 이동 없이 즉시 상담을 신청할 수 있습니다.

이사·인테리어·에어컨 청소 등 광고주와 이용자 간 상담·견적이 필요한 업종에서 효과적으로 활용하실 수 있습니다.

**등록 전 확인 사항**

톡톡 상담 확장소재를 등록하려면 광고주센터와 톡톡 파트너센터에서 아래 두 가지가 모두 준비되어 있어야 합니다.

| **준비 사항** |
| --- |
| ① 광고주센터: 톡톡 비즈채널 연동 | 광고주센터 > 비즈채널 관리에서 네이버 톡톡 비즈채널을 연동하고, 상태가 '운영 가능' 이어야 합니다. |
| ② 톡톡 파트너센터: 상담요청서 등록 | 톡톡 파트너센터에 '공개' 상태인 상담요청서가 1개 이상 등록되어 있어야 합니다. |

**참고**: 광고주센터 로그인 네이버 아이디와 톡톡 파트너센터 로그인 네이버 아이디가 동일해야 합니다. [톡톡 파트너센터 바로가기](https://partner.talk.naver.com/web/main?isMobile=false&talkPage=partner_home)

**등록 방법**

1단계. 확장소재 추가 화면 진입

파워링크 광고그룹 > 확장소재 탭 > 새 확장소재 추가 클릭 후 톡톡 상담을 선택합니다.

2단계. 상담요청서 불러오기

연동할 톡톡 비즈채널과 상담요청서를 선택한 후, 광고에 표시될 설명 문구를 입력합니다.

설명 문구는 고객이 상담요청서 제출했을 때의 혜택이 드러나도록 작성하시는 것을 권장드립니다. ex) 상담시 전원 상품권 증정

**유의 사항**

**상담요청서 상태 변경 시 광고 영향**

-   톡톡 파트너센터에서 상담요청서를 미공개 또는 삭제하면 광고 확장소재 상태가 자동으로 '확장소재 연동 상태 비정상' 으로 변경됩니다.
    
-   미공개 처리한 상담요청서를 다시 공개로 변경하더라도 광고 상태는 자동으로 복구되지 않습니다. 재노출을 원하시는 경우 광고주센터에서 톡톡 상담 확장소재를 다시 등록해 주세요.
    

**노출**

-   톡톡 상담 확장소재와 홍보문구는 동시에 노출되지 않습니다.
    
-   두 가지가 모두 등록된 경우 톡톡 상담 확장소재가 우선 노출됩니다.
    
-   서브링크와는 동시 노출이 가능합니다.
    
-   톡톡 상담 확장소재 노출이 불가한 경우 홍보문구가 대신 노출됩니다.
    

**보고서**

-   광고관리>확장소재 탭 뿐만 아니라 다차원 보고서의 확장 소재 보고서 및 대용량 보고서에서 톡톡상담 확장소재 성과 확인이 가능합니다.
    

**이용 제한 업종**

아래 업종은 톡톡 상담 확장소재를 이용하실 수 없습니다.

-   병·의원 업종 (의료광고 사전심의 제도에 따른 제한)
    
-   성인 업종
    

**자주 묻는 질문**

**Q. 톡톡 비즈채널을 연동했는데 상담요청서 목록이 보이지 않습니다.**

A. 광고주센터 로그인 네이버 아이디와 톡톡 파트너센터 로그인 아이디가 동일한지 확인해 주세요. 아이디가 다른 경우 상담요청서 정보를 불러올 수 없습니다. 또한 톡톡 파트너센터에 상담요청서가 등록되어 있는지 확인해 주세요.

**Q. 상담요청서를 다른 것으로 변경하고 싶습니다.**

A. 등록된 확장소재를 삭제한 후 원하는 상담요청서로 새로 등록해 주세요. 기존 확장소재에서 상담요청서만 변경하는 기능은 제공되지 않습니다.

**Q. 광고그룹에 확장소재를 몇 개까지 등록할 수 있나요?**

A. 톡톡 상담 확장소재는 광고그룹당 1개만 등록할 수 있습니다.

**Q. 설명 문구 작성 시 주의할 점이 있나요?**

A. 검색광고 광고소재 등록기준(설명문구 기준)을 준용합니다. 상담 요청의 혜택 정보를 허위 또는 과장된 내용으로 기재함에 따른 모든 법적 책임은 광고주에게 있습니다.
