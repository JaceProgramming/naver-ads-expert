# [AI작성] 검색광고 키워드 재검토를 요청하려면 어떻게 하나요?

광고그룹 상세 \[키워드\] 탭에서 키워드를 체크하고 \[선택한 키워드 관리\] > \[재검토 요청\]을 클릭하면 '선택한 키워드를 재검토 요청' 창이 열립니다.

**요청 절차**

1.  광고그룹 상세 \[키워드\] 탭에서 보류·노출 제한 상태의 키워드를 선택합니다.
    
2.  \[선택한 키워드 관리\]를 클릭하고 \[재검토 요청\]을 선택합니다.
    
3.  '선택한 키워드를 재검토 요청' 창에서 다음을 확인합니다.
    

-   안내문: '선택한 키워드를 재검토 요청합니다.'
    
-   선택한 키워드(N): 재검토 요청할 키워드 이름 (예: 고구마, 용인이사견적)
    

**4\.** \[재검토 요청\] 버튼을 클릭해 검수 요청을 보냅니다.

**5\.** 요청을 취소하려면 \[닫기\]를 클릭합니다.

**알아두세요.**

검토에는 영업일 기준 1~2일이 소요되며, 통과 후에 광고가 노출됩니다. 보류 또는 노출 제한 상태가 아닌 키워드는 재검토 요청 대상에서 제외됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
