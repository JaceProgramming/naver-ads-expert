# [AI작성] 앱 전환 캠페인 설정에서 어떤 항목을 입력하나요?

'앱 전환' 캠페인 설정은 광고주님이 홍보하실 앱의 설치·전환을 유도하기 위한 핵심 정보를 입력하는 단계입니다. 캠페인 만들기 흐름과 이름·기간·예산 입력 등 공통 절차는 디스플레이광고 공통 안내를 참고하시고, 본 안내에서는 '앱 전환' 캠페인 설정 카드에서만 노출되는 항목을 중심으로 설명드립니다.

**앱 전환 캠페인 설정 항목**

| **항목** | **설명** |
| --- | --- |
| 대표 URL | 광고와 연결할 비즈채널을 선택합니다. 비즈채널이 없으시면 \[비즈채널 관리 바로가기\]에서 먼저 등록하실 수 있습니다. (캠페인 수정 시 대표 URL은 변경할 수 없습니다.) |
| 전환 추적 대상 | 전환을 측정할 대상을 선택합니다. '소재 랜딩 URL의 도메인이 전환 추적 대상의 도메인과 일치하는지 확인해 주세요.'라는 안내에 따라 도메인을 맞춰 주시기 바랍니다. \[전환 추적 관리 바로가기\]에서 대상을 관리하실 수 있습니다. |
| 최적화 전환 유형 | 선택하신 전환 추적 대상이 보유한 전환 유형 중에서 최적화 기준이 될 전환 유형을 선택합니다. 전환 추적 대상을 먼저 선택하셔야 활성화됩니다. |
| 브랜드 | 본 캠페인의 대상 브랜드를 선택합니다(필수). '여러 브랜드를 보유하신 경우, 본 캠페인의 대상 브랜드를 선택해 주세요.'라는 안내가 제공되며, \[브랜드 설정하기\]에서 브랜드를 추가하실 수 있습니다. |

**입력 순서**

1.  대표 URL에서 광고와 연결할 비즈채널을 선택합니다.
    
2.  전환 추적 대상을 선택한 뒤, 최적화 전환 유형을 선택합니다.
    
3.  대상 브랜드를 선택합니다.
    
4.  필수 항목을 모두 입력하시면 \[다음\] 버튼이 활성화되어 광고그룹 단계로 이동합니다.
    

**참고.**

'앱 전환' 캠페인은 캠페인 단위로 예산을 자동 분배하는 캠페인 예산 최적화(CBO)를 지원합니다. CBO 설정 방법은 디스플레이광고 공통 안내를 참고하시기 바랍니다.

**주의하세요.**

선택하신 비즈채널이 검토 대기 상태이면 \[다음\] 버튼이 비활성화되어 다음 단계로 진행할 수 없습니다. 필수 항목(대표 URL·브랜드 등)을 등록하지 않으신 경우에는 각 항목의 관리 바로가기에서 먼저 등록해 주시기 바랍니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
