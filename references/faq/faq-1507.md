# [AI작성] 새 쇼핑검색 광고그룹을 만들려면 어떻게 하나요?

쇼핑검색 캠페인 상세에서 \[새 광고그룹\]을 클릭하면 그룹 유형을 선택하고 이름·비즈채널·입찰가·예산 등을 설정해 새 광고그룹을 등록할 수 있습니다. 기존 광고그룹 수정에도 동일한 입력 폼을 사용합니다.

**그룹 유형 선택**

먼저 그룹 유형을 선택합니다. 선택한 유형은 생성 후 변경할 수 없습니다.

| **유형** | **설명** |
| --- | --- |
| 쇼핑몰 상품형 | 쇼핑몰(판매처)을 가진 광고주가 상품 판매를 유도하기 위해 광고할 때 선택합니다. |
| 제품 카탈로그형 | 제조사·브랜드 상품의 판매 유도와 브랜드 광고 효과를 얻으려 할 때 선택합니다. |
| 쇼핑 브랜드형 | 브랜드 공식몰 운영 광고주가 다양한 소재로 브랜드 콘텐츠·제품 라인업을 홍보할 때 선택합니다. 키워드·제품 탭이 추가로 제공됩니다. |

**광고그룹 만들기 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 쇼핑검색\]에서 캠페인 이름을 클릭해 상세로 이동합니다.
    
2.  '광고그룹' 탭에서 \[새 광고그룹\]을 클릭합니다. 창 좌측의 \[기존 광고그룹 설정 불러오기\]로 기존 설정을 가져올 수 있습니다.
    
3.  '그룹 유형'을 선택합니다. 각 유형별 등록 절차는 창의 \[등록 절차 자세히보기\]에서 확인할 수 있습니다.
    
4.  아래 입력 항목을 설정한 뒤 \[저장\]을 클릭하면 광고그룹이 등록됩니다.
    

**입력 항목**

| **항목** | **설명** |
| --- | --- |
| 광고그룹 이름 | 1~30자 이내로 입력합니다. 같은 캠페인 내에서 중복될 수 없습니다. |
| 비즈채널 | 광고에 연결할 쇼핑몰 비즈채널을 선택합니다. |
| 기본 입찰가 | 50원에서 100,000원까지 10원 단위로 입력합니다. |
| 하루 예산 | 50원에서 1,000,000,000원까지 10원 단위로 입력하거나 제한없음으로 둡니다. |
| 브랜드 선택 | 쇼핑 브랜드형에서만 표시되며, 브랜드 1개를 필수로 선택합니다. |

**고급옵션**

고급옵션을 펼치면 매체 등 노출 조건을 추가로 설정할 수 있습니다.

**알아두세요.**

광고그룹 유형은 생성 시 한 번만 선택할 수 있으며 이후 변경할 수 없습니다. 쇼핑 브랜드형 광고그룹은 키워드와 제품 탭이 추가로 제공됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
