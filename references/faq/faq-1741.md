# [AI작성] 알림 수신 설정은 어떻게 하나요?

알림 관리 화면에서 계정·광고 관리 관련 알림의 수신 채널(이메일/문자/톡톡)을 켜거나 끌 수 있습니다. \[내 정보 관리 > 알림 관리\]로 이동한 뒤 '알림 수신 설정' 탭에서 설정합니다.

**알림 그룹**

알림은 다음 4개 그룹으로 구분됩니다. 그룹 머리행의 설정으로 하위 항목을 한 번에 켜거나 끌 수 있고, 각 항목을 개별로 설정할 수도 있습니다.

| **그룹** | **포함 항목** |
| --- | --- |
| 광고계정 | 광고계정 권한 변경 / 회원 초대 상태 변경 / 회원 권한 변경 / 광고 계정 정보 변경 (이메일·문자) |
| 관리 계정 관리 | 관리계정 권한 변경 / 회원 초대 상태 변경 / 회원 권한 변경 / 계정 연동 상태 변경 / 관리 계정 정보 변경 (이메일·문자) |
| 광고 관리 | 검토 결과(승인) / 검토 결과(반려/코멘트) / 캠페인 지출 한도 도달 시 / 캠페인 예산 도달 시 / 남은 캠페인·광고 그룹 예산 알림 / 잠재고객 상태 변경시 / 대행권 이관 요청 및 해제 알림 (이메일·문자) |
| 홍보성·정보성 알림 수신 | 홍보성 알림 / 정보성 알림 + 톡톡 심야 시간(21시-익일 8시) 정보성 알림 문자 수신 (이메일·문자·톡톡) |

**알아두세요.**

'광고 관리' 그룹은 디스플레이 광고 캠페인의 알림을 설정합니다. 검색광고 캠페인의 광고 관리 알림은 각 광고 계정의 관리 페이지에서 설정하실 수 있습니다.

**참고.**

심야 시간 정보성 알림 문자 수신은 정보성 알림 수신이 활성화되어 있어야 사용할 수 있습니다. 설정 변경에 실패하면 변경 실패 안내가 표시되고 이전 상태로 돌아갑니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
