# [AI작성] 검색광고 변경 이력 관리 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 도구 > 변경 이력 관리\]에서 검색광고의 각종 변경 이력 및 검토 이력을 조회할 수 있습니다. 디스플레이광고의 변경 이력은 별도 화면에서 조회합니다. 페이지에 처음 진입하면 최근 1개월 기간으로 변경 이력이 자동 조회됩니다.

**조회 조건**

조회 조건을 설정한 뒤 \[검색하기\]를 클릭해 결과를 조회합니다.

| **항목** | **설명** |
| --- | --- |
| 조회 기간 | 시작일~종료일을 선택합니다. 기본값은 최근 1개월이며, 이전/다음 기간 버튼으로 기간을 이동할 수 있습니다. |
| 변경 유형 | 기본값은 '모든 변경'입니다. 카테고리를 고른 뒤 세부 이력 유형을 선택할 수 있습니다. 카테고리에는 캠페인·광고그룹·확장 소재·소재·애셋·키워드·전환추적·공유예산·타겟팅·광고노출제한·검토이력·광고중단재개·대상 URL 수집 진단 요청이 있습니다. |
| 캠페인 | 기본값은 '모든 캠페인'입니다. |
| 광고그룹 | 기본값은 '모든 광고그룹'이며, 캠페인을 선택하기 전에는 비활성화됩니다. |
| 대상 ID | 광고계정·캠페인·광고그룹·소재·키워드 ID 등을 직접 입력해 조회할 수 있습니다. |

**변경 이력 목록 구성**

조회 결과 목록은 다음 항목으로 구성되며, 상단 우측에 \[다운로드\]·\[열 맞춤 설정\]·\[변경 내용\] 버튼이 제공됩니다.

| **항목** | **설명** |
| --- | --- |
| 변경일자 | 변경이 발생한 일시입니다. |
| 변경 유형 | 변경 이력의 종류입니다. |
| 변경자 | 변경을 수행한 주체로, 사용자 ID 또는 시스템 변경으로 표시됩니다. |
| 캠페인 | 변경 대상 캠페인명이며, 해당 없으면 '-'로 표시됩니다. |
| 광고그룹 | 변경 대상 광고그룹명이며, 해당 없으면 '-'로 표시됩니다. |
| 변경 내용 | 변경 내용 요약입니다. 상세보기로 변경 전/후 값을 펼쳐 볼 수 있습니다. |

**알아두세요.**

변경 이력은 운영자가 수행한 캠페인·광고그룹·소재·키워드·확장 소재·예산 등의 변경과 검토 결과(승인·반려·재검토)를 모두 포함합니다. 조회된 변경 이력이 없으면 '조회된 변경 이력이 없습니다' 안내가 표시됩니다.

**참고.**

변경 내용 행의 상세보기를 누르면 해당 행 하단에 변경 전/후 값이 펼쳐서 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
