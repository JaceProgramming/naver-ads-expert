# [AI작성] 전체 캠페인 테이블을 조회·정리하고 데이터를 내려받으려면 어떻게 하나요?

전체 캠페인 테이블에서는 필터·상세 데이터·다운로드·열 맞춤 설정 기능으로 캠페인 목록을 원하는 형태로 조회하고 정리할 수 있습니다.

**주요 기능**

| **기능** | **설명** |
| --- | --- |
| 필터 | '필터를 입력해 주세요' 입력란에 조건을 입력해 ON/OFF·광고 구분·캠페인 이름·캠페인 분류·지표 기준으로 목록을 좁힐 수 있습니다. |
| 상세 데이터 | 조회 기간이 7일 이하일 때, 요일·시간대·전환 유형 등 세부 단위로 나눠 데이터를 볼 수 있습니다. |
| 다운로드 | 현재 목록을 엑셀 파일로 내려받습니다. |
| 열 맞춤 설정 | 테이블에 표시할 지표 열을 기본/성과/전환/재생 분류에서 선택해 구성합니다. |

**페이지 표시**

한 페이지에 표시할 행 수는 10·30·50·100·200건 중에서 선택할 수 있으며, 페이지 이동으로 다음 목록을 볼 수 있습니다.

**알아두세요.**

다운로드에 실패하면 '다운로드에 실패했습니다. 잠시 후 다시 시도해 주세요' 안내가 표시됩니다.

**참고.**

조회 기간이 7일을 초과하면 상세 데이터의 세부 분석 항목은 선택할 수 없습니다. 기간을 7일 이하로 조정한 뒤 사용해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
