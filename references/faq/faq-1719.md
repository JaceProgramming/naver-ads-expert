# [AI작성] 디스플레이광고 MAT 연동 정보를 확인하려면 어떻게 하나요?

'MAT 연동' 탭에서는 모바일 앱 분석 도구(MAT, Mobile Attribution Tracker)의 연동 코드 목록을 조회하고 상세 정보를 확인할 수 있습니다. \['도구' > '전환 추적 관리'\] 화면에서 'MAT 연동' 탭을 선택하면 진입합니다.

**목록 구성**

| **컬럼** | **설명** |
| --- | --- |
| MAT 코드 | 연동 코드입니다. 코드를 선택하면 상세 정보 화면으로 이동합니다. |
| MAT 유형 | MAT 서비스 유형입니다. Adjust, AppsFlyer 등이 표시됩니다. |

목록 행 또는 MAT 코드를 선택하면 우측에서 상세 정보 화면이 열려 코드, 유형, 연동 URL, 생성일 등을 확인할 수 있습니다.

**알아두세요.**

새 MAT를 연동하려면 \[전환 Key 생성\]을 사용합니다.

**참고.**

연동된 항목이 없으면 '연동된 MAT가 없습니다' 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
