# [AI작성] 브랜드검색/신제품검색 캠페인 상세 화면에서 무엇을 확인할 수 있나요?

브랜드검색/신제품검색 캠페인 상세 화면에서는 특정 캠페인의 성과 추이와 광고그룹 목록을 확인합니다. 광고그룹은 계약 정보와 함께 표시됩니다.

**화면 구성**

-   경로 표시 \[브랜드검색/신제품검색 > 캠페인 이름\]
    
-   조회 기간 영역
    
-   성과 추이 차트 (노출수·클릭수 등)
    
-   캠페인 정보 카드 (상태·캠페인 유형: '브랜드검색/신제품검색' + \[수정\])
    
-   광고그룹 탭 + \[새 광고그룹\]·\[선택한 광고그룹 관리\]·\[계약 관리\]·\[다운로드\] 액션
    

**광고그룹 테이블 컬럼**

| **컬럼** | **설명** |
| --- | --- |
| ON/OFF | 광고그룹 노출 상태를 켜거나 끕니다. |
| 광고그룹 이름 | 광고그룹 이름이 표시되며 클릭 시 광고그룹 상세로 이동합니다. |
| 상태 | 광고그룹의 현재 운영 상태가 표시됩니다. |
| 계약 이름 | '집행 기간: 미계약' / \[계약하기\] / '연결된 계약: 0건' 형태로 계약 정보가 표시됩니다. |
| 채널 정보 | 연결된 비즈채널 URL이 표시됩니다. |
| 노출수 / 클릭수 / 클릭률(%) | 조회 기간 내 성과 지표입니다. |

**알아두세요.**

브랜드검색/신제품검색은 정해진 기간 동안 정액으로 노출하는 계약형 상품이므로, 평균 클릭비용·총비용·하루예산 항목이 없습니다.

**참고.**

\[계약 관리\]를 클릭하면 \[도구 > 브랜드/신제품검색 계약 관리\] 화면으로 이동합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
