# [AI작성] ADVoost 쇼핑 여러 애셋그룹을 한 번에 관리하려면 어떻게 하나요?

**적용 대상:** 디스플레이광고 > ADVoost 쇼핑 (광고그룹 대신 애셋그룹 사용)

광고주님께서는 여러 애셋그룹을 한 번에 켜거나 끄고, 삭제하거나 내려받으실 수 있습니다. 애셋그룹 목록에서 하나 이상을 선택하면 화면 하단에 일괄 작업 막대가 나타납니다.

**일괄 관리 방법**

1.  캠페인 상세 화면의 애셋그룹 목록에서 관리할 애셋그룹을 선택합니다.
    
2.  화면 하단에 나타나는 일괄 작업 막대에서 원하는 작업을 선택합니다.
    
3.  삭제를 선택하면 확인 안내가 표시되며, 확인하시면 선택한 애셋그룹이 삭제됩니다.
    

**일괄 작업 막대에서 할 수 있는 작업**

| **작업** | **설명** |
| --- | --- |
| \[ON\] | 선택한 애셋그룹을 한 번에 켭니다. |
| \[OFF\] | 선택한 애셋그룹을 한 번에 끕니다. |
| \[삭제\] | 선택한 애셋그룹을 한 번에 삭제합니다. |
| \[다운로드\] | 선택한 애셋그룹 정보를 파일로 내려받습니다. |
| \[닫기\] | 선택을 해제하고 일괄 작업 막대를 닫습니다. |

**주의하세요.**

삭제된 애셋그룹이 선택에 포함된 경우 해당 애셋그룹은 일괄 작업에서 제외됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
