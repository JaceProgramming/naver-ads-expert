# [AI작성] 관리 계정 변경 이력 화면은 어떻게 구성되어 있나요?

관리 계정 변경 이력에서는 관리 계정 단위의 변경 내역을 탭별로 조회할 수 있습니다. 로그인 후 관리 계정을 선택하고 좌측 메뉴에서 도구 > '관리 계정 변경 이력'을 선택해 진입합니다.

**탭 구성**

화면은 다음 두 개의 탭으로 구성되며, 각 탭의 조회 조건은 독립적으로 유지됩니다.

| **탭** | **조회 대상** |
| --- | --- |
| 계정 관리 | 계정명·권한·연동 등 계정 관련 변경 이력 |
| 결제 관리 | 자동결제·결제 수단·세금계산서 등 결제 관련 변경 이력 |

**목록 컬럼**

각 탭의 목록은 다음 6개 컬럼으로 표시됩니다.

| **컬럼** | **설명** |
| --- | --- |
| 변경 일시 | 변경이 발생한 일시입니다. 정렬할 수 있습니다. |
| 구분 | 변경 유형입니다. 컬럼 헤더에서 필터링할 수 있습니다. |
| 발신 | 변경 전 발신 정보입니다. |
| 수신 | 변경 후 수신 정보입니다. |
| 변경 내용 | 변경된 세부 내용입니다. |
| 처리자 | 변경을 처리한 주체입니다. |

**알아두세요.**

기간은 기본 7일 범위로 조회되며, 최대 2년 전까지 조회할 수 있습니다. 2년이 넘는 기간은 날짜 선택이 제한됩니다.

**참고.**

조회 조건에 해당하는 이력이 없으면 '변경 이력이 없습니다.' 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
