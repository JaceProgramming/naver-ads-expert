# 플레이스광고가 노출될 키워드를 선택할 수 있나요?

플레이스광고는 별도의 키워드 등록 없이, 등록된 업체 정보를 활용하여 연관도 높은 키워드를 자동으로 매칭하여 노출합니다.

광고 등록 시 노출 예상 키워드 확인이 가능하며, 실제 노출이 된 이후 노출된 키워드 확인도 가능합니다.

해당 키워드 확인 후 노출을 원치 않은 키워드에 대해서 노출 제외 키워드로 설정하실 수 있습니다.

**참고.**

-   광고그룹 등록 또는 생성 시 제공되는 노출 예상 키워드는 그룹 등록 이후에는 제공되지 않습니다.
    
-   실제 광고가 노출된 키워드는 '제외검색어'를 통해 확인할 수 있습니다.
