# [AI작성] 검색광고 키워드를 켜거나 끄려면 어떻게 하나요?

적용 대상: 파워링크 · 쇼핑검색(쇼핑 브랜드형) · 파워컨텐츠. 키워드 목록에서 각 키워드의 'ON/OFF'를 전환해 노출 상태를 제어합니다(편집 권한 보유자만 사용).

**전환 절차**

1.  광고그룹 상세 '키워드' 탭으로 이동합니다.
    
2.  단건: 키워드 행의 'ON/OFF'를 클릭합니다.
    
3.  일괄: 변경할 키워드를 선택하면 'N개 선택됨' 작업 바가 표시되며 \[ON\]/\[OFF\]를 클릭합니다.
    

**알아두세요.**

키워드를 OFF로 설정하면 노출이 중단됩니다. 캠페인 또는 광고그룹이 OFF 상태이면 키워드를 ON으로 두어도 광고가 노출되지 않습니다. 키워드의 검토 결과는 '검토 상태'에서 확인할 수 있으며(노출가능·검토중 등), 노출이 제한되면 '키워드 노출제한'으로 표시됩니다.

**참고.**

실제 노출 여부는 상위 광고그룹·캠페인 상태, 검토 결과 등에 따라 달라지며 그 사유가 '상태' 열에 표시됩니다. 변경에 실패하면 안내가 표시되고 원래 값으로 돌아오니 잠시 후 다시 시도해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
