# [AI작성] 디스플레이광고 여러 소재를 한 번에 관리하려면 어떻게 하나요?

**적용 대상:** 디스플레이광고(웹사이트 전환·앱 전환·인지도 및 트래픽·동영상 조회·카탈로그 판매·쇼핑 프로모션·참여 유도)

광고그룹 상세 화면의 소재 목록에서 여러 소재를 선택하면, 선택한 소재를 한 번에 켜고 끄거나 삭제할 수 있습니다.

**일괄 관리 방법**

1.  광고그룹 상세 화면의 소재 목록에서 관리할 소재를 1개 이상 선택합니다.
    
2.  1개 이상 선택하면 하단에 일괄 작업 버튼이 나타납니다.
    
3.  원하는 작업을 실행합니다.
    

| **버튼** | **동작** |
| --- | --- |
| \[ON\] | 선택한 소재를 일괄 활성화합니다. |
| \[OFF\] | 선택한 소재를 일괄 일시정지합니다. |
| \[삭제\] | 선택한 소재를 일괄 삭제합니다. |
| \[다운로드\] | 선택한 소재를 파일로 내려받습니다. |
| \[닫기\] | 선택을 해제하고 일괄 작업 영역을 닫습니다. |

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
