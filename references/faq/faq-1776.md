# [AI작성] 광고 계정의 권한 관리 화면은 어떻게 구성되어 있나요?

광고 계정의 회원 권한, 관리 계정 연동, 대행권 이관을 \[광고주센터 > 우측 상단 네이버 ID > 광고 계정 관리 > 광고 계정 클릭 > 설정 > 권한 관리\]에서 통합 관리할 수 있습니다. 화면 상단의 탭으로 영역을 전환합니다.

**1차 탭 구성**

| **탭** | **내용** |
| --- | --- |
| 회원 관리 | 광고 계정에 권한이 부여된 회원과 초대 중인 회원을 관리합니다. 하위 탭으로 '권한 받은 회원'과 '초대 중인 회원'이 있습니다. |
| 관리 계정 연동 | 광고 계정과 연동된 관리 계정을 조회·관리합니다. |
| 대행권 이관 관리 | 광고 운영을 파트너사에 위임하는 대행권 이관을 관리합니다. |

**권한 레벨**

회원에게 부여되는 권한 레벨은 다음 세 가지입니다.

| **권한 레벨** | **설명** |
| --- | --- |
| 계정 책임자 | 광고 계정을 대표하는 권한으로, 계정당 1명입니다. 회원 초대·권한 수정 시 직접 선택할 수 없으며 계정 책임자 이전으로만 부여됩니다. |
| 운영 관리 | 회원 관리, 광고 관리, 충전 및 환불 요청, 보고서 조회 등을 수행합니다. |
| 운영 조회 | 등록된 광고와 지표 확인, 보고서 조회를 할 수 있습니다. |

**권한 받은 회원 목록**

'권한 받은 회원' 탭의 목록은 회원 ID / 권한 레벨 / 가입 일자 / 회원 상태 / 관리 항목으로 구성되며, '관리'에서 권한 수정·해제 또는 권한 이전을 할 수 있습니다.

**알아두세요.**

각 작업의 상세 절차는 회원 초대, 권한 수정·해제, 계정 책임자 이전, 관리 계정 연동, 대행권 이관 도움말을 참고해 주시기 바랍니다.

**참고.**

권한 변경은 계정 보안에 영향을 주는 작업입니다. 부여 범위를 확인한 뒤 진행해 주시기 바랍니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
