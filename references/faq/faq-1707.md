# [AI작성] 디스플레이광고 시너지 상세 보고서 화면 안내

**화면 구성**

시너지 상세 보고서 화면은 브랜드서치 시너지 데이터를 조회하고 분석하는 화면입니다. 시너지 보고서 목록에서 캠페인 행을 클릭하면 진입하며, 화면은 위에서부터 조회 조건 영역, 시너지 차트 영역, 시너지 데이터 테이블 영역 순으로 구성됩니다.

| **영역** | **설명** |
| --- | --- |
| 조회 조건 | 조회 기간과 캠페인을 설정하고 \[확인\]을 실행하는 영역입니다. 캠페인 선택은 필수입니다. |
| 시너지 차트 | 브랜드서치 시너지 효과를 시계열 선 차트로 시각화합니다. 좌측 축은 디스플레이광고 지표, 우측 축은 브랜드서치 지표로 표시되는 양축 차트입니다. |
| 시너지 데이터 테이블 | 일별 시너지 상세 데이터를 표 형태로 제시합니다. 데이터 다운로드를 지원합니다. |

**데이터 제공 기준**

시너지 데이터는 브랜드서치 캠페인 데이터를 기반으로 산정됩니다. 캠페인에 확인하고자 하는 지정 키워드를 설정하고 총비용 조건을 충족하면 데이터가 제공됩니다.

**알아두세요.**

조회 기간은 최대 84일까지 설정할 수 있으며, 선택한 기간은 주 단위로 자동 변환되어 분석됩니다.

**참고.**

차트와 데이터 테이블은 조회를 실행하여 데이터가 존재할 때 표시됩니다. 조회 결과가 없으면 '조회 결과가 없습니다' 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
