# [AI작성] 디스플레이광고 성과 보고서를 조회하려면 어떻게 하나요?

**디스플레이광고 성과 보고서 조회**

성과 보고서는 조회 조건을 설정한 뒤 조회를 실행하면 분석 단위별 성과 데이터를 표 형태로 보여줍니다. \[광고주센터 > 디스플레이광고 > 보고서 > 성과 보고서\]에서 '성과 보고서' 행을 클릭해 상세 화면으로 이동합니다.

**조회 절차**

1.  조회 조건 영역에서 조회 기간을 선택합니다. 기본값은 최근 7일(오늘 제외)입니다.
    
2.  분석 단위를 선택합니다. '광고 계정', '캠페인', '광고 그룹', '애셋 그룹', '광고 소재' 중에서 선택할 수 있습니다.
    
3.  기간 단위를 '전체', '일', '주', '월', '시간' 중에서 선택합니다. 기본값은 '일별'입니다.
    
4.  게재 위치를 '전체', '매체 그룹', '매체 그룹 및 게재 위치' 중에서 선택합니다. 기본값은 '전체'입니다.
    
5.  오디언스 세그먼트를 '전체', '연령', '성별', '연령 및 성별', '기기', '기기 및 OS' 중에서 선택합니다. 기본값은 '전체'입니다.
    
6.  \[확인\]을 클릭하면 설정한 조건으로 데이터가 표시됩니다.
    

조회 결과 표에는 노출·클릭·CTR·CPC·광고비·전환 등 분석 단위별 지표가 표시되며, 한 페이지에 10건씩 나누어 표시됩니다. 결과가 10건을 초과하면 페이지 이동으로 나머지를 확인합니다.

**분석 단위 변경 시 안내**

이미 필터를 설정한 상태에서 분석 단위를 변경하면 **'필터가 삭제됩니다. 분석 단위가 변경되어 기존 분석 단위에서 설정한 필터는 삭제됩니다.'**라는 안내가 표시됩니다. \[변경\]을 누르면 기존 필터가 초기화된 상태로 분석 단위가 바뀝니다. 설정된 필터가 없으면 안내 없이 바로 변경됩니다.

**참고.**

조회 조건에 해당하는 데이터가 없으면 데이터 없음 안내가 표시됩니다. 이 경우 조회 조건을 변경해 다시 조회해 주세요.

**주의하세요.**

조회 기간이 비어 있으면 \[확인\] 버튼이 비활성화됩니다. 날짜를 선택한 뒤 조회해 주세요. 조회 기간은 분석 기간 단위에 따라 선택 가능한 최대 범위가 제한됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
