# [AI작성] 디스플레이광고 상품 성과 보고서를 조회하려면 어떻게 하나요?

**디스플레이광고 상품 성과 보고서**

상품 성과 보고서는 상품별 노출·클릭·전환 등의 성과를 보여줍니다. \[광고주센터 > 디스플레이광고 > 보고서 > 성과 보고서\]에서 '상품 성과 보고서' 행을 클릭해 상세 화면으로 이동합니다.

**조회 절차**

1.  조회 기간을 선택합니다. 기본값은 최근 7일(오늘 제외)입니다.
    
2.  그룹핑 기준(일별·캠페인별·광고그룹별·소재별)을 선택합니다. 기본값은 '일별'입니다.
    
3.  캠페인 목적 필터를 선택합니다. 기본값은 '전체'입니다.
    
4.  \[확인\]을 클릭하면 데이터가 표시됩니다.
    

표 상단에는 총 비용·클릭수·평균 CPC·총 전환율(%) 등 전체 합산·평균 지표가 요약행으로 고정 표시됩니다. 데이터가 많은 경우 표를 아래로 스크롤하면 다음 데이터가 이어서 자동으로 불러와집니다.

**상품 성과 보고서 조회 기간**

상품 성과 보고서는 31일 이내 기간만 화면상에서 즉시 조회할 수 있습니다.

만약 31일을 초과하는 기간의 데이터가 필요하시다면, 보고서 다운로드를 통해 확인하실 수 있으므로 보다 자세한 데이터 조회가 필요하신 경우, 보고서 다운로드를 통해 데이터를 가공하여 활용하시도록 권장드립니다.

**참고.**

조회 결과가 없으면 데이터 없음 안내가 표시됩니다. 이때는 요약행과 다운로드 버튼이 표시되지 않으며, 조회 조건을 변경해 다시 조회해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
