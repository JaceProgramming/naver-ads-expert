# [AI작성] ADVoost 쇼핑 캠페인 설정에서 전환 추적·입찰·예산을 지정하려면 어떻게 하나요?

ADVoost 쇼핑 캠페인 설정에서는 전환 추적, 입찰 전략, 예산을 지정합니다. 광고에 노출할 상품의 출처와 광고비 사용 방식을 결정하는 핵심 단계입니다.

**설정 항목**

| **항목** | **설명** |
| --- | --- |
| 대표 URL | 대표 URL로 선택된 비즈 채널에 인증된 네이버 쇼핑몰의 상품 정보를 활용하여 광고가 집행됩니다. |
| 전환 추적 대상 | 전환을 측정할 대상을 선택합니다. '소재 랜딩 URL의 도메인이 전환 추적 대상의 도메인과 일치하는지 확인해 주세요.' |
| 최적화 전환 유형 | '구매완료' 유형으로 고정 선택됩니다. |
| 입찰 전략 | '전환 가치 최대화'로 고정 선택됩니다. |
| 예산 | 하루예산을 설정합니다. |

**설정 방법**

1.  대표 URL로 사용할 비즈채널을 선택합니다.
    
2.  전환 추적 대상을 선택합니다.
    
3.  입찰 전략을 선택하고 예산을 입력한 뒤 \[다음\]을 클릭합니다.
    

**알아두세요.**

비즈채널이 검토 대기 상태이면 \[다음\] 버튼이 비활성화됩니다. 검토가 완료된 후 진행해 주시기 바랍니다.

**참고.**

예산이 너무 작을 경우 자동입찰 머신러닝에 필요한 학습이 충분히 이루어지지 않을 수 있습니다. 적절한 예산을 설정해 주세요.

**주의하세요.**

입찰 자동화 관련 안내입니다.

본 캠페인은 성과 최적화를 위해 매체별로 광고에 적합한 유저를 찾고 최적의 입찰가를 자동 산정합니다.

자동 입찰은 설정된 예산 내에서 목표 결과 최대화를 위해 입찰가를 자동으로 관리하지만 모든 경우에서의 성과 향상을 보장하지는 않습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
