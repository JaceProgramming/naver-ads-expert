# 브랜드검색 집행중에 키워드를 추가하면, 추가한 키워드로는 언제까지 노출되나요?

브랜드검색 광고 집행 중 키워드를 추가하는 경우, 키워드 검토가 통과된 시점부터 광고 노출이 가능하며 해당 계약에 설정된 광고 노출 종료일까지 광고로 노출이 가능합니다.

예시.

광고노출 기간(계약기간) : 8월 1일 ~10월 31일

키워드 추가/검토 통과 : 8월 10일

추가 키워드 광고노출 기간 : 8월 10일 ~ 10월 31일
