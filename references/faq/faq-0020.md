# 초대 받은 관리 계정은 어디서 확인하나요?

광고주센터 > 계정 관리 > 관리 계정 관리 > 초대 받은 관리 계정의 ‘초대 받은 관리 계정‘ 목록에서 관리 계정에 초대된 내역을 확인할 수 있습니다.

**목록 컬럼 안내**

| **컬럼** | **설명** |
| --- | --- |
| 관리 계정(ID) | 초대한 관리 계정 이름과 ID |
| 권한 레벨 | 초대 시 부여된 권한 ('운영 관리' / '운영 조회') |
| 초대 일자 | 초대받은 날짜 |
| 관리 | \[수락\] / \[거절\] 버튼 |

| **알아두세요.** \[수락\]을 선택해 초대를 수락하면 관리 계정 탭으로 이동합니다. 받은 초대가 없으면 "초대 받은 관리 계정이 없습니다." 메시지가 표시됩니다. |
| --- |

목록 우측 관리의 \[ 거절 \] 및 \[ 승인 \] 버튼을 눌러 초대를 승인하거나 거절할 수 있습니다.

관리 계정 초대는 30일간 유효하며, 초대를 보낸 일자로부터 30일이 경과하는 경우 초대가 자동으로 취소되어 ‘초대 받은 관리 계정’ 목록에서 더 이상 표시되지 않습니다.

초대가 취소되거나, 또는 초대를 직접 거절한 경우에도 해당 관리 계정으로부터 다시 초대를 받을 수 있는 점 참고 부탁드립니다.
