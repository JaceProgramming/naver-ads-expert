# [AI작성] 검색광고 키워드를 추가하려면 어떻게 하나요?

적용 대상: 파워링크 · 쇼핑검색(쇼핑 브랜드형) · 파워컨텐츠. 광고그룹 상세 '키워드' 탭에서 \[새 키워드\]를 클릭하면 광고가 노출될 키워드를 추가할 수 있습니다.

**키워드 추가 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리\]에서 광고그룹 이름을 클릭해 상세로 이동합니다.
    
2.  '키워드' 탭에서 \[새 키워드\]를 클릭합니다.
    
3.  좌측 '키워드 추가하기'에 직접 입력하거나, 우측 연관 키워드 영역에서 선택해 추가합니다. '선택한 키워드(N / 100)'에 한 번에 최대 100개까지 담을 수 있습니다.
    
4.  필요 시 키워드별 개별 입찰가를 설정합니다(미설정 시 광고그룹 기본 입찰가 적용).
    
5.  \[저장하고 계속하기\]를 클릭해 등록합니다.
    

**캠페인 유형별 키워드의 의미**

같은 '키워드 추가' 기능이지만 캠페인 유형에 따라 키워드 작동 방식이 다릅니다.

| **캠페인 유형** | **키워드의 의미** |
| --- | --- |
| 파워링크 | 사용자가 검색한 검색어와 매칭되어 통합검색 등에 광고가 노출됩니다. |
| 쇼핑검색(쇼핑 브랜드형) | 쇼핑 브랜드 광고가 노출될 검색어로, 키워드별 입찰가와 품질지수가 적용됩니다. |
| 파워컨텐츠 | 콘텐츠 매칭(타겟팅)에 사용되는 키워드로, 관련 콘텐츠 지면에 광고가 노출됩니다. |

**키워드 추가 방법**

| **방법** | **설명** |
| --- | --- |
| 직접 입력 | 키워드를 한 줄에 하나씩 직접 입력합니다. 허용되지 않는 특수문자는 사용할 수 없습니다. |
| 연관 키워드 | \[광고그룹기준 연관키워드\] / \[키워드기준 연관키워드\]에서 추천 키워드를 선택해 추가합니다. 키워드별 월간 검색수(PC/모바일)가 표시됩니다. |

**알아두세요.**

키워드는 한 번에 최대 100개, 광고그룹당 최대 1,000개까지 등록할 수 있으며, 이미 등록된 키워드는 중복 추가할 수 없습니다. 광고법규·운영정책에 어긋나는 키워드는 검토 단계에서 노출이 제한될 수 있습니다.

**참고.**

더 다양한 연관 키워드는 \[키워드 도구\]에서 확인하고, \[추가 실적 예상하기\]로 예상 실적을 확인할 수 있습니다. 연관 키워드가 없으면 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
