# [AI작성] 디스플레이광고 여러 캠페인을 한 번에 관리하려면 어떻게 하나요?

**적용 대상:** 디스플레이광고(웹사이트 전환·앱 전환·인지도 및 트래픽·동영상 조회·ADVoost 쇼핑·카탈로그 판매·쇼핑 프로모션·참여 유도)

여러 캠페인을 선택하면 화면 하단에 일괄 작업 영역이 나타나, 선택한 캠페인을 한 번에 켜거나 끄고 삭제할 수 있습니다. 일괄 관리는 디스플레이광고 8개 목적에서 동일하게 제공됩니다.

**일괄 관리 방법**

1.  '광고 관리'에서 해당 캠페인 목적의 캠페인 목록을 엽니다.
    
2.  관리할 캠페인을 1개 이상 선택합니다. 머리글의 전체 선택을 사용하면 한 번에 선택할 수 있습니다.
    
3.  1개 이상 선택하면 하단에 '몇 개 선택됨' 표시와 함께 일괄 작업 버튼이 나타납니다.
    
4.  원하는 작업 버튼을 선택해 실행합니다.
    

**일괄 작업 종류**

| **버튼** | **동작** |
| --- | --- |
| \[ON\] | 선택한 캠페인을 일괄 활성화합니다. |
| \[OFF\] | 선택한 캠페인을 일괄 일시정지합니다. |
| \[삭제\] | 선택한 캠페인을 일괄 삭제합니다. 삭제 전 '선택한 캠페인을 삭제하시겠습니까?' 확인 안내가 표시됩니다. |
| \[다운로드\] | 선택한 캠페인을 파일로 내려받습니다. |
| \[닫기\] | 선택을 해제하고 일괄 작업 영역을 닫습니다. |

**참고.**

일부 캠페인만 처리에 성공한 경우, 성공·실패 건수가 안내되고 목록이 갱신됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
