# 비즈채널 상태는 어떻게 확인하나요?

등록한 비즈채널 상태는 \[구성요소 관리 > 비즈채널 메뉴에서 확인할 수 있습니다.

조회하는 방법 및 각 상태의 의미는 아래와 같습니다.

---

**비즈채널 조회하기**

광고시스템의 \[구성요소 관리 > 비즈채널\] 메뉴의 첫 화면에서 등록된 비즈채널의 유형, 정보, 상태를 조회할 수 있습니다.

-   **ID 포함 정보 조회**
    
-   목록 오른쪽 위의 \[열 맞춤 설정\] 드롭다운 목록 상자에서 조회할 수 있습니다.
    

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfNDMg/MDAxNzc0OTIyNzkyMDE5.BSTdaTugzKNdGrpBaujb8sD7K66Cd-KvGElXkAzXVqYg.frDyacm6tBgHnsMwf0_5OgIkcxZOi35v9o_IclWcZpsg.PNG/image.png)

-   또한, 드롭다운 목록 상자에서 \[열 맞춤 설정\]을 클릭하면 \[열 맞춤 설정\] 대화 상자가 나타납니다. \[열 맞춤 설정\] 대화 상자의 왼쪽 영역에서 원하는 항목의 확인란을 선택하거나 선택을 해제하면 조회할 항목을 추가하거나 제외할 수 있습니다. 대화 상자 오른쪽 영역에서 선택된 항목을 끌어다 놓아 항목 노출 순서를 변경할 수 있습니다. 또한 대화 상자의 왼쪽 위에서 열 설정 이름을 설정할 수 있습니다. 열 맞춤 설정은 최대 5개까지 등록 가능합니다. 등록된 사용자 설정은 \[열 맞춤 설정\] 드롭다운 목록 상자에서 바로 클릭하여 사용할 수 있습니다.
    

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMzQg/MDAxNzc0OTIyNzk3OTU2.aANdWoTPnj9mUxbqorellF7uE-JP5dkuSHDt0oWv3O8g.udWjTaUSCAuPjAjLeEXSXEK79WSF0KqBi05YuDAm9osg.PNG/image.png)

-   **필터로 조회**
    
-   비즈채널 목록 오른쪽 위의 \[필터\] 드롭다운 목록 상자에서 \[새 필터 만들기\]를 클릭하면 필터를 설정할 수 있는 영역이 나타납니다. 원하는 조건을 설정하여 비즈채널을 조회할 수 있으며, \[추가\] 버튼을 클릭하면 필터를 추가할 수 있습니다. 또한 \[필터 저장\] 버튼을 클릭하면 현재 설정된 필터를 저장할 수 있습니다. 저장된 필터는 \[필터\] 드롭다운 목록 상자에서 바로 클릭하여 사용할 수 있습니다.
    

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMzFfMTAg/MDAxNzc0OTIyODAzNDY5.z4cajHmAV-n6JnE1VstoWgsVSEl34e5WPmATIPHf2tIg.LtyzatLMNd5Ox1VepK2asPHdVYV_O0OVpV1qfIAVbIAg.PNG/image.png)

**비즈채널의 상태 이해하기**

채널 유형별 상태는 아래와 같이 표시됩니다.

-   **웹 사이트**
    
    -   검토 중: 사이트의 검토가 진행 중인 상태입니다.
        
    -   노출 가능: 사이트 검토 결과, 등록 기준에 부합하여 사이트 노출이 가능한 상태입니다.
        
    -   노출 제한: 사이트 검토 결과, 등록 기준에 부합되지 않아 사이트 노출이 제한된 상태입니다.
        
-   **쇼핑몰**
    
    -   검토중: 해당 비즈채널(쇼핑몰)이 검토 중인 상태입니다.
        
    -   노출가능 : 비즈채널(쇼핑몰) 검토결과, 등록 기준에 부합하여 노출이 가능한 상태입니다.
        
    -   노출제한 : 비즈채널(쇼핑몰) 검토결과, 등록 기준에 부합되지 않아 노출이 제한된 상태입니다.
        
    -   노출제한(연결안됨): 네이버 쇼핑의 계정 상태가 서비스 중이 아니어서(가퇴점, 완전퇴점 상태 등), 검색광고와의 연결이 안된 상태입니다. 이 경우 광고 노출이 제한됩니다.
        
-   **전화번호**
    
    -   검토 중: 전화번호의 검토가 진행 중인 상태입니다.
        
    -   노출 가능: 전화번호 검토 결과 등록 기준에 부합하여 노출이 가능한 상태입니다.
        
    -   노출 제한: 전화번호 검토 결과 등록 기준에 부합되지 않아 노출이 제한된 상태입니다.
        
-   **위치정보 - 위치정보 비즈채널은 24년 11월 25일 이후 '노출 제한' 상태로 일괄 변경되었습니다. (**[관련공지](https://ads.naver.com/notice/17529)**)**
    
    -   검토 중: 위치정보의 검토가 진행 중인 상태입니다.
        
    -   노출 가능: 위치정보 검토 결과 등록 기준에 부합하여 노출이 가능한 상태입니다.
        
    -   노출 제한: 위치정보 검토 결과 등록 기준에 부합되지 않아 노출이 제한된 상태입니다.
        
-   **네이버 예약**
    
    -   검토 중: 네이버 예약의 연동 신청이 진행 중인 상태입니다.
        
    -   노출 가능: 네이버 예약의 연동이 완료되어 노출이 가능한 상태입니다.
        
    -   노출 제한: 네이버 예약 URL 검토 결과 등록 기준에 부합되지 않아 노출이 제한된 상태입니다.
        
    -   노출 제한(연결 안 됨): 네이버 예약이 'OFF' 상태이거나 삭제된 경우 등 네이버 예약 서비스의 사유로 검색광고와 연결되지 않은 상태입니다. 자세한 내용은 [네이버 예약 파트너센터](https://easybooking.naver.com/)에서 확인할 수 있습니다.
        
-   **네이버 톡톡**
    
    -   검토 중: 네이버 톡톡 계정의 연동 신청이 진행 중인 상태입니다.
        
    -   노출 가능: 네이버 톡톡 계정의 연동이 완료되어 노출이 가능한 상태입니다.
        
    -   노출 제한: 네이버 톡톡 계정 검토 결과 등록 기준에 부합되지 않아 노출이 제한된 상태입니다.
        
    -   노출 제한(연결 안 됨) : 네이버 톡톡 계정이 'OFF' 상태이거나 삭제된 경우 등 네이버 톡톡 서비스의사유로 검색광고와 연결되지 않은 상태입니다. 자세한 내용은 [네이버 톡톡 파트너센터](https://partner.talk.naver.com/)에서 확인할 수 있습니다.
        

**Tip.**

-   ‘노출 제한’ 상태를 클릭하면 노출 제한 상세 사유를 설명하는 대화 상자가 나타납니다.
    
-   ‘노출 제한’, ‘모바일 최적화 미인증’ 상태인 경우 \[재검토 요청\] 버튼을 클릭하여 재검토를 요청할 수 있습니다.
