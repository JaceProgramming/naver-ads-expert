# 노출 영역이란 무엇인가요?

노출 영역이란 광고가 실제로 고객 화면에 표시되는 위치(장소)를 의미합니다.

스마트스토어 광고는 AI가 내 상품 중 매출이 극대화될 수 있는 상품을 자동으로 선별하여 네이버 서비스 광고 지면 곳곳에 내 상품을 자동으로 노출해 줍니다.

**노출될 광고 소재는 만들지 않아도 되나요?**

AI가 각 지면에 맞게 광고 소재를 만들어주기 때문에 판매자가 직접 광고 콘텐츠나 문구를 만드실 필요가 없습니다.

검색 지면의 경우에는 상품 리스트 형식으로 소재를 만들어 주고 각 서비스에 자연스러운 콘텐츠처럼 보여지는 콘텐츠 지면의 경우에는 4개 상품이 보여지는 타일 형과 최대 10개 상품이 제공되는 캐로셀 형식 등으로 보여지게 됩니다.

**어디에 노출되나요?**

판매자님의 상품이 최고의 성과를 낼 수 있는 지면에 AI가 자동으로 광고를 생성하여 노출합니다.

검색 영역뿐 아니라 콘텐츠가 추천되는 네이버 서비스 곳곳에 내 상품이 광고됩니다.
