# [AI작성] 관리 계정 정보를 확인하고 이름을 변경하려면 어떻게 하나요?

관리 계정 정보 화면에서 관리 계정의 기본 정보를 확인하고 이름을 변경할 수 있습니다. 로그인 후 관리 계정을 선택하고 좌측 메뉴에서 설정 > '관리 계정 정보'를 선택해 진입합니다.

**표시 정보**

| **항목** | **설명** |
| --- | --- |
| 관리 계정 이름 | 관리 계정의 표시 이름입니다. \[정보 변경\]으로 수정할 수 있습니다. |
| 관리 계정 ID | 관리 계정 식별자입니다. 읽기 전용으로 표시됩니다. |

**이름 변경 방법**

1.  \[정보 변경\]을 선택하면 관리 계정 이름 입력 필드가 활성화됩니다.
    
2.  새 이름을 1~50자로 입력합니다.
    
3.  \[저장\]을 선택하면 변경이 적용됩니다.
    

**알아두세요.**

변경된 이름은 연동된 광고 계정과 메뉴 표시에 반영됩니다. \[정보 변경\]은 권한이 있는 회원에게만 활성화됩니다.

**주의하세요.**

이름이 비어 있으면 '필수 입력값입니다.', 사용할 수 없는 문자가 포함되면 '사용이 불가능한 특수문자가 포함되어 있습니다.' 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
