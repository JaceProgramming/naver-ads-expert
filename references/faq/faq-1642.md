# [AI작성] 키워드의 검색 사용자 통계를 차트로 확인하려면 어떻게 하나요?

\[광고주센터 > 검색광고 > 도구 > 키워드 도구\]에서 키워드를 선택한 뒤 \[월간 예상 실적 보기\]를 클릭하면 '월간 예상 실적' 화면이 열립니다. 입찰가 변화에 따른 예상 노출수 차트와 예상 클릭수·비용 등의 통계를 확인할 수 있습니다.

**확인 절차**

1.  \[광고주센터 > 검색광고 > 도구 > 키워드 도구\]에 진입합니다.
    
2.  키워드를 입력해 \[조회하기\]를 클릭하고 결과 표에서 키워드를 선택(\[추가\] 또는 \[전체추가\])합니다.
    
3.  화면 우측의 '선택한 키워드 N/100' 영역에서 \[월간 예상 실적 보기\]를 클릭합니다.
    
4.  '월간 예상 실적' 화면에서 입찰가 / 매체구분(PC/모바일) 등을 설정하고 \[조회하기\]를 클릭합니다.
    
5.  차트와 표에서 예상 통계를 확인합니다.
    

-   차트: 예상 노출수 그래프 (가로축=입찰가, 세로축=노출수). 그래프 마우스 오버하면 '입찰가: NNN / 노출수: NNN'이 표시됩니다.
    
-   표: 컬럼은 '키워드 / 입찰가 / 예상 노출수 / 예상 클릭수 / 예상평균클릭 비용 (VAT제외) / 예상 광고비'
    

1.  필요 시 \[다운로드\]로 결과를 내려받거나 \[선택 키워드 등록하기\]로 광고그룹에 바로 등록합니다. \[선택 키워드 제외\]로 키워드를 제외할 수 있습니다.
    
2.  키워드 도구로 돌아가려면 \[돌아가기\]를 클릭합니다.
    

**알아두세요.**

조회되는 모든 예상 실적(예상 노출수·예상 클릭수·예상 평균클릭비용·예상비용)은 파워링크 캠페인을 통해 광고 집행된 키워드의 과거 데이터를 기반으로 예측한 값으로, 현재와 미래의 광고 성과나 발생 비용을 보장하지 않습니다. 제공되는 모든 예상 데이터는 참고 용도로 사용하시기 바랍니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
