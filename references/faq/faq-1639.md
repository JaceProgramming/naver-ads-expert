# [AI작성] 검색광고 키워드 도구 화면은 어떻게 구성되어 있나요?

\[광고주센터 > 검색광고 > 도구 > 키워드 도구\]에서 '파워링크 캠페인'에 사용할 새로운 키워드(연관키워드)를 발굴하고, 검색·클릭 지표를 확인해 광고그룹에 바로 추가할 수 있습니다.

**화면 구성**

| **영역** | **설명** |
| --- | --- |
| 연관키워드 조회 기준 | 화면 상단 영역입니다. 키워드·웹사이트·업종·시즌 월·시즌 테마 조건을 설정해 조회하며(다중선택 가능), \[접기\]로 접을 수 있습니다. |
| 연관키워드 조회 결과 | 조회 기준 하단의 결과 표입니다. 연관키워드와 PC·모바일로 구분된 지표를 표시하며, \[전체추가\]로 결과 키워드를 선택 목록에 담을 수 있습니다. |
| 선택한 키워드 | '선택한 키워드 N/100' 영역입니다. 담은 키워드를 모아 관리하고 광고그룹에 한 번에 추가합니다. |

**조회 결과 표의 항목**

| **항목** | **설명** |
| --- | --- |
| 연관키워드 | 발굴된 키워드명입니다. |
| 월간검색수 (PC / 모바일) | 월평균 검색수입니다. 10 미만은 '< 10'으로 표기됩니다. |
| 월평균클릭수 (PC / 모바일) | 월평균 클릭수입니다. |
| 월평균클릭률 (PC / 모바일) | 월평균 클릭률(%)입니다. |
| 경쟁정도 | 키워드 경쟁 지수입니다. |
| 월평균노출광고수 | 해당 키워드에 월평균 노출되는 광고 수입니다. |

각 지표 열은 정렬할 수 있고, 결과 위의 '필터를 입력해 주세요' 입력란으로 목록을 좁힐 수 있습니다. \[전체 다운로드\]로 결과를 Excel 파일로 받을 수 있으며, \[지우기\]·\[바로추가\]·\[월간 예상 실적 보기\] 버튼으로 선택한 키워드를 관리합니다.

**알아두세요.**

키워드 도구의 연관키워드 조회와 키워드 추가는 '파워링크 캠페인' 유형에 한해 지원됩니다.

**참고.**

연관키워드는 과거 데이터를 기반으로 추출된 통계 결과로, 실제 광고 성과나 광고 검토 통과를 보장하지 않습니다. 키워드 선택에 대한 법적 책임은 광고주에게 있습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
