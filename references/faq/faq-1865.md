# [AI작성] 동영상 조회 캠페인에서도 캠페인 예산 최적화(CBO)를 사용할 수 있나요?

동영상 조회 캠페인은 캠페인 예산 최적화(CBO)를 지원하지 않습니다. 따라서 동영상 조회 캠페인을 만들 때에는 캠페인 단계에서 예산 최적화 설정 영역이 노출되지 않습니다.

**캠페인 예산 최적화(CBO)를 사용할 수 있는 목적**

캠페인 예산 최적화는 아래 목적의 캠페인에서만 사용할 수 있습니다.

| **목적** | **CBO 사용 여부** |
| --- | --- |
| 웹사이트 전환 | 사용 가능 |
| 앱 전환 | 사용 가능 |
| 인지도 및 트래픽 | 사용 가능 |
| 쇼핑 프로모션 | 사용 가능 |
| 참여 유도 | 사용 가능 |
| 동영상 조회 | 사용 불가 |

동영상 조회 캠페인에서는 캠페인 단위로 예산을 자동 배분하는 대신, 광고 그룹 단계에서 입찰 전략과 예산을 직접 설정하여 운영합니다.

**참고.**

캠페인 예산 최적화는 하나의 캠페인 예산을 성과가 좋은 광고 그룹에 자동으로 배분하는 기능입니다. 동영상 조회 외에 카탈로그 판매, ADVoost 쇼핑 목적도 캠페인 예산 최적화를 지원하지 않습니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
