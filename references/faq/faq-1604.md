# [AI작성] 검색광고 확장 소재를 등록하려면 어떻게 하나요?

**적용 대상:** 파워링크 · 쇼핑검색 · 플레이스

광고그룹 상세 \[확장 소재\] 탭에서 \[새 확장 소재\]를 클릭하면 광고에 추가 정보를 제공하는 확장 소재를 등록할 수 있습니다. 유형을 선택하면 '새 확장 소재 추가 ({유형명})' 창이 열리며, 유형에 맞는 정보를 입력해 등록합니다.

**등록 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리\]에서 광고그룹 이름을 클릭해 광고그룹 상세로 이동합니다.
    
2.  \[확장 소재\] 탭에서 \[새 확장 소재\]를 클릭합니다.
    
3.  등록 가능한 확장 소재 유형 목록(웹사이트정보·쇼핑정보·전화번호·네이버 예약·톡톡 상담·계산·추가제목·추가설명·홍보문구·서브링크·파워링크 이미지·이미지형 서브링크·플레이스 정보·홍보 영상·블로그 리뷰)에서 등록할 유형을 클릭합니다.
    
4.  유형에 맞는 정보를 입력합니다. 입력 방식은 유형에 따라 다릅니다.
    
5.  필요 시 \[고급옵션\]에서 노출 요일·시간과 노출 기간을 설정합니다.
    
6.  \[저장\]을 클릭해 확장 소재를 등록합니다.
    

**유형별 입력 방식**

| **입력 방식** | **설명** |
| --- | --- |
| 텍스트 입력 | 추가제목·추가설명·홍보문구 등 텍스트를 직접 입력합니다. 유형별로 최대 글자 수가 다릅니다. |
| URL 입력 | 서브링크·이미지형 서브링크 등 제목과 URL을 입력합니다. |
| 비즈채널 선택 | 전화번호·네이버 예약·플레이스 정보 등 사전에 등록된 비즈채널을 선택합니다. 비즈채널이 없으면 먼저 등록해야 합니다. |
| 이미지·동영상 | 파워링크 이미지·이미지형 서브링크·홍보 영상 등은 이미지 또는 동영상을 등록합니다. |

**고급옵션**

| **항목** | **설명** |
| --- | --- |
| 노출 요일/시간 | 모든 요일·시간에 노출하거나 특정 요일·시간대를 지정합니다. |
| 노출 기간 | 계속 노출하거나 시작일·종료일을 지정합니다. |

**알아두세요.**

등록된 확장 소재는 검토(영업일 기준 1~2일)를 거친 후 광고에 함께 노출됩니다. 비즈채널 연동 유형은 비즈채널이 먼저 등록되어 있어야 합니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
