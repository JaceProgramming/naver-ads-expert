# [AI작성] 광고 계정의 비즈머니 이용 내역을 조회하려면 어떻게 하나요?

비즈머니 관리 화면 하단에서 충전·소진·환불 등 비즈머니 이용 내역을 8개 탭으로 구분하여 조회할 수 있습니다.

\[광고주센터 > 우측 상단 네이버 ID > 광고 계정 관리 > 광고 계정 클릭 > 결제 > 비즈머니 관리\]에서 확인합니다.

**조회 탭**

'기간별 내역' / '소진 내역' / '충전 내역' / '환불 내역' / '환급 내역' / '(기존) 소진 내역' / '(기존) 충전 내역' / '(기존) 환불 내역' 8개 탭으로 구분됩니다. (기존) 탭은 디스플레이 광고 기준 과거 내역입니다.

**조회 방법**

1.  월별 또는 일별 단위를 선택합니다.
    
2.  조회 기간을 지정합니다. 이전·다음 기간 이동과 날짜 입력을 지원하며 기본값은 최근 30일(오늘 포함)입니다.
    
3.  유무상 합산 여부를 선택해 내역을 확인합니다.
    
4.  \[다운로드\]로 현재 탭의 데이터를 내려받을 수 있습니다.
    

**기간별 내역 표 구성**

| **컬럼** | **설명** |
| --- | --- |
| 기간 | 월별 또는 일별 단위로 표시됩니다. |
| 충전액 | 해당 기간의 충전 합계입니다. |
| 소진액(VAT포함) | 해당 기간의 광고 집행 소진액입니다. |
| 환불 | 해당 기간의 환불액입니다. |
| 잔액 | 해당 기간 종료 시점의 잔액입니다. |

**참고.**

조회된 내역이 없으면 "해당 기간에 조회된 내역이 없습니다."가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
