# 브랜드검색 노출제한 된 키워드가 통과되어야만 광고 계약이 가능한가요?

노출 가능한 키워드와 소재가 각 하나 이상인 경우, 노출제한 또는 검토중인 키워드가 있더라도 해당 키워드를 포함하여 계약을 체결할 수 있습니다.

노출제한 또는 검토중인 키워드를 포함하여 계약을 진행할지 선택 가능하며 해당 키워드를 포함하여 계약을 진행한 경우 '노출가능' 상태가 되도록 재검토 요청 등 후속 처리가 필요합니다. 노출가능 키워드로만 계약을 진행하고자 하는 경우, 해당 키워드를 삭제한 후 계약이 가능합니다.
