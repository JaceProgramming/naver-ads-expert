# [AI작성] 검색광고 여러 광고그룹을 한 번에 관리하려면 어떻게 하나요?

캠페인 상세의 광고그룹 목록에서 광고그룹을 선택한 뒤 \[선택한 광고그룹 관리\]를 클릭하면 13가지 일괄 관리 메뉴가 표시됩니다. 메뉴별 창에서 입찰가·매체·예산·타게팅·확장 검색 옵션·소재 노출 방식 등을 일괄 변경합니다.

**\[선택한 광고그룹 관리\] 메뉴 (13종)**

| **메뉴** | **창 / 입력** |
| --- | --- |
| 입찰가 변경 | '입찰가 변경 (N개 광고그룹 선택)' / 70~100,000원(10원 단위) / \[변경사항 미리보기\]·\[변경\] |
| 매체 변경 | 매체 변경 / \[변경사항 미리보기\]·\[변경\] |
| 지역 변경 | 지역 트리 / 시/도·시/군/구·읍/면/동 선택 |
| 요일/시간대 변경 | '요일/시간대 타겟팅' 1차 안내 창 → '광고그룹 타겟팅 일괄 수정' / 안내 '선택한 N개 광고그룹의 요일/시간대 타겟팅이 일괄 변경됩니다. 각 광고그룹의 기존 타겟팅 설정은 사라지고 새롭게 입력한 내용으로 재설정되며, 입찰 가중치는 모두 100%로 조정됩니다.' / \[동의 후 계속하기\] → 입력 폼 |
| 성별 변경 | '성별 타겟팅' 1차 안내 창 → 동일한 일괄 수정 안내 → 남성·여성·알 수 없음 선택 항목 |
| 연령대 변경 | '연령대 타겟팅' 1차 안내 창 → 동일한 일괄 수정 안내 → 13세 이하·14~19세·20·30·40·50·60대 이상·알 수 없음 선택 항목 |
| 이용자 세그먼트 변경 | '이용자 세그먼트 변경' 창 / 관심사·구매의도 세그먼트 최대 20개 선택 (파워링크만) |
| 예산 변경 | '예산 변경' 창 / 50원~1,000,000,000원(10원 단위) / 제한없음 / \[변경사항 미리보기\]·\[변경\] |
| PC/모바일 입찰가중치 변경 | PC 입찰가중치 % / 모바일 입찰가중치 % / 기본 가중치 적용 |
| 확장 검색 옵션 변경 | 확장 검색 by ADVoost / 확장 검색·일치 검색 라디오 / 확장 검색 예산 상한 비율 1~100%(파워링크만) |
| 소재 노출 방식 | 성과 기반 노출 / 동일 비중 노출 라디오(파워링크만) |
| 다른 캠페인으로 복사 | '선택한 광고그룹 복사 하기' 창 / 복사 위치 캠페인 선택 / 광고그룹 내 포함 요소(키워드·소재·확장 소재) 체크 |
| 즐겨찾기 | 즐겨찾기 그룹 선택 또는 새 그룹 만들기 |

**알아두세요.**

브랜드검색/신제품검색 광고그룹의 \[선택한 광고그룹 관리\] 메뉴는 '다른 캠페인으로 복사 / 상품그룹 연결 수정 / 즐겨찾기' 3종으로 다릅니다.

**주의하세요.**

타겟팅 일괄 수정(요일/시간대·성별·연령대 등) 시 1차 안내 창의 \[동의 후 계속하기\]를 클릭해야 입력 폼이 열립니다. 각 광고그룹의 기존 타겟팅 설정은 사라지고 새롭게 입력한 내용으로 재설정되며, 입찰 가중치는 모두 100%로 초기화됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
