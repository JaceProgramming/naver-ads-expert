# [AI작성] 검색광고 캠페인 알림 수신을 설정하려면 어떻게 하나요?

검색광고 캠페인 관련 알림 수신 여부는 \[광고주센터 > 우측 상단 네이버 ID > 광고 계정 관리 > 광고 계정 클릭 > 설정 > 알림 관리 > 검색광고 캠페인 타입\]에서 설정합니다. 설정 대상은 사이트검색, 쇼핑검색, 콘텐츠검색, 브랜드검색, 신제품검색, 플레이스, 지역소상공인입니다.

**알림 항목**

다음 그룹별로 수신 여부를 선택할 수 있습니다.

| **그룹** | **알림 항목** |
| --- | --- |
| 검토 알림 문자/톡톡메시지 | 비즈채널 및 사이트 검토 결과 알림 수신 / 업체정보 검토 결과 알림 수신 |
| 소재 검토 알림 문자/톡톡/이메일 | 검색광고 소재 검토 결과가 '노출가능'일 경우에도 알림 수신 |
| 광고 검토 결과 알림 메시지 | 파워링크, 쇼핑검색, 파워컨텐츠, 브랜드검색, 플레이스 광고 검토 알림 |
| 광고운영 알림 문자/톡톡 메시지 | 캠페인 / 광고그룹 하루예산 부족 알림 / 브랜드 검색 계약 결제 알림 |
| 톡톡메시지 수신 | 톡톡 운영 안내 수신 / 문자 알림 받지 않기 |

**설정 방법**

1.  수신을 원하는 항목을 선택하거나 해제합니다.
    
2.  변경한 항목은 즉시 저장되며 완료 안내가 표시됩니다.
    

**알아두세요.**

소재 검토 결과가 '노출제한'될 경우에는 설정과 상관없이 검토 결과 문자·톡톡·이메일이 발송됩니다. '문자 알림 받지 않기'는 톡톡 운영 안내 수신을 선택한 경우에만 설정할 수 있습니다.

**참고.**

톡톡 알림은 계정 책임자의 네이버 아이디로 발송됩니다. 알림 설정은 계정 정보 변경 권한이 있는 회원만 변경할 수 있으며, 권한이 없으면 항목이 비활성 상태로 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
