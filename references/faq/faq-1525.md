# [AI작성] 파워링크 소재 목록 화면 안내

파워링크 광고그룹 상세 화면의 '소재' 탭에서 광고그룹에 등록된 소재를 조회하고 관리할 수 있습니다. 소재 목록에서는 소재별 노출 상태, 유형, 성과 지표를 확인할 수 있으며, 소재 등록·ON/OFF·복사·재검토 요청 등의 작업을 수행할 수 있습니다.

**소재 목록 컬럼**

| **컬럼** | **설명** |
| --- | --- |
| ON/OFF | 소재의 노출 상태를 켜거나 끕니다. |
| '소재' | 소재의 제목, 설명, URL 일부가 미리보기 형태로 표시됩니다. 클릭하면 실제 광고 형태로 미리볼 수 있습니다. |
| '상태' | '운영가능', '중지: 소재 OFF', '중지: 검토중', '중지: 노출제한', '중지: 비즈채널 노출 제한', '중지: 광고그룹 OFF' 등 소재의 현재 상태가 표시됩니다. |
| '소재 유형' | '단일형 소재', '반응형 소재', '병의원 업종 특화 소재' 등 소재 유형이 표시됩니다. |
| '소재 ID' | 소재의 고유 ID가 표시됩니다. |
| '노출수' / '클릭수' / '클릭률(%)' / '평균 CPC' / '총비용' | 성과 지표가 표시됩니다. |

**주요 기능**

| **기능** | **설명** |
| --- | --- |
| \[새 소재\] | 파워링크 소재 등록 화면이 열립니다. |
| '선택한 소재 관리' | 소재를 선택한 후 일괄 ON/OFF, 삭제, 다른 그룹으로 복사, 재검토 요청 등을 수행할 수 있습니다. |
| '다운로드' | 소재 목록을 파일로 다운로드합니다. |
| '열 맞춤 설정' | 목록에 표시할 컬럼을 선택합니다. |
| '상세 데이터' | 소재의 상세 성과 데이터를 조회합니다. |
| 통합 필터 | '필터를 입력해 주세요' 입력란에 조건을 입력하여 소재를 검색합니다. |

**알아두세요.**

-   소재가 없는 경우 '등록된 소재가 없습니다. '+ 새 소재'를 클릭해 추가하세요' 안내가 표시됩니다.
    
-   소재의 ON/OFF는 편집 권한이 있으면 변경할 수 있습니다. 상위 광고그룹·캠페인이 OFF이거나 검토 중·반려 상태여도 ON/OFF 자체는 변경할 수 있으며, 그 사유는 '상태' 열에 표시됩니다.
    

**참고.**

'선택한 소재 관리'는 소재를 1건 이상 선택해야 활성화됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
