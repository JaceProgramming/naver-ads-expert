# [AI작성] 파워컨텐츠 광고그룹을 만들거나 수정하려면 어떻게 하나요?

파워컨텐츠 광고그룹은 그룹 유형을 정하고 콘텐츠가 연결될 비즈채널과 입찰가·예산을 설정해 만듭니다. 새로 만들 때와 기존 광고그룹을 수정할 때 모두 동일한 입력 폼을 사용합니다.

**만들기 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 파워컨텐츠\]에서 캠페인 이름을 클릭해 상세로 이동합니다.
    
2.  \[새 광고그룹\]을 클릭합니다. 창 좌측의 \[기존 광고그룹 설정 불러오기\]로 기존 설정을 가져올 수 있습니다.
    
3.  '광고 그룹 이름'을 1~30자 이내로 입력합니다.
    
4.  'URL'에서 콘텐츠가 연결될 비즈채널(네이버 블로그·카페)을 선택합니다.
    
5.  '기본 입찰가'를 70원~100,000원(10원 단위)으로 입력합니다.
    
6.  '하루 예산'을 50원~1,000,000,000원(10원 단위)으로 입력하거나 '제한없음'을 선택합니다.
    
7.  필요 시 \[고급옵션\]을 펼쳐 매체·추천/콘텐츠 지면 전용 입찰가·PC/모바일 입찰 가중치를 설정합니다.
    
8.  \[저장\]을 클릭해 광고그룹을 등록합니다.
    

**고급옵션**

| **항목** | **설명** |
| --- | --- |
| 매체 | 광고를 노출할 매체를 선택합니다. |
| 추천 및 콘텐츠 지면 전용 입찰가 | 추천·콘텐츠 지면 전용 입찰가를 설정합니다. 설정하지 않으면 기본 입찰가가 적용됩니다. |
| PC/모바일 입찰가중치 | PC와 모바일 영역에 적용할 입찰가중치를 설정합니다. |

**알아두세요.**

비즈채널이 의료업종이면 의료업종 광고그룹으로 처리되어, 소재를 만들 때 의료심의번호 입력란이 추가로 표시되고 일부 이미지 관련 항목이 제한됩니다.

**참고.**

이름·입찰가·예산이 범위를 벗어나면 각 항목에 안내가 표시됩니다. 동일한 이름이 이미 있으면 저장이 거부되니 다른 이름으로 변경해 주세요.

**주의하세요.**

광고 최종 입찰가는 (기본 입찰가 × 각 타겟팅 입찰 가중치 × 매체 입찰 가중치)로 결정되며, 최대 10만 원(VAT 제외)입니다. 연결할 블로그·카페 비즈채널이 없으면 '비즈채널을 등록해 주세요' 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
