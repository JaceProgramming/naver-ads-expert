# 신제품검색 광고 검토는 언제 완료되는지 궁금해요.

신제품검색광고 신규등록 시, 비즈채널과 소재 검토가 진행됩니다.

비즈채널은 영업일 기준 1~2일 이내, 소재 검토는 영업일 1~3일이 소요됩니다.

**주의하세요.**

-   비즈머니 잔액이 부족한 경우, 검토가 진행되지 않습니다. 비즈머니 잔액은 '결제관리 > 비즈머니관리' 페이지에서 확인이 가능합니다.
    
-   소재 검토를 통과하지 못할 경우, 계약(입찰)이 불가하므로 입찰 일정을 고려하여 소재 등록을 여유있게 진행해 주시기 바랍니다.
