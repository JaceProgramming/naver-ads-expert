# URL 수집진단 기능은 무엇인가요?

URL 수집진단 기능은 광고그룹에 등록된 연결URL의 수집 및 색인 결과를 확인하고, 색인/수집 실패로 미노출된 URL들의 실패 사유를 파악하여 문제를 개선하는데 도움이 됩니다.

제공 기준은 다음과 같습니다.

• 제공 범위 : 사이트검색광고에만 제공

• 제공 화면 : 광고그룹 화면에서 '연결URL 수집 상태' 항목을 통해 확인 가능

◦ 기본 설정으로 제공되는 항목이 아니기 때문에 광고그룹 목록 상단 오른쪽 위 \[기본 설정\]의 사용자 설정을 통해

'연결URL 수집 상태' 항목을 추가하실 수 있습니다.

• 제공 기간 및 업데이트 주기 : 선택한 기간과 관계없이 전일 기준으로 제공되며 하루에 한번 업데이트

![](https://ads-home-phinf.pstatic.net/MjAyNjAzMjVfMTc5/MDAxNzc0NDM0Nzk2OTkz.oz5vRGL8MkqKGrL59ItGxwHZCzYzwI9bMqogwoJsTjog.nVp8FOQBzlVJzbOIG8lUeA1BTpklcIQmnAvJyYT4IYYg.PNG/image.png)

'연결URL 수집 상태' 항목 제공 값의 정의는 다음과 같습니다.

• 정상 : 모든 수집 대상URL이 정상적으로 색인/수집 된 경우 입니다.

• 점검 필요 : 수집 대상URL 중 1개라도 색인/수집이 실패된 경우 입니다.

• **\-** : 수집 결과가 없거나 광고그룹 노출이 불가능한 상태로, 이때는 '연결 URL 수집상태' 항목이 클릭되지 않습니다.

◦ 캠페인/광고그룹이 OFF된 경우

◦ 광고그룹 매체 설정에 '네이버 통합검색-모바일/PC' 및 '네이버 통합검색 광고더보기'가 모두 제한된 경우

◦ 광고그룹 하위 노출 가능한 소재/키워드가 존재하지 않는 경우

◦ 광고그룹의 비즈채널이 노출 가능 상태가 아닌 경우

◦ 계정 잔액이 부족하여 광고가 일시중지된 경우

◦ 일정 기간 과금 이력 및 광고 설정 정보 변경 이력이 없는 경우

◦ 조회시점의 기간이 캠페인 기간의 시작 및 종료 날짜에 포함되지 않는 경우

**참고**

수집 대상URL은 광고그룹 내 등록된 키워드/소재의 연결URL이며, OFF된 키워드는 제외됩니다.

상태값이 '정상'인 경우 연결URL들의 수집/색인이 모두 성공했다는 의미로, 광고 노출을 보장하는 것은 아닙니다.

**수집 대상URL 상세 결과 보기**

위에서 설명드린 광고시스템의 \[광고관리 > 광고그룹 탭\]에서 '연결URL 수집 상태' 항목을 클릭하면 '수집 대상URL 상세 결과'를 확인할 수 있습니다.

색인/수집 결과에 대해 유형별 비중을 도식화하여 제공합니다.

**1\. 유형별 상세 결과**

해당 화면에서는 수집 대상URL의 세부 유형별 상세 내용 및 개선 예시를 제공하고 URL 수를 확인하실 수 있습니다.

색인/수집이 실패된 URL은 광고에 미노출되기 때문에 개선 예시를 참고하여 보완하시길 권유 드립니다.

![](https://ads-home-phinf.pstatic.net/MjAyNTA4MTlfMTg0/MDAxNzU1NTc4NzQxMDUz.5azL0EX9S6sBYUwJBWxkDlRpY4taVSPa_fpGBnUBGKkg.7zsWkyPi1_8a_ngl-oWFjz011YCxcXgDfec6NqnEacog.PNG/URL%EC%A7%84%EB%8B%A82.png?type=w1600)

상세 유형은 총 28가지로 분류되어 제공되며, 유형별 상세 내용 및 개선 예시에 대한 내용은 [URL 수집 상태의 상세 유형 도움말](https://ads.naver.com/help/faq/1009)을 통해 확인하실 수 있습니다. 해당 화면도 동일하게 선택한 기간과 관계없이 전일 기준으로 제공되며 하루에 한번 업데이트 됩니다.

**참고.**

SEO 점검 필요는 색인/수집이 성공된 URL 중 검색엔진 최적화(SEO)가 필요한 상태를 의미합니다.

\* SEO(검색엔진 최적화)는 네이버 광고 로봇의 분석에 용이하며, 검색결과에 더 나은 콘텐츠를 제공하는데 도움이 됩니다. 단, SEO 점검필요 항목 개선이 광고 노출을 보장하지 않습니다.

**2\. 수집 대상URL 목록 보기**

'유형별 상세 결과' 표에서 '전체 보기' 또는 수집 대상URL 수를 클릭하면, 수집 대상URL 목록 화면이 제공됩니다.

해당 화면에서는 URL별로 재수집 요청 및 현황 진단 기능을 활용하실 수 있습니다.

![](https://ads-home-phinf.pstatic.net/MjAyNTA4MTlfMTI5/MDAxNzU1NTc4Nzc4OTUy.8aSERPhQ6K1Gr9aMsX25sLShI_GmrvpD5LcHeH5oTiUg.wDFszmdsSxtriW5ejdvdk5ZWbaEdMOmBE-0vS1aVRKIg.PNG/URL%EC%A7%84%EB%8B%A83.png?type=w1600)

**TIP.** 수집 대상URL이 많을 때는 필터 기능을 이용하여 확인할 수 있습니다.

• 재수집 요청하기

재수집 요청은 변경 또는 보완된 URL의 광고 반영을 위해 활용되며, 재수집이 필요한 URL을 선택하여 요청하실 수 있습니다.

일일 요청 한도는 계정당 10,000건이며 매일 0시에 초기화 됩니다.

**참고.**

재수집 요청 후 통상적으로 1일 이내로 수집이 완료되지만 정확한 시점은 상황에 따라 달라질 수 있습니다.

재수집 요청 후 수집 결과는 '연결URL 수집상태'를 통해 확인하시길 바랍니다.

-   현황 진단하기
    

![](https://ads-home-phinf.pstatic.net/MjAyNTA4MTlfMTU4/MDAxNzU1NTc4Nzk2OTM2.0nPcbsiPyp4tg8CWPDIFLqXCZ7RVvfgfozkCnQozGxkg.LXTHcnMuVZ8NEa61ndUXUWaRRruk-wNjUKCZOXQiM6Ig.PNG/URL%EC%A7%84%EB%8B%A84.png?type=w1600)

현황 진단은 진단 요청 시점을 기준으로 최신의 색인/수집 결과를 확인할 수 있습니다.

**참고.** 전일 기준인 '수집 대상URL 상세 결과'와는 시점 차이가 있어 구분해주시기 바랍니다.

제공되는 항목은 총 4가지로 '색인 성공여부', '수집 성공여부', '수집 허용여부', 'HTTP 응답결과'를 제공합니다.

• 수집 성공여부 : 광고용 검색로봇이 수집 대상URL에 방문하여 정상적으로 페이지 내용을 가져왔는지를 뜻하는 '수집'의 성공 여부입니다. 일반적으로 수집이 성공하지 않으면 색인이 진행되지 않아 색인 상태 또한 실패로 표시됩니다.

• 색인 성공여부 : 수집 성공 후 검색광고에 노출될 준비 상태를 뜻하는 '색인'의 성공 여부입니다. 단, 색인 성공 상태이더라도 광고 노출을 보장하지는 않습니다.

• 수집 허용여부 : 수집 대상URL의 robots.txt 규칙에서 광고용 검색로봇을 차단했는지의 여부입니다. 수집 '차단됨' 상태라면 [Ads-Naver 도움말](https://ads.naver.com/help/faq/994)을 참고해 수집을 허용하시길 바랍니다.

• HTTP 응답결과 : 수집 대상URL에 접근했을 때 웹서버가 응답한 결과 상태로 해당 URL이 정상적으로 로드되는지를 파악할 수 있습니다. HTTP 응답 '오류'일 경우 괄호 안에 표시된 응답코드 숫자의 의미를 [HTTP 규약 도움말](https://searchadvisor.naver.com/guide/seo-basic-http)을 통해 확인해 수집 실패 유형 개선에 참고하시길 바랍니다.

현황 진단도 계정당 10,000건의 한도가 존재하며, 매일 0시에 초기화 됩니다.

**Tip.** 최근 수집일이 2개월이 지난 URL이라면 재수집을 권장드립니다.

**주의하세요.**

수집 대상URL은 수집 목적으로 정규화되어 입력하신 연결URL과는 다를 수 있습니다.

재수집 요청과 현황 진단은 계정당 일 허용 한도 초과시 당일에는 사용이 불가하오니 유의하시기 바랍니다.

URL 수집진단 기능에서 제공되는 결과는 내부 기준에 기반한 분석 결과로 정확한 분류를 보장하지 않습니다. 이로 인해 발생할 수 있는 해석상의 오해나 불이익에 대해서는 당사는 책임을 지지 않습니다.
