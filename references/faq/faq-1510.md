# [AI작성] 쇼핑검색 소재를 등록하려면 어떻게 하나요?

쇼핑검색 광고그룹에서 상품을 검색하여 소재로 등록할 수 있습니다. 쇼핑검색 소재는 텍스트를 직접 입력하는 방식이 아니라, 네이버 쇼핑에 등록된 상품을 검색한 뒤 선택하여 등록하는 방식입니다.

**소재 등록 절차**

1.  \[광고주센터 > 검색광고 > 광고 관리 > 쇼핑검색\]에서 캠페인을 선택한 뒤, 광고그룹 상세 화면으로 이동합니다.
    
2.  소재 탭에서 \[새 소재\]를 클릭합니다.
    
3.  상품 검색 영역에서 검색어를 입력하거나 카테고리를 선택한 뒤 검색합니다.
    
4.  검색 결과에서 등록할 상품을 선택합니다. 선택한 상품은 장바구니 영역에 추가됩니다.
    
5.  장바구니에 1개 이상의 상품이 담기면 \[저장\]를 클릭합니다.
    

**입력 영역**

| **영역** | **설명** |
| --- | --- |
| 쇼핑몰 채널 정보 | 현재 광고그룹에 연결된 쇼핑몰 채널과 카테고리 정보가 표시됩니다. |
| 상품 검색 | 검색어, 카테고리, 정렬 조건을 설정하여 상품을 검색합니다. |
| 검색 결과 | 이미지, 상품명, 제조사, 최저가, 판매처 수, 노출 가능 여부가 표시됩니다. |
| 선택한 상품 | 선택한 상품 목록이 표시되며, 개별 삭제가 가능합니다. |

**참고.**

검색 결과가 없을 경우 검색어를 변경하거나 다른 카테고리를 선택해 주세요. 장바구니에 상품이 없으면 저장할 수 없습니다.

**주의하세요.**

이미 등록된 상품을 중복으로 등록하면 오류가 발생할 수 있습니다. 등록 전 기존 소재 목록을 확인해 주세요.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
