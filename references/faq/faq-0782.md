# 로그인 오류 셀프 체크리스트

로그인이 안될 경우, 노출 메시지에 따라 로그인 문제를 해결할 수 있습니다.

**로그인 오류 1. 아이디와 비밀번호를 정확하게 입력하였나요?**

아래 이미지처럼 메시지가 노출되었다면 로그인 정보가 맞지 않는 것으로 '아이디' 또는 '비밀번호' 확인이 필요합니다.

![](https://ads-home-phinf.pstatic.net/MjAyNTEyMDlfOCAg/MDAxNzY1MjYxNjQ3OTg4.3PQhfPS9TsdEjm7CWW7m82BIIiUrstGKz91U1XEdkHYg.QhiryXLoyrDEmFEvQxHqNBYLRoVW-Y9nTu6Exf1k6R4g.PNG/image.png)

**Tip.** 아이디 또는 비밀번호가 기억나지 않는다면 아래 도움말을 참고하여 정보를 찾아주세요.

[아이디 또는 비밀번호를 분실한 경우 도움말 보기](https://ads.naver.com/help/faq/781) 

**로그인 오류 2. 인증이 만료되었다는 알럿이 노출되거나 자동으로 로그아웃 되었나요?**

아래 이미지 또는 증상이 확인된다면 몇가지 사항을 점검해야 합니다.

**주요 증상**

· 로그인 후 광고시스템에 접속하면 아래 메시지가 표시되고 다시 로그인 창으로 이동합니다.

![](https://saedu.naver.com/upfile/1533713563867.png)

· 로그인 직후 다시 로그인 화면으로 이동합니다.

**브라우저를 점검해 주세요**

-   **최신 버전의 브라우저를 사용중이신가요?**
    

광고시스템은 최신 버전의 브라우저에서 원활하게 이용이 가능합니다

이용 중인 웹 브라우저 버전 확인은 아래 방법을 통해 확인 가능합니다.

인터넷 창을 열어 상단 메뉴 중 ‘도움말 > 도구 > Internet Explorer 정보’를 클릭합니다.

버전이 낮다면 최신 브라우저를 다운로드 받아보세요.

[최신 버전 다운로드](https://support.microsoft.com/ko-kr/help/17621/internet-explorer-downloads)

-   **인터넷 사용 기록을 삭제해 주세요**
    

일반적인 웹 브라우저는 이전에 방문했던 웹사이트의 정보를 PC에 저장합니다.

이로 인해 과거 정보가 남아있어 로그인 시 오류가 발생할 수 있습니다.

인터넷 사용 기록을 삭제하고 로그인 문제를 해결해 보세요.

**크롬**

\- 우측 상단 ‘점 세개’ 모양의 메뉴를 클릭한 후 \[설정\]을 클릭합니다.

최하단에 \[고급\] 클릭하여, 개인 정보 및 보안 항목에 \[인터넷 사용 기록 삭제\] 메뉴를 클릭합니다.

\- 하단 ‘고급’을 클릭하여, 개인정보 및 보안 항목에 ‘인터넷 사용 기록 삭제’를 클릭합니다.

 ![](https://saedu.naver.com/upfile/1533714903291.png)

\- '쿠키 및 기타 사이트 데이터', '캐시 된 이미지 또는 파일'을 선택한 후 \[인터넷 사용 기록 삭제\] 버튼을 클릭합니다.

 ![](https://saedu.naver.com/upfile/1533714049855.png)

\- 모든 웹 브라우저를 종료한 후 다시 네이버 광고센터에 접속하여 로그인합니다.

-   **보안프로그램이나 툴바 등의 프로그램이 작동되고 있나요?**
    

보안 프로그램이나 툴바 등의 프로그램이 로그인 기능을 차단하거나 인증에 관련된 일부 정보를 차단하는 경우가 있습니다.

보안 프로그램의 설정을 변경하거나 툴바 사용을 종료한 뒤 다시 시도해 보세요.

**위 사항을 모두 점검하였으나 로그인이 안되시나요?**

크롬을 주로 사용하는 경우에는 네이버 웨일, 엣지를 이용해서 네이버 광고센터를 이용해 보세요.

[크롬 브라우저 다운로드 바로가기](https://www.google.co.kr/chrome/) 

[네이버 웨일 브라우저 다운로드 바로가기](https://whale.naver.com/)

[마이크로 엣지 브라우저 다운로드 바로가기](https://microsoft-edge.softonic.kr/)

위의 모든 항목을 점검한 후에도 로그인 실패 시 네이버 광고 고객센터로 문의하시기 바랍니다.
