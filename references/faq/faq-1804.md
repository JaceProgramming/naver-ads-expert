# [AI작성] 관리 계정에 광고 계정을 연동하려면 어떻게 하나요?

권한 관리의 '광고 계정 연동' 탭에서 관리 계정에 연동된 광고 계정을 조회하고, 새로운 광고 계정의 연동을 요청할 수 있습니다.

**목록 구성**

탭은 '연동 중인'·'연동 요청 중인' 광고 계정으로 구분되며, 상단에 '관리 계정 하위에 연동 중인 모든 광고 계정 N' 카운터가 표시됩니다. 목록은 다음 컬럼으로 구성됩니다.

| **컬럼** | **설명** |
| --- | --- |
| 광고 계정(ID) | 연동된 광고 계정의 번호와 이름입니다. |
| 연동 승인자 ID | 연동을 승인한 회원의 ID입니다. |
| 연동 일자 | 연동이 이루어진 일자입니다. |
| 광고 계정 회원 관리 여부 | '관리 가능' 또는 '관리 불가'로 표시됩니다. |

**연동 요청 방법**

1.  '광고 계정 연동' 탭에서 \[광고 계정 연동 요청\]을 선택합니다.
    
2.  안내에 따라 연동을 요청하면 '연동 요청 중인' 목록에 표시됩니다.
    

**알아두세요.**

연동 추가 등 관리 액션은 권한이 없는 회원에게는 표시되지 않거나 비활성화됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
