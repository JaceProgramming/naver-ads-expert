# [AI작성] 광고 계정의 비즈머니를 환불받으려면 어떻게 하나요?

광고 계정에 충전된 유상(현금·카드) 비즈머니는 환불받으실 수 있습니다. 환불 권한이 있는 광고주님은 \[결제 > 비즈머니 관리\]의 '유상(현금/카드) 잔액' 영역에서 \[환불하기\]를 눌러 신청하실 수 있으며, 무상 잔액과 비즈쿠폰은 환불 대상이 아닙니다.

**주의하세요.**

모든 캠페인이 OFF인 상태에서만 환불이 가능합니다. 캠페인이 켜져 있으면 '모든 캠페인이 OFF인 상태에서만 환불 가능합니다.' 안내가 표시되며, 모든 캠페인을 끈 뒤 다시 시도해 주세요.

**환불 신청 절차**

1.  \[결제 > 비즈머니 관리\]로 이동한 뒤 '유상(현금/카드) 잔액'의 \[환불하기\]를 클릭합니다.
    
2.  환불 유형으로 '전액환불' 또는 '일부환불'을 선택하고, 환불 사유를 선택합니다. 환불 사유는 '탈퇴 신청 / 광고주 사정 / 오결제·오입금 / 기타' 중에서 고를 수 있으며, 사유를 선택해야 \[확인\]이 활성화됩니다.
    
3.  유형에 따라 환불 상세 화면이 열립니다. 안내된 금액과 내용을 확인한 뒤 신청합니다.
    

**알아두세요.**

상품에 따라 전액환불만 가능한 경우가 있어, 이때는 일부환불을 선택할 수 없습니다.

**전액 환불**

전액환불을 선택하면 '환불 예상 금액 상세' 화면에 전체 환불 예상 금액(현금·카드 구분), 환불 계좌 정보, 최근 6개월 이내 카드 결제 내역이 표시됩니다.

| **컬럼** | **설명** |
| --- | --- |
| 카드사 | 카드 결제에 사용한 카드사 |
| 결제일 | 해당 카드 결제가 이루어진 날짜 |
| 환불 가능 금액(결제금액) | 해당 결제 건의 환불 가능 금액 |

주의사항을 확인하고 '위 내용을 모두 확인했으며, 환불 신청에 동의합니다.'에 동의하면 \[환불하기\]가 활성화됩니다. 단, 다음의 경우에는 비활성화됩니다.

-   환불 가능한 잔액이 없는 경우
    
-   환불 계좌가 등록되어 있지 않거나 검토 중인 경우 (이 경우 환불 계좌 등록·승인이 필요합니다)
    
-   캠페인이 켜져 있는 경우
    

**일부 환불**

일부환불을 선택하면 환불받을 금액을 직접 입력하는 화면이 열립니다. 현금 환불 금액과 카드 결제 건별 환불 금액을 각각 입력할 수 있으며, 입력한 금액의 합계(환불 신청 합계)는 전체 환불 가능 금액·현금 환불 가능 금액과 함께 실시간으로 계산되어 표시됩니다.

-   각 카드 환불 금액은 해당 건의 결제금액을 초과할 수 없습니다.
    
-   환불 신청 합계가 0원이거나 전체 환불 가능 금액을 초과하면 신청할 수 없습니다.
    
-   상품에 따라 환불 가능 금액과 정확히 일치하는 금액만 신청할 수 있는 경우가 있습니다.
    

입력을 마치고 \[환불하기\]를 누르면 '환불을 신청하시겠습니까?' 확인을 거쳐 신청이 진행됩니다.

**차액 결제 안내**

카드 환불 시 차액 결제가 필요한 건이 있으면 '차액 결제 안내'가 표시됩니다. 차액 결제는 과거 결제 내역을 전액 취소한 뒤 다시 결제하는 방식이며, 환불 요청 금액·차액 결제 금액·취소 금액이 함께 안내됩니다.

-   \[확인\]을 누르면 차액 결제가 진행됩니다.
    
-   \[취소\]를 누르면 차액 결제 건을 제외하고 나머지 환불만 정상 진행됩니다.
    

**환불 결과 안내**

환불 신청이 완료되면 '비즈머니 환불 결과 안내'에서 처리 내역을 확인하실 수 있습니다. 내역 표는 '환불 신청 금액 / 차액 결제 금액 / 환불·취소 금액 / 유형(현금·카드) / 결과'의 다섯 항목으로 구성됩니다. 환불 금액은 등록하신 환불 계좌로 입금되며, 신청 내역은 \[결제 > 비즈머니 관리 > 환불 내역\] 탭에서 다시 확인하실 수 있습니다.

**참고.**

환불 계좌는 \[결제 > 결제설정\]의 환불 계좌 영역에서 \[등록하기\]로 직접 입력해 등록합니다. 등록 후 검토 중·거절·등록 완료 상태로 표시되며, 환불이 진행 중인 동안에는 환불 계좌를 삭제할 수 없습니다.

**주의하세요.**

이전 환불 요청이 처리 중이면 '이전 환불 요청이 처리 중입니다.' 안내가 표시되며, 처리 완료 후 다시 신청하실 수 있습니다. 환불 가능한 잔액이 없으면 '환불 가능한 잔액이 없습니다.' 안내가 표시됩니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
