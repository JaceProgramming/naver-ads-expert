# [AI작성] 광고 계정에 관리 계정을 연동하려면 어떻게 하나요?

광고 계정과 연동된 관리 계정은 \[광고주센터 > 우측 상단 네이버 ID > 광고 계정 관리 > 광고 계정 클릭 > 설정 > 권한 관리 > 관리 계정 연동\]에서 조회하고 관리할 수 있습니다. 하위 탭으로 '연동 중인 관리 계정'과 '연동 요청 중인 관리 계정'이 있습니다.

**연동 목록 구성**

'연동 중인 관리 계정' 목록은 다음 5개 항목으로 구성됩니다.

| **항목** | **설명** |
| --- | --- |
| 관리 계정(ID) | 연동된 관리 계정 |
| 연동 승인자 ID | 연동을 승인한 회원 |
| 연동 일자 | 연동된 날짜 |
| 광고 계정 회원 관리 여부 | '관리 가능' 또는 '관리 불가' |
| 관리 | \[연동 해제\] |

**광고 계정 회원 관리 여부**

'광고 계정 회원 관리 여부'는 연동된 관리 계정이 본 광고 계정의 회원을 관리할 수 있는지를 결정합니다.

| **설정** | **의미** |
| --- | --- |
| 관리 가능 | 관리 계정의 운영 관리 권한 회원이 본 광고 계정의 회원 초대·권한 수정·해제를 할 수 있습니다. |
| 관리 불가 | 관리 계정의 운영 관리 권한 회원도 본 광고 계정의 회원을 관리할 수 없습니다. |

**회원 관리 권한 수정**

1.  '광고 계정 회원 관리 여부' 항목의 \[수정\]을 클릭합니다.
    
2.  "광고 계정 회원 관리 여부를 선택해주세요." 안내에서 '관리 가능' 또는 '관리 불가'를 선택합니다.
    
3.  동의 안내가 표시되는 경우 "위 내용을 숙지하였으며 관리 계정 연동 정책에 동의합니다."에 동의한 뒤 저장합니다.
    

**연동 해제**

'관리' 항목의 \[연동 해제\]를 클릭하고 확인하면 연동이 해제됩니다.

**알아두세요.**

회원 관리 권한 수정·연동 해제는 계정 책임자 권한이 필요합니다. 권한이 없으면 해당 버튼이 비활성화되며, 관리 계정 책임자에게 요청해 주시기 바랍니다.

**주의하세요.**

관리 계정 연동을 승인하면 해당 관리 계정의 모든 회원이 본 광고 계정에 접근할 수 있으며, 관리 계정 회원으로 접근하는 경우 광고 운영 알림은 발송되지 않습니다. 연동 범위를 확인한 뒤 진행해 주시기 바랍니다.

\*AI가 작성한 도움말로, 기능 중심으로 설명되어 있습니다.
